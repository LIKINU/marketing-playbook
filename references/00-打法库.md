> **這是什麼**：打法引擎：**104 條打法**，每條含「為什麼用它／具體動作到每一步／驗收指標／可抄案例」
> **什麼時候讀**：**動筆前出骨架時**（第 -1 步導航表：『動筆前出骨架』）
> **讀完你能**：按客戶狀況查到 3–7 條可執行打法，每條都能直接抄成動作
> **目錄**：§0 打法總表（一頁速查） ｜ §1 認知類打法（讓客戶記住你） ｜ §2 內容類打法（自產內容獲客） ｜ §3 投放類打法（花錢買流量） ｜ §4 私域類打法（讓客戶回頭） ｜ §5 渠道類打法（貨怎麼鋪出去） ｜ §6 事件與話題類打法（借勢與造勢） ｜ §7 信任類打法（讓人敢買） ｜ §8 定價與轉化類打法（把流量變成錢） ｜ §9 診斷類打法（先搞清楚卡在哪） ｜ §10 特殊主體專用打法（小企業／新品牌／第二曲線／AI產品／B2B）
> **規模**：8.7 萬字
> 定位：**生成器的引擎**。接到客戶狀況 → 在本檔查打法 → 組合成方案。
> 用法：先看 §0 總表定位，再跳對應章節讀具體打法。
> 建立 2026-09-14 ｜ 可信度：【已核實】【行業認知】【未核實】【判斷】

**怎麼用這本檔（給 AI 的調取規則）**
1. 先把客戶狀況拆成四件事：**賣什麼**（品類/客單/毛利）、**給誰**（人群/場景/頻次）、**現在卡在哪**（曝光/信任/轉化/復購/渠道任一環節）、**有多少錢和多少人**。
2. 拿這四件事去 §0 總表對「適用狀況」欄做匹配，挑出 3–7 條候選打法。
3. 用「預算量級 × 見效週期 × 誰來做」三欄做減法，砍掉客戶做不了、等不起、做不動的。
4. 排序原則：**診斷類常駐在第一位**（§9），先確認卡點再選打法；**信任類與轉化類必須配套出現**，只做曝光不做承接是常見死法。
5. 每條打法都要回報「主要風險」，讓客戶知道代價。

**可信度標記規則**
- 【已核實】：有公開可查來源、數據可對得上。
- 【行業認知】：行業內普遍這麼認為，但無單一權威來源。
- 【未核實】：聽過但找不到可靠出處，僅供假設，必須先驗證。
- 【判斷】：本檔給出的操作建議與經驗值，不是事實，是決策建議。
- 所有預算與週期數字，除標【已核實】外，一律視為【判斷】的量級參考，實際必須按客戶所在城市、品類、平台競價波動重新報價。

## §1 認知類打法（讓客戶記住你）

> 本節只解決一件事：**消費者能不能記住你、能不能用一句話把你轉述給別人。** 認知沒解決就投流量，等於往漏桶裡倒水。所有打法在報價前都必須先過 §1.12 品牌三問自檢。

### 1.1 超級符號（視覺記憶點）

**一句話定義**：把品牌壓縮成一個不用解釋、看一眼就記住的圖形或角色，並在所有觸點反覆重複它。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 客戶說不清自己是誰；投了廣告但沒人記得；品牌名抽象（X 科技／X 優選）；競品視覺全一個樣 |
| 不適用 | 品牌已有清晰形象；沒有重複曝光的預算（符號靠重複才生效） |
| 預算量級 | 一次性 0.5–5 萬（設計）；含 IP 三視圖＋延展 5–20 萬 |
| 見效週期 | 3–6 個月 |
| 誰來做 | 外部設計／符號顧問；老闆必須親自拍板 |
| 難度 | ★★☆ |

**怎麼做**：
1. 找出產品最核心的一個動作或結果（快／辣／洗得乾淨／送得快），寫成一句核心詞。產出：核心詞 1 句。
2. 把核心詞轉成 3–5 個可視化方向（動物／器物／動作／字體變形／幾何）。產出：草圖方向清單。
3. 用三條標準篩：不解釋就懂、與品類有關聯、競品沒在用。產出：1–2 個候選。
4. 做「一秒測試」：給 10 個外行看 1 秒，問「這是幹什麼的」，答對率低於 5 成淘汰。產出：測試記錄。
5. 定稿並出規範：主符號、輔助圖形、最小尺寸、禁用示例。產出：符號使用規範 1 份。
6. 全觸點鋪開：包裝、門頭、快遞箱、直播背景、詳情頁首屏、工服。產出：觸點改造清單。
7. 設固定露出位：短視頻片尾、直播貼片、包裝固定角落。產出：露出 SOP。

**關鍵技巧**：符號要綁「購買理由」而非好看；能動起來的（可做表情包、貼紙、片尾）勝過純靜態；先在單一渠道打透再鋪全渠道。
**常見錯誤**：設計師按審美選、不看品類關聯；細節太多縮小就糊；一年換一版，永遠從零開始。
**怎麼驗收**：無提示回憶測試——抽 30 個目標消費者看符號圖，能正確說出品牌名的比例，3 個月由 <10% 升到 30% 以上算有效。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城「雪王」，2018 年起）；`cases/02-食品饮料与酒.md`（旺旺旺仔，長期符號資產）。

### 1.2 品牌諺語（口號寫作）

**一句話定義**：寫一句消費者願意主動替你說出去的話，而不是一句你希望他記住的話。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有產品、無一句可傳播的話；廣告語全是「引領／賦能／匠心」；銷售靠人解釋半天 |
| 不適用 | 產品本身沒有一個明確購買理由；to B 超長決策鏈（此時口號作用有限） |
| 預算量級 | 一次性 1–8 萬（含創作＋測試） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 文案／策略；老闆定稿 |
| 難度 | ★★☆ |

**怎麼做**：
1. 收齊三樣素材：消費者買你的原話（客服記錄、評論區）、競品口號、你的最大差異。產出：素材表。
2. 從買家原話裡找「已存在的句子」，諺語多半是發現而不是發明。產出：10 句候選原話。
3. 按四個模板各寫 5 句：**說結果**（怕上火喝王老吉）、**說場景**（送禮就送…）、**說身分**（我是…我選…）、**說對立**（不含…的…）。產出：20 句。
4. 用三條刪：同行也能說（刪）、說了等於沒說（刪）、讀出來拗口（刪）。產出：3–5 句。
5. 做轉述測試：讓 20 個非用戶聽一次，隔 24 小時後問「那句話是什麼／你會跟朋友怎麼說」。產出：轉述準確率。
6. 定稿後全線統一：包裝、門頭、電商首圖、直播背景、員工話術。產出：口號使用規範。

**關鍵技巧**：一句話只能有一個意思；口語優先於書面語（能被說出來才叫諺語）；字數 6–12 字最穩；帶節奏／押韻的更好記。
**常見錯誤**：老闆自己寫一句自我感動的話；堆砌四個字的漂亮詞；口號與產品體驗不符，喊越大越假。
**怎麼驗收**：24 小時轉述準確率 >30%，且能寫出大致意思；同時追蹤客服「客戶主動提及口號」的次數。
**案例**：`cases/02-食品饮料与酒.md`（王老吉「怕上火」，2003 年起）；`cases/04-服饰运动户外.md`（安踏、lululemon 中文語境改寫）。

### 1.3 品牌命名（取名與改名）

**一句話定義**：選一個好記、好讀、能註冊、能延伸的名字，這是品牌最貴的一次性決策。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 新品牌註冊；商標被駁回或被搶註；名字本地話讀出來有歧義；名字完全看不出品類 |
| 不適用 | 品牌已有一定資產、改名成本大於收益（此情況只做「加註釋」而非改名） |
| 預算量級 | 一次性 0.3–10 萬（含商標檢索與註冊） |
| 見效週期 | 1–2 個月（含商標風險排查） |
| 誰來做 | 品牌方主導；商標事務所配合檢索 |
| 難度 | ★★☆ |

**怎麼做**：
1. 先做商標檢索（同類＋近似類），把已被佔用的方向整體劃掉。產出：可註冊詞庫。
2. 明確命名策略：**描述型**（看出品類）、**聯想型**（有畫面）、**造詞型**（無含義、好註冊）、**人名型**（創辦人背書）。產出：策略選擇 1 項。
3. 每種策略出 10 個候選，共 30–40 個。產出：候選清單。
4. 用五條硬標準篩：能註冊、2–4 字、不含生僻字、普通話與主要方言都讀得順、不會被誤解。產出：10 個。
5. 做「電話測試」：電話裡念一次，對方能不能一次寫對。寫錯的淘汰。產出：通過名單 3 個。
6. 同步想域名與社群帳號名是否可用、能否延伸（未來出新品不尷尬）。產出：終選 1 個＋備胎 2 個。
7. 完成註冊類別佈局（核心類＋防禦類）再對外公佈。產出：註冊清單。

**關鍵技巧**：名字自帶場景或結果，等於免費廣告；兩字名稀缺，三字是主流，四字上限；避免用「王／皇／極／尊」等溢價詞，顯假且難註冊。
**常見錯誤**：先做包裝再做商標檢索；名字要解釋才懂；用生僻字顯得高級（用戶打不出來就搜不到你）。
**怎麼驗收**：電話測試一次寫對率 >70%；商標初審通過；半年後自然搜索（品牌詞）有穩定量。
**案例**：`cases/02-食品饮料与酒.md`（元氣森林改名前的商標糾紛）；`cases/05-3C数码与家电.md`（小米生態鏈命名體系）。

### 1.4 包裝即媒體（貨架與快遞箱）

**一句話定義**：把包裝當成免費的廣告位，讓它在貨架、快遞站、用戶家裡持續替你說話。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 產品在貨架／快遞箱上無人注意；用戶收到貨直接扔包裝；包裝只是為了好看 |
| 不適用 | 純 to B 大宗原料；產品形態無法承載資訊（如裸裝生鮮） |
| 預算量級 | 一次性 1–20 萬（設計＋開版）；開版費按印刷方式差異極大 |
| 見效週期 | 2–6 個月 |
| 誰來做 | 包裝設計＋印刷廠；行銷方給「要傳達的資訊」 |
| 難度 | ★★☆ |

**怎麼做**：
1. 列清包裝要承擔的 4 件事：品類識別、核心賣點、信任憑證、引流入口（QR／企微）。產出：資訊優先級表。
2. 定「3 米／1 米／30 公分」三級可讀性：3 米看得到品類色塊，1 米看到品牌與口味，30 公分看到成分與信任狀。產出：包裝版面草圖。
3. 印前做盲測：把新舊包裝放一起，讓 20 人各看 3 秒，問「哪個更想買、為什麼」。產出：盲測結果。
4. 快遞箱／外箱單獨設計：加一句社群引流語＋一個 QR，不寫廢話。產出：外箱設計稿。
5. 開版前確認印刷工藝與成本（專色、UV、擊凸會顯著加價）。產出：報價對比。
6. 上市後做「開箱 UGC 監控」：看用戶自發拍開箱的比例。產出：開箱內容月報。

**關鍵技巧**：貨架上是比色塊不是比插畫——同品類裡「最不像」的那個最容易被拿走；包裝上只放一個購買理由；把 QR 的位置做成用戶不得不看的動作位（如撕口處）。
**常見錯誤**：設計圖很美，縮小到實物就廢；資訊堆滿沒有主次；包裝和詳情頁各說一套，用戶困惑。
**怎麼驗收**：貨架拿取率（門店可抽樣觀察）、開箱 UGC 條數、QR 掃碼率（行業經驗值 3–10%，【判斷】）。
**案例**：`cases/02-食品饮料与酒.md`（農夫山泉、元氣森林氣泡水包裝資訊結構）；`cases/03-美妆个护.md`（觀夏、聞獻的內容型包裝）。

### 1.5 門頭改造（招牌即廣告）

**一句話定義**：把最貴的那塊廣告位（門頭）從「裝修的一部分」改成「一天 24 小時的銷售員」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 街邊／商場店路過人流不進；門頭只有品牌名沒有品類；晚上看不清；隔壁店更抓眼 |
| 不適用 | 純線上生意；門頭位置被物業限制無法改動 |
| 預算量級 | 一次性 0.5–8 萬／店 |
| 見效週期 | 1 個月內 |
| 誰來做 | 招牌製作商＋品牌方；連鎖需先做 1 家樣板店 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 先記數：高峰與低峰各站店外 30 分鐘，數「經過人數／看門頭人數／進店人數」。產出：進店率基線。
2. 定門頭要回答的三個問題：賣什麼、多少錢起、為什麼現在進（優惠／新品）。產出：門頭文案清單。
3. 做「夜色測試」：拍一張晚上 8 點的實景照，看 10 公尺外能否讀清品牌與品類。產出：測試照。
4. 強化三個元素：大色塊（品類色）、大字（品類詞＋品牌名）、燈光（亮燈時間與門頭同時）。產出：設計稿。
5. 加一個「可讀的價格／爆品圖片」，讓路人不用問就知道消費門檻。產出：側招／燈箱。
6. 施工後同法再數一次，對比進店率。產出：改造前後數據表。

**關鍵技巧**：門頭上「品類詞」比「品牌名」更能帶來第一次進店；一句話最強是「結果＋價格」；同商圈做到「最亮／最大字」通常贏一半。
**常見錯誤**：只換門頭不改產品與服務，來一次不回頭；門頭放英文與抽象 logo，路人看不懂；白天好看、晚上黑。
**怎麼驗收**：進店率提升幅度（樣本 ≥3 天，各時段）；改造後 1 個月內自然到店佔比。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞、蜜雪冰城的門頭資訊結構）。

### 1.6 貨架陳列（終端動銷）

**一句話定義**：在貨架這個「最後三秒的戰場」上，用位置與陳列方式換取被拿取的概率。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 商超／便利店／藥店有鋪貨但動銷差；陳列費花了沒效果；新品進店後被埋在底層 |
| 不適用 | 純電商品牌；渠道拒絕讓價或無陳列資源 |
| 預算量級 | 一次性 0.3–3 萬／渠道（陳列費＋物料） |
| 見效週期 | 1–2 個月 |
| 誰來做 | 業務／督導團隊；需門店配合 |
| 難度 | ★★☆ |

**怎麼做**：
1. 走店 20 家，記錄你的位置（層高、左右鄰居、朝向）與動銷。產出：位置—動銷對照表。
2. 鎖定「黃金層」（視線 1.2–1.6 公尺、主通道右手邊、收銀動線末端）。產出：要爭取的位置清單。
3. 設計陳列物料：跳跳卡、貨架貼、爆炸貼、堆頭，每件只承載一個資訊。產出：物料清單與效果圖。
4. 談陳列方式：爭取「端架／堆頭／收銀台小展架」，這三處動銷效率遠高於普通貨架。產出：陳列協議。
5. 做「陳列前後對比照」制度：業務每次拜訪拍 6 張標準角度照片上傳。產出：陳列稽核表。
6. 建立「動銷監控」：按週看單店單品銷量，做不動銷的門店淘汰或換位。產出：門店分級表。

**關鍵技巧**：貨架上的第一競爭對手是「左右鄰居」，不是品類領導者；同色系陳列會被淹沒，要製造對比；陳列資源要和導購試吃／試用配套才有效。
**常見錯誤**：花了陳列費但沒有稽核，物料被扔倉庫；同一位置放太多 SKU，每個都不顯眼；只做堆頭不做補貨，三天後就空了。
**怎麼驗收**：單店單品週銷量對比、陳列執行率（拜訪抽查合格率 ≥80%）、堆頭 ROl。
**案例**：`cases/02-食品饮料与酒.md`（農夫山泉終端陳列體系）；`cases/03-美妆个护.md`（藥妝店貨架爭奪）。

### 1.7 品牌色與視覺錘

**一句話定義**：用一個專屬顏色或重複出現的視覺元素，讓消費者在 0.5 秒內把你從貨架／資訊流裡認出來。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 品類同質化嚴重、辨識度低；資訊流素材換一套就不像同一家；品牌看起來「沒有品牌感」 |
| 不適用 | 品類已有強勢顏色壟斷（如快遞用橙）且你無法差異化 |
| 預算量級 | 一次性 0.5–5 萬 |
| 見效週期 | 3–6 個月 |
| 誰來做 | 品牌設計；行銷方管一致性執行 |
| 難度 | ★★☆ |

**怎麼做**：
1. 掃競品主色，列出前三名已被佔用的顏色。產出：顏色佔位圖。
2. 選色標準：與品類聯想不衝突、在手機屏幕上不刺眼、印刷不易偏色。產出：2–3 個候選色（含專色號）。
3. 定「視覺錘」：一個反覆出現的形狀／構圖／人物姿勢／畫面處理方式。產出：視覺錘定義。
4. 做縮略圖測試：把 20 張競品圖與你的圖縮到 100px，測能否認出你。產出：辨識率。
5. 寫死「一致性清單」：主色佔比、字體、版式、禁用項，交給所有外包團隊。產出：VI 執行清單。
6. 每月抽查素材，一致性不合格的退回重做。產出：一致性稽核記錄。

**關鍵技巧**：顏色要「搶」而不是「美」——飽和度稍高反而記得牢；一個品牌只用一個主色最有效；視覺錘要能適配不同媒介（豎屏、方圖、包裝）。
**常見錯誤**：主色用黑色白色（等於沒有顏色）；同一帳號每條視頻風格都不一樣；顏色與品類衝突（食品用工業灰）。
**怎麼驗收**：縮略圖辨識率（測試組 vs 對照組）、資訊流點擊率變化、品牌搜索量。
**案例**：`cases/03-美妆个护.md`（花西子東方美學色系）；`cases/05-3C数码与家电.md`（大疆、Anker 的視覺一致性）。

### 1.8 聲音符號（jingle／聽覺錘）

**一句話定義**：用一段 2–5 秒的聲音，在用戶不看屏幕時也能觸發品牌記憶。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有大量視頻、直播、門店播報但無聲音記憶點；品類在音頻場景被消費（開車、做家務） |
| 不適用 | 內容以圖文為主、無視頻矩陣；預算撐不起持續投放（聲音需重複才有效） |
| 預算量級 | 一次性 1–15 萬（原創＋製作） |
| 見效週期 | 3–12 個月 |
| 誰來做 | 音樂製作＋品牌方；需法律確認版權歸屬 |
| 難度 | ★★★ |

**怎麼做**：
1. 定聲音要傳遞的情緒（快／暖／高端／有趣）與使用場景。產出：聲音 brief。
2. 選形式：**旋律型**（朗朗上口）、**口播型**（一句話固定唸法）、**音效型**（一個標誌性聲音）。產出：形式選擇。
3. 出 3 個版本 Demo，各 2–5 秒，做 AB 測試：聽 3 次隔 1 天再聽，測能否哼出。產出：測試結果。
4. 定稿後規範使用位置：視頻開頭／片尾、直播間進人提醒、門店廣播、客服來電問候。產出：聲音使用規範。
5. 做成資產包（不同時長版本），並註冊版權與商標（聲音商標）。產出：資產包＋權利文件。
6. 追蹤效果：品牌詞搜索、無提示哼唱測試。產出：季度評估。

**關鍵技巧**：越短越好，2–4 秒；旋律要「容易唱錯」才好記（有記憶鉤）；口播型最便宜，效果靠重複次數；不要用已經很紅的歌，用戶只記得歌不記得你。
**常見錯誤**：做得太複雜像廣告歌聽不完；太難聽導致用戶反感（負面記憶也是記憶）；只在廣告用、門店不用，浪費觸點。
**怎麼驗收**：無提示哼唱測試正確率、品牌詞搜索量增幅、直播間進人停留時長變化。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/45-物流与快递服务.md`（貨拉拉）。

### 1.9 品類定位（開新品類）

**一句話定義**：不在老品類裡競爭排名，而是新造一個品類，讓你自動成為第一名。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 老品類被巨頭壟斷、擠不進前五；客戶有真實技術／產品差異化；有教育市場的預算與耐心 |
| 不適用 | 產品沒有實質差異；預算和時間撐不起 1 年以上教育；品類太小養不活自己 |
| 預算量級 | 一次性 5–30 萬（含調研與定位）；落地傳播 30 萬起 |
| 見效週期 | 6–18 個月 |
| 誰來做 | 策略顧問＋創辦人；需老闆親自決策 |
| 難度 | ★★★ |

**怎麼做**：
1. 做品類樹：把用戶購買時的心智路徑寫出來（想吃點好的 → 零食 → 堅果 → 每日堅果）。產出：品類心智圖。
2. 找「未被命名的需求」：用戶已在用老品類解決但覺得不滿意的場景。產出：需求缺口 3 條。
3. 命名新品類（名字要能自己解釋自己，如「每日堅果」「電動牙刷」「即食燕窩」）。產出：品類名候選。
4. 造「品類標準」：定義憑什麼算這個品類（原料標準、工藝標準、使用場景）。產出：品類標準 1 頁。
5. 選「品類第一」的證據：銷量／專利／檢測／權威背書，用一句話說「開創者」。產出：定位語。
6. 先在小圈層打透（一個城市／一個平台／一個人群），跑通再放大。產出：樣板市場數據。
7. 用內容持續教育：每年固定投入教育預算，並監控品類詞搜索量。產出：品類詞監控表。

**關鍵技巧**：品類名要「口語化到能被搜索」；先做「品類第一」再做「品牌第一」；別造一個連自己員工都講不清的品類。
**常見錯誤**：品類太小，做到第一也只有幾百萬市場；品類名太抽象（消費者記不住也搜不到）；定位改了產品沒改，講一次就露餡。
**怎麼驗收**：品類詞搜索量趨勢、被媒體／競品用你的品類名描述（這是最高信號）、新品類貢獻的營收佔比。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（黃天鵝）；`cases/40-预制菜与方便速食.md`（空刻意面）；`cases/41-文具文创与办公.md`（貓太子）。

### 1.10 對立定位（打第一品牌）

**一句話定義**：找準行業第一的「強勢中的弱點」，站到它的對立面，借它的名氣把自己抬進消費者視野。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 行業有絕對老大（市佔 30%+）；客戶是老二老三，正攻打不動；老大有明顯的「反面訴求」 |
| 不適用 | 沒有明確老大；客戶自己也有同樣的弱點（對立會反噬自己） |
| 預算量級 | 一次性 3–20 萬（策略＋傳播創意） |
| 見效週期 | 3–12 個月 |
| 誰來做 | 策略＋傳播；需法務把關（避免不正當競爭） |
| 難度 | ★★★ |

**怎麼做**：
1. 列出老大的三個強項與對應的三個弱點（強的代價）。產出：強弱對照表。
2. 挑一個「老大不能反駁也不能跟進」的角度（跟進就自我否定）。產出：對立點 1 個。
3. 寫對立句式：「他不是…我是…」「別人都…我偏偏…」。產出：口號 3 句。
4. 法務審查：不點名、不貶損、不比數據（避免法律風險）。產出：法務意見。
5. 用具體證據支撐對立點（配方、工序、材質、服務）；沒證據就別說。產出：證據清單。
6. 全線落地：包裝、詳情頁、直播話術、門店物料統一說同一句話。產出：落地清單。
7. 監控老大是否回應；若老大跟進，立即升級到「新的差異點」。產出：競爭應對手冊。

**關鍵技巧**：對立點要選「老大不能改」的（改了要放棄它最大的優勢）；不必點名，消費者自己會對號入座；要能在 5 秒內講清楚。
**常見錯誤**：選了老大可以輕鬆跟進的點（如降價、加料）；說話太狠變成攻擊，引發反感；自己也被同一句話反打（如說別人含糖自己卻含更多）。
**怎麼驗收**：品牌認知度提升、與老大的「替代率」（有無搶到它的用戶）、媒體／用戶是否自發引述這個對立。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/20-跨境电商与出海品牌.md`（石頭科技）。

### 1.11 單一特性佔位

**一句話定義**：產品有很多優點，但只選一個最能被打贏的特性，反覆說到底。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 產品有多個賣點、一個都記不住；競品也都在說「十全十美」；已有一定產品力可支撐某一項 |
| 不適用 | 所選特性競品也同樣強且已佔位；特性無法驗證（說不出具體證據） |
| 預算量級 | 一次性 2–10 萬（含證據挖掘與傳播創意） |
| 見效週期 | 3–12 個月 |
| 誰來做 | 策略＋產品端配合 |
| 難度 | ★★☆ |

**怎麼做**：
1. 窮舉賣點（10–20 個），每個寫清「證據是什麼」。產出：賣點—證據表。
2. 用四條篩：用戶真在乎、競品沒佔或佔得不牢、你有硬證據、能一句話說清。產出：3 個候選特性。
3. 做「特性優先級測試」：給 50 個目標用戶看 3 個特性，問如果只能記住一個選哪個。產出：得票結果。
4. 把特性變成一句「可驗證的宣稱」（不是形容詞，是事實）。產出：核心宣稱 1 句。
5. 全媒體只講這一句，其他賣點退到詳情頁與客服話術。產出：資訊層級表。
6. 每季度復核一次是否被競品跟進佔位。產出：佔位監控表。

**關鍵技巧**：特性最好是「可被測量」的（速度、時長、成分含量）；選「用戶能感知」的而非「技術上最厲害」的；說一個就要放棄其他，這是策略的必然代價。
**常見錯誤**：特性選得太抽象（「更懂你」沒法驗證）；口號說一個，包裝說五個，用戶混亂；特性被競品抄了也不換。
**怎麼驗收**：無提示下能說出「你等於什麼」的用戶比例、該特性相關搜索詞的點擊與轉化率。
**案例**：`cases/32-珠宝钟表.md`（老鋪黃金）；`cases/33-箱包皮具配饰.md`（山下有松）。

### 1.12 品牌三問自檢（接案第一步）

**一句話定義**：用三個問題判斷客戶的品牌認知到底有沒有問題——答不出來就別往下花錢。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 所有新接案的客戶，尤其是「產品不錯但賣不動」的；預算有限、怕花錯錢 |
| 不適用 | 已在做具體執行、需要立刻解決單點問題時可暫時跳過 |
| 預算量級 | 0（2 小時人工） |
| 見效週期 | 當天 |
| 誰來做 | 顧問／行銷負責人，直接訪談老闆 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 問第一題「**你是誰**」：顧客會怎麼向朋友介紹你？寫下你聽到的原話。產出：顧客原話 3 條。
2. 問第二題「**你賣給誰、在什麼場景**」：把訂單按人群／場景分類，看是不是同一批人。產出：人群—場景表。
3. 問第三題「**憑什麼選你不選別人**」：要求說出對方沒有的證據。產出：差異點＋證據。
4. 對照老闆的自述與顧客的原話，找出落差（落差就是問題所在）。產出：落差清單。
5. 判斷卡點類型：是「不知道」還是「不信」還是「買不到」——三者打法完全不同。產出：卡點結論 1 句。
6. 出 1 頁診斷結論，含建議下一步（可搭配 §9 診斷類）。產出：診斷 1 頁。

**關鍵技巧**：三問要問「顧客」，不要只問老闆；老闆的答案與顧客答案不一致時，一律以顧客為準；三問跑完再談預算，順序反了就白做。
**常見錯誤**：走過場，直接跳到「做個活動吧」；把老闆的自我定位當答案；三問結果不落到具體打法。
**怎麼驗收**：能否用一句話寫出「卡點在曝光／信任／轉化／復購／渠道中的哪一個」；客戶是否認同這個結論。
**案例**：`cases/23-银发经济与健康养老.md`（足力健）；`cases/29-农业生鲜与供应链品牌.md`（認養一頭牛）。

### 1.13 VI 一致性（識別落地）

**一句話定義**：把已經定好的符號、顏色、字體、話術，在所有觸點上執行到「像同一家公司」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 門店／電商／物料／外包團隊各說各話；換個代運營就變風格；用戶在各平台認不出是同一品牌 |
| 不適用 | VI 尚未定稿就先別做手冊（會白做） |
| 預算量級 | 一次性 1–10 萬（含手冊與模板） |
| 見效週期 | 2–6 個月 |
| 誰來做 | 品牌設計＋內部行銷；需要有人負責稽核 |
| 難度 | ★★☆ |

**怎麼做**：
1. 清點全部觸點（線上＋線下），列出每個觸點現在用什麼視覺／話術。產出：觸點清單。
2. 定義最小必要規範：主色、輔助色、字體、logo 使用、圖片風格、話術三句。產出：核心規範 1 頁。
3. 做成「填空式模板」：詳情頁、九宮格、海報、直播貼片、門店物料，讓外包照填。產出：模板包。
4. 交付給所有執行方（設計、代運營、門店、員工），並要求回簽。產出：交底記錄。
5. 建立稽核機制：每月抽查 20 份素材，不合格退回。產出：稽核表。
6. 每半年更新一次規範（隨著新觸點出現補充）。產出：版本記錄。

**關鍵技巧**：手冊一定要做成模板而非 PDF 說明書，否則沒人看；規範條目越少越可能被執行（10 條以內）；把「稽核」寫進外包合約。
**常見錯誤**：出一本 80 頁手冊，結果吃灰；只規範 logo 不規範語氣；門店加盟商不執行，總部也沒罰則。
**怎麼驗收**：素材抽查合格率 ≥85%；用戶能否在無 logo 情況下認出你的內容（盲測）。
**案例**：`cases/01-餐饮与茶饮.md`（喜茶 × FENDI、蜜雪冰城）。

## §2 內容類打法（自產內容獲客）

> 本節解決：**沒有投放預算，靠內容把陌生人變成客戶。** 順序鐵律：先有帳號定位與模型（2.1、2.3），再做鉤子與量產（2.2、2.14），最後才談投放放大。沒跑通自然流就別投。

### 2.1 短視頻帳號冷啟動

**一句話定義**：用 30–60 條內容把一個新帳號從「沒人看」推到「有一批穩定精準觀眾」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有抖音／快手／視頻號帳號但播放長期三位數；新品類需要低成本獲客；有老闆或員工人格可出鏡 |
| 不適用 | 品類完全無視覺可展示性；團隊沒人能持續拍 3 個月 |
| 預算量級 | 0.3–3 萬／月（手機拍攝可近 0） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 1 人主導＋1 人剪輯；前期建議老闆本人出鏡 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定帳號身分一句話：**誰（職業／身分）＋為誰＋解決什麼**。產出：帳號一句話定位。
2. 找 20 個同品類對標帳號，按「內容類型」拆解（教學／測評／劇情／探店／Vlog）。產出：對標表。
3. 選 3 個能長期做的內容支柱，各寫 10 個題目。產出：30 條選題庫。
4. 用最低成本拍攝：自然光、手機、一到兩個場景，先解決「能發出來」。產出：首批 10 條。
5. 每天固定時間發 1 條，連發 30 天不間斷（前 30 條是練手，不是成果）。產出：30 條記錄。
6. 每 10 條做一次復盤：看 3 秒完播率、平均播放、漲粉、諮詢數，砍掉最差類型。產出：復盤表。
7. 出一條數據明顯好的內容後，複製該結構再拍 5 條。產出：爆款複製清單。

**關鍵技巧**：前 30 條不要追求爆，追求「穩定產出能力」；帳號定位要窄到能一句話講清；先做「能被搜索」的內容（品類詞／問題詞）比追熱點更穩。
**常見錯誤**：拍 5 條沒數據就放棄；每條風格都不同，系統不知道推薦給誰；追求畫質卻沒有內容訊息，完播率極低。
**怎麼驗收**：3 秒完播率（經驗值 >35% 合格，【判斷】）、平均播放量趨勢、私信／諮詢數（最終指標）。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞、費大廚的帳號冷啟）；`references/cases/51-本土数字营销与MCN.md`。

### 2.2 前 3 秒鉤子設計

**一句話定義**：把視頻最貴的 3 秒重新設計，讓刷到的人停下來，而不是划走。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有播放但不完播、不進店；帳號播放量靠系統推薦但轉化為 0；同一內容換開頭效果差好幾倍 |
| 不適用 | 內容本身無價值，鉤子只會加速流失與負評 |
| 預算量級 | 人工為主，0.2–1 萬／月 |
| 見效週期 | 1–2 週 |
| 誰來做 | 編導／剪輯；需大量 AB 測試 |
| 難度 | ★★☆ |

**怎麼做**：
1. 把現有 10 條視頻的開頭逐條寫成文字，標出問題。產出：開頭診斷表。
2. 用五種鉤子各改 3 條：**結果前置**（先給成品／效果）、**衝突提問**（你是不是也…）、**反常識**（千萬別…）、**利益直給**（教你一招省…）、**身分喊話**（做 XX 的一定要看）。產出：15 條開頭。
3. 前 3 秒內必須出現「畫面變化」或「關鍵詞字幕」，不能只有靜態人物說話。產出：成片。
4. 同素材剪 3 個不同開頭，用小額投放或自然流量 AB 測試。產出：完播率對比。
5. 建立「鉤子庫」：把跑得好的開頭句式存檔，之後重複套用。產出：鉤子庫文件。
6. 每周新增 5 條鉤子並測試，汰換效果最差的。產出：週更記錄。

**關鍵技巧**：鉤子要與內容一致，標題黨會拉高跳出並傷帳號；前 3 秒不要出現 logo 與自我介紹；字幕的前 6 個字就是第二個鉤子。
**常見錯誤**：開頭先打招呼「大家好，今天講…」；鉤子太泛（「一個很重要的知識」）；用了鉤子但內容接不住，評論區罵人。
**怎麼驗收**：3 秒完播率提升幅度、5 秒留存，以及最終的進店／私信轉化率（不能只看播放）。
**案例**：`cases/03-美妆个护.md`（韓束、完美日記）。

### 2.3 口播腳本結構

**一句話定義**：給不會講話的老闆或員工一套固定結構，讓鏡頭前有話可說、說了有用。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 客戶本人不會講、鏡頭前尬；有專業知識但講出來像課本；拍了幾十條都是流水帳 |
| 不適用 | 品類適合展示不需要講解（純視覺類） |
| 預算量級 | 人工，0–1 萬／月 |
| 見效週期 | 1 個月 |
| 誰來做 | 編導寫模板，客戶本人講 |
| 難度 | ★★☆ |

**怎麼做**：
1. 選一個固定結構，建議四段式：**鉤子（3 秒）→ 痛點共鳴（5 秒）→ 具體解法 1–3 步（20–40 秒）→ 一句行動指令（5 秒）**。產出：腳本模板。
2. 每條只講一件事（一個問題、一個方法），能寫在標題裡。產出：單一主題確認。
3. 用「說人話」原則改稿：刪掉專業術語、每句話不超過 15 個字。產出：定稿。
4. 加「具體數字與場景」（我上週遇到一個客戶…），避免空泛。產出：案例補充。
5. 拍攝時用手機提詞器，控制在 60–90 秒。產出：成片。
6. 建立「內容轉化位」：每 3 條裡有 1 條提產品或引導私信，其餘純給價值。產出：比例表。

**關鍵技巧**：先寫「口語稿」不要寫「書面稿」，寫完唸一遍、唸不順就改；一次錄 5 條，提高效率；結尾指令要具體（「評論區扣 1」勝過「歡迎諮詢」）。
**常見錯誤**：抄同行的稿導致同質化；一條視頻講五個點，用戶記不住；全程只講產品不講用戶問題。
**怎麼驗收**：平均觀看時長、評論區提問數、私信諮詢數、單條內容帶來的成交（哪怕 1 單）。
**案例**：`cases/03-美妆个护.md`（韓束、珀萊雅）。

### 2.4 探店視頻

**一句話定義**：用第三方視角把門店的「值得來一趟」講清楚，換取周邊人的到店。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 本地門店需要周邊客流；有明確的一個到店理由（新店／新菜／環境／價格） |
| 不適用 | 產品體驗撐不住探店（來一次就差評）；無本地達人資源且預算極低 |
| 預算量級 | 0.1–1 萬／條（含置換） |
| 見效週期 | 2–6 週 |
| 誰來做 | 本地生活達人／素人；店家配合安排 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 定「一個到店理由」並寫成 5 個字以內（如「39 塊吃到飽」）。產出：到店理由。
2. 選人：優先本地 1–10 萬粉的生活類達人，粉絲畫像需與門店商圈重疊。產出：達人清單 5–10 人。
3. 出拍攝 briefing：必拍的 5 個鏡頭（門頭／招牌菜特寫／價格牌／環境／吃後表情）。產出：brief 1 頁。
4. 要求達人掛團購連結／定位，並在評論區置頂核銷方式。產出：連結核銷數據。
5. 同步做「素人探店」：邀請真實顧客拍攝，給予免單＋小禮。產出：素人內容 10 條。
6. 把達人內容二次剪輯放在門店自有帳號，形成內容矩陣。產出：二次剪輯 3 條。
7. 一週後看核銷率，不是看播放量。產出：核銷報告。

**關鍵技巧**：探店必須說清價格與位置，這是兩大轉化要素；同時找 3–5 個中小達人比 1 個大達人風險更低、核銷更真實；要求達人在視頻裡「當場下單」示範流程。
**常見錯誤**：只看播放量不看核銷；探店內容拍成了宣傳片；一次投 10 個達人同一週發，流量互相沖淡。
**怎麼驗收**：團購核銷率（經驗值 5–20%，【判斷】）、到店提及「看視頻來的」的比例、核銷後是否加私域。
**案例**：`cases/15-教育文旅与本地生活.md`（淄博燒烤）；`cases/10-B2B工业品与农产品区域品牌.md`（天水麻辣燙）。

### 2.5 工廠溯源內容

**一句話定義**：把生產過程拍給用戶看，用「看得見的真實」換取信任。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 品類信任門檻高（食品／保健品／母嬰／護膚）；被質疑「智商稅」「代工貼牌」 |
| 不適用 | 生產過程有合規風險不能公開；工廠不允許拍攝 |
| 預算量級 | 0.5–3 萬／條（含差旅與製作） |
| 見效週期 | 2–4 個月 |
| 誰來做 | 內容團隊進廠；工廠配合 |
| 難度 | ★★☆ |

**怎麼做**：
1. 讓用戶提問：收集「你們是不是代工」「原料哪來的」等質疑。產出：信任缺口清單。
2. 按缺口設計拍攝腳本：原料進廠 → 檢驗 → 生產線 → 質檢 → 包裝出庫，全程不跳。產出：分鏡腳本。
3. 必須有三個「不能造假」的鏡頭：原料包裝上的產地／批號、檢測儀器讀數、工人真實操作。產出：關鍵鏡頭清單。
4. 用「一鏡到底」或顯著時間戳，提高可信度。產出：成片。
5. 拍成系列（每集回答一個質疑），不要一支宣傳片講完。產出：系列規劃 5 集。
6. 在詳情頁、包裝 QR、直播間循環使用。產出：素材再分發清單。

**關鍵技巧**：允許拍「不完美」（工人手上有麵粉、機器有噪音）比乾淨的宣傳片更可信；讓工人自己說話，比旁白可信；一定要拍到「你在別的地方看不到的東西」。
**常見錯誤**：拍成 3 分鐘企業宣傳片，沒人看完；找專業演員演工人，一眼假；講了工藝但沒講「這對用戶有什麼好處」。
**怎麼驗收**：溯源系列的平均完播率、詳情頁停留時長、「代工／假貨」類質疑在評論區的下降。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞、蜜雪冰城）。

### 2.6 產品測評內容

**一句話定義**：用可被驗證的硬指標對比，讓第三方替你回答「到底值不值」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 產品有硬參數（續航／成分含量／清潔力／耐用度）；品類充斥智商稅爭議 |
| 不適用 | 產品參數不如競品（測評會反傷自己）；無第三方願意測 |
| 預算量級 | 0.3–2 萬／條 |
| 見效週期 | 1–3 個月 |
| 誰來做 | 垂直測評達人／機構；需送樣與配合答疑 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「可測的宣稱」：把賣點轉成能測的指標（如「洗得乾淨」→ 去污率對比）。產出：測試指標表。
2. 選測評方：優先「長期做同品類對比」的帳號，而非純種草號。產出：達人名單。
3. 提供完整樣品與資料，但不干預結論（干預會毀掉可信度）。產出：寄樣記錄。
4. 要求測評含「對比組」與「測試方法」，方法越透明越可信。產出：內容驗收標準。
5. 內容發布後在官方帳號轉發並補充「測試條件說明」。產出：轉發內容。
6. 針對「測出來的弱點」提前準備回應話術，避免評論區崩。產出：FAQ 話術表。

**關鍵技巧**：中立測評的價值在於「可能說你不好」，全說好的等於廣告；優先選「有對比、有儀器、有重複測試」的內容形態；測評要和客服話術對接，用戶會帶著問題來問。
**常見錯誤**：買測評結論，被扒出後信任破產；測評只講參數不講使用場景；測評人恰飯痕跡明顯，用戶一眼識破。
**怎麼驗收**：測評內容帶來的搜索量、進店流量、轉化率；評論區負面質疑比例的變化。
**案例**：`cases/20-跨境电商与出海品牌.md`（石頭科技）；`cases/05-3C数码与家电.md`（大疆 DJI）。

### 2.7 圖文種草（小紅書筆記）

**一句話定義**：用「像朋友分享」的圖文，在女性為主的生活方式平台卡住搜索與推薦兩條流量。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 女性／生活方式品類；客單 50–500 元；決策前會搜索（美妝／家居／母嬰／旅行） |
| 不適用 | 極低價衝動消費；純男性向硬科技；平台判定違規的品類 |
| 預算量級 | 0.5–5 萬／月（含達人與投流） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 內容運營＋達人／素人矩陣 |
| 難度 | ★★☆ |

**怎麼做**：
1. 挖詞：在站內搜索框輸入品類詞，記錄下拉詞與「大家都在搜」。產出：關鍵詞庫（20–50 個）。
2. 按「搜索意圖」分四類筆記：**痛點型**（我的問題）、**攻略型**（怎麼選）、**開箱型**（我買了）、**對比型**（A vs B）。產出：選題表。
3. 寫標題：關鍵詞前置＋情緒／結果（「敏感肌｜用了 3 個月終於不泛紅」）。產出：標題 20 條。
4. 做封面：一張圖說清主題，大字＋真實場景，避免純產品圖。產出：封面模板 3 套。
5. 正文用「口語＋分行＋emoji 分段」，結尾埋 2 個相關關鍵詞。產出：正文模板。
6. 發布節奏：自有號每週 3–5 篇，達人／素人每週 5–10 篇。產出：排期表。
7. 對有自然流量的筆記做小額投流（薯條／聚光），放大搜索排名。產出：投流記錄。

**關鍵技巧**：小紅書是「搜索＋推薦」雙引擎，關鍵詞比創意更決定生死；真實感來自「不完美的細節」（如自己家裡的亂背景）；一個帳號只做一個垂直方向，混發會掉權重。
**常見錯誤**：筆記像廣告（全是產品美圖＋誇張效果），被限流；標題不帶關鍵詞，搜不到；一次鋪太多同質內容被封。
**怎麼驗收**：筆記搜索排名、單篇互動率（讚藏比）、店鋪／私域的來源佔比、投流 ROI。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞）。

### 2.8 公眾號長圖文

**一句話定義**：用一篇有觀點的長文，把品牌想說的立場說清楚，換取「被轉發」與深度信任。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有品牌故事或創辦人觀點可講；需要影響行業／媒體／B 端；客單高、決策週期長 |
| 不適用 | 純低價快消；沒有持續寫作能力 |
| 預算量級 | 人工 0.3–2 萬／月 |
| 見效週期 | 3–6 個月 |
| 誰來做 | 內容主編／創辦人親寫 |
| 難度 | ★★★ |

**怎麼做**：
1. 定專欄結構：如「行業觀察」「用戶故事」「幕後」三個固定欄目。產出：欄目規劃。
2. 選題標準：能給讀者一個「新的看法」，而不是通知新品。產出：選題庫 10 條。
3. 寫作結構：**具體故事開頭（第一段就有畫面）→ 引出問題 → 給出觀點／方法 → 落到品牌做的事**。產出：長文 1 篇。
4. 標題與摘要單獨打磨，微信打開率主要取決於標題與首圖。產出：標題 10 個。
5. 排版：段落短、關鍵句加粗、配圖 3–6 張，控制在 1500–2500 字。產出：排版稿。
6. 分發：公眾號＋知乎／頭條／行業社群轉發，把一篇長文拆成 5 條短內容。產出：二次分發清單。

**關鍵技巧**：先寫給 100 個精準的人看，而不是給所有人；觀點要具體、可被反駁；結尾不要硬推銷，放一個自然入口。
**常見錯誤**：寫成企業新聞稿，無觀點；標題平淡，打開率個位數；只發不推，讀者只有自己人。
**怎麼驗收**：打開率（行業均值 3–8%，【判斷】）、在看／轉發數、由文章帶來的 B 端諮詢或合作。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞）；`cases/02-食品饮料与酒.md`（衛龍）。

### 2.9 短劇植入

**一句話定義**：把產品寫進有劇情的短劇裡，借劇的流量做一次性大曝光。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要快速起量；品類適合劇情化（美妝／食品／小家電／App）；能承受 ROI 波動 |
| 不適用 | 預算不足 30 萬；需要精準轉化與可控 ROI 的生意 |
| 預算量級 | 30–500 萬／部（頭部作品更高） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 短劇製作方＋平台；品牌方做植入監審 |
| 難度 | ★★★ |

**怎麼做**：
1. 選劇：看製作方過往作品的完播與人群畫像，不看明星。產出：候選劇單。
2. 定植入方式：**道具植入**（出現產品）、**台詞植入**（角色說出賣點）、**劇情植入**（產品推動情節）。產出：植入方案。
3. 寫清「必現信息」：品牌名、核心賣點、購買入口，且必須自然融入。產出：植入要求單。
4. 談權益：除劇內露出，要拿到片段剪輯權、達人帳號二次分發權。產出：權益清單。
5. 播出後同步承接：搜索廣告卡位品牌詞與劇名詞、旗艦店首頁改版。產出：承接方案。
6. 監控：劇集播放量 → 品牌詞搜索量 → 店鋪訪客 → 成交，做歸因。產出：歸因報告。

**關鍵技巧**：一定要提前準備承接，短劇流量來得快去得也快；「劇名＋品牌」的組合搜索關鍵詞要提前買好；選劇先看它的「人群」與你的目標人群是否重疊。
**常見錯誤**：植入太硬像廣告，觀眾反感；沒做承接，流量全漏掉；只看播放量不看品牌詞搜索增幅。
**怎麼驗收**：品牌詞／劇名搜索量增幅、播出期間店鋪訪客與成交增幅、單次曝光的有效觸達成本。
**案例**：`cases/03-美妆个护.md`（韓束）；`cases/26-影视综艺与内容IP.md`（金典 ×《乘風2025》）。

### 2.10 微短劇自製

**一句話定義**：品牌自己做一部劇，把產品變成故事主角，長期沉澱為可反覆使用的內容資產。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有內容團隊與持續預算；品類需要反覆解釋（新品类／複雜產品）；想建品牌世界觀 |
| 不適用 | 沒有內容製作能力；只想做一次性曝光（那用植入更划算） |
| 預算量級 | 5–50 萬／部 |
| 見效週期 | 1–3 個月 |
| 誰來做 | 自有內容團隊或外部製作公司 |
| 難度 | ★★★ |

**怎麼做**：
1. 定劇集核心設定：主角是誰、每集解決什麼問題、產品在劇中的角色。產出：世界觀 1 頁。
2. 選平台：抖音／快手走豎屏強衝突、視頻號走生活流。產出：平台選擇。
3. 寫前 5 集劇本，每集 1–3 分鐘，主要目的是「讓人想追下一集」。產出：劇本。
4. 邊拍邊測：先發 5 集測數據，好就續，不好就改。產出：數據決策點。
5. 產品植入遵循「解決問題的道具」原則，不做硬廣口播。產出：植入檢查表。
6. 做 IP 化沉澱：角色做成頭像、表情包、周邊，形成長期資產。產出：IP 延展清單。

**關鍵技巧**：先做小成本試水再放大；每集結尾留鉤子；把劇的片段剪成 20 條短內容二次分發。
**常見錯誤**：一上來就拍 30 集，全部撲掉；劇本像廣告劇本；平台審核與版權沒提前確認。
**怎麼驗收**：追更率、單集完播率、劇集帶來的品牌搜索與復購、IP 內容的自然傳播量。
**案例**：`cases/03-美妆个护.md`（韓束）；`cases/26-影视综艺与内容IP.md`（開心麻花）。

### 2.11 品牌 IP 形象

**一句話定義**：養一個有性格、會說話的虛擬角色，讓它替品牌長期與用戶互動。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 面向年輕人；需要長期品牌資產；有持續內容預算（3 年以上） |
| 不適用 | 需要短期業績；沒有內容團隊餵養 IP |
| 預算量級 | 一次性 3–30 萬；養成 5–20 萬／年 |
| 見效週期 | 6–18 個月 |
| 誰來做 | 設計＋內容運營團隊 |
| 難度 | ★★★ |

**怎麼做**：
1. 定 IP 的「性格三詞」與「口頭禪」，越具體越好。產出：人設卡 1 頁。
2. 定與品牌關係：是品牌的化身，還是品牌的夥伴。產出：關係設定。
3. 出三視圖＋表情包＋動作庫，確保全平台可用。產出：素材包。
4. 讓 IP 進入日常內容：客服頭像、評論區回覆、視頻角色、包裝。產出：觸點清單。
5. 給 IP 設固定欄目（每週一期），保證持續曝光。產出：欄目規劃。
6. 半年一次檢驗：用戶是否能說出 IP 的名字與性格。產出：認知調研。

**關鍵技巧**：IP 的性格要「有缺點」才可愛；要先有內容場景再設計形象，否則只是一個 logo；IP 的說話方式要統一，連客服回覆都要照著寫。
**常見錯誤**：設計得很可愛但沒有內容餵養，變成吉祥物；IP 與品牌無關聯，養大了用戶不記得是誰家的；多個 IP 同時做，資源分散。
**怎麼驗收**：IP 名稱的自發提及量、IP 相關內容的互動率、周邊／表情包的使用量。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/14-零售商超与便利店.md`（泡泡瑪特）。

### 2.12 創始人 IP（不寫腳本版）

**一句話定義**：讓老闆本人成為品牌的信任入口，用「真人」代替「廣告」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 老闆願意露臉、有表達欲；品類需要人格信任（食品／教育／醫療／B2B）；沒有預算請明星 |
| 不適用 | 老闆不願意／不會表達；創辦人有未處理的負面風險 |
| 預算量級 | 0–2 萬／月（含剪輯） |
| 見效週期 | 3–6 個月 |
| 誰來做 | 老闆本人＋1 個剪輯 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「一句話人設」：我做這個生意的最初原因（故事比頭銜有用）。產出：人設 1 句。
2. 設計三個固定內容欄目（如「帶你看工廠」「回答一個問題」「行業真相」）。產出：欄目規劃。
3. 不寫稿，用「問題清單」代替：每條視頻前列 3 個要回答的問題，直接講。產出：問題清單。
4. 固定拍攝場景（辦公室／門店／工廠），形成視覺識別。產出：場景選擇。
5. 每週固定更新 2–3 條，並在評論區親自回覆。產出：互動記錄。
6. 把老闆內容與產品賣點對接：講行業知識時自然帶出產品標準。產出：內容—產品對應表。

**關鍵技巧**：講「行業真相」比講「我們多好」更能建立信任；允許有情緒與觀點，太圓滑等於沒人設；評論區回覆是第二條內容線，不能外包。
**常見錯誤**：找人代寫稿導致語氣不像本人；只講成功不講困難，假；更新斷斷續續，人設立不住。
**怎麼驗收**：老闆帳號的粉絲畫像是否與客戶重疊、私信諮詢數、由「創始人推薦」帶來的成交佔比。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞）；`cases/16-金融与保险.md`（保險經紀人 IP）。

### 2.13 員工矩陣號

**一句話定義**：把一線員工變成一批小帳號，用「量」覆蓋本地流量，降低對單一帳號的依賴。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有 5 家以上門店／30 人以上團隊；本地生意需要周邊覆蓋；已有可複製的內容模板 |
| 不適用 | 團隊小於 5 人；員工完全不配合；產品不適合出鏡 |
| 預算量級 | 0.3–2 萬／月（激勵＋剪輯支持） |
| 見效週期 | 2–4 個月 |
| 誰來做 | 總部做模板與培訓，員工產出 |
| 難度 | ★★★ |

**怎麼做**：
1. 定「統一動作清單」：每條視頻必有的 3 個元素（定位／一句門店資訊／統一音樂）。產出：SOP。
2. 給模板與選題庫：每週總部下發 5 個題目與示範片。產出：週更選題包。
3. 培訓一次：手機拍攝角度、光線、口播三句話。產出：培訓記錄。
4. 設激勵：按播放量／帶來的到店數給獎金，不按發帖數。產出：激勵規則。
5. 統一掛定位與團購連結，形成本地流量網。產出：帳號清單表。
6. 建立「內容稽核」防止跑偏與違規（用詞、價格、承諾）。產出：稽核表。

**關鍵技巧**：激勵必須和「生意結果」掛鉤；帳號歸屬要在入職文件裡寫清（避免離職帶走）；總部只做模板與素材，不做審美要求。
**常見錯誤**：只發文件不培訓，員工不會做；考核發帖數導致應付式內容；員工離職帶走帳號與粉絲。
**怎麼驗收**：矩陣號總曝光、本地到店提及率、平均單帳號產生的諮詢數。
**案例**：`cases/01-餐饮与茶饮.md`（海底撈、老鄉雞）。

### 2.14 內容日曆

**一句話定義**：把「靠靈感更新」改成「按表更新」，讓內容變成可持續的生產線。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 內容靠靈感、經常斷更；多人協作沒有統一節奏；不知道下週發什麼 |
| 不適用 | 只有 1 個人且內容量極小（先解決產能） |
| 預算量級 | 0（人工為主） |
| 見效週期 | 1 個月 |
| 誰來做 | 內容負責人統籌 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 定更新頻率（不要貪多，先定一個能完成的數字）。產出：頻率承諾。
2. 把內容分成四類並配比例：**引流型**（知識／痛點）50%、**種草型**（產品）30%、**信任型**（幕後／溯源）15%、**互動型** 5%。產出：內容配比表。
3. 建立「選題池」：把用戶問題、客服記錄、評論區問題都丟進去，每週補充 20 條。產出：選題池文件。
4. 排月曆：把固定欄目與節點（節日／大促／新品）先排好，再填空。產出：月度日曆。
5. 建立「一次生產多次分發」流程：一條視頻拆成圖文、短句、音頻。產出：分發清單。
6. 每月復盤一次：哪類內容產出最多諮詢，調整下月比例。產出：復盤報告。

**關鍵技巧**：日曆要排「能完成的量」而不是理想的量；把節日、大促、新品、行業節點一次排半年；內容要「可複用」，別每條都從零開始。
**常見錯誤**：日曆排滿但沒人執行；只排節日不排日常；不與業務節奏對齊（如淡季猛推）。
**怎麼驗收**：更新達成率（實際／計劃 ≥80%）、每月由內容帶來的諮詢與成交。
**案例**：`cases/42-摄影与影像服务.md`（海馬體）；`cases/01-餐饮与茶饮.md`（麥當勞中國）。

### 2.15 UGC 徵集機制

**一句話定義**：設計一個讓用戶願意主動拍內容的機制，用用戶的內容做免費的廣告。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有一定用戶基數；產品有可展示性（外觀／效果／場景）；缺素材 |
| 不適用 | 用戶基數太小；產品無視覺展示價值；沒有可給的獎勵 |
| 預算量級 | 1–20 萬（獎品＋傳播） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 內容運營＋社群 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「一句話參與指令」：讓用戶知道拍什麼、怎麼拍、發哪裡、加什麼標籤。產出：活動規則（≤50 字）。
2. 定獎勵結構：**參與獎**（人人有份，低成本）＋**排名獎**（大獎吸引認真拍）。產出：獎勵方案。
3. 降低門檻：提供模板、貼紙、濾鏡、拍攝角度示範。產出：素材包。
4. 建「徵集入口」：包裝 QR、社群、直播間、詳情頁。產出：入口清單。
5. 做「二次傳播」：把優質 UGC 官方轉發，並給作者獎勵，刺激更多人拍。產出：轉發排期。
6. 監控負面內容：設定關鍵詞監控，避免徵集變成吐槽大會。產出：監控清單。

**關鍵技巧**：參與門檻越低越好（一張圖＋一句話也算）；要先示範 5 條「樣板 UGC」，用戶才知道怎麼拍；獎勵要有「曬得出來」的價值感。
**常見錯誤**：規則太複雜沒人看懂；獎勵太小沒人參與；不審核內容，負面 UGC 被大量傳播。
**怎麼驗收**：UGC 提交量、帶標籤的總曝光、UGC 內容被官方二次使用的比例。
**案例**：`cases/08-游戏与泛娱乐.md`（《蛋仔派對》）；`cases/01-餐饮与茶饮.md`（蜜雪冰城）。

### 2.16 直播間腳本結構

**一句話定義**：把直播從「隨機聊」變成有節奏的循環腳本，讓任何主播上場都能講出同樣效果。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 開了直播但留不住人、講不明白；主播一換業績就崩；流量來了不知道怎麼接 |
| 不適用 | 產品不適合直播展示；沒有穩定小時流量 |
| 預算量級 | 人工，1–3 萬／月 |
| 見效週期 | 1–2 個月 |
| 誰來做 | 直播運營寫腳本，主播執行 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「5 分鐘一循環」腳本：**鉤子（留人）→ 產品痛點 → 產品賣點 → 價格對比 → 庫存緊迫 → 下單指令**。產出：循環腳本模板。
2. 寫 3 套不同循環（進人循環、講品循環、逼單循環），按在線人數切換。產出：腳本三套。
3. 準備「話術卡」：材質、成分、價格、售後、常見質疑的回答，貼在主播台前。產出：話術卡。
4. 設計「憋單—放價」節奏：整點或半點放一波，形成觀看習慣。產出：場控時間表。
5. 每場復盤三個數：進入率、停留時長、轉化率，針對最差的環節改腳本。產出：復盤表。
6. 把最強的一段腳本錄成示範視頻，用來培訓新主播。產出：培訓素材。

**關鍵技巧**：主播不需要背稿，需要的是「順序」；每 30 秒要有一個「留人動作」（提問、抽獎、發券）；價格對比必須有參照物。
**常見錯誤**：全程硬喊麥，來人就走；腳本太長太複雜，主播記不住；只講賣點不講價格與售後。
**怎麼驗收**：平均停留時長、每小時成交額、進人—停留—下單的漏斗轉化率。
**案例**：`cases/42-摄影与影像服务.md`（海馬體）；`cases/33-箱包皮具配饰.md`（妃魚）。

### 2.17 自播 vs 達播（算帳決策）

**一句話定義**：用真實的利潤帳，判斷該自建直播團隊還是投達人，而不是跟風。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有直播收入但算不清哪個更划算；達播一直虧但停不下來；想決定要不要建自播團隊 |
| 不適用 | 完全沒有直播基礎，先做 §5.2 直播間搭建 |
| 預算量級 | 自播 3–20 萬／月（含人力）；達播按坑位＋佣 |
| 見效週期 | 1–2 個月 |
| 誰來做 | 財務＋直播負責人共同測算 |
| 難度 | ★★★ |

**怎麼做**：
1. 建立「單場損益表」：GMV − 佣金 − 坑位費 − 樣品 − 退貨 − 履約成本 = 淨利。產出：達播損益表。
2. 同樣算自播：人力＋場景折舊＋投流＋退貨，算出「單場淨利」與「單小時成本」。產出：自播損益表。
3. 對比三件事：**淨利率、可控性（價格／話術／數據歸屬）、可複製性**。產出：對比表。
4. 判斷品類適合性：高毛利＋需反覆講解 → 自播；極低價＋需大流量 → 達播。
5. 定組合策略：達播做拉新與背書，自播做承接與復購。產出：比例方案。
6. 設定「止損線」：達播 ROI 低於某值連續 2 場即停。產出：止損規則。

**關鍵技巧**：達播的坑位費是「租流量」，自播是「買產能」，兩者要算不同的帳；自播的核心價值是數據與用戶資產歸自己；達播要看「複播 ROI」而不是單場。
**常見錯誤**：達播虧錢做規模，越做越虧；自播團隊建了但沒有穩定流量；只看 GMV 不看退貨與履約成本。
**怎麼驗收**：自播與達播的淨利潤率對比、複播率、用戶留存（達播帶來的用戶是否復購）。
**案例**：`cases/33-箱包皮具配饰.md`（妃魚、山下有松）。

## §3 投放類打法（花錢買流量）

> 本節解決：**付錢換流量，並且算得清划不划算。** 鐵律：投放前必須先有「承接」（詳情頁 §8.8、客服 §8.9、私域 §4），否則買來的流量全漏。任何投放都要先做小額測試帳戶，跑通 ROI 再放量。

### 3.1 信息流投放（冷啟動）

**一句話定義**：用平台演算法把廣告推給「可能感興趣的人」，靠素材與人群包不斷測試找到能賺錢的組合。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 已有成交模型想放大；新品要快速起量；客單與毛利支撐得起單次獲客成本 |
| 不適用 | 毛利極低（<30%）且無復購；詳情頁與客服沒做好（投了必虧） |
| 預算量級 | 1–10 萬／月起（測試期建議 300–500 元／天） |
| 見效週期 | 1–4 週 |
| 誰來做 | 投手＋素材團隊；素材產能決定成敗 |
| 難度 | ★★★ |

**怎麼做**：
1. 先算清楚「能承受的獲客成本」（CAC 上限 = 客單 × 毛利率 × 可接受回本週期係數）。產出：CAC 紅線。
2. 建 3 個帳戶分別測：**人群包**（相似人群／興趣／達人粉絲）、**素材**（口播／劇情／開箱）、**出價方式**。產出：測試矩陣。
3. 每天固定時間看數據，前 3 天只看「消耗與點擊」，第 4 天起看「轉化成本」。產出：日報表。
4. 每個變量至少測到 50 個轉化再判斷，否則樣本不足。產出：決策記錄。
5. 找到「低成本素材＋高轉化人群」後，逐步提預算（每次不超過 30%），避免帳戶跑崩。產出：放量計劃。
6. 建立「素材迭代機制」：每週至少上新 5 條素材，因為素材會衰減。產出：素材排期。
7. 做「承接優化」：落地頁、客服、庫存同步，避免流量來了接不住。產出：承接檢查表。

**關鍵技巧**：信息流的成敗 80% 在素材，不在出價技巧；不要頻繁調整帳戶設定，會打亂模型學習；「低價起量」的素材常帶來低質用戶，要按 LTV 而非單次轉化判斷。
**常見錯誤**：一天改十次出價，模型永遠學不出來；只做一套素材，兩週後成本翻倍；沒設 CAC 紅線，虧到最後才發現。
**怎麼驗收**：ROI（首單 ROI 與 90 天 LTV ROI 兩個口徑都要看）、單次轉化成本、素材衰減週期。
**案例**：`cases/03-美妆个护.md`（完美日記、韓束）。

### 3.2 搜索廣告

**一句話定義**：買用戶已經在搜索的關鍵詞，接住「有明確需求」的流量。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 用戶會主動搜的品類（家電／教育／醫療／B2B／高客單）；有明確品類詞與品牌詞 |
| 不適用 | 完全衝動型消費、無人搜索的品類；關鍵詞被競品壟斷且價格極高 |
| 預算量級 | 0.5–20 萬／月 |
| 見效週期 | 2–4 週 |
| 誰來做 | 投手；需與客服／落地頁配合 |
| 難度 | ★★☆ |

**怎麼做**：
1. 分四類建詞：**品牌詞**（防守，必買）、**競品詞**（進攻，看預算）、**品類詞**（主力）、**問題詞**（長尾，成本低）。產出：關鍵詞表。
2. 給每個詞組配對應的落地頁，不要全部丟首頁。產出：詞—頁對應表。
3. 設否定詞清單（避免買到無關流量），每週更新。產出：否定詞庫。
4. 分帳戶／分計劃跑，分別設定目標轉化成本。產出：計劃結構。
5. 用「搜索詞報告」反查實際來的流量，砍掉無效詞。產出：優化記錄。
6. 對高轉化詞加價搶排名，對無效詞降價或暫停。產出：出價調整表。

**關鍵技巧**：品牌詞必須買（否則競品會截走你的老客）；問題詞（如「XX 怎麼選」）往往 ROI 最高；落地頁標題要與關鍵詞一字對應，點擊後不跳脫。
**常見錯誤**：只買大詞不買長尾；落地頁與搜索意圖不符，跳出率極高；不設否定詞，錢被無關流量吃掉。
**怎麼驗收**：關鍵詞質量分、單詞轉化成本、有效諮詢率、品牌詞的截流保護率。
**案例**：`cases/20-跨境电商与出海品牌.md`（石頭科技）；`cases/06-汽车与出行.md`（長城坦克 300）。

### 3.3 場景化長尾詞挖掘

**一句話定義**：不搶貴的大詞，專買「帶場景、帶問題」的長尾詞，用低成本卡精準需求。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 大詞買不起（單次點擊過高）；品類有大量細分場景（如「產後掉髮」「加班胃疼」） |
| 不適用 | 品類場景極少、無搜索行為 |
| 預算量級 | 人工＋0.3–2 萬／月 |
| 見效週期 | 1 個月 |
| 誰來做 | 內容＋投手協作 |
| 難度 | ★★☆ |

**怎麼做**：
1. 用三種來源挖詞：平台搜索下拉框、客服高頻問題、評論區與小紅書筆記標題。產出：原始詞庫。
2. 按「人群 × 場景 × 需求」三維組合生成詞（如「哺乳期 掉髮 怎麼辦」）。產出：長尾詞 100+。
3. 用工具看每個詞的搜索量與競爭度，選「有量＋低競爭」的。產出：優先詞表。
4. 每個詞寫一條對應的內容或落地頁（標題即關鍵詞）。產出：詞—內容對應表。
5. 小額投搜索，觀察 7 天，留下有轉化的詞。產出：驗證結果。
6. 把驗證過的詞做成「內容日曆」，用自然流量長期卡位。產出：長期卡位計劃。

**關鍵技巧**：長尾詞最好用「內容」接而不是「廣告」接，成本更低；把客服問題直接變成詞庫，最精準；同一場景的多個詞要合併到同一落地頁，避免分散權重。
**常見錯誤**：詞挖了一堆但不做內容承接；詞太冷門，搜尋量撐不起量；只投不做自然排名，一停投就沒流量。
**怎麼驗收**：長尾詞的整體轉化成本（應顯著低於大詞）、自然搜索進站佔比、詞庫的月度新增數。
**案例**：`cases/03-美妆个护.md`（珀萊雅）；`cases/29-农业生鲜与供应链品牌.md`（認養一頭牛）。

### 3.4 本地生活團購

**一句話定義**：在平台（抖音／美團）上用低價套餐卡住周邊客流，換取到店與核銷。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有線下門店、需要周邊客流；有可標準化的套餐；門店承接能力足夠 |
| 不適用 | 服務品質不穩定（差評會發酵）；門店坪效已滿、無需引流 |
| 預算量級 | 0.3–3 萬／月（含佣金與達人） |
| 見效週期 | 2–6 週 |
| 誰來做 | 平台運營＋門店；達人探店配合 |
| 難度 | ★★☆ |

**怎麼做**：
1. 設計「引流套餐」：一份明顯低於正價但有辨識度的組合（不是全品類打折）。產出：套餐設計。
2. 算清「核銷成本」：套餐讓利＋平台佣金＋履約成本，確認單客不虧或可接受。產出：單位經濟測算。
3. 上架並優化「團購主圖與標題」：寫清價格、內容、位置、使用時間。產出：商品頁。
4. 找 3–5 個本地達人拍探店視頻掛連結，錯峰發布（不要同一天）。產出：發布排期。
5. 門店做「核銷動作」：核銷時引導加私域、發複購券。產出：門店 SOP。
6. 每週看三個數：曝光→點擊→核銷，卡在哪一環改哪一環。產出：週報。

**關鍵技巧**：引流套餐要「看得出便宜」而不是「真的全打折」；核銷時必須做私域承接，否則只是一次性虧錢；達人分層（1 個中腰部＋4 個素人）比單投頭部更穩。
**常見錯誤**：低價套餐把利潤打穿還不帶私域；達人同一天發布互相搶流量；套餐使用限制太多，被投訴。
**怎麼驗收**：核銷率、核銷後 30 天復購率、加私域人數、單客綜合成本。
**案例**：`cases/15-教育文旅与本地生活.md`（淄博燒烤）；`cases/01-餐饮与茶饮.md`（太二酸菜魚）。

### 3.5 達人分層投放

**一句話定義**：按粉絲量與內容類型分層投放達人，用頭部做聲量、腰部做背書、尾部做量大。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要規模曝光且預算 10 萬以上；新品上市需要集中聲量 |
| 不適用 | 預算小於 5 萬（先做 KOC）；沒有承接方案 |
| 預算量級 | 頭部 5–50 萬／條；腰部 0.5–3 萬／條；尾部 500–3000 元／條 |
| 見效週期 | 1–3 個月 |
| 誰來做 | 媒介／MCN 對接＋內容審核 |
| 難度 | ★★★ |

**怎麼做**：
1. 定「投放目的」：是搜索卡位、是聲量、還是直接轉化？不同目的選不同層。產出：目的界定。
2. 選人標準四條：粉絲畫像匹配、互動率真實、內容類型吻合、過往帶貨數據可查。產出：達人名單。
3. 分層配比（經驗值）：頭部 10%、腰部 30%、尾部 60%（【判斷】）。產出：投放結構。
4. 給統一 brief：必講 3 個賣點、必出 1 個證據、必有購買入口。產出：brief。
5. 排期錯峰：避免所有內容同週發布，形成持續聲量。產出：日曆。
6. 監控數據：播放、互動、進店、成交，識別「有水分的達人」。產出：效果歸因表。
7. 對有真實轉化的達人做「複投」。產出：複投名單。

**關鍵技巧**：看互動率與評論區真實度，不看粉絲量；同一達人連投 3 次比投 3 個新達人更能沉澱認知；一定要拿「二次分發權」，把達人內容放在自己帳號再投一次。
**常見錯誤**：只買粉絲量大的頭部，結果殭屍粉一片；brief 太鬆，達人全講自己想講的；沒有承接，流量來了一次性流走。
**怎麼驗收**：達人內容的進店率、單條 ROI、複投率、品牌詞搜索增幅。
**案例**：`cases/03-美妆个护.md`（完美日記）；`cases/51-本土数字营销与MCN.md`（無憂傳媒）。

### 3.6 KOC 鋪量

**一句話定義**：用大量真實素人／小微帳號的內容，把「搜索結果」鋪滿，形成看起來「很多人都在用」的效果。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要真實口碑、預算有限；用戶決策前會搜（美妝／母嬰／家居） |
| 不適用 | 品類無搜索行為；沒有足夠的真實體驗素材 |
| 預算量級 | 500–5 萬／月（單條 100–2000 元或置換） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 內容運營＋素人資源池 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「搜索關鍵詞」：確定用戶搜什麼，所有 KOC 內容都埋這些詞。產出：關鍵詞表。
2. 招募 KOC：從老客、社群活躍用戶、垂直社群中找，真實用戶優先。產出：KOC 名單 30–100 人。
3. 給「內容框架」不給「統一文案」：規定必講的 3 點，其餘讓他們自由寫。產出：內容指引。
4. 分批發布：每天 3–5 篇，持續 4 週，避免集中發布被判定水軍。產出：發布排期。
5. 對自然流量好的內容做小額投流，推上搜索首頁。產出：投流清單。
6. 監控「筆記存活率」與「搜索排名」。產出：鋪量報告。

**關鍵技巧**：內容必須「不一樣」，否則平台判定同質化；優先選有真實使用場景的帳號；KOC 的核心價值是搜索卡位而不是爆文。
**常見錯誤**：統一發同一段文案，被平台一鍋端；只發不投，筆記沉底；用了殭屍號，一眼看出是水軍。
**怎麼驗收**：目標關鍵詞下自有內容佔比、筆記存活率、由搜索帶來的進店與成交。
**案例**：`cases/03-美妆个护.md`（完美日記、珀萊雅）。

### 3.7 電商站內推廣

**一句話定義**：在天貓／京東／拼多多站內買關鍵詞與展示位，換取搜索排名與流量。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有站內店鋪；需要衝銷量、拿搜索權重；有明確主推款 |
| 不適用 | 店鋪基礎（詳情頁／評價）沒做好，投了等於燒錢 |
| 預算量級 | 1–20 萬／月 |
| 見效週期 | 2–6 週 |
| 誰來做 | 店鋪運營＋投手 |
| 難度 | ★★☆ |

**怎麼做**：
1. 先做店鋪基礎體檢：主圖、詳情頁、評價數、售後分數。產出：體檢表。
2. 選 1–2 個「主推款」，集中所有資源打單品排名。產出：主推策略。
3. 分兩種計劃：**搜索推廣**（卡關鍵詞）＋**展示推廣**（拉新人群）。產出：計劃結構。
4. 用「低價引流款」拿流量，「利潤款」承接轉化。產出：產品組合。
5. 每天監控「投產比（ROI）」與「自然搜索排名」，兩者一起漲才算成功。產出：日報。
6. 大促前 30 天開始蓄水，大促期間放量，大促後收縮保利潤。產出：大促節奏表。

**關鍵技巧**：站內推廣的目的是「用付費換自然權重」，不是長期靠付費賣貨；評價與銷量是搜索權重的核心，必須先解決；ROI 要看「付費＋自然」的綜合賬。
**常見錯誤**：只做直通車不做店鋪基礎，越投越虧；停投即死（沒有沉澱自然權重）；忽略大促節奏，該收的時候還在衝。
**怎麼驗收**：綜合 ROI、自然搜索排名提升、主推款的自然流量佔比。
**案例**：`cases/03-美妆个护.md`（韓束）；`cases/40-预制菜与方便速食.md`（空刻意面）。

### 3.8 品牌廣告（開屏／樓宇／電梯）

**一句話定義**：用大曝光媒介一次性觸達大量人群，目的是「記住」，不是「馬上買」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 已驗證轉化模型、要做品類心智；有預算支撐 3 個月以上持續曝光 |
| 不適用 | 沒驗證模型就砸（純燒錢）；預算撐不過 3 個月 |
| 預算量級 | 開屏 10–100 萬／期；分眾類 30 萬起 |
| 見效週期 | 3–12 個月 |
| 誰來做 | 品牌方＋媒介代理 |
| 難度 | ★★★ |

**怎麼做**：
1. 明確「要佔什麼心智」：一句話＋一個符號，其他全砍。產出：傳播主題。
2. 選媒介與人群：電梯看社區與寫字樓（覆蓋重複率高）、開屏看平台用戶畫像。產出：媒介組合。
3. 素材必須「3 秒可讀」：品牌＋品類＋一句話，不要堆資訊。產出：素材 3 版。
4. 排週期：至少連續 4–8 週，覆蓋同一批人 3 次以上。產出：投放排期。
5. 同步做線上承接：搜索廣告買品牌詞、旗艦店首頁改為廣告主題。產出：承接方案。
6. 用「品牌搜索量」與「無提示認知度」而不是即時 ROI 驗收。產出：效果評估。

**關鍵技巧**：品牌廣告的驗收指標是搜索量與認知，不是當期 ROI；重複比覆蓋廣度重要；線上線下必須同主題，否則錢白花。
**常見錯誤**：素材資訊太多，3 秒看不完；只投一週，等於沒投；投了品牌廣告但品牌詞沒買，流量被競品截走。
**怎麼驗收**：品牌詞搜索量增幅、無提示認知度、品類詞搜索中的品牌提及率。
**案例**：`cases/51-本土数字营销与MCN.md`（分眾傳媒）；`cases/33-箱包皮具配饰.md`（愛華仕）。

### 3.9 朋友圈廣告

**一句話定義**：用微信生態的精準定向能力，把廣告投給指定人群並直接留資或到店。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要精準定向＋留資／到店；客單較高、需要線索；有能承接的客服或門店 |
| 不適用 | 無法承接線索（沒人跟進就等於白投）；素材違規風險高的品類 |
| 預算量級 | 1–10 萬／月 |
| 見效週期 | 2–6 週 |
| 誰來做 | 投手＋客服／門店 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「轉化動作」：留電話、加企微、領券到店——只能有一個。產出：轉化目標。
2. 定人群包：地域（半徑）、年齡、性別、興趣、行為（如「近期關注裝修」）。產出：定向方案。
3. 做素材：外層圖（3 秒看懂）+ 內層落地頁（表單 3 個欄位以內）。產出：素材包。
4. 小額測試（1000–3000 元）測 3 套素材，挑最好的放量。產出：測試結果。
5. 線索進入客服後 5 分鐘內必須跟進，否則轉化率斷崖。產出：跟進 SOP。
6. 記錄每個線索的來源與最終成交，計算「單線索成本」與「單線索價值」。產出：線索賬。

**關鍵技巧**：表單欄位越少越好（多一個欄位流失 20%+，【判斷】）；外層素材要像「原生內容」而不是廣告；線索響應速度決定成交率。
**常見錯誤**：素材違規被拒審還沒備用方案；線索沒人跟；投給太寬的人群，成本虛高。
**怎麼驗收**：單線索成本、線索有效率（能聯繫上且有意向的比例）、線索成交轉化率與 ROI。
**案例**：`cases/06-汽车与出行.md`（長城坦克 300）；`cases/33-箱包皮具配饰.md`（愛華仕）。

### 3.10 平台活動報名

**一句話定義**：報名平台大促與行業日，借平台流量池做一次集中的銷量與曝光。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 平台有大促／行業日；產品有價格競爭力與庫存準備 |
| 不適用 | 產品無讓利空間；大促後無法維持價格體系 |
| 預算量級 | 讓利 5–20% ＋ 報名門檻＋活動費 |
| 見效週期 | 1 個月 |
| 誰來做 | 店鋪運營；需與供應鏈協同 |
| 難度 | ★★☆ |

**怎麼做**：
1. 提前 45–60 天拿到平台活動規則（門檻、價格要求、資源位）。產出：活動規則表。
2. 算「活動價」：讓利後是否仍有利潤，是否會破壞日常價格體系。產出：價格測算。
3. 準備專屬貨盤：大促款／清倉款／新品首發，不要用日常主推款全讓。產出：活動貨盤。
4. 報名並爭取資源位（會場坑位、搜索加權），用歷史數據談。產出：資源位清單。
5. 蓄水：活動前 2 週透過私域、內容、老客預告。產出：蓄水計劃。
6. 活動期間實時監控庫存與客服，活動後做復盤與老客沉澱。產出：復盤表。

**關鍵技巧**：大促的目的是「拉新客＋清庫存」，不是「賺錢」；一定要做活動款的專屬規格，避免和日常價比；大促後必須做價格修復（透過換規格、換組合）。
**常見錯誤**：大促後價格回不去，日常賣不動；庫存備太多造成滯銷；活動沒做私域承接，新客一次流失。
**怎麼驗收**：活動期 GMV、新客佔比、活動後 30 天復購率、價格體系恢復情況。
**案例**：`cases/42-摄影与影像服务.md`（海馬體）；`cases/27-茶饮咖啡与烘焙.md`（古茗）。

### 3.11 CPS 分佣投放

**一句話定義**：不預付廣告費，按成交付佣金，用別人的流量換自己的銷量。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 毛利高、能承受 20–40% 分佣；有用戶但缺流量；想低成本測試渠道 |
| 不適用 | 毛利低於 40%（分佣後不賺）；不能接受價格體系被衝擊 |
| 預算量級 | 按成交付；先備 1–5 萬保證金／樣品 |
| 見效週期 | 2–8 週 |
| 誰來做 | 渠道運營＋財務結算 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定佣金階梯：按銷售額分檔（如 10 萬內 20%、以上 25%），激勵做大。產出：佣金政策。
2. 選渠道：導購類 App、社群團長、內容帶貨達人、異業夥伴。產出：渠道清單。
3. 提供「專屬連結＋素材包」：圖片、文案、短視頻、直播切片。產出：推廣素材包。
4. 建立結算與對帳制度：數據實時可查，每月固定結算。產出：結算規則。
5. 監控「退貨與刷單」，設定風控紅線。產出：風控規則。
6. 對業績好的渠道升級為「獨家／定制款」合作，避免互相比價。產出：渠道分層。

**關鍵技巧**：一定要做「一物一碼／專屬連結」防串貨與歸因；把結算週期寫進協議（結算慢＝渠道跑）；用「定制規格」避免各渠道比價。
**常見錯誤**：分佣養出不可控的推廣大戶，反過來要挾品牌；沒有風控，被刷單刷走佣金；各渠道價格不一，用戶比價後退貨。
**怎麼驗收**：單渠道 ROI、渠道留存（複推率）、退貨率與刷單率、綜合毛利。
**案例**：`cases/33-箱包皮具配饰.md`（妃魚）；`cases/03-美妆个护.md`（完美日記）。

## §4 私域類打法（讓客戶回頭）

> 本節解決：**把一次性流量變成可反覆觸達的資產，提升復購與客單。** 私域的核心公式：**收到好友的人數 × 觸達頻率 × 內容質量 × 時機精準度 = 復購。** 沒有「加好友的理由」就別做私域，硬加只會被刪。

### 4.1 包裹卡引流

**一句話定義**：在包裹裡放一張卡，把已購買的用戶從平台導到自己的私域。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 已有穩定發貨量（月 1000 單以上）；想累積自有用戶池 |
| 不適用 | 發貨量太小（<300 單／月）；平台明確禁止導流且有封店風險 |
| 預算量級 | 0.1–0.3 元／張（含印刷） |
| 見效週期 | 2–6 週 |
| 誰來做 | 電商運營；客服承接 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 定「加好友的理由」：不是「加我領券」，而是「加我領一份專屬的東西」（食譜／使用指南／售後服務包）。產出：引流鉤子。
2. 設計卡片：正面一句利益，反面一個大 QR＋一句「掃碼需要 3 秒」。產出：卡面設計。
3. 選投放位置：放在用戶一定會看到的地方（如產品說明書旁、外包裝內側）。產出：投放位置測試。
4. 做「來源標記」：不同渠道用不同 QR，追蹤哪個渠道效率高。產出：渠道碼表。
5. 加好友後 24 小時內發放承諾的權益，建立第一印象。產出：履約 SOP。
6. 測試三版卡面，選加好友率最高的（經驗值 5–15%，【判斷】）。產出：測試結果。

**關鍵技巧**：利益要「具體且即時」（馬上給），不要「入群抽獎」；QR 要大到不用對焦；不同渠道分開統計才能持續優化。
**常見錯誤**：卡片寫「掃碼領券」但券沒吸引力；加了不加群，好友沉底；沒有來源標記，不知道哪個渠道有效。
**怎麼驗收**：包裹卡掃碼率、加好友率、加好友後 7 天內首單／複購率。
**案例**：`cases/03-美妆个护.md`（完美日記）；`cases/02-食品饮料与酒.md`（元氣森林）。

### 4.2 企微歡迎語 SOP

**一句話定義**：用戶剛加你時的那 3 條訊息，決定了他是留下還是刪除。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 已加好友但沒人回覆；加好友後直接發廣告導致刪除 |
| 不適用 | 還沒有好友來源（先解決引流） |
| 預算量級 | 人工，0–0.5 萬 |
| 見效週期 | 1–2 週 |
| 誰來做 | 私域運營；需客服配合 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 定「歡迎語三段」：**我是誰**（一句，帶真人頭像）→ **你能得到什麼**（三條具體價值）→ **現在做一個小動作**（回覆 1／領取權益）。產出：歡迎語模板。
2. 不要一上來發券，先發「內容型價值」（如「這是新手最常問的 3 個問題」）。產出：價值內容。
3. 設定發送節奏：加好友後即時 1 條，10 分鐘後 1 條，次日 1 條。產出：發送時間表。
4. 準備「標籤問題」：問 1–2 個問題以打標籤（如「你偏好哪種口味」）。產出：標籤規則。
5. 監控「首日回覆率」與「首週刪除率」，迭代文案。產出：迭代記錄。

**關鍵技巧**：用真人頭像與真實姓名（或暱稱），不要用 logo；歡迎語要短，一屏能讀完；第一個動作要簡單（回覆數字），讓用戶養成互動習慣。
**常見錯誤**：一上來發優惠券＋長篇介紹；歡迎語太長（超過一屏）；沒有標籤，後續無法分層運營。
**怎麼驗收**：首日回覆率（經驗值 30–50%，【判斷】）、首週刪除率、標籤完成率。
**案例**：`cases/31-眼镜与视光.md`（寶島眼鏡）；`cases/43-婚庆与人生仪式消费.md`（蜜絲卡倫）。

### 4.3 社群分層運營

**一句話定義**：把不同價值、不同意圖的用戶分到不同群，用不同的內容與節奏運營。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 群超過 3 個、人群混雜；群變成廣告群、退群率高 |
| 不適用 | 好友數少於 300（先做一對一） |
| 預算量級 | 0.3–1.5 萬／月（人工為主） |
| 見效週期 | 1–2 個月 |
| 誰來做 | 私域運營＋群管理員 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定分層維度：**價值**（成交金額／頻次）、**意圖**（潛在客戶／老客／KOC）。產出：分層規則。
2. 建三類群：**福利群**（大而泛，走量）、**VIP 群**（小而精，高客單）、**興趣群**（按主題，如「減脂食譜」）。產出：群結構。
3. 每群定「群規＋固定欄目」：如週一上新、週三問答、週五福利。產出：群運營日曆。
4. 配「群管理員」：真人負責，不要純機器人。產出：人員安排。
5. 設置「群內價值內容」：群主每天至少發 1 條非廣告的價值內容。產出：內容庫。
6. 每月清理沉默用戶，重新分層。產出：分層更新表。

**關鍵技巧**：群越小越有效（VIP 群 50–150 人最佳）；群必須有「非廣告內容」，否則用戶只當廣告群；用「興趣」而非「消費金額」來建群，互動更好。
**常見錯誤**：所有人群丟一個群；群裡只有廣告沒有內容；群規不執行，變成刷屏群。
**怎麼驗收**：群活躍度、群內成交額佔比、退群率、VIP 群的人均產出。
**案例**：`cases/31-眼镜与视光.md`（寶島眼鏡）；`cases/21-企业服务与SaaS.md`（Notion）。

### 4.4 朋友圈內容配比

**一句話定義**：用「不像廣告的人」的姿態發朋友圈，讓用戶不屏蔽你並主動找你。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 好友數 1000 以上但發圈沒人點；全是賣貨內容被屏蔽 |
| 不適用 | 好友太少（先解決加好友） |
| 預算量級 | 人工 |
| 見效週期 | 2–4 週 |
| 誰來做 | 私域運營／導購 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 定「四類內容配比」：**生活類** 30%（有畫面、有情緒）、**專業類** 30%（知識／答疑）、**用戶類** 25%（證言／案例）、**賣貨類** 15%。產出：配比表。
2. 每天發 1–2 條，固定時段（早 8 點、午 12 點、晚 9 點）。產出：發布時間表。
3. 每條配「真人場景圖」，不用產品白底圖。產出：素材庫。
4. 賣貨內容要「有理由」：上新／限時／斷貨補貨，不要天天折扣。產出：賣貨理由清單。
5. 每週看一次「互動率」（點讚＋評論／好友數），少於 3% 就換內容結構。產出：週報。

**關鍵技巧**：先用「生活與專業」內容建立人格，再賣貨；評論區主動互動比內容本身更重要；同一個內容可以「一張圖＋一句話」，不要長文。
**常見錯誤**：一天發 5 條全是產品圖；把朋友圈當公眾號發長文；複製黏貼統一文案，一眼是機器。
**怎麼驗收**：單條互動率、私聊諮詢數、朋友圈帶來的成交佔比。
**案例**：`cases/31-眼镜与视光.md`（寶島眼鏡）；`cases/03-美妆个护.md`（完美日記）。

### 4.5 分時段分人群發券

**一句話定義**：不再群發同一張券，而是按人群與時間點給「他此刻需要的券」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有標籤數據、想提升核銷率；券發很多但核銷率低 |
| 不適用 | 沒有用戶標籤（先做標籤體系） |
| 預算量級 | 讓利 3–15% |
| 見效週期 | 2–4 週 |
| 誰來做 | 私域運營＋數據 |
| 難度 | ★★☆ |

**怎麼做**：
1. 給用戶打三類標籤：**價值**（客單／頻次）、**偏好**（品類／口味）、**狀態**（新客／沉睡／活躍）。產出：標籤體系。
2. 設計券的類型：**新客首單券**、**復購券**、**喚醒券**、**升單券**（滿 X 減 Y）。產出：券矩陣。
3. 定發送時機：新客加好友 24 小時內、復購周期到點前 3 天、沉睡 60 天後。產出：發送時間表。
4. 分時段發送（如晚餐前發食品券、週末前發到店券）。產出：時段規則。
5. AB 測試：同人群一半發券一半不發，測增量。產出：測試結果。
6. 監控核銷率與帶來的客單，砍掉核銷率過低的券型。產出：券效果表。

**關鍵技巧**：券要有「使用理由」與「期限」；測試組要有對照，否則分不清是券帶來的還是自然購買；券的金額要與客單匹配（太低沒感覺、太高傷利潤）。
**常見錯誤**：所有人發同一張券，成本高效果差；券面額過大，正價賣不動；不設對照組，無法判斷增量。
**怎麼驗收**：核銷率、領券到核銷的轉化、券帶來的增量 GMV（對照組法）、優惠成本佔比。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/01-餐饮与茶饮.md`（麥當勞中國）。

### 4.6 會員階梯設計

**一句話定義**：設計一套「爬梯子」的會員體系，讓用戶為了升等級而不斷買。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有復購但客戶沒有升級理由；想提升用戶終身價值 |
| 不適用 | 一次性消費品類；沒有可持續提供的會員權益 |
| 預算量級 | 讓利 3–10% |
| 見效週期 | 3–6 個月 |
| 誰來做 | 私域／會員運營 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定 3–4 級（不要超過 4 級），每級有明確門檻（累計消費／次數）。產出：等級結構。
2. 設計「權益階梯」：低級給價格優惠，中級給專屬服務，高級給身分與特權。產出：權益表。
3. 確保「每級都有感」：升級後必須立刻能感受到差異。產出：升級觸點清單。
4. 設計「保級／降級」規則，製造每年回頭的理由。產出：升降規則。
5. 通知機制：進度條、差多少升級、升級提醒。產出：觸達腳本。
6. 監控升級率與高級會員的貢獻佔比。產出：會員報告。

**關鍵技巧**：第一級門檻必須「很容易達到」（第一單就能進）；高級權益要「稀缺」，不能人人可得；身分感比折扣更能留住高價值用戶。
**常見錯誤**：門檻設太高，沒人爬到第二階；權益只是折扣，用戶沒感覺；等級太多，用戶記不住。
**怎麼驗收**：會員升級率、高級會員的人均消費與復購頻次、會員貢獻的 GMV 佔比。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/31-眼镜与视光.md`（寶島眼鏡）。

### 4.7 積分體系

**一句話定義**：把消費變成積分，用積分換取下一次消費的理由，適合高頻低客單品類。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 高頻低客單品類（飲料／零食／日用）；有線上或門店的會員系統 |
| 不適用 | 低頻高客單品類（積分兌換週期太長，無感） |
| 預算量級 | 讓利 1–5% |
| 見效週期 | 3–6 個月 |
| 誰來做 | 會員運營＋系統支持 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定積分獲取規則：消費、簽到、評價、分享各給多少分。產出：獲取規則表。
2. 定積分使用規則：可兌換的商品、比例、是否有門檻。產出：兌換商城。
3. 設計「積分有效期」（如 12 個月），製造使用緊迫。產出：有效期規則。
4. 兌換商品要是「用戶真想要的」，不要放賣不掉的庫存。產出：兌換品清單。
5. 做「積分進度提示」：差多少分能換什麼，提高黏性。產出：觸達腳本。
6. 每季核算積分成本佔營收比，控制在目標內。產出：成本報告。

**關鍵技巧**：兌換門檻要低（第一檔 100 分就能換點東西）；積分是「負債」，成本要提前算；兌換品最好和主營相關（能帶動連帶銷售）。
**常見錯誤**：積分只能換滯銷品，用戶懶得用；積分成本失控，變成純虧損；兌換規則太複雜，用戶看不懂。
**怎麼驗收**：積分獲取率與使用率、積分會員的復購頻次、積分成本佔營收比。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/01-餐饮与茶饮.md`（蜜雪冰城）。

### 4.8 沉睡用戶喚醒

**一句話定義**：對 60 天以上沒買的用戶做一次有理由的觸達，把一部分人拉回來。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 沉睡用戶佔比高（如 60 天未購 >50%）；有完整的用戶聯繫方式 |
| 不適用 | 產品已停產或品牌已轉型；用戶明確表達過不想被打擾 |
| 預算量級 | 0.2–1 元／人（含讓利） |
| 見效週期 | 2–6 週 |
| 誰來做 | 私域／CRM 運營 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 分層沉睡用戶：30–60 天、60–90 天、90 天以上，分開對待。產出：沉睡前段表。
2. 找「喚醒理由」：新品／升級／專屬回歸價／庫存清倉。產出：喚醒主題。
3. 用不同渠道分頭測：企微一對一、簡訊、公眾號、外呼。產出：渠道測試結果。
4. 一對一訊息要「像人寫的」：帶稱呼、帶上次購買的品類。產出：訊息模板。
5. 給「回歸的台階」：不是直接買，而是先領個小權益。產出：回歸路徑。
6. 一個月後統計喚醒率與復購率，砍掉無效渠道。產出：喚醒報告。

**關鍵技巧**：帶上「上次買的產品」資訊，喚醒率顯著提升（【判斷】）；一次只提供一個理由，不要一次發三張券；對 90 天以上的用戶考慮「放棄」而不是一直打擾。
**常見錯誤**：群發同一條訊息給所有人；不帶稱呼的模板訊息；喚醒太頻繁，被拉黑。
**怎麼驗收**：喚醒率（回覆或下單比例）、喚醒成本、喚醒後的 30 天留存。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/31-眼镜与视光.md`（寶島眼鏡）。

### 4.9 老帶新裂變機制

**一句話定義**：設計一套讓老客願意主動帶新客的機制，用老客的信任降低獲客成本。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 產品有社交屬性、滿意度高；獲客成本高於預期 |
| 不適用 | 產品體驗差（帶來的客會反噬）；沒有可追蹤的推薦機制 |
| 預算量級 | 讓利 8–30%（含獎勵） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 私域運營＋技術支持 |
| 難度 | ★★☆ |

**怎麼做**：
1. 選「推薦動機」：省錢（雙方得券）、賺錢（分佣）、面子（專屬邀請碼）。產出：激勵設計。
2. 降低分享門檻：一鍵生成的分享圖＋一句現成的話。產出：分享物料。
3. 設「雙向獎勵」：老客得券，新客也得券（雙邊都有好處，轉化才高）。產出：獎勵規則。
4. 做「進度可視化」：老客能看到我已推薦幾人、還差幾人升級。產出：進度頁。
5. 分層激勵：推薦 1 人得小獎，推薦 5 人得大獎。產出：階梯獎勵。
6. 監控「裂變質量」：新客的復購率，避免拉來純羊毛。產出：質量報告。

**關鍵技巧**：獎勵要「即時到帳」，延遲到帳等於沒有；新客的門檻要低（首單即可）；推薦人最好有「身分感」（如合夥人、體驗官）。
**常見錯誤**：只獎勵老客，新客沒動力；獎勵太大，被刷單黨盯上；裂變來的用戶無後續承接，一次流失。
**怎麼驗收**：老帶新佔新客比例、新客首單率、新客 90 天復購率、單個新客獲客成本。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/24-二手与循环消费.md`（轉轉）。

### 4.10 復購提醒

**一句話定義**：在產品快用完的時點主動提醒用戶，把「想起來要買」變成「剛好收到訊息」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有明確消耗週期的品類（護膚／母嬰／寵物糧／耗材） |
| 不適用 | 耐用品（無消耗週期）；購買頻率極低 |
| 預算量級 | 0.1–0.5 元／人 |
| 見效週期 | 1 個月 |
| 誰來做 | 私域／CRM 運營 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 測算每個品類的消耗週期（從購買記錄算平均間隔）。產出：週期表。
2. 定提醒時點：消耗週期的 70% 處第一次提醒，90% 處第二次。產出：提醒節奏。
3. 提醒內容要「有用」：附使用建議／新用法，不要只是催單。產出：提醒模板。
4. 附一個「一鍵復購」連結，減少操作步驟。產出：直達連結。
5. 對提醒後未購的用戶，隔 7 天再用不同理由觸達一次。產出：二次觸達。
6. 監控「提醒後購買率」與「騷擾投訴率」。產出：效果報告。

**關鍵技巧**：提醒時點比內容更重要——早了沒需求，晚了已買別家；提醒要帶「新資訊」（新配方／優惠／用法），否則像催單；允許用戶一鍵「暫停提醒」。
**常見錯誤**：憑感覺定週期，不按數據；提醒太頻繁，用戶反感；只催單不給價值。
**怎麼驗收**：提醒後 7 天購買率、復購週期縮短幅度、投訴／拉黑比例。
**案例**：`cases/43-婚庆与人生仪式消费.md`（蜜絲卡倫）；`cases/31-眼镜与视光.md`（寶島眼鏡）。

### 4.11 私域反哺選品

**一句話定義**：用私域用戶的真實需求與投票，決定下一個新品做什麼，降低開發風險。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 私域有 3000 人以上；有新品開發計劃；想降低開發失敗率 |
| 不適用 | 私域人數太少（樣本不足）；只有單一產品線且不打算擴 |
| 預算量級 | 0（調研成本） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 產品＋私域運營 |
| 難度 | ★★☆ |

**怎麼做**：
1. 從私域收集「未被滿足的需求」：群聊、客服、評論區的問題都記下來。產出：需求清單。
2. 讓用戶投票：給 3–5 個方向，用群投票或表單選。產出：投票數據。
3. 邀請 20–50 個核心用戶做「試用官」，參與樣品測試。產出：試用官名單。
4. 做「預售測試」：在新品量產前用小批量預售驗證真實購買意願。產出：預售數據。
5. 讓參與者成為「首批推薦人」，形成口碑。產出：推薦計劃。
6. 把「用戶共創」的故事做成內容，強化品牌與用戶的關係。產出：內容素材。

**關鍵技巧**：最貴的資訊是「用戶願意為什麼付錢」，預售比投票更真實；只聽核心用戶會做出小眾產品，要搭配沉默用戶數據；讓用戶參與的過程本身就是行銷。
**常見錯誤**：只聽老客意見，做成小眾產品；投票結果好看但沒人真買（沒做預售驗證）；參與者覺得被利用，沒有後續反饋。
**怎麼驗收**：新品預售轉化率、試用官的推薦轉化、新品上市後的復購率。
**案例**：`cases/31-眼镜与视光.md`（寶島眼鏡）；`cases/03-美妆个护.md`（完美日記）。

## §5 渠道類打法（貨怎麼鋪出去）

> 本節解決：**消費者想買的時候，能不能買到。** 渠道是承接，不是曝光。渠道類打法最大的坑是「只鋪貨不做動銷」，貨鋪出去不等於賣出去。

### 5.1 電商店鋪從零

**一句話定義**：把一個空店鋪搭成「能承接流量並完成轉化」的完整銷售系統。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有產品沒店，或店是「殭屍店」；準備開始做線上零售 |
| 不適用 | 產品不適合線上銷售（需體驗／需安裝／保鮮期極短） |
| 預算量級 | 1–5 萬起步（不含投流） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 運營＋視覺＋客服（可 1 人起步） |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「店鋪定位」：賣什麼、賣給誰、主推哪一款。產出：店鋪定位 1 頁。
2. 建立基礎設施：類目選擇、店鋪首頁、分類結構、優惠券、客服自動回覆。產出：店鋪框架。
3. 做主推款詳情頁（按 §8.8 六要素），務必先做完再投流。產出：詳情頁。
4. 鋪基礎評價：透過老客／私域做前 30 條真實評價與曬圖。產出：評價計劃。
5. 開通必要工具：優惠券、滿減、物流模板、售後政策。產出：工具清單。
6. 測轉化率：用小額流量測試，看「訪客—加購—下單」的漏斗。產出：轉化基線。
7. 轉化率達標（高於同類目均值）後才開始放量投放。產出：放量決策。

**關鍵技巧**：詳情頁與評價是「轉化地基」，沒打牢就投流等於漏錢；店鋪首頁只做三件事：主推款、活動、信任；先做單品爆款再談店鋪。
**常見錯誤**：詳情頁沒做完就投流，錢全放空；鋪 50 個 SKU 沒有一個主推；沒有客服自動回覆，夜間流量白流。
**怎麼驗收**：店鋪轉化率（對標類目均值）、主推款訪客數與加購率、客服響應時長。
**案例**：`cases/03-美妆个护.md`（韓束）；`cases/40-预制菜与方便速食.md`（空刻意面）。

### 5.2 直播間搭建

**一句話定義**：從零建一個能開播、能承接、能持續產出的直播間（人／貨／場）。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有貨源想開播，缺人缺場景；已有直播但場景寒酸、進人就走 |
| 不適用 | 沒有穩定流量來源（先解決流量）；產品無法在直播中展示價值 |
| 預算量級 | 一次性 2–15 萬（設備＋場景）；每月人力 2–10 萬 |
| 見效週期 | 1–2 個月 |
| 誰來做 | 主播＋場控＋運營（最少 2–3 人） |
| 難度 | ★★★ |

**怎麼做**：
1. 定「直播定位」：賣誰的貨、什麼價格帶、什麼時間段播。產出：定位 1 頁。
2. 搭場景：背景要有品牌辨識（色塊／符號／燈光），不要白牆。產出：場景設計。
3. 配置設備：相機／手機＋補光＋收音（收音比畫質更重要）。產出：設備清單。
4. 定「貨盤結構」：引流款（不賺錢拉人）＋利潤款（賺錢）＋形象款（拉品牌）。產出：貨盤表。
5. 用 §2.16 的循環腳本排練，先錄播測試再開播。產出：腳本＋錄播。
6. 定開播節奏：固定時間、固定時長（不要隨意改），養成用戶習慣。產出：排期表。
7. 每場復盤三數：進入率、停留、轉化，只改一個變量。產出：復盤記錄。

**關鍵技巧**：貨盤結構比主播話術更重要；固定開播時間讓系統與用戶都養成習慣；直播間的核心指標是「停留」，先讓人留下再談賣貨。
**常見錯誤**：先買貴設備再想內容；主播換來換去，沒有穩定人設；賣的貨和平時價一樣，用戶沒有下單理由。
**怎麼驗收**：平均停留時長、每小時 GMV、進入率、退貨率。
**案例**：`cases/33-箱包皮具配饰.md`（妃魚、山下有松）。

### 5.3 線下門店動線

**一句話定義**：重新設計顧客從進門到結帳的行走路線，讓該看到的都看到、該買的都買到。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 進店人數不少但成交率低；客單低、顧客買完就走 |
| 不適用 | 進店人數本身就極少（先做引流） |
| 預算量級 | 一次性 0.5–5 萬 |
| 見效週期 | 2–6 週 |
| 誰來做 | 門店運營＋設計；店長執行 |
| 難度 | ★★☆ |

**怎麼做**：
1. 畫「實際動線圖」：連續 3 天觀察 30 個顧客怎麼走、在哪停、在哪買單。產出：動線熱區圖。
2. 定三個關鍵位置：**入口吸引區**（3 秒內看到爆品）、**主動線陳列區**（高毛利／要推的品）、**收銀台加購區**。
3. 調整動線：把「要賣的」放在必經之路上；把「順手買的」放收銀台。產出：陳列調整方案。
4. 做「價格可見」：主推品必須有清楚價格牌，降低詢問門檻。產出：物料清單。
5. 導購話術配套：把「歡迎光臨」改成「今天有 X 活動」。產出：話術卡。
6. 觀察 2 週後的「停留時長」與「客單」，再調整。產出：效果對比。

**關鍵技巧**：門店的核心不是陳列好看，是「讓人多走兩步」；收銀台是最後一次加購機會，必須放東西；價格牌能顯著降低詢問門檻。
**常見錯誤**：只改陳列不改導購話術；動線設計成「繞一圈」，顧客煩躁；把高毛利品放在死角。
**怎麼驗收**：進店成交率、客單價、顧客平均停留時長、動線熱區是否符合設計。
**案例**：`cases/01-餐饮与茶饮.md`（太二酸菜魚）；`cases/42-摄影与影像服务.md`（海馬體）。

### 5.4 異業合作

**一句話定義**：找客群重疊但不衝突的品牌互換資源，用低成本換來對方的客戶。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 客群重疊但品類不衝突；雙方體量相當；都想低成本擴客 |
| 不適用 | 對方會截走你的客戶（品類有替代關係）；體量差距太大（談不動） |
| 預算量級 | 0–5 萬（資源互換為主） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 商務／BD；需老闆拍板 |
| 難度 | ★★☆ |

**怎麼做**：
1. 列出「同一批客戶還會買什麼」的清單，找 20 個候選品牌。產出：合作清單。
2. 篩選：客群重疊度高、品類不衝突、體量相當、對方也有擴客需求。產出：優先名單。
3. 設計「互換方案」：不是你買我我買你，而是**聯合權益**（聯名券包／互相引流贈品／聯合活動）。產出：合作方案。
4. 明確權責：誰出物料、誰出場地、數據怎麼共享、誰負責客服。產出：合作協議。
5. 做一次小規模測試（一場活動／一個券包），成功再擴大。產出：測試結果。
6. 建立長期機制：季度聯名／固定互推位。產出：年度合作表。

**關鍵技巧**：最好的異業合作是「同一場景不同需求」（婚禮＋婚紗＋婚宴）；先小後大，一次活動驗證再談年度；數據共享要寫清，否則無法評估。
**常見錯誤**：找了替代品類合作，客戶被截走；只換物料不換客戶；沒有明確 KPI，做完不知道有沒有用。
**怎麼驗收**：互換帶來的實際線索／訂單數、獲客成本對比、合作方是否願意續約。
**案例**：`cases/01-餐饮与茶饮.md`（喜茶 × FENDI）；`cases/42-摄影与影像服务.md`（海馬體）。

### 5.5 加盟招商

**一句話定義**：把已跑通的單店模型打包成可複製的「招商品」，賣給想創業的人。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 單店模型已跑通（穩定盈利 6 個月以上）；有標準化能力與管理團隊 |
| 不適用 | 模型沒跑通就招商（加盟商全虧，品牌被毀）；無供應鏈與督導能力 |
| 預算量級 | 招商會 5–50 萬；每年品牌建設 30 萬+ |
| 見效週期 | 3–12 個月 |
| 誰來做 | 招商團隊＋督導＋供應鏈 |
| 難度 | ★★★ |

**怎麼做**：
1. 驗證「單店模型」：把單店損益表、回本週期、選址標準做成一頁。產出：樣板店檔案。
2. 打包「招商品」：品牌手冊、選址評估表、開店手冊、督導流程、供應鏈清單。產出：招商資料包。
3. 找「加盟商畫像」：誰適合開你的店（資金、時間、性格）。產出：畫像定義。
4. 拓客：招商會、短視頻內容、行業網站、老加盟商轉介紹。產出：招商渠道。
5. 嚴格篩選：不只看錢，看是否願意執行標準（不合格的加盟商是品牌殺手）。產出：篩選標準。
6. 建立督導與培訓：開店前培訓＋開業扶持＋每月巡店。產出：督導 SOP。
7. 設退出機制：虧損店如何處置，避免長期拖累品牌。產出：退出條款。

**關鍵技巧**：加盟的核心是「讓加盟商賺錢」，所以要挑好址、控好成本；用老加盟商的真實數據做招商素材，比廣告可信；供應鏈是長期利潤來源，但要透明定價。
**常見錯誤**：模型未跑通就大規模招商；只收加盟費不管運營；區域保護沒做好，同品牌互打。
**怎麼驗收**：樣板店平均回本週期、加盟商 12 個月存活率、加盟商轉介紹率。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/32-珠宝钟表.md`（老鳳祥）。

### 5.6 分銷體系

**一句話定義**：讓一批中間商／個人幫你賣貨，你給分潤並管住價格與秩序。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有毛利空間＋現成渠道人脈；想快速鋪開渠道 |
| 不適用 | 毛利低於 40%；沒有價格管控能力 |
| 預算量級 | 讓利 10–40% |
| 見效週期 | 2–6 個月 |
| 誰來做 | 渠道運營＋財務；需系統支持 |
| 難度 | ★★★ |

**怎麼做**：
1. 定「分銷層級」（建議不超過 2 級）與每級利潤空間。產出：分潤政策。
2. 建立「價格體系」：零售價、渠道價、活動價，寫死並執行。產出：價格表。
3. 招募分銷商：從老客戶、行業社群、展會中找。產出：分銷商名單。
4. 提供「一套工具」：產品素材、下單系統、培訓、售後支持。產出：賦能包。
5. 做「一物一碼／專屬連結」管理竄貨與歸因。產出：管控方案。
6. 建立「分銷商分級」：業績好的給獨家款、給返點；差的淘汰。產出：分級表。

**關鍵技巧**：價格體系是分銷的生命線，崩了就沒人賣；分銷商要的是「好賣」不是「利潤高」；一定要有數字化管控，否則串貨無法查。
**常見錯誤**：多級分銷導致終端價虛高；不做控價，各渠道亂價；只招不管，分銷商拿了貨就消失。
**怎麼驗收**：分銷商活躍率（持續下單的比例）、終端價格穩定性、竄貨投訴數。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/03-美妆个护.md`（完美日記）。

### 5.7 即時零售（閃購）

**一句話定義**：透過平台（美團閃購／京東到家／淘鮮達）做「半小時送達」，承接即時性需求。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 快消／日用／藥品／生鮮；門店在核心城區；有揀貨配送能力 |
| 不適用 | 低頻高客單耐用消費品；無線下履約能力 |
| 預算量級 | 0.3–3 萬／月（含平台費用與履約） |
| 見效週期 | 1–2 個月 |
| 誰來做 | 門店＋線上運營；需與平台對接 |
| 難度 | ★★☆ |

**怎麼做**：
1. 選品：只上「即時需求高＋毛利夠＋易配送」的 SKU（20–100 個）。產出：上架清單。
2. 優化商品卡片：主圖清晰、名稱含關鍵詞、價格有競爭力。產出：商品頁。
3. 計算「履約成本」：包裝＋配送＋平台佣金，確認單均有利潤。產出：單位經濟表。
4. 設置「起送價與滿減」引導客單。產出：門檻設計。
5. 用站內廣告與平台活動拉首單。產出：推廣計劃。
6. 監控「缺貨率」與「逾時率」，這兩項直接影響平台流量分配。產出：履約看板。

**關鍵技巧**：即時零售的對手是「樓下便利店」，所以價格與速度都要過關；缺貨率是平台流量分配的關鍵；起送價設計得好能顯著提升單均。
**常見錯誤**：把全品類都上架，揀貨效率低；履約成本沒算清，單單虧損；缺貨不及時下架，被平台降權。
**怎麼驗收**：單均利潤、缺貨率、逾時率、月訂單量與復購率。
**案例**：`cases/40-预制菜与方便速食.md`（三全食品）；`cases/29-农业生鲜与供应链品牌.md`（錢大媽）。

### 5.8 出海（選市場／本地化／自播）

**一句話定義**：把國內驗證過的產品與打法搬到海外，但要重新做市場選擇、本地化和流量通路。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 國內見頂；產品有供應鏈優勢；有跨境團隊或願意投入學習 |
| 不適用 | 產品有本地化壁壘（食品口味／尺碼／法規）；資金撐不過 18 個月 |
| 預算量級 | 10–200 萬（首期） |
| 見效週期 | 6–18 個月 |
| 誰來做 | 跨境團隊＋本地合作方 |
| 難度 | ★★★ |

**怎麼做**：
1. 選市場：用「品類搜索量／競品密度／物流成本／合規難度」四項打分，選 1 個市場先做。產出：市場評分表。
2. 選通路：平台型（Amazon／Shopee／TikTok Shop）、獨立站（Shopify）、線下分銷，先選一個。產出：通路決策。
3. 做本地化：包裝文案、產品規格、支付方式、售後政策、客服語言。產出：本地化清單。
4. 合規先行：認證、商標、稅務、標籤法規，一項都不能省。產出：合規清單。
5. 做自播／達人：TikTok 直播與達人分銷是當前主要增長通路。產出：直播排期。
6. 建履約：海外倉或本地倉，先算清「時效—成本」平衡。產出：履約方案。
7. 每月看三數：單件利潤、退貨率、獲客成本，一項不達標就調整。產出：月度看板。

**關鍵技巧**：不要用國內打法硬套（價格戰、直播話術都要改）；先做「小而美」的單點市場，別一上來鋪全歐美；本地化不只是翻譯，是消費習慣。
**常見錯誤**：一上來多市場並行，資源全散；忽略認證與稅務，貨被扣；只看 GMV 不看單件利潤與退貨。
**怎麼驗收**：單件淨利、退貨率、複購率、單市場的月度增長。
**案例**：`cases/20-跨境电商与出海品牌.md`（石頭科技、SHEIN）。

### 5.9 批發與供應鏈

**一句話定義**：把產品賣給 B 端（經銷商／零售商／工廠客戶），用穩定的大單換取現金流與規模。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有生產能力；想做 B 端；產品標準化程度高 |
| 不適用 | 產能不足；無帳期承受能力 |
| 預算量級 | 0.5–10 萬（含展會與樣品） |
| 見效週期 | 3–12 個月 |
| 誰來做 | 銷售團隊＋供應鏈；需財務配合 |
| 難度 | ★★★ |

**怎麼做**：
1. 定「B 端客戶畫像」：是經銷商、連鎖零售、還是工廠配套。產出：客戶畫像。
2. 做「報價體系」：按量分檔，並算清帳期成本（帳期 = 隱性利息）。產出：報價表。
3. 準備「B 端資料包」：資質、檢測報告、產能、交期、樣品。產出：招商資料。
4. 拓客渠道：行業展會、B2B 平台（1688／阿里國際）、老客轉介紹、直拜訪。產出：拓客計劃。
5. 做「樣品測試」：先小批量試單，驗證品質與交期再談大單。產出：試單記錄。
6. 管控「帳期與回款」：設信用額度，超額停止發貨。產出：風控規則。
7. 用 B 端訂單反哺自有品牌（供應鏈能力成為信任背書）。產出：協同計劃。

**關鍵技巧**：B 端要的是「穩定」而不是「便宜」，交期與品質一致性最重要；帳期是最大的隱形殺手，必須算進報價；先做小單建立信任再談大單。
**常見錯誤**：為了接單無限延長帳期，現金流被拖死；報價沒算帳期成本，越做越虧；只做一家大客戶，被對方議價壓死。
**怎麼驗收**：回款週期、客戶複單率、單客戶毛利率、應收帳款週轉。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/40-预制菜与方便速食.md`（安井食品）。

## §6 事件與話題類打法（借勢與造勢）

> 本節解決：**在短時間內獲得大量關注。** 事件類打法是「脈衝式」的，必須配好承接（私域、庫存、客服），否則熱度來得快、走得也快。

### 6.1 聯名合作

**一句話定義**：與另一個品牌／IP 合作推出限定產品或活動，借雙方的粉絲做一次集中爆發。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要一次集中爆發、破圈；品牌年輕化；有話題嫁接點 |
| 不適用 | 品牌缺乏基礎粉絲（借不到力）；找不到契合的聯名對象 |
| 預算量級 | 5–200 萬 |
| 見效週期 | 1–3 個月 |
| 誰來做 | 品牌＋商務；需法務確認 IP 授權 |
| 難度 | ★★★ |

**怎麼做**：
1. 定「聯名目的」：拉新、破圈、還是清庫存。產出：目的界定。
2. 選對象三條標準：粉絲重疊但人群不同、調性有張力（反差有話題）、對方也願意投入。產出：候選名單。
3. 定「聯名產品」：必須是「只有在這次才能買到」的限定款（換包裝不算）。產出：產品方案。
4. 談清權益：授權範圍、使用期限、分成、宣傳義務。產出：合作協議。
5. 造勢節奏：懸念預熱（§6.5）→ 官宣 → 限量開售 → 二次傳播。產出：傳播排期。
6. 準備承接：庫存、客服、物流、二級市場話題管理。產出：承接方案。
7. 復盤：拉新數、話題量、二級市場溢價（重要信號）。產出：復盤報告。

**關鍵技巧**：聯名必須有「限定理由」（過期不補），否則只是換包裝；選「有反差」的對象最容易出話題；二級市場有溢價說明聯名成功。
**常見錯誤**：聯名只有包裝，產品沒變化；雙方都不投入宣傳，變成單方自嗨；限量太少/太多，沒有稀缺感或賣不完。
**怎麼驗收**：話題量與自然討論、聯名款售罄速度、新客佔比、二級市場溢價。
**案例**：`cases/01-餐饮与茶饮.md`（瑞幸 × 貴州茅台、喜茶 × FENDI）。

### 6.2 造節（自己的節日）

**一句話定義**：創造一個屬於品牌的固定節日，讓每年到這個時間用戶就會想起你。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 想固定流量高峰、建立節奏；有明確的品類場景（如夏天／開學／年貨） |
| 不適用 | 品類沒有季節性；沒有持續投入 3 年以上的準備 |
| 預算量級 | 一次性 1–20 萬；每年固定投入 |
| 見效週期 | 6–18 個月 |
| 誰來做 | 品牌＋市場部 |
| 難度 | ★★★ |

**怎麼做**：
1. 選「時間點」：與品類場景強綁定（如冬天第一杯奶茶、會員日）。產出：節日時間。
2. 給節日一個「固定名字與動作」：名字要短、動作要有辨識度。產出：節日設定。
3. 設計「只有這天才有」的權益：限定產品、限定價格、限定活動。產出：權益方案。
4. 做第一年：不要追求大，追求「記住日期」。產出：首年方案。
5. 每年重複同一動作 3 年，形成習慣。產出：三年規劃。
6. 讓用戶參與共創（投票、徵集），把節日變成「大家的」。產出：互動機制。

**關鍵技巧**：節日必須固定在「同一天／同一時間」，才能形成期待；第一年做得小沒關係，關鍵是年年重複；給節日一個用戶能參與的動作。
**常見錯誤**：造了節沒人記得住日期；每年換主題，無法沉澱；第一次就投大錢，第二年撐不住。
**怎麼驗收**：節日當天的銷售峰值、用戶主動提及節日的量、節日的年增長。
**案例**：`cases/01-餐饮与茶饮.md`（麥當勞中國）；`cases/43-婚庆与人生仪式消费.md`（中國婚博會）。

### 6.3 熱點接梗（響應機制）

**一句話定義**：建立一套快速響應機制，讓熱點發生時能在數小時內產出自己的版本。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 品類容易與熱點掛鉤；品牌調性輕鬆、有網感 |
| 不適用 | 嚴肅／專業品類；熱點涉及災難、政治、敏感事件 |
| 預算量級 | 0.5–5 萬／次 |
| 見效週期 | 48 小時內 |
| 誰來做 | 內容團隊；需有「快速拍板」的授權 |
| 難度 | ★★☆ |

**怎麼做**：
1. 建「熱點雷達」：固定人每天盯平台熱榜、行業新聞、社群話題。產出：熱點日報。
2. 定「響應分級」：可以接的（娛樂／生活）、不接的（災難／政治／悲劇）。產出：紅線清單。
3. 建「模板庫」：把品牌的核心賣點轉成 10 個可以套熱點的句式。產出：句式庫。
4. 設定「30 分鐘決策鏈」：誰拍板、誰製作、誰發布，寫清楚避免來不及。產出：響應 SOP。
5. 執行：只做「輕快的 15 秒內容／一張圖」，不追求製作精良。產出：響應內容。
6. 復盤：哪些接了有效、哪些接了反而掉粉，更新紅線。產出：復盤記錄。

**關鍵技巧**：熱點只有 4–24 小時窗口，慢了就沒意義；可以不完美但要快；「不接」也是一種策略，亂接比不接更傷。
**常見錯誤**：蹭災難／敏感事件翻車；接了但內容與品牌無關，用戶莫名其妙；響應太慢，發出來已經過氣。
**怎麼驗收**：響應內容的互動量與漲粉、響應帶來的品牌搜索、負面反饋比例。
**案例**：`cases/01-餐饮与茶饮.md`（海底撈、老鄉雞）。

### 6.4 城市營銷

**一句話定義**：把品牌與一座城市綁定，用城市的文化與情緒換取本地的深度認同。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 本地屬性強（地方餐飲／文旅／區域品牌）；想從本地走向全國 |
| 不適用 | 品牌與城市無關聯；沒有地方政府／文旅資源配合 |
| 預算量級 | 5–100 萬 |
| 見效週期 | 3–12 個月 |
| 誰來做 | 品牌＋本地資源方（文旅／政府） |
| 難度 | ★★★ |

**怎麼做**：
1. 找「城市的一個符號」：一種食物、一句方言、一個地標、一種情緒。產出：城市符號。
2. 把品牌與這個符號綁定：產品命名、包裝、門店設計、內容都呼應。產出：綁定方案。
3. 爭取官方支持：文旅／商務部門的背書與資源位。產出：合作文件。
4. 做「本地專屬」：只有本地才有的產品或體驗。產出：地域限定款。
5. 引爆：本地達人矩陣＋外地遊客的打卡內容同步。產出：傳播排期。
6. 走出本地：在外地的門店複製「城市主題」，把地域感變成品牌風格。產出：擴張方案。

**關鍵技巧**：城市營銷的關鍵是「本地人覺得驕傲」；官方背書能顯著放大效果；要有「外地人來一定要打卡」的理由。
**常見錯誤**：官方不認可，變成自嗨；只做外地人不懂的梗，無法外傳；用完城市符號後沒有累積品牌資產。
**怎麼驗收**：本地人的主動傳播量、外地遊客打卡數、城市主題產品的銷售佔比、政府資源落地情況。
**案例**：`cases/15-教育文旅与本地生活.md`（淄博燒烤）；`cases/10-B2B工业品与农产品区域品牌.md`（哈爾濱、天水麻辣燙）。

### 6.5 懸念預熱

**一句話定義**：在正式發布前有節奏地放出一點資訊，讓用戶自己猜、自己討論、自己期待。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 新品發布需要攢期待；已有一定粉絲基礎；產品本身有話題點 |
| 不適用 | 沒有粉絲基礎（沒人一起猜）；預熱期太長用戶失去耐心 |
| 預算量級 | 1–20 萬 |
| 見效週期 | 2–6 週 |
| 誰來做 | 品牌市場部＋內容團隊 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「一個核心懸念」：只能有一個（新品是什麼／價格多少／和誰合作）。產出：懸念設定。
2. 設計 3–4 個「資訊碎片」，分週釋放：先是輪廓，再是局部，最後是答案。產出：釋放節奏表。
3. 在社群／評論區收集猜測，並給猜對的人獎勵。產出：互動機制。
4. 製造「可討論空間」：留一點爭議性（好／不好看都要有人說）。產出：討論話題。
5. 發布日一次性給出答案，並同步公布「預熱期的猜測合集」。產出：發布內容。
6. 追蹤預熱期間的「主動提及量」與「預約人數」。產出：預熱報告。

**關鍵技巧**：懸念要「能猜得到但猜不全」；預熱期控制在 2–4 週最有效；一定要給參與猜測的人回饋，否則下次沒人參與。
**常見錯誤**：吊太久（超過 6 週）用戶失去耐心；懸念太抽象，沒人猜得出來；預熱很熱但發布日無貨可賣。
**怎麼驗收**：預熱期的討論量與預約數、發布日的首日銷量、預約到購買的轉化率。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞、瑞幸 × 貴州茅台）。

### 6.6 快閃店

**一句話定義**：開一家只存在幾天到幾週的店，用限時稀缺換取打卡與體驗。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要短期曝光＋試用；新品上市；想進新城市試水 |
| 不適用 | 只想做曝光不想沉澱用戶；選址人流本身不足 |
| 預算量級 | 3–60 萬／場 |
| 見效週期 | 2–6 週 |
| 誰來做 | 品牌＋活動執行公司 |
| 難度 | ★★★ |

**怎麼做**：
1. 定「一個到店理由」：限定產品／沉浸體驗／明星到場／免費試用。產出：核心賣點。
2. 選址：人流＋目標人群密度＋社交媒體友好度（好拍照）。產出：選址評估。
3. 設計「必拍場景」：至少一個能出片的裝置或空間。產出：空間設計。
4. 設計「數據獲取」：進店掃碼、試用登記、加私域，每個動作都要有激勵。產出：數據方案。
5. 內容配套：本地達人探店＋用戶自發打卡＋官方帳號直播。產出：傳播排期。
6. 收尾：把快閃店的裝置／內容二次利用到其他渠道。產出：資產再利用清單。

**關鍵技巧**：快閃店的核心 KPI 不是賣貨，是「數據獲取＋內容生產」；一定要有一個「非來不可」的理由；離場後要有沉澱（私域、會員）。
**常見錯誤**：只換來打卡照，沒沉澱用戶；選址在偏僻商場，人流不足；沒有內容配套，全靠路人自發。
**怎麼驗收**：進店人數、內容生產量（UGC 條數）、加私域人數、媒體曝光。
**案例**：`cases/33-箱包皮具配饰.md`（山下有松）；`cases/42-摄影与影像服务.md`（盤子女人坊）。

### 6.7 線下活動引流

**一句話定義**：辦一場有吸引力的線下活動，把周邊人流變成進店客流與私域用戶。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有門店或園區；需要周邊導流；有可承辦活動的場地 |
| 不適用 | 場地本身無人流；活動與生意無關聯 |
| 預算量級 | 0.5–20 萬／場 |
| 見效週期 | 2–6 週 |
| 誰來做 | 門店＋活動執行 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「活動鉤子」：免費體驗、比賽、市集、親子活動，選一個與客群匹配的。產出：活動主題。
2. 選時間：與門店的低峰時段錯開或補峰（如工作日晚上）。產出：時間安排。
3. 做「進店動線」：活動區與銷售區連結，讓參與者必經貨架。產出：場地動線。
4. 定「數據動作」：報名填資料、掃碼進群、領券到店。產出：數據方案。
5. 預熱：社群＋本地達人＋門店海報，提前 1 週。產出：預熱排期。
6. 現場執行 SOP：簽到、引導、轉化、拍照。產出：執行手冊。
7. 會後跟進：48 小時內觸達所有參與者。產出：跟進清單。

**關鍵技巧**：活動必須與主營生意相關，否則來的是「活動愛好者」不是客戶；現場必須設計一個「購買動作」；會後跟進比活動本身更重要。
**常見錯誤**：只來一次，不進私域；活動太泛（如免費送雞蛋），來的人不是目標客群；沒有現場轉化設計，活動結束就結束了。
**怎麼驗收**：活動參與人數、進店率、加私域人數、活動後 30 天成交額。
**案例**：`cases/01-餐饮与茶饮.md`（太二酸菜魚、老鄉雞）。

### 6.8 媒體發布會

**一句話定義**：用一次正式的發布會向媒體與行業宣告「我們要做一件大事」，換取報導與背書。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有明確新聞點（新技術／新品类／大融資／戰略合作）；需要行業與媒體背書 |
| 不適用 | 沒有新聞點（記者不會發稿）；面向純 C 端低價產品 |
| 預算量級 | 3–100 萬 |
| 見效週期 | 1–2 個月 |
| 誰來做 | 公關團隊＋活動執行 |
| 難度 | ★★★ |

**怎麼做**：
1. 提煉「一句話新聞點」：記者會用這個標題寫稿。產出：新聞點。
2. 準備「新聞資料包」：新聞稿、數據、圖片、創辦人簡介（本檔不含人物資訊，採訪由品牌方自行提供）。產出：媒體包。
3. 邀約名單：產業媒體（影響行業）＋大眾媒體（影響消費者）＋垂直 KOL。產出：邀約清單。
4. 設計「可被引用的數據或產品」：發布會要有硬內容，不能只有情懷。產出：核心發布內容。
5. 流程排練：控制在 60–90 分鐘，創辦人講話不超過 20 分鐘。產出：流程表。
6. 會後分發：48 小時內完成通稿分發與二次解讀。產出：分發記錄。

**關鍵技巧**：發布會的成功標準是「報導篇數與質量」，不是現場熱鬧；必須給媒體一個「可以寫的標題」；能現場演示的產品比 PPT 更有說服力。
**常見錯誤**：沒有新聞點，記者不發稿；創辦人講太久，媒體提前離場；會後不跟進，報導量歸零。
**怎麼驗收**：報導篇數與媒體層級、行業內主動討論量、會後一週內的合作諮詢數。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞）；`cases/06-汽车与出行.md`（長城坦克 300）。

### 6.9 公關事件（危機處理）

**一句話定義**：在負面事件發生後，用最快的速度、最誠實的姿態控制損失並重建信任。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 出現產品／服務／言論負面；輿情正在擴散；需要轉危為機 |
| 不適用 | 尚無負面（可先做預案）；事實未查清前不要急著發聲 |
| 預算量級 | 應急 1–50 萬 |
| 見效週期 | 48 小時起，修復期 3–12 個月 |
| 誰來做 | 公關＋法務＋最高決策人 |
| 難度 | ★★★ |

**怎麼做**：
1. 建「危機預案」：常見風險清單＋對應話術＋決策鏈，提前做好。產出：預案手冊。
2. 事發 4 小時內：確認事實、評估範圍、指定唯一發言人。產出：事實核查表。
3. 24 小時內發聲：**承認事實 → 說明處理 → 給出補償 → 承諾改進**，四段不能少。產出：聲明稿。
4. 執行補償：把承諾兌現並公開進度。產出：進度公示。
5. 持續溝通：不迴避、不刪評、不做小動作（刪評是二次危機）。產出：溝通記錄。
6. 修復期：用產品改進與透明化內容重建信任。產出：修復計劃。

**關鍵技巧**：速度 > 完美，慢一步輿論就定型；誠實承認比狡辯有效；唯一發言人，多人發聲必然互相矛盾。
**常見錯誤**：回應太慢或撒謊，二次爆炸；刪評／控評被截圖，火上澆油；只道歉不賠償，用戶不買帳。
**怎麼驗收**：輿情峰值持續天數、負面聲量佔比回落速度、事後 6 個月的品牌搜索與銷售恢復。
**案例**：`cases/02-食品饮料与酒.md`（鐘薛高）；`cases/01-餐饮与茶饮.md`（西貝）。

### 6.10 公益綁定

**一句話定義**：把品牌與一項社會議題長期綁定，用「持續做對的事」換取信任與情感認同。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要信任與情感認同；品類與某個議題天然相關（環保／助農／教育） |
| 不適用 | 只想做一次性曝光（會被看穿作秀）；沒有可持續投入的資源 |
| 預算量級 | 5–100 萬 |
| 見效週期 | 3–12 個月 |
| 誰來做 | 品牌＋公益組織；需財務透明 |
| 難度 | ★★★ |

**怎麼做**：
1. 選「與生意相關的議題」：你賣什麼就關心什麼（賣水的做水源保護）。產出：議題選擇。
2. 找合作方：正規公益組織，需具備公開募捐資格。產出：合作確認。
3. 定「可量化承諾」：如「每賣一瓶捐一分」。產出：承諾條款。
4. 做「透明披露」：定期公開捐贈金額與去向。產出：披露報告。
5. 讓消費者參與：設計可參與的動作（如包裝上寫「你已捐出」）。產出：參與機制。
6. 長期做：至少 3 年，不要一年換一個議題。產出：三年規劃。

**關鍵技巧**：公益要和生意相關，否則顯得刻意；透明是最好的公關；消費者參與感比捐款本身更能換取忠誠。
**常見錯誤**：被扒出作秀或數據不實，反噬更狠；一次做完就停，變成一次性營銷；承諾過度，無法兌現。
**怎麼驗收**：議題相關的品牌好感度、公益相關內容的自然傳播量、參與消費者的復購率。
**案例**：`cases/45-物流与快递服务.md`（順豐專業包裝）；`cases/02-食品饮料与酒.md`（白象）。

## §7 信任類打法（讓人敢買）

> 本節解決：**用戶已經知道你、也有需求，但不敢下單。** 信任類打法是轉化率提升最快的一類，成本低、見效快，且幾乎所有客單 100 元以上的生意都必須做。

### 7.1 評測與背書

**一句話定義**：讓第三方替你說話，用「別人說好」代替「自己說好」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 新品無信任基礎；需要第三方發聲；品類有「王婆賣瓜」的天然質疑 |
| 不適用 | 找不到可信的第三方；產品經不起檢驗 |
| 預算量級 | 0.3–10 萬 |
| 見效週期 | 1–3 個月 |
| 誰來做 | 公關／媒介；需產品端配合送樣 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「要證明的三件事」：安全、有效、值得這個價。產出：信任缺口清單。
2. 選背書類型：**權威機構**（檢測／認證）、**專業人士**（醫生／工程師／主廚）、**垂直媒體**、**真實用戶**。產出：背書組合。
3. 準備「可驗證的證據」：檢測報告編號、專利號、實測數據。產出：證據包。
4. 安排第三方獨立體驗，不給「結論要求」。產出：體驗記錄。
5. 把背書做成「可視化物料」：詳情頁、包裝、門店展板。產出：物料清單。
6. 監控「背書是否被質疑」，有質疑立即補證據。產出：輿情監控。

**關鍵技巧**：能被驗證的背書才有效（有編號、有機構、有日期）；不要買評測結論，會被扒；專業人士的背書比明星更適合功能型產品。
**常見錯誤**：買來的背書被扒，信譽破產；背書放在詳情頁底部沒人看；背書內容與用戶關心的問題不對位。
**怎麼驗收**：詳情頁停留時長、加購率變化、諮詢中「可信嗎」類問題的下降。
**案例**：`cases/31-眼镜与视光.md`（小米 AI 眼鏡 × 明月鏡片）；`cases/20-跨境电商与出海品牌.md`（石頭科技）。

### 7.2 權威認證展示

**一句話定義**：把已獲得的資質、認證、標準用最直觀的方式展示給用戶看。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 專業品類（醫療／母嬰／食品／建材）；用戶對安全與合規敏感 |
| 不適用 | 沒有任何真實認證（不可造假，造假直接違法） |
| 預算量級 | 0.5–20 萬（含認證申請成本） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 合規／品控＋品牌設計 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 盤點已擁有的認證與資質（生產許可、檢測標準、專利、行業協會）。產出：認證清單。
2. 判斷「用戶真正在乎哪一項」，不要全堆上去。產出：優先展示項。
3. 做成「圖形化標籤」放在用戶必看位置（詳情頁前 3 屏、包裝、門店）。產出：標籤設計。
4. 每項認證配一句「這對你有什麼好處」的解釋。產出：解釋文案。
5. 附上「可查詢的編號或連結」，提高可信度。產出：查詢入口。
6. 定期更新（認證過期是常見的翻車點）。產出：到期提醒表。

**關鍵技巧**：認證要「翻譯成人話」（用戶不懂國標編號）；放在決策位置而不是頁尾；可查詢的編號能顯著提升可信度。
**常見錯誤**：把認證堆成一面牆，用戶看不懂；認證過期未更新被用戶發現；展示的認證與用戶關心的問題無關。
**怎麼驗收**：詳情頁跳出率、轉化率變化、諮詢中合規類問題的下降。
**案例**：`cases/20-跨境电商与出海品牌.md`（石頭科技）；`cases/31-眼镜与视光.md`（小米 AI 眼鏡 × 明月鏡片）。

### 7.3 真實用戶證言

**一句話定義**：把用戶的原話蒐集起來，用最真實的樣子展示，讓潛在客戶看到「和你一樣的人已經買了」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有種子用戶但沒收集；用戶決策受同儕影響大（母嬰／教育／3C） |
| 不適用 | 用戶基數太小；證言未經授權使用 |
| 預算量級 | 0–2 萬 |
| 見效週期 | 1 個月 |
| 誰來做 | 社群運營＋內容 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 主動收集：售後回訪、社群、評論區，用「三個問題」引導（你為什麼買／用了多久／效果如何）。產出：證言池。
2. 分三類整理：**功效型**（解決了什麼問題）、**場景型**（什麼場景用）、**對比型**（比之前用的好在哪）。產出：證言分類表。
3. 保留真實感：原文照登、不修飾、允許有小瑕疵。產出：證言卡片。
4. 展示位置：詳情頁、直播間貼片、門店展板、社群。產出：投放位置表。
5. 徵得授權（文字或錄音同意），避免法律風險。產出：授權文件。
6. 持續更新，避免「三年前的證言」。產出：更新節奏。

**關鍵技巧**：有具體細節的證言更可信（「用了 3 週，早上起來不泛紅了」勝過「很好用」）；帶真實場景照（不是擺拍）勝過純文字；負面轉正的證言力量最大。
**常見錯誤**：編造證言被識破；用網圖配假證言；證言與產品宣稱不一致（如食品說療效）。
**怎麼驗收**：詳情頁加購率、社群中用戶主動分享的數量、諮詢轉化率。
**案例**：`cases/03-美妆个护.md`（珀萊雅）；`cases/31-眼镜与视光.md`（寶島眼鏡）。

### 7.4 成分與工藝透明化

**一句話定義**：把配方、原料、工藝攤開給用戶看，用透明換信任。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 品類信任門檻高（護膚／保健品／母嬰／食品）；用戶對「智商稅」敏感 |
| 不適用 | 配方是核心機密且無法迴避（可改為展示工序而非配方） |
| 預算量級 | 0.5–20 萬 |
| 見效週期 | 3–6 個月 |
| 誰來做 | 產品／研發＋內容團隊 |
| 難度 | ★★☆ |

**怎麼做**：
1. 列出用戶最常質疑的 5 件事（含什麼／不含什麼／為什麼貴）。產出：質疑清單。
2. 針對每一項給出「可公開的資訊」：成分表、含量、產地、檢測結果、工藝流程。產出：公開資訊表。
3. 把專業內容「翻譯成人話」：一句成分，配一句「對你有什麼用」。產出：成分卡。
4. 做成系列內容（每集講一個成分／一道工序）。產出：內容系列規劃。
5. 在包裝與詳情頁設置「成分查詢區」。產出：查詢入口。
6. 開放參觀／直播工廠，讓透明可被驗證。產出：開放計劃。

**關鍵技巧**：透明不是把所有資訊丟出來，是「回答用戶真正想問的」；主動講「我們不含什麼」比講「我們含什麼」更有力；工藝透明要和價格掛鉤（解釋為什麼貴）。
**常見錯誤**：講太專業，消費者聽不懂；只講優點不講取捨（顯得不真誠）；透明化後被發現有隱瞞，信任崩塌更嚴重。
**怎麼驗收**：詳情頁停留時長、客單價接受度、關於成分的諮詢轉化率。
**案例**：`cases/03-美妆个护.md`（珀萊雅）；`cases/32-珠宝钟表.md`（老鋪黃金）。

### 7.5 第三方檢測

**一句話定義**：花錢做一次公開的第三方檢測，用機構的公信力對抗「智商稅」質疑。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要對抗「智商稅」質疑；品類有明確可測指標（功效／安全／耐用） |
| 不適用 | 檢測項目與用戶關切不對位（測了沒人關心的指標） |
| 預算量級 | 0.3–5 萬／次 |
| 見效週期 | 1–2 個月 |
| 誰來做 | 品控＋公關；需選有公信力的機構 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「用戶最想被證明的指標」（不是你能測的指標）。產出：檢測項目清單。
2. 選機構：優先國家級／國際互認（CNAS、SGS、Intertek 等），並確認其報告可公開。產出：機構選擇。
3. 送檢並保留完整樣品鏈路憑證。產出：檢測報告。
4. 把報告「可視化」：把結論翻譯成一句話＋圖表。產出：物料。
5. 把報告編號做成可查詢入口。產出：查詢連結。
6. 若結果不理想，先改產品而不是隱瞞。產出：改進決策。

**關鍵技巧**：測用戶關心的指標，不是自己最容易過的指標；報告要能查；把「檢測條件」一併公開，避免被質疑「有條件才達標」。
**常見錯誤**：檢測項目與用戶關切不對位；報告不可查被質疑造假；測出問題後隱瞞，被扒後爆炸。
**怎麼驗收**：諮詢中質疑類問題的下降、詳情頁轉化率、公關負面聲量佔比。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（黃天鵝）；`cases/31-眼镜与视光.md`（小米 AI 眼鏡 × 明月鏡片）。

### 7.6 創始人出鏡背書

**一句話定義**：創辦人用自己的名字與人格替產品做擔保，讓「跑路」的擔心消失。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 品類需要人格擔保（食品／教育／醫療／高客單）；用戶擔心售後與跑路 |
| 不適用 | 創辦人有未處理的負面；創辦人不願承擔（口頭背書不可靠） |
| 預算量級 | 0–3 萬／月 |
| 見效週期 | 2–6 個月 |
| 誰來做 | 創辦人本人＋內容團隊 |
| 難度 | ★★☆ |

**怎麼做**：
1. 讓創辦人做一個「具體承諾」：如「不滿意我親自退」。產出：承諾條款。
2. 承諾要「可執行」：寫明規則與時限（空話無效）。產出：執行細則。
3. 用內容反覆展示承諾：短視頻／直播／詳情頁。產出：內容排期。
4. 讓創辦人親自處理一次投訴並公開過程。產出：案例內容。
5. 保持一致性：承諾不因銷量增長而縮水。產出：履約監控。
6. 若創辦人有專業背景（如醫生／工程師），優先展示專業而非身分。產出：背書重點。

**關鍵技巧**：承諾要「具體到能被檢驗」；創辦人的專業背景比職位更有說服力；一次真實的售後處理比 10 條廣告有效。
**常見錯誤**：承諾太模糊（「做好每一件產品」）；承諾後不執行被用戶截圖；創辦人說錯話翻車，波及品牌。
**怎麼驗收**：售後糾紛的用戶滿意度、詳情頁信任類模組的停留與點擊、退款率與好評率。
**案例**：`cases/01-餐饮与茶饮.md`（老鄉雞）；`cases/29-农业生鲜与供应链品牌.md`（認養一頭牛）。

### 7.7 試用裝策略

**一句話定義**：用一個小規格讓用戶零風險試一次，把「不敢買」變成「先試試」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 客單高、決策門檻高（護膚／香氛／小家電）；用戶對效果有疑慮 |
| 不適用 | 試用裝成本高於獲客價值；產品無法用小規格呈現效果 |
| 預算量級 | 單份成本 3–20 元 |
| 見效週期 | 1–2 個月 |
| 誰來做 | 產品＋電商／私域運營 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 定「試用裝要證明的唯一效果」，不要什麼都試。產出：試用目標。
2. 設計規格：能用 3–7 天（夠判斷效果），成本可控。產出：規格與成本表。
3. 定發放方式：隨正裝附贈、低價單獨售、社群免費領、門店派樣。產出：發放方案。
4. 設置「回購鉤子」：試用裝裡放專屬正裝券，並限定有效期。產出：券策略。
5. 追蹤「試用—購買」轉化路徑，識別哪個渠道的試用轉化最好。產出：轉化追蹤表。
6. 對未回購的試用用戶做二次觸達（問效果，不催單）。產出：回訪話術。

**關鍵技巧**：試用裝要「真的夠用出效果」，太小的試用裝等於沒試；券要有期限；別讓試用裝比正裝更划算（會只賣試用裝）。
**常見錯誤**：只領不買，虧在物流與包裝；試用裝效果不明顯，反而打消購買；沒有券與回訪，試用就白費。
**怎麼驗收**：試用裝發放量、試用後 30 天回購率、單個回購客的獲客成本。
**案例**：`cases/03-美妆个护.md`（完美日記、珀萊雅）。

### 7.8 無條件退換

**一句話定義**：把退換貨門檻降到零，用「你自己承擔風險」換取消費者的下單決心。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 用戶擔心買錯、轉化卡在最後一步；退貨成本可控；產品不易被惡意退 |
| 不適用 | 食品／個護等衛生類不可退品類；退貨成本極高的品類 |
| 預算量級 | 退貨率上浮 2–8% |
| 見效週期 | 2–8 週 |
| 誰來做 | 客服＋財務；需系統支持 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 算清「退貨成本」：物流＋損耗＋人工，與轉化率提升做對比。產出：成本測算。
2. 定規則：如「30 天無理由，運費我出」，規則要一眼看懂。產出：退換政策。
3. 把政策放在「決策位置」：詳情頁、商品標題、客服話術第一句。產出：物料位置。
4. 簡化流程：一鍵申請、免舉證、快速退款。產出：流程設計。
5. 監控「惡意退貨」：設定風控門檻（如同一帳號頻繁退）。產出：風控規則。
6. 對退貨用戶做「為什麼退」的調研，反哺產品。產出：退貨原因報告。

**關鍵技巧**：政策要「口語化到能被記住」（30 天不喜歡就退）；流程越簡單效果越好（要舉證的等於沒有）；退貨原因是最真實的產品反饋。
**常見錯誤**：政策寫在隱蔽處等於沒做；退貨流程複雜，用戶放棄；被惡意退貨拖垮，沒設風控。
**怎麼驗收**：轉化率提升幅度、退貨率、退貨用戶的二次購買率、退貨成本佔營收比。
**案例**：`cases/24-二手与循环消费.md`（只二）；`cases/20-跨境电商与出海品牌.md`（石頭科技）。

## §8 定價與轉化類打法（把流量變成錢）

> 本節解決：**流量已經有了，但轉化率低、客單低。** 轉化類打法見效最快、成本最低，通常是投入產出比最高的一類，任何客戶都應該先做一輪。

### 8.1 價格錨定

**一句話定義**：用一個參照價格讓用戶覺得「現在這個價很划算」，從而提升客單與轉化。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要拉高客單或顯得划算；有高價款與主推款可組合 |
| 不適用 | 單一 SKU、無對比空間；錨點太假（用戶會算出溢價） |
| 預算量級 | 0（策略設計） |
| 見效週期 | 1–3 個月 |
| 誰來做 | 定價／運營 |
| 難度 | ★★☆ |

**怎麼做**：
1. 建立三個價格點：**錨點款**（高價，樹立價值）、**主推款**（想賣的，居中）、**引流款**（低價，拉人）。產出：價格結構。
2. 錨點款要「真實存在且功能更強」，不能只是虛高標價。產出：產品差異表。
3. 在詳情頁做「對比展示」：把三個款並排放，標出各自適合誰。產出：對比模組。
4. 用「原價劃線」時，必須是真實的歷史售價（否則違法）。產出：合規檢查。
5. 測試：A 版只放主推款，B 版放三款對比，看客單與轉化。產出：測試結果。
6. 每季復核價格結構是否還合理。產出：價格復核表。

**關鍵技巧**：錨點的核心是「讓主推款看起來是性價比最高的」；三個價格點最有效，多了用戶會決策癱瘓；錨點必須真實，否則被投訴。
**常見錯誤**：錨點太假，用戶算出溢價；只標高價卻沒有對應價值；原價劃線不實，觸法風險。
**怎麼驗收**：客單價、主推款銷售佔比、轉化率、價格相關投訴數。
**案例**：`cases/32-珠宝钟表.md`（老鋪黃金）；`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）。

### 8.2 套餐設計

**一句話定義**：把商品組合成套餐，用「配套更省」的理由提升客單與轉化。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 單品毛利低，需要提升客單；產品有天然搭配關係 |
| 不適用 | 產品之間無搭配關係；套餐賣爆但毛利為負 |
| 預算量級 | 讓利 3–12% |
| 見效週期 | 1–2 個月 |
| 誰來做 | 產品＋運營 |
| 難度 | ★★☆ |

**怎麼做**：
1. 找「天然搭配」：用戶買 A 也常買 B（用訂單數據找）。產出：搭配關聯表。
2. 定套餐類型：**入門組合**（降低嘗試門檻）、**週期組合**（一次買夠一個週期）、**升級組合**（含高毛利款）。產出：套餐矩陣。
3. 定價格：套餐價要比單買便宜，但整體毛利不能為負。產出：毛利測算表。
4. 在詳情頁／直播間把套餐放在預設選中位置。產出：頁面設計。
5. 給套餐一個「使用場景名字」（如「新手 7 天入門裝」）。產出：命名。
6. 監控套餐佔比與毛利，砍掉虧損套餐。產出：套餐效果表。

**關鍵技巧**：套餐要有一個「使用者故事」（誰在什麼場景用）；套餐裡的高毛利款要「藏在組合裡」而不是單獨賣；週期組合最能提升客單。
**常見錯誤**：為湊客單硬搭不相關商品；套餐打折太狠，毛利為負；套餐讓用戶更難選擇。
**怎麼驗收**：套餐銷售佔比、客單價提升幅度、套餐毛利率、退貨率。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）。

### 8.3 首單鉤子（引流品）

**一句話定義**：設計一個「幾乎不賺錢但讓人願意試一次」的產品，把新客拉進來。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 新客進不來、不敢試；需要快速累積首批用戶與評價 |
| 不適用 | 鉤子太便宜引來純羊毛黨，永遠不買正價；鉤子與正價品無關聯 |
| 預算量級 | 讓利 30–100%（單品） |
| 見效週期 | 2–6 週 |
| 誰來做 | 產品＋運營 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 選「鉤子品」：必須是「體驗得到核心價值」的產品（不是最便宜的那個）。產出：鉤子品。
2. 定價格與限量（免費／1 元／9.9 元），並設定每人限購 1 份。產出：規則。
3. 設計「升級路徑」：鉤子品用完後自然需要正裝（如小樣→正裝、耗材→主機）。產出：路徑設計。
4. 承接：領鉤子的用戶必須進私域或留下聯繫方式。產出：承接 SOP。
5. 追蹤「鉤子客的 90 天復購率」，這才是真正的 KPI。產出：追蹤表。
6. 對未復購的用戶做一次定向喚醒。產出：喚醒方案。

**關鍵技巧**：鉤子品要能「體驗到核心價值」，否則領了也不知道你好在哪；一定要有升級路徑，否則就是純虧；鉤子客的質量用復購率衡量，不用領取量。
**常見錯誤**：鉤子太便宜，引來純羊毛（用完就走）；鉤子與正價品無關，領了也不會買；沒有承接，領完即流失。
**怎麼驗收**：鉤子客的 90 天復購率、鉤子客的 LTV、單個鉤子客的獲客成本。
**案例**：`cases/42-摄影与影像服务.md`（海馬體）；`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）。

### 8.4 免費模式（前端免費後端賺）

**一句話定義**：前端用免費換用戶規模，後端用高毛利服務或耗材把錢賺回來。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 後端有高毛利服務／耗材；產品有網絡效應；有資金撐前期虧損 |
| 不適用 | 沒有後端變現路徑；現金流撐不過 18 個月 |
| 預算量級 | 前期投入 5–100 萬 |
| 見效週期 | 6–18 個月 |
| 誰來做 | 創辦人＋財務；需精算模型 |
| 難度 | ★★★ |

**怎麼做**：
1. 算清「後端轉化率」：多少人會為後端付費、付多少。這是整個模式的生死線。產出：模型測算表。
2. 定「免費的邊界」：免費的部分剛好讓用戶體驗到價值，但不足以完全解決問題。產出：功能分層。
3. 算「單用戶補貼上限」：CAC 必須小於 LTV × 轉化率。產出：補貼紅線。
4. 先小範圍驗證：在一個城市／一個人群跑通，再放大。產出：驗證數據。
5. 設「止損線」：轉化率低於某值即停補貼。產出：止損規則。
6. 逐步收窄免費邊界（隨著用戶習慣形成）。產出：調整計劃。

**關鍵技巧**：免費模式最常死於「後端轉化率算錯」；免費的邊界設計是核心技藝；一定要有止損線，否則越免費越虧。
**常見錯誤**：後端轉化率算太樂觀；免費版太強，沒人付費；補貼換來的用戶沒有真實需求。
**怎麼驗收**：免費用戶到付費的轉化率、付費用戶的 LTV、補貼總額與回本週期。
**案例**：`cases/21-企业服务与SaaS.md`（釘釘、Zoom）。

### 8.5 滿減與湊單

**一句話定義**：設置「滿 X 減 Y」的門檻，讓用戶為了達到金額多買一件。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 已有流量，想提升客單；商品單價低、有組合購買可能 |
| 不適用 | 客單已很高；商品間無組合可能 |
| 預算量級 | 讓利 5–15% |
| 見效週期 | 2–4 週 |
| 誰來做 | 運營 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 定門檻：設在「當前客單的 1.2–1.3 倍」位置，讓用戶「差一點就想湊」。產出：門檻金額。
2. 算清「讓利後毛利」：滿減不能讓整體毛利為負。產出：毛利測算。
3. 在購物車顯示「再買 X 元可減 Y」，推動湊單。產出：購物車提示。
4. 提供「湊單專區」：放低價、高需求的小件商品（如配件、小樣）。產出：湊單商品池。
5. 設置階梯（滿 199 減 20、滿 299 減 40），引導往上一檔湊。產出：階梯表。
6. 監控「湊單商品是否為低毛利品」，避免湊單拉低毛利。產出：毛利監控。

**關鍵技巧**：門檻要「差一點就能達到」，太高沒人湊；湊單區的商品要「本來就想買」；階梯檔位差異要明顯，才有升級動力。
**常見錯誤**：門檻設太高，用戶直接放棄；湊單買一堆低毛利品；滿減常年開，變成變相降價。
**怎麼驗收**：客單價提升幅度、滿減使用率、整體毛利率、湊單商品的動銷。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城、麥當勞中國）。

### 8.6 限時限量

**一句話定義**：給優惠加上時間或數量限制，把「以後再買」變成「現在就買」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 需要節奏感、製造緊迫；有明確的活動節點 |
| 不適用 | 天天限時，用戶不信；庫存不足導致履約問題 |
| 預算量級 | 讓利 5–20% |
| 見效週期 | 1–2 週 |
| 誰來做 | 運營＋客服 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 定「限制類型」：限時（幾小時）、限量（幾百件）、限人（前 N 名）——只選一種為主。產出：限制設計。
2. 讓限制「可見」：倒計時插件、庫存進度條、已搶數量。產出：頁面組件。
3. 提前預告（24 小時前），讓用戶有準備。產出：預告內容。
4. 開搶後的「節奏」：分批放量，製造二次搶購。產出：放量節奏。
5. 售罄後立刻公示，強化稀缺信任。產出：售罄公告。
6. 監控用戶是否開始「疲勞」，降低頻次。產出：疲勞度指標。

**關鍵技巧**：限制必須真實（假限量被發現後信任崩塌）；倒計時與進度條能顯著提升即時轉化；頻次控制在每月 1–2 次。
**常見錯誤**：天天限時，用戶不信了；假限量被截圖，品牌受損；限量後庫存不足，履約出問題。
**怎麼驗收**：活動期轉化率、單場銷售額、用戶對活動的響應度變化（是否遞減）。
**案例**：`cases/32-珠宝钟表.md`（DR）；`cases/42-摄影与影像服务.md`（海馬體）。

### 8.7 會員價

**一句話定義**：用價格分層獎勵會員，讓非會員為了省錢而加入，讓會員為了划算而多買。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有復購客群，想做價格分層；已有會員系統 |
| 不適用 | 非會員基數大且會覺得被歧視；沒有系統支持 |
| 預算量級 | 讓利 5–15% |
| 見效週期 | 1–3 個月 |
| 誰來做 | 會員運營＋系統 |
| 難度 | ★★☆ |

**怎麼做**：
1. 定「會員價的幅度」：要讓人有感但不傷毛利（建議比非會員低 5–15%）。產出：價格表。
2. 加入門檻要低（免費註冊／首單即可），目的是把人變成會員。產出：入會規則。
3. 會員價要「明顯標示」（如「會員價 ¥89，非會員 ¥109」）。產出：商品頁設計。
4. 給會員「額外權益」（免運、專屬客服、優先購），不要只有便宜。產出：權益清單。
5. 在結帳頁推「一鍵入會立省 X 元」，是最有效的入會時機。產出：入會引導。
6. 監控會員與非會員的客單、復購差異。產出：會員報告。

**關鍵技巧**：入會時機選在結帳頁最有效；會員價要能「一眼算出省多少」；權益中「專屬感」比折扣更能留人。
**常見錯誤**：非會員覺得被歧視，流失；會員價太低，毛利受損；會員權益只有折扣，沒有差異。
**怎麼驗收**：會員轉化率（入會人數／訪客）、會員客單與非會員對比、會員復購率。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/01-餐饮与茶饮.md`（蜜雪冰城）。

### 8.8 詳情頁六要素

**一句話定義**：用固定的六個模組重寫詳情頁，系統性解決「看不懂、不信、不敢買」。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 有流量但轉化率低於行業；詳情頁靠自誇文案堆砌 |
| 不適用 | 沒有流量（先解決流量）；沒有證據可用 |
| 預算量級 | 一次性 0.3–5 萬 |
| 見效週期 | 2–4 週 |
| 誰來做 | 運營＋設計 |
| 難度 | ★★☆ |

**怎麼做**：
1. 重寫第 1 屏：**一句話說清你是誰＋解決什麼問題＋一個證據**（不要 logo＋大圖）。產出：首屏方案。
2. 第 2 屏：**用戶痛點場景**（第一人稱描述，讓用戶覺得「說的就是我」）。產出：痛點模組。
3. 第 3 屏：**產品如何解決**（用圖示，不用術語）。產出：原理圖。
4. 第 4 屏：**證據區**（檢測／認證／用戶證言／數據）。產出：證據模組。
5. 第 5 屏：**對比區**（與競品／與舊款的對比表）。產出：對比表。
6. 第 6 屏：**打消疑慮**（售後政策、FQA、快遞時效、客服入口）。產出：FAQ 模組。
7. 上線後做 A/B 測試，逐屏優化轉化。產出：測試記錄。

**關鍵技巧**：第一屏決定 80% 的去留；每個賣點必須配證據；用「用戶說」代替「我們說」。
**常見錯誤**：首屏是大 logo 與品牌故事；全是形容詞沒有證據；模組順序錯（先講自己再講用戶）。
**怎麼驗收**：詳情頁跳出率、停留時長、加購率、轉化率（對標行業均值）。
**案例**：`cases/03-美妆个护.md`（韓束）；`cases/40-预制菜与方便速食.md`（空刻意面）。

### 8.9 客服話術

**一句話定義**：把客服從「回答問題」變成「解決疑慮並促成下單」，用話術把詢單變成訂單。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 詢單多、下單少；客服只會報價格與庫存 |
| 不適用 | 沒有詢單（先解決流量與詳情頁） |
| 預算量級 | 人工，0–1 萬 |
| 見效週期 | 1–2 週 |
| 誰來做 | 客服主管＋運營 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 收集「詢單後沒下單」的 20 個常見問題。產出：疑慮清單。
2. 為每個問題寫「三步話術」：**先共情 → 再給證據 → 最後給一個小推動**。產出：話術庫。
3. 建立「主動提問」機制：不等待，先問「你主要想解決什麼問題」。產出：開場話術。
4. 設定「異議處理」話術：太貴／再看看／怕沒效果，各有應對。產出：異議話術表。
5. 用快捷回覆但不機械：保留個性化稱呼與上下文。產出：快捷短語庫。
6. 每週復盤「詢單轉化率」，更新話術。產出：週報。

**關鍵技巧**：客服的第一句要「提問」而不是「您好」；給一個「小推動」（今日下單贈 X）比講十個賣點有效；把差評與退款原因寫進話術庫。
**常見錯誤**：話術機械被用戶識破；只回答不引導；把「親，還有什麼問題嗎」當結尾。
**怎麼驗收**：詢單轉化率、平均回覆速度、客服滿意度評價、退款原因分佈。
**案例**：`cases/42-摄影与影像服务.md`（海馬體）；`cases/31-眼镜与视光.md`（寶島眼鏡）。

### 8.10 加購推薦

**一句話定義**：在用戶已經決定買的時候，順手推薦一件相關商品，用最低成本提升客單。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 已在成交，想提升客單；有搭配關係的商品 |
| 不適用 | 推薦不相關商品，干擾成交 |
| 預算量級 | 0 |
| 見效週期 | 2–4 週 |
| 誰來做 | 運營＋客服 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 從訂單數據找出「買 A 也常買 B」的組合。產出：關聯商品表。
2. 選「低價、高相關、高毛利」的加購品。產出：加購品池。
3. 設置「加購價」：比單買略便宜，但幅度不用太大（用戶已在買）。產出：加購定價。
4. 在三個位置推：購物車、結帳頁、客服確認訂單時。產出：推薦位置。
5. 話術要「順手」：如「要不要順便帶一支替換刷頭，一起發」。產出：加購話術。
6. 監控加購接受率，砍掉接受率低於 5% 的商品。產出：加購效果表。

**關鍵技巧**：加購品要「買了主商品一定會需要」；推一個就好，推三個等於沒推；客服主動提加購比頁面推薦更有效。
**常見錯誤**：推不相關商品干擾成交；加購品太多選擇癱瘓；加購價太低，變成變相打折。
**怎麼驗收**：加購接受率、客單價提升、加購品的毛利率。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）。

### 8.11 購物車挽回

**一句話定義**：對「加購但沒下單」的用戶做定向觸達，把已經有購買意向的人拉回來。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 加購不下單佔比 30% 以上；有用戶聯繫方式或平台觸達工具 |
| 不適用 | 沒有觸達渠道；加購率高但下單率本來就正常 |
| 預算量級 | 讓利 3–10% |
| 見效週期 | 1–2 週 |
| 誰來做 | 運營＋客服 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 分析「加購未下單」的原因：價格、運費、庫存、忘了、比價。產出：原因分佈。
2. 分頭設計觸達：**忘了**用提醒、**價格**用限時券、**運費**用免運、**比價**用差異說明。產出：觸達策略表。
3. 用平台工具（站內信／簡訊／企微）分渠道觸達，間隔 4 小時以上。產出：觸達排期。
4. 話術不要提「你沒付款」，要提「你的商品快沒了／有優惠」。產出：話術模板。
5. 對 24 小時仍未下單的用戶，給「一次性限時補貼」（用完即失效）。產出：補貼規則。
6. 監控挽回率，並注意「別傷正價客」（優惠只給未下單者）。產出：效果報告。

**關鍵技巧**：觸達要「給理由」而不是「催付款」；第一次觸達不要給錢（先提醒），第二次再給；優惠要限時，否則用戶會習慣等券。
**常見錯誤**：直接降價傷正價客；觸達太頻繁；不分析原因就統一發券。
**怎麼驗收**：挽回率（觸達後 48 小時下單比例）、一次觸達 vs 二次觸達的效果對比、補貼成本佔比。
**案例**：`cases/03-美妆个护.md`（完美日記、韓束）。

## §9 診斷類打法（先搞清楚卡在哪）

> 本節是所有接案的第一步。**沒有診斷就打法，等於亂開藥。** 診斷類打法成本極低、價值極高，建議每個案子的第一週都做一遍。診斷結論必須落到「曝光／信任／轉化／復購／渠道」五個環節中的具體一個。

### 9.1 全鏈路數據表

**一句話定義**：把從曝光到復購的所有環節數據拉到一張表，一眼看出哪一環在漏水。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 所有客戶的第一步；客戶說「生意不好」但說不出哪不好 |
| 不適用 | 完全沒有數據（先建最小可用的數據採集） |
| 預算量級 | 0 |
| 見效週期 | 1–2 週 |
| 誰來做 | 顧問＋客戶的運營／財務 |
| 難度 | ★★☆ |

**怎麼做**：
1. 畫出完整鏈路：曝光 → 點擊／進店 → 瀏覽 → 加購／詢單 → 下單 → 收貨 → 復購 → 推薦。產出：鏈路圖。
2. 為每一環填寫「數量、成本、轉化率」三個數字。產出：全鏈路數據表。
3. 標出「行業基準值」（可查平台公開數據或行業報告）。產出：對照表。
4. 找出「低於基準值最多的那一環」——這就是主卡點。產出：卡點結論。
5. 用一行話寫出結論：「我們卡在 ___ 環節，轉化率 ___，行業均值 ___」。產出：診斷結論。
6. 每月更新一次，追蹤改善效果。產出：月度追蹤表。

**關鍵技巧**：只找一個主卡點，不要同時修五個；沒有行業基準值就無法判斷好壞；數據造假是這個打法最大的死因。
**常見錯誤**：數據造假或口徑不一致，結論全錯；只看最後的成交額，不看中間環節；找到卡點但不落實到打法。
**怎麼驗收**：能否用一句話說清卡點；改善動作執行後該環節數據是否提升。
**案例**：`cases/42-摄影与影像服务.md`（海馬體）；`cases/31-眼镜与视光.md`（寶島眼鏡）。

### 9.2 流失用戶深訪

**一句話定義**：找已經流失的用戶做 1 對 1 深度訪談，聽他們為什麼不買了——這是付錢也買不到的真話。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 復購率低、不知道為什麼；有可聯繫的流失用戶名單 |
| 不適用 | 用戶基數太小；沒有聯繫方式 |
| 預算量級 | 300–500 元／人（訪談費／禮品） |
| 見效週期 | 2–4 週 |
| 誰來做 | 顧問本人訪談（不要交給客服） |
| 難度 | ★★☆ |

**怎麼做**：
1. 定義「流失」：如 90 天未購且無互動。產出：流失定義。
2. 抽樣 15–30 人，覆蓋不同客單與購買時間段。產出：訪談名單。
3. 設計「不誘導」的問題：先問「你當時為什麼買」，再問「後來怎麼沒買了」。產出：訪談提綱。
4. 訪談 30–45 分鐘，全程錄音，不做產品推銷。產出：錄音與逐字稿。
5. 編碼歸類：把原因分成 4–6 類（產品／價格／服務／替代品／需求消失）。產出：歸因分類表。
6. 每類原因對應一個可執行的改善動作。產出：行動清單。

**關鍵技巧**：一定要問「當時為什麼買」，否則聽不到真話；用戶說的「太貴」通常不是真原因，要追問「和什麼比」；找第三方訪談，用戶才敢說實話。
**常見錯誤**：只訪熟人，聽不到真話；訪談中推銷產品；把用戶的表面理由當結論。
**怎麼驗收**：能否列出「流失原因分佈」與對應改善動作；改善後 3 個月復購率是否回升。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（認養一頭牛）；`cases/42-摄影与影像服务.md`（盤子女人坊）。

### 9.3 復購用戶深訪

**一句話定義**：訪談最忠誠的用戶，找出「真正讓人不斷回購的理由」，並放大它。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 想找可放大的買點；要做新客獲取的素材；想開發新品 |
| 不適用 | 復購用戶太少（先做客單—頻次判斷） |
| 預算量級 | 300–500 元／人 |
| 見效週期 | 2–4 週 |
| 誰來做 | 顧問／產品經理 |
| 難度 | ★★☆ |

**怎麼做**：
1. 選「復購 3 次以上」的用戶 10–20 人。產出：訪談名單。
2. 問三個核心問題：**第一次為什麼買**、**為什麼又買**、**會不會推薦給朋友、怎麼推薦**。產出：訪談稿。
3. 重點抓「用戶的原話」，尤其是「描述產品時用的詞」——這些詞就是你的廣告詞。產出：原話庫。
4. 找出「未被自己發現的買點」（用戶在乎但品牌沒在講的）。產出：新買點清單。
5. 把原話轉成內容素材（詳情頁、廣告、證言）。產出：素材轉化清單。
6. 對照流失用戶的原因，找「留與走」的關鍵差異。產出：對比結論。

**關鍵技巧**：用戶描述產品的原話就是最好的廣告文案；注意「用戶在乎但品牌沒講」的點，這是增長機會；一定要問推薦場景（會怎麼說給朋友聽）。
**常見錯誤**：只聽忠粉，樣本偏；把用戶的客套話當結論；訪完不轉成內容素材，白訪。
**怎麼驗收**：能否產出 5 條以上可直接用的用戶原話；新素材的轉化率是否優於舊素材。
**案例**：`cases/43-婚庆与人生仪式消费.md`（蜜絲卡倫）；`cases/31-眼镜与视光.md`（寶島眼鏡）。

### 9.4 競品拆解

**一句話定義**：把賣得好的競品拆到「可抄的動作」層面，搞清楚它到底贏在哪。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 競品賣得好，想抄得明白；要進新市場前先做；定價與定位需要參照 |
| 不適用 | 完全沒有可比競品（新品类） |
| 預算量級 | 0–2 萬 |
| 見效週期 | 2–4 週 |
| 誰來做 | 顧問＋客戶團隊 |
| 難度 | ★★☆ |

**怎麼做**：
1. 選 3 個競品：**領導者**、**直接對手**、**新興挑戰者**。產出：競品名單。
2. 拆四個維度：**產品**（規格／成分／價格帶）、**渠道**（在哪賣）、**內容**（發什麼、發多少、什麼火）、**承接**（詳情頁／客服／售後）。產出：競品拆解表。
3. 做「用戶視角體驗」：完整走一遍競品的購買流程，記錄每個觸點。產出：體驗記錄。
4. 找出「它做對了但你能做得更好的」與「它沒做而你能補的」。產出：機會點清單。
5. 判斷它的成功是「產品力」還是「流量紅利」（決定值不值得學）。產出：歸因結論。
6. 輸出 3–5 個「可執行抄法」。產出：行動清單。

**關鍵技巧**：必須親身做一次競品的完整購買流程，光看數據看不出關鍵；區分「產品力」與「流量紅利」；抄動作不抄表面。
**常見錯誤**：只抄形式（包裝／話術），不懂機制；用舊數據判斷；拆完不落地。
**怎麼驗收**：能否說出「競品贏在哪一個環節」＋3 個可執行動作；執行後相關指標是否改善。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（霸王茶姬、瑞幸咖啡）。

### 9.5 品類機會掃描

**一句話定義**：在既定品類裡系統掃一遍，找出「需求在漲但供給不足」的縫隙。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 想開新品、找新賽道；現有品類增長停滯 |
| 不適用 | 只看宏大趨勢不看自家能力（必失敗） |
| 預算量級 | 0–5 萬 |
| 見效週期 | 2–8 週 |
| 誰來做 | 顧問＋產品 |
| 難度 | ★★★ |

**怎麼做**：
1. 選掃描維度：**人群**（誰在變）、**場景**（新的使用場景）、**價格帶**（哪個價位缺貨）、**規格**（大小／包裝／組合）。產出：維度表。
2. 用平台數據找「搜索增長快但商品供給少」的詞。產出：機會詞清單。
3. 用「需求增速 vs 競爭密度」兩維打分，圈出候選機會。產出：機會矩陣。
4. 對每個機會做「能力匹配」：你有什麼供應鏈／渠道／團隊優勢。產出：能力匹配表。
5. 選 1 個機會做小成本驗證（預售／小批量）。產出：驗證方案。
6. 決定投入或放棄（明確的 go／no-go 標準）。產出：決策記錄。

**關鍵技巧**：機會要「有供應鏈支撐」才算機會，否則只是別人的機會；先做小批量驗證，不要一次備大量庫存；價格帶的空隙常常是最好的機會。
**常見錯誤**：只看趨勢不看自家能力；機會太大（巨頭也看到了）；驗證成本太高，不敢試。
**怎麼驗收**：驗證批次的售罄率與復購率、單品毛利、是否值得加大投入。
**案例**：`cases/40-预制菜与方便速食.md`（空刻意面）；`cases/41-文具文创与办公.md`（貓太子）。

### 9.6 客單-頻次四象限

**一句話定義**：用「客單價 × 購買頻次」兩個維度把生意定位，決定資源該投拉新還是複購。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 不確定該做拉新還是複購；資源分配拿不定主意 |
| 不適用 | 數據不足以算出客單與頻次（先補數據） |
| 預算量級 | 0 |
| 見效週期 | 當天 |
| 誰來做 | 顧問＋老闆 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 算出實際客單價（一年營收／訂單數）與年均購買頻次。產出：兩個數字。
2. 畫四象限：**高客單高頻**、**高客單低頻**、**低客單高頻**、**低客單低頻**。產出：象限定位。
3. 對照策略：高頻高客單重複購與會員；高客單低頻重信任與轉介紹；低客單高頻重規模與便利；低客單低頻要重新審視商業模式。產出：策略對應。
4. 檢查「客戶自以為的定位」與「實際數據的定位」是否一致。產出：落差分析。
5. 據此重排資源優先級。產出：資源分配表。

**關鍵技巧**：「低客單＋低頻」是最危險的象限，必須改模式而不是加投放；客戶的自我認知常與數據不符；象限會隨業務變化，每半年重算一次。
**常見錯誤**：象限判斷錯，資源全押錯方向；用「希望」而非數據定位；定位後不調整打法。
**怎麼驗收**：資源分配是否與象限匹配；半年後客單／頻次是否按預期移動。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（錢大媽、百果園）。

### 9.7 LTV-CAC 測算

**一句話定義**：算出「一個用戶一生能賺多少」與「獲取一個用戶要花多少」，決定能不能放大投放。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 決定要不要放大投放；投放虧損但不知道是否正常 |
| 不適用 | 沒有復購數據（可用 90 天窗口估算） |
| 預算量級 | 0 |
| 見效週期 | 1–2 週 |
| 誰來做 | 財務＋運營 |
| 難度 | ★★☆ |

**怎麼做**：
1. 算 LTV：客單價 × 年均購買次數 × 平均留存年限 × 毛利率。產出：LTV 數字。
2. 算 CAC：總獲客成本／新增客戶數（只算新客，不算復購）。產出：CAC 數字。
3. 計算 **LTV / CAC 比值**，健康線通常為 3:1（【判斷】）。產出：比值。
4. 算「回本週期」：多久能收回獲客成本（超過 12 個月要警惕）。產出：回本週期。
5. 用「首單 ROI」與「90 天 ROI」兩個口徑分別看（首單虧、長期賺是允許的）。產出：雙口徑報表。
6. 設定「投放上限」：CAC 不得超過 LTV ÷ 3。產出：投放紅線。

**關鍵技巧**：一定要用「分渠道」算 LTV，不同渠道用戶質量差異巨大；把退貨與履約成本算進 CAC；不要用最樂觀的復購率。
**常見錯誤**：把復購算太樂觀，LTV 虛高；CAC 沒算退貨與履約；用平均值掩蓋渠道差異。
**怎麼驗收**：LTV/CAC 是否 >3、回本週期是否 <12 個月、分渠道的差異是否被識別並用於分配預算。
**案例**：`cases/40-预制菜与方便速食.md`（自嗨鍋）；`cases/29-农业生鲜与供应链品牌.md`（認養一頭牛）。

## §10 特殊主體專用打法（小企業／新品牌／第二曲線／AI產品／B2B）

> 本節是「整套組合拳」——不是單一打法，而是把前面 9 節的打法按主體類型排成順序。接到這五類客戶時，先看本節的順序，再回去調具體打法。

### 10.1 小店三公里打法

**一句話定義**：一家服務半徑 3 公里的門店，用最小的錢把周邊的人變成回頭客。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 單店、服務半徑 3 公里；預算極有限；周邊有穩定居住或辦公人群 |
| 不適用 | 想服務全市（什麼都做不深）；選址本身人流不足 |
| 預算量級 | 0.3–2 萬／月 |
| 見效週期 | 1–2 個月 |
| 誰來做 | 店主本人＋1 名員工 |
| 難度 | ★☆☆ |

**怎麼做**：
1. 畫「3 公里地圖」：標出周邊的社區、寫字樓、學校、競品，找出你真正能服務的人群。產出：商圈地圖。
2. 定「一個到店理由」並寫在門頭（§1.5）。產出：門頭改造方案。
3. 做「本地生活團購」（§3.4）＋「探店視頻」（§2.4），拿下第一批客流。產出：引流動作。
4. 進店必做三件事：加企微（§4.1 的邏輯用在店內）、發複購券、掃碼進群。產出：店內 SOP。
5. 做「社群運營」（§4.3）：只做一個群，每週 1 次福利、每天 1 條價值內容。產出：群運營表。
6. 做「老帶新」（§4.9）：附近鄰里關係強，裂變成本最低。產出：裂變機制。
7. 每月看三個數：進店人數、加私域人數、復購率。產出：月度看板。

**關鍵技巧**：3 公里的生意靠「熟悉感」，記住老客的名字比發傳單有效；所有動作都要落到「加微信」；不要投大範圍廣告，錢會浪費在不住在附近的人身上。
**常見錯誤**：想服務全市，投了大範圍廣告；不做私域，來一次就沒了；只做開業活動，活動結束客流歸零。
**怎麼驗收**：周邊人群滲透率、加私域人數、30 天復購率、單客月均消費。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（錢大媽）；`cases/23-银发经济与健康养老.md`（足力健）。

### 10.2 單店餐飲全套

**一句話定義**：一家餐廳從開業到穩定的完整節奏，按開業期、磨合期、穩定期分別配置不同打法。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 一家店從開業到穩定；需要完整節奏而不是單點動作 |
| 不適用 | 連鎖品牌（另有總部體系） |
| 預算量級 | 開業期 1–10 萬；穩定期 0.3–2 萬／月 |
| 見效週期 | 3–6 個月 |
| 誰來做 | 店主＋店長＋服務團隊 |
| 難度 | ★★☆ |

**怎麼做**：
1. **開業前 30 天**：定菜單結構（引流菜／利潤菜／形象菜）、門頭改造（§1.5）、周邊探店預熱（§2.4）。產出：開業方案。
2. **開業前 7 天**：上架團購套餐（§3.4）、建社群、印好包裹／桌卡引流物料。產出：物料與套餐。
3. **開業 1–14 天**：控節奏——不要一次爆量，先驗證出餐與服務能力。產出：每日客流與出餐時長表。
4. **開業 15–45 天**：收集評價（大眾點評／抖音），做「證言與評分」（§7.1、§7.3）。產出：評分提升計劃。
5. **第 2–3 個月**：做復購體系（§4.6 會員、§4.10 復購提醒），把首批客人變成回頭客。產出：會員方案。
6. **第 3–6 個月**：做社群與老帶新（§4.3、§4.9），把客流從平台轉到自有用戶池。產出：私域規模。
7. **穩定期**：固定每月活動節奏（§6.2 造節），維持熱度。產出：年度活動日曆。

**關鍵技巧**：開業不要爆量，服務跟不上會毀掉評分；平台流量一定要轉到私域；菜品結構比活動更重要（引流菜撐人氣、利潤菜撐賺錢）。
**常見錯誤**：開業活動爆量後服務崩潰，差評一堆；只做平台不做私域；沒有引流菜，客單撐不住。
**怎麼驗收**：開業 90 天的復購率、平台評分、私域人數、單店月利潤。
**案例**：`cases/01-餐饮与茶饮.md`（太二酸菜魚、海底撈）。

### 10.3 新品牌 90 天

**一句話定義**：零基礎的新品牌，用 90 天跑出「一個能複製的獲客模型」，而不是追求規模。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 零基礎、90 天要見結果；新品上市；預算有限 |
| 不適用 | 想 90 天做規模（不現實）；沒有產品力支撐 |
| 預算量級 | 5–50 萬 |
| 見效週期 | 90 天 |
| 誰來做 | 小團隊（1 個負責人＋內容＋運營） |
| 難度 | ★★★ |

**怎麼做**：
1. **第 1–10 天（定位）**：完成 §1.12 品牌三問、§1.11 單一特性佔位、§1.3 命名與商標檢索。產出：定位 1 頁。
2. **第 11–20 天（面子）**：做符號（§1.1）、包裝（§1.4）、詳情頁（§8.8）、定價結構（§8.1、§8.2）。產出：銷售物料。
3. **第 21–45 天（驗證渠道）**：只選 1 個渠道打透（內容或投放或私域），小預算測 3 組素材。產出：渠道驗證結果。
4. **第 46–60 天（跑通模型）**：找到「可複製的獲客模型」——一組能穩定帶來正 ROI 的動作。產出：模型說明（1 頁）。
5. **第 61–75 天（放大）**：把模型放大 2–3 倍預算，看是否還成立。產出：放大結果。
6. **第 76–90 天（承接）**：建私域與復購機制（§4），把買過的用戶留下。產出：私域規模。
7. **第 90 天覆盤**：輸出下一階段 3 個月的打法清單。產出：覆盤報告。

**關鍵技巧**：90 天只做一個渠道，別什麼都做；成功的標準是「模型可複製」而不是「某一條爆了」；前 20 天必須把物料做完，否則投放會漏錢。
**常見錯誤**：什麼都做，什麼都沒做透；追求單條爆款而不是可複製模型；忽略承接，買過的人留不下。
**怎麼驗收**：是否有一頁「可複製獲客模型」；90 天末的 ROI、私域人數、復購率。
**案例**：`cases/02-食品饮料与酒.md`（元氣森林）；`cases/40-预制菜与方便速食.md`（空刻意面）。

### 10.4 第二曲線品牌架構

**一句話定義**：主品牌老化時，用新的品牌架構承接新人群，避免新舊互相拖累。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 主品牌老化、想開新品牌；老客與新客需求割裂；主品牌溢價下滑 |
| 不適用 | 主品牌還有增長空間（先做 §9.5 品類掃描）；沒有獨立團隊 |
| 預算量級 | 30–300 萬 |
| 見效週期 | 12–24 個月 |
| 誰來做 | 需獨立團隊（不能由主品牌團隊兼職） |
| 難度 | ★★★ |

**怎麼做**：
1. 判斷「用主品牌延伸還是做新品牌」：若新人群與老客「調性衝突」，就做新品牌。產出：架構決策。
2. 設計品牌架構：**獨立品牌**（完全另起）、**背書式新品牌**（「X 出品」）、**副線**（共享品牌但不同系列）。產出：架構圖。
3. 給新品牌獨立團隊與預算，不與主品牌共用 KPI。產出：組織設計。
4. 明確「不共用什麼」：人群、內容調性、渠道、價格帶。產出：隔離清單。
5. 明確「可共用什麼」：供應鏈、財務、法務、後台。產出：共享清單。
6. 給新品牌 18 個月獨立考核期，不要求短期盈利。產出：考核規則。
7. 每半年評估一次：是繼續投、合併還是關閉。產出：評估記錄。

**關鍵技巧**：新品牌必須「獨立團隊、獨立 KPI」，否則一定被主品牌的慣性拖死；品牌架構的關鍵是「隔離」，不是「協同」；背書式新品牌在早期借力最有效。
**常見錯誤**：用主品牌名硬套新人群；新品牌共用主品牌 KPI，被逼著短期盈利；供應鏈共用但品質標準沒對齊，互相拖累。
**怎麼驗收**：新品牌 18 個月的新客成本、復購率、是否形成獨立人群認知；主品牌是否被影響。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/14-零售商超与便利店.md`（名創優品）。

### 10.5 AI 產品的 PLG 與開發者營銷

**一句話定義**：AI／工具類產品靠「產品自己會傳播」來增長，行銷的工作是降低首次使用門檻與建立開發者社群。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | AI／工具類產品，需要自增長；目標用戶是開發者／專業用戶 |
| 不適用 | 產品體驗差（PLG 會放大差評）；純 to C 情緒消費品 |
| 預算量級 | 5–100 萬 |
| 見效週期 | 3–12 個月 |
| 誰來做 | 增長團隊＋開發者關係（DevRel） |
| 難度 | ★★★ |

**怎麼做**：
1. 定「Aha 時刻」：用戶第一次感受到價值的具體時刻，並把到達它的步驟壓到 3 步以內。產出：註冊到 aha 的路徑圖。
2. 設計免費層：**額度剛好夠體驗價值，但不足以解決完整問題**。產出：免費／付費功能分層。
3. 做「可分享的產出」：讓用戶生成的成果自帶品牌標識（水印、連結、模板）。產出：分享機制。
4. 建開發者內容：API 文件、教學、範例專案、開源倉庫。產出：開發者內容庫。
5. 做社群：Discord／GitHub／技術論壇，官方必須在裡面回答問題。產出：社群運營 SOP。
6. 做「模板與插件生態」：讓用戶貢獻模板，形成網絡效應。產出：模板市場。
7. 監控三個數：**激活率**（註冊到 aha）、**免費到付費轉化率**、**週留存**。產出：增長看板。

**關鍵技巧**：PLG 的核心是「首次體驗」，第一天不用完就永遠不會回來；免費層太強沒人付費，太弱沒人體驗到價值；開發者只信「自己試過的」，所以文件與範例比廣告重要。
**常見錯誤**：免費版太強，沒人付費；註冊流程太長，用戶在 aha 前流失；沒有社群，用戶遇到問題就跑了。
**怎麼驗收**：激活率、免費用戶到付費的轉化率、週留存、由分享／模板帶來的新用戶佔比。
**案例**：`cases/42-摄影与影像服务.md`（妙鴨相機）；`cases/21-企业服务与SaaS.md`（Notion）。

### 10.6 B2B 信任營銷

**一句話定義**：面對長決策鏈的大客戶，用「內容＋案例＋關係」慢慢建立信任，而不是做消費品那套廣告。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 大客戶、長決策鏈（3 個月以上）；客單高、決策人多 |
| 不適用 | 做消費品那套（完全打不動）；沒有耐心做 12 個月 |
| 預算量級 | 5–100 萬 |
| 見效週期 | 6–18 個月 |
| 誰來做 | 市場＋銷售＋高層 |
| 難度 | ★★★ |

**怎麼做**：
1. 畫「決策鏈地圖」：誰提出、誰評估、誰批准、誰使用、誰付款，各在意什麼。產出：決策鏈地圖。
2. 為每個角色準備「對應材料」：使用者看效果、評估者看參數、財務看 ROI、老闆看風險。產出：材料矩陣。
3. 做「標杆案例」：把 1 個客戶的真實成果寫成可公開的案例（含數據）。產出：案例 1 篇。
4. 做行業內容：白皮書、報告、行業洞察，用專業度建立權威（§7.1、§7.2）。產出：內容資產。
5. 建「關係網」：行業會議、協會、社群，讓決策者認識你。產出：關係清單。
6. 做「試點（POC）」：用一個小專案證明效果，再談大合約。產出：試點方案。
7. 追蹤「線索培育」：從認識到成交的每個節點記錄與跟進。產出：CRM 記錄。

**關鍵技巧**：B2B 的信任來自「同行用過」；標杆案例的價值遠大於廣告；決策鏈上每個角色的關注點不同，不能用同一份資料。
**常見錯誤**：只對接一個聯絡人，沒覆蓋決策鏈；沒有案例就談大單；用消費品的「爆量」思維做 B2B。
**怎麼驗收**：合格線索數、從初次接觸到試點的時間、試點到合約的轉化率、單客戶獲取成本。
**案例**：`cases/21-企业服务与SaaS.md`（飛書）；`cases/45-物流与快递服务.md`（京東物流）。

### 10.7 區域公用品牌

**一句話定義**：為一個地方產業帶或農產品做區域公用品牌，用統一標準與統一形象把地方貨賣出溢價。

| 項目 | 內容 |
|---|---|
| 什麼情況用 | 農產品／地方產業帶；多家小生產者需要統一出口；政府或協會有推動意願 |
| 不適用 | 沒有統一標準能力；生產者不願執行標準 |
| 預算量級 | 50–500 萬（常為政府專項） |
| 見效週期 | 12–36 個月 |
| 誰來做 | 品牌方＋協會＋政府；需第三方運營主體 |
| 難度 | ★★★ |

**怎麼做**：
1. 定「地區品類」：選一個最有辨識度的產品，不貪多。產出：品類選擇。
2. 制定「統一標準」：品種、種植、採收、分級、包裝，全部寫成可執行的規範。產出：標準手冊。
3. 設計「區域品牌視覺」：區域符號、名稱、包裝體系（§1.1、§1.4）。產出：品牌手冊。
4. 建立「授權與監管機制」：誰能用、怎麼用、違規怎麼罰。產出：授權管理辦法。
5. 做「標杆產品」：先做 1–2 家示範戶，跑通溢價再推廣。產出：示範案例。
6. 渠道落地：電商平台旗艦店、批發市場、文旅場景、直播助農。產出：渠道方案。
7. 做「產地內容」：溯源、產地故事、農民故事（§2.5）。產出：內容體系。
8. 建立「長期運營主體」：不能依賴單次專案預算。產出：運營架構。

**關鍵技巧**：區域品牌的成敗在「標準執行」，不在設計好看；必須有一個可持續的運營主體（否則政府換屆就斷檔）；先做 1 個標杆產品跑出溢價，再擴品類。
**常見錯誤**：只做視覺不做標準，變成「換個包裝」；沒有運營主體，專案結束即停擺；多家生產者品質不一，砸掉牌子。
**怎麼驗收**：授權企業數量與合規率、標杆產品的溢價幅度（農戶收購價提升）、區域品牌的市場認知度。
**案例**：`cases/19-城市与区域公共品牌.md`（好客山東）；`cases/15-教育文旅与本地生活.md`（淄博燒烤）。
