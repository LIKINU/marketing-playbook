## 一、海报文案（5 类母版）

海报不是「把卖点堆上去」，而是「一句话让人停下来」。下面 5 类对应不同任务，每条都给：**主标题 / 副文案 / 行动指令 / 为什么这么写**。

### 1.1 痛点直击型（适合认知低、需求隐性的品类）

```
主标题：你家的空调，可能不是不凉，是没人洗
副文案：3 年没洗的内机，吹出来的风比马桶圈还脏
行动指令：9.9 元上门拆洗 · 本周限前 200 名
底部小字：预约后 24 小时内师傅联系，不干净当场重洗不收钱
```

**为什么这么写**：把「隐性需求」翻译成「可感知的脏」——人对「脏」的反应远快于对「保养」的反应。行动指令给低价锚点 + 限量，降低决策门槛。

### 1.2 结果前置型（适合有硬数据的服务/工具）

```
主标题：30 天，复购率从 18% 涨到 31%
副文案：我们替 300 家门店做了一件事：把老客拉回群里
行动指令：免费领《复购提升 7 步清单》
```

**为什么这么写**：先用结果数字抓眼，再用「我们替谁做了什么」建立可信，「免费领清单」是低门槛钩子（对应获客漏斗的钩子层）。

### 1.3 对立定位型（适合行业有绝对老大、你是老二老三）

```
主标题：不追「更大」，只做「更懂本地」
副文案：全国性品牌标准化的背后，是千篇一律。我们就在你这条街
行动指令：步行 5 分钟到店，今天进店送手写菜单
```

**为什么这么写**：不打「比老大更强」，打「老大做不到的」（本地、近、人情味）。对应对立定位理论——在老大强势处避让，在其弱势处进攻。

### 1.4 场景唤醒型（适合低频、决策重的品类）

```
主标题：爸妈第一次用智能手机的那天
副文案：你不在身边时，它替你多陪他们一会儿
行动指令：带爸妈来体验，我们手把手教到第 3 遍
```

**为什么这么写**：用具体场景触发情绪记忆，把「产品功能」翻译成「关系」。低频品类靠情绪记忆拉动，不靠参数。

### 1.5 权威背书型（适合信任门槛高的品类：金融、医疗、教育、B2B）

```
主标题：服务过 12 家上市公司的财税团队，现在接中小企业
副文案：同样的合规标准，预算只要原来的 1/3
行动指令：免费做一次合规体检，出具风险清单
```

**为什么这么写**：用「服务过谁」做信任前置（信任类打法），再用「同样标准、更低价格」破「大机构贵」的顾虑。

**可抄要点**：① 主标题必须是一句话能念出来的「结论」，不是形容词堆；② 副文案只补一个理由，不写三个；③ 行动指令必须带「动作 + 门槛/时限/利益」三要素之一；④ 底部小字是「不打脸的承诺」，能兑现才写。

## 二、短视频脚本（分镜级，15 秒 / 30 秒）

短视频前 3 秒决定完播。下面给「分镜表」写法：时间 / 画面 / 口播 / 字幕 / 音效。

### 2.1 15 秒「钩子-证明-指令」结构（通用型）

| 时间 | 画面 | 口播 | 字幕 | 音效 |
|---|---|---|---|---|
| 0–3s | 主播举着对比图，表情夸张 | 「别再花冤枉钱买 XX 了」 | 别再花冤枉钱 | 重音「咚」 |
| 3–9s | 屏幕分屏：左错误用法 / 右正确用法 | 「90% 的人都用错了，正确是这一步」 | 90% 用错｜正确做法 | 翻页声 |
| 9–13s | 主播演示正确动作 | 「跟着做，3 天见效」 | 跟着做·3天见效 | 轻快 BGM |
| 13–15s | 手指向评论区 + 产品页箭头 | 「评论区扣 1，发你同款清单」 | 扣 1 领清单 | 提示音 |

**为什么这么写**：0–3s 用反直觉结论当钩子（完播前提）；3–9s 给「错误 vs 正确」的强对比（人爱看自己错在哪）；结尾指令带具体动作「扣 1」，把观看转成互动。

### 2.2 30 秒「场景剧」结构（适合消费品种草）

| 时间 | 画面 | 口播 | 字幕 |
|---|---|---|---|
| 0–5s | 主人公抓狂场景（衣服染色） | 「白衬衫染了怎么办，别急」 | 白衬衫染了？ |
| 5–15s | 产品出场，三步还原 | 「一泡二搓三冲，5 分钟回白」 | 一泡·二搓·三冲 |
| 15–25s | 前后对比特写 + 旁白 | 「上周染的也能救，我家已回购 3 瓶」 | 回购 3 瓶 |
| 25–30s | 购物车弹窗 | 「同款在左下，今天第二件半价」 | 第二件半价 |

**为什么这么写**：用「人人都遇到的倒霉事」开场（共鸣），三步动作可模仿（可抄），「回购 3 瓶」是无意间的信任证据。

**可抄要点**：① 钩子必须是「观众自己的麻烦」，不是「我的产品多好」；② 每屏只讲一件事；③ 口播用口语，字幕提炼关键词；④ 结尾指令和视频挂车/评论区动作一致。

## 三、详情页 / 落地页结构（转化型）

详情页不是信息罗列，是「说服的递进」。下面给标准 8 屏结构，每屏一个任务。

```
屏 1（首屏）：一句话主张 + 主视觉
   · 例：「XX 拖把，一次推完 120 平不脏手」
   · 任务：3 秒内说清「你是什么、解决什么」
屏 2（信任前置）：为什么能做这件事（资质/销量/背书）
   · 例：「连续 3 年品类销量第一【已核实：XX 榜单 2025】」
屏 3（痛点）：用户现在的麻烦（场景化）
屏 4（方案）：产品怎么解决（核心功能 3 点，每点配图）
屏 5（证据）：真实使用前后对比 / 用户原话
屏 6（风险逆转）：不退换吗？→ 写「30 天无理由，坏了包赔」
屏 7（稀缺/紧迫）：限时 / 限量 / 阶梯价
屏 8（行动）：按钮一句话「立即领券，到手价 XX 元」
```

**为什么这么写**：对应 AISAS（注意→兴趣→搜索→行动→分享）的精简版；屏 6 的风险逆转是转化临门一脚（信任类打法：人不敢买常因「怕吃亏」，把风险接过来就敢买）。

**可抄要点**：① 首屏别放 logo 和slogan 占位，直接给「主张 + 利益」；② 证据必须可核实，标来源；③ 行动按钮文案写「利益 + 动作」，不写「了解更多」。

## 四、社群与一线话术（私域 / 销售）

话术是「人话 + 结构」，不是背稿。给三类可直接用的结构。

### 4.1 社群激活话术（沉睡用户唤醒）

```
主题：帮你省了 200 块，顺手提一句
正文：
  哥/姐，翻到您去年买的 XX，刚好赶上我们老客回馈。
  不用您再买，是把您之前那件的耗材免费补一份（价值 39）。
  领取就两步：回「1」，我给您登记。
  （不领也完全 OK，就想让您知道我们记着老客）
```

**为什么这么写**：用「给您补不赚您钱」的姿态降低戒备（私域分层的「轻触达」原则），「回 1」是唯一动作，零门槛。

### 4.2 一线成交话术（门店 / 销售）

```
F（事实）：这款和您看的那款，电机是同一家供应商
A（优势）：所以安静度一样，但这台便宜 400
B（利益）：您每天用，一年省下的电费也够喝几杯奶茶
E（证据）：这是供应商授权书，您手机拍一下留底
```

**为什么这么写**：FABE 结构（特性-优势-利益-证据），把「便宜」翻译成「同样东西少花钱」，用证据收尾防「便宜没好货」的怀疑。

### 4.3 客诉回应话术（舆情 / 售后）

```
第一步（共情，不辩解）：「这事给您添麻烦了，我先替您解决，再查原因」
第二步（动作，给时限）：「今天 18 点前给您处理方案，不行我上门」
第三步（闭环）：「处理后我会回访，您满意了才算完」
```

**为什么这么写**：客诉第一句决定火势。先接情绪再接事，给具体时限（不是「尽快」），闭环回访把差评变忠诚。

**可抄要点**：① 话术给结构不给逐字稿，执行人才能活学活用；② 每句只做一件事；③ 凡承诺必须能兑现，否则写进话术就是埋雷。

## 五、提案 PPT 骨架（大赛 / B端 / G端 / 投标通用）

提案「讲得好」和「写得好」差 30–50 分。下面给 8 分钟 / 12 页骨架。

```
P1 封面：客户名 + 项目名 + 一句核心主张
P2 背景与问题：用 1 张图说清「为什么要做」（SCQA 的 S-C）
P3 核心结论：我们建议做什么、预期得到什么（结论先行）
P4 问题定义：真正的卡点 + 排除了哪些假设
P5 策略主线：目标 → 策略 → 三次收窄（不做什么）
P6–P7 核心打法：挑最强的 2–3 条深讲（为什么 + 怎么做 + 案例）
P8 创意/执行：亮样稿（对应本文库一~四的样本）
P9 排期与分工：谁、什么时候、交什么
P10 预算与效果：分项加总 = 总预算；KPI 与预期
P11 风险与兜底：四件套（为什么发生/预警/兜底/预防）
P12 收尾：回到 P3 的结论，留一个行动号召
```

**为什么这么写**：金字塔原理——每页第一句是结论，全篇第一页就给答案（评委/客户没耐心听铺垫）。P4「排除假设」是咨询公司级动作，证明你想过别的可能。

**可抄要点**：① 永远先给结论再给论证；② 打法只深讲 2–3 条，别贪多；③ 排期必须具体到周/日，不能只写阶段名。

## 六、G 端公文段落（政府项目 / 汇报材料）

G 端第一看合规，第二看绩效，第三才看创意。下面给可直接套的公文段落母版。

### 6.1 政策依据段落

```
本项目紧扣《XX 发展规划（2021–2025）》（X 政发〔2021〕12 号）第三章
「推进 XX 产业高质量发展」相关要求，同时落实《关于 XX 的指导意见》
（X 办发〔2023〕8 号）中「……」条款。项目实施与上级规划形成上下贯通、
同频共振的落实链条。
```

**为什么这么写**：G 端立项先证明「师出有名」——文件名称 + 文号 + 具体条款 + 与本项目对应关系，四者缺一不可。

### 6.2 绩效目标段落

```
围绕「可考核、可量化、可追踪」，设定三级绩效指标：
  一级：带动村集体年收入增长
  二级：年度新增就业人数、游客接待量
  三级：每万元投入带动增收额、培训覆盖率
目标值：村集体年收入由 80 万元提升至 150 万元（2027 年底）；
年度新增本地就业 320 人；游客接待量年增 25%。
```

**为什么这么写**：G 端立项靠「可考核的绩效目标」——指标必须分级、有目标值、有考核方式，否则立不了项。

### 6.3 保障性段落

```
成立由分管领导任组长的专项工作领导小组，文旅局牵头，财政、农业、
人社配合；建立「月度调度、季度考核、年度评估」督导机制；
资金实行专账管理、专款专用，接受审计与社会监督。
```

**为什么这么写**：G 端最怕「写了没人管」。组织保障 + 督导机制 + 资金管理办法，是把「纸面方案」变成「能落地」的三根支柱。

**可抄要点**：① 公文不用形容词，用「文件 + 文号 + 条款」；② 数字必须标来源与口径；③ 绝对化用语（最/第一/国家级）一律不用；④ 承诺必须做得到。

付款节奏：签约付 40%，中期交付付 30%，验收付 30%。知识产权：交付物著作权归客户，我方保留方法论使用权。

### 7.2 投标商务响应偏离表（投标第一优先）

| 序号 | 招标要求 | 我方响应 | 偏离说明 |
|---|---|---|---|
| 1 | 具备 XX 资质 | 完全响应（附证书编号） | 无偏离 |
| 2 | 项目周期 ≤ 90 天 | 完全响应，承诺 85 天 | 正偏离（提前 5 天） |
| 3 | 驻场人员 ≥ 3 人 | 响应，投入 4 人 | 正偏离 |

**为什么这么写**：投标「格式不符 = 废标，一票否决」。偏离表逐条对照，能「正偏离」的标出来（显得更优），「负偏离」超过 N 项直接废标——所以先把「符合性审查表」过一遍再谈创意。

**可抄要点**：① 报价分项加总必须 = 合计，且与给定预算一致；② 偏离表「负偏离」能免则免；③ 资质证书编号、业绩合同号要真实可查。

## 八、使用纪律（别踩的坑）

1. **样本是骨架不是稿件**：数字、品牌、地名全部替换成真实数据；留 【填】 的地方必须填，不能交带占位符的稿。
2. **可信度分级**：样本里的数字若要进对外交付物，必须标【已核实】/【行业认知】/【未核实】；【未核实】不进交付稿。
3. **不挂内部坐标**：本文库是给执行 AI 和客户看的参考，交付稿里不要出现 `cases/xx.md`、`§X.X`、模型码这类内部编号。
4. **合规红线**：绝对化用语（最/第一/国家级/唯一）、医疗功效承诺、金融保本承诺，一律不写。
5. **每个样本都要回答「为什么这么写」**：照抄结构可以，但要知道背后的道理（对应打法库里的方法论），客户追问才接得住。

> 配合阅读：`references/09-完整策划标准与评分表.md`（四类场景必须有哪些章节）、`references/00-打法库.md`（每条打法的原理与案例）。

## 九、反面样板：**写成这样就是不合格**（2026-09-17 补）

> **为什么要有这一节**：本文库原本 26 个样例**全是正面样板**，全库 0 处「不合格／反例」。
> 而模型是**从对照里学会边界的** —— 只给好例子，它改不出「差在哪」。
> 以下 5 组对照，每组都指出**命中了什么病**；「成对替换词表」可直接当检查清单用。

### 9.1 海报主标题

| | 文案 | 命中什么病 |
|---|---|---|
| ❌ 不合格 | 「以专业之力深度赋能眼部护理，打造健康美学新生态」 | 形容词堆叠（赋能／打造／生态）＋没有一个具体动作，读完不知道卖什么 |
| ✅ 合格 | 「你家的眼霜，可能不是没用，是**你没涂够**」 | 先给一个**反直觉的具体判断**，再给一个可执行的动作 |
| 为什么 | | 海报主标题的任务是**让人停下来**。要靠「一句具体到像说你」的话，不靠形容词。 |

### 9.2 短视频前 3 秒

| | 内容 | 命中什么病 |
|---|---|---|
| ❌ 不合格 | 「欢迎来到 XX 品牌，我们致力于为消费者提供高品质的产品与服务」 | 自我介绍开场＋官方腔，观众第 1 秒就划走 |
| ✅ 合格 | 「（镜头：凌晨两点的电脑屏幕）**又是一个两点睡的人。**」 | 前 3 秒给**场景**，不给品牌 |
| 为什么 | | 短视频的前 3 秒只负责一件事：**让对的人认出「这说的是我」**。品牌可以第 8 秒再出来。 |

### 9.3 电商详情页

| | 文案 | 命中什么病 |
|---|---|---|
| ❌ 不合格 | 「匠心工艺，品质之选，为您的美丽保驾护航」 | 三句都是**可套在任何一个品牌上**的话（换品牌也成立） |
| ✅ 合格 | 「专利号 ZL20xxxxxx ｜ 非遗眼药技艺第 4 代 ｜ 可现场试用，不满意当场退」 | 全是**可核查的证据**，换到别的品牌就不成立 |
| 为什么 | | 判据：**把品牌名换成「X」，这句话还成立吗？** 成立＝废话。 |

### 9.4 社群／私域话术

| | 话术 | 命中什么病 |
|---|---|---|
| ❌ 不合格 | 「亲爱的家人们，今天给大家带来一个超值福利，千万不要错过哦～」 | 万能话术，没有**理由**也没有**动作** |
| ✅ 合格 | 「上次说眼睛干的那位，**你问的那支到货了**，今天到店先试，试完不合适我帮你退」 | 给**理由**（你问过）＋给**具体动作**（今天到店试） |
| 为什么 | | 私域话术要回答「**凭什么现在动**」。指向一个具体的人、一件具体的事。 |

### 9.5 G 端公文段落

| | 段落 | 命中什么病 |
|---|---|---|
| ❌ 不合格 | 「本项目积极响应国家号召，深入贯彻落实相关精神，着力推动高质量发展」 | 只有口号，**没有一个文号、没有一个数字** |
| ✅ 合格 | 「依据《XX 市促进消费若干措施》（X政办发〔2026〕12 号）第三条，本项目按 '一店一策' 给予不超过投资额 30% 的支持，拟申请 XX 万元」 | 文号＋条款＋金额，评审可逐项核对 |
| 为什么 | | G 端评审第一关是**依据是否成立**。没有文号的「贯彻落实」＝没有依据。 |
