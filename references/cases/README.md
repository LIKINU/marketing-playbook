1. **只開你客戶所屬的那 1 個行業檔**（見下方對照表）。其餘 44 個行業檔與你的案子無關。

## 四、卡片格式（**2026-09-16 起的統一規範**）

每張深度卡必須有 **五個要素標題**：

```
### 3.N 品牌｜角度（年份）

**① 是什麼** —— 誰、賣什麼、什麼賽道（只講理解這個案子必需的）
**② 為什麼** —— 當時的問題／目標（不是公司困境，是**營銷上的卡點**）
**③ 做了什麼** —— 動作的**實概括**（不是「共 N 件，見④」這種指針）
**④ 怎麼做** —— **精確到每一步**：每步寫「做什麼／要點／產出」
**⑤ 效果** —— 只寫「這次動作造成的結果」＋ ⚠️ 歸因提醒
```

**卡尾建議附三個實用塊**（這是「小客戶怎麼抄」的關鍵）：
- **適配不同規模客戶** —— 大／中／小三個版本分別怎麼抄
- **常見錯誤** —— 照抄時最容易踩的 3 個坑
- **本檔關聯** —— 交叉引用的其他卡號

### ⛔ 硬規則（違反＝這張卡白做）

1. **嚴禁公司背景**：創始人、成立年份、股權、融資、營收、人事 —— 對做營銷毫無用處。
   - **例外**：`46–50` 機構／書籍類可保留「理解其方法所必需」的背景。
   - **卡標題（品牌名）必須留** —— 參考案例就是要知道「參考的是誰」。
2. **唯一允許的數字是「這次營銷動作造成的結果」**（銷量／曝光／門店／復購）；公司財報數字不算。
3. 必須寫**具體動作**（例：「用包裹卡把線下客導到企微、朋友圈按 3:2:1 發、4.8 折社群券替代全量 3.8 折補貼」），
   禁止只寫「私域運營」「品類創新」「超級符號」。
4. 每張卡要有 **「解決了什麼問題」＋「得到了什麼結果」**，且**至少 1 處可信度標記**（`【已核實】`／`【行業認知】`／`【未核實】`）。
   **`【未核實】` 不得寫進對外交付物。**
5. **查不到就寫「未披露」**，不猜不編。編造數字在商務場景會害死人。
