## 一、为什么要这一篇

此前这套 skill 只回答「怎么打」，没回答「一份完整的方案长什么样」。典型后果：

- 打法写得很好，但**没有市场环境分析**——评委／客户不知道你为什么选这个方向
- 有策略没**财务测算**——B 端客户问「花多少、赚多少」答不上来
- 有创意没**媒介排期表**——执行的人不知道哪天发什么
- G 端项目没**政策依据**——第一关就出局
- 投标没**商务响应偏离表**——格式不符直接废标

这些都是「章节缺失」，不是「写得不好」。写得再好，缺一块就是不完整。

## 二、四类交付场景的完整章节

先判断你属于哪一类，再照对应的清单搭骨架。**判断不清就问客户／看征稿通知／看招标文件。**

### 2.1 大赛策划案（大广赛、学院奖、挑战杯、各类命题赛）

官方要求的内容框架（大广赛策划案类）：内容提要 → 市场分析 → 营销策略 → 创意设计执行 → 广告预算及媒介计划。
**规格硬约束**：A4、正文不超过 30 页、附件不超过 10 页、PDF、预算必须符合命题给定的总预算。

| # | 章节 | 必须写什么 | 常见失分点 |
|---|---|---|---|
| 1 | 内容提要 | 一页讲完：背景／问题／核心策略／预期效果 | 写成目录、没结论 |
| 2 | 市场分析 | 行业规模与趋势、品类格局、**目标人群画像（有数据）**、竞品逐个拆、SWOT | 数据不注明出处／没有一手调研 |
| 3 | 问题定义 | 用一句话说清「真正的卡点是什么」，并说明排除了哪些假设 | 把现象当问题（"销量不好"不是问题） |
| 4 | 营销策略 | 目标（可量化）→ 策略主线 → 三次收窄（不做什么）→ 打法组合 | 策略和目标脱节／贪多不收窄 |
| 5 | 创意设计执行 | Big Idea 一句话 → 主视觉／文案／物料样稿 → 传播内容矩阵 | 只有概念没有样稿 |
| 6 | 媒介策略 | 渠道选择理由、触达路径、**排期表（哪天发什么）**、媒介组合占比 | 只列渠道名、没有排期 |
| 7 | 预算与效果 | 分项预算表（**加总＝命题给定的总预算**）、KPI、效果预估、盈亏线 | 预算超命题／加总对不上 |
| 8 | 附件 | 调查问卷原件、访谈记录、数据来源清单、物料完稿 | 没附调查表（官方明确要求） |

**一等奖的分水岭**：现场提案。同一份稿子，讲得好与讲得不好差 30–50 分。所以还要有：
- 提案脚本（8 分钟版，配 PPT 页序）
- 评委问答预判（10 个最可能被问的问题＋标准答法）

### 2.2 B 端商业策划（品牌方／甲方采购）

B 端和大赛最大的不同：**对方要拿这份东西去内部立项、要预算、要背 KPI**。所以必须回答「凭什么信你」。

| # | 章节 | 必须写什么 |
|---|---|---|
| 1 | 执行摘要 | 一页：现状／机会／建议动作／投入／预期回报／风险 |
| 2 | 生意诊断 | 生意拆解（营收＝流量×转化×客单×复购）、逐层找最大的漏、与同行业基准对比 |
| 3 | 市场与竞品 | 市场规模与增速、竞品逐个拆（定位／价格／渠道／传播打法／份额）、我们的位置 |
| 4 | 人群与洞察 | 人群细分（至少 3 类）、优先人群是谁、他的决策链路、真需求与伪需求 |
| 5 | 策略 | 目标（SMART）→ 策略主线 → 不做的事 → 打法组合 → 差异化支点 |
| 6 | 落地方案 | 分阶段（0–1／1–10／放量）、每阶段的动作／渠道／物料／负责人／时间 |
| 7 | **财务测算** | 投入明细、产出模型（LTV／CAC／回本周期）、**盈亏平衡测算**、敏感性分析（乐观／基准／悲观三档） |
| 8 | 组织与资源 | 需要哪些人、现有团队够不够、缺的怎么补、外部供应商清单 |
| 9 | KPI 与追踪 | 北极星指标、过程指标、观测频率、数据来源、谁来盯 |
| 10 | 风险与假设 | 关键假设清单（每条可验证）、风险四件套、Plan B |
| 11 | 排期与里程碑 | 甘特图（文字版即可）、里程碑验收点 |
| 12 | 商务 | 报价／付款节奏／知识产权归属／验收标准 |

### 2.3 G 端政府项目（文旅、乡村振兴、城市品牌、产业招商）

G 端和 B 端最大的不同：**第一看合规，第二看绩效，第三才看创意**。没有政策依据，再好的创意也过不了。

| # | 章节 | 必须写什么 |
|---|---|---|
| 1 | 项目背景与必要性 | 为什么要做（问题导向）、不做的后果 |
| 2 | **政策依据** | 上位规划（国家／省／市三级）、文件名称与文号、具体条款、与本项目的对应关系 |
| 3 | 现状与资源盘点 | 家底清单（资源／资产／文化／产业）、已有什么、缺什么 |
| 4 | 问题诊断 | 用数据说明问题，不空谈 |
| 5 | 总体思路与目标 | 指导思想、基本原则、**可考核的绩效目标**（如：年度游客量、带动就业人数、村集体收入） |
| 6 | 主要任务 | 分工程／分任务，每项写清：做什么、谁牵头、什么时间、花多少、达到什么效果 |
| 7 | 实施路径 | 分期（近期／中期／远期）、年度计划 |
| 8 | **资金与预算** | 总投资、资金来源（财政／专项债／社会资本）、分年度用款计划、资金管理办法 |
| 9 | 保障措施 | 组织保障（领导小组）、人才、技术、督导考核 |
| 10 | **绩效与考核** | 绩效指标表（一级／二级／三级指标、目标值、考核方式） |
| 11 | 风险与应对 | 舆情、安全、资金、实施风险 |
| 12 | 附件 | 政策文件复印件、调研数据、专家意见 |

**G 端红线**：公文格式（标题层级、字号、行距）、字数页数限制、不能用绝对化用语、不能承诺做不到的事、涉密内容不出稿。

### 2.4 投标响应文件（技术标＋商务标）

投标和其他三类都不同：**格式不符＝废标，一票否决**。所以先看招标文件的「符合性审查表」。

| # | 章节 | 必须写什么 |
|---|---|---|
| 1 | **商务响应偏离表** | 逐条对照招标要求，写「完全响应／正偏离／负偏离」，负偏离超过 N 项废标 |
| 2 | 需求理解 | 复述招标方需求，证明你听懂了（很多标输在这一步） |
| 3 | 整体方案 | 思路框架、技术路线、创新点 |
| 4 | 实施方案 | 项目组配置、进度计划、质量保障、交付物清单 |
| 5 | 业绩与案例 | 同类项目业绩（合同／验收证明）、团队资历 |
| 6 | 售后与培训 | 服务承诺、响应时效、培训计划 |
| 7 | 报价 | 分项报价表、总价、付款方式、报价说明 |
| 8 | 资质文件 | 营业执照、资质证书、财务报表、无重大违法声明 |

**投标第一原则**：先把「符合性审查表」逐条过一遍，再谈创意。

## 三、评分标准（可自评）

### 3.1 大赛策划案官方评分（100 分）

| 项 | 分值 | 拿分要点 |
|---|---|---|
| 内容提要 | 10 | 一页讲完，有结论，不是目录 |
| 市场环境分析 | 20 | 数据翔实、**引用注明出处**、附调查表 |
| 营销提案 | 25 | 策略清晰、有取舍、可落地 |
| 创意设计提案 | 25 | Big Idea 有力、有完稿样稿、与策略一致 |
| 媒介提案 | 10 | 渠道选择有理由、有排期表 |
| 广告预算 | 10 | 分项加总＝命题总预算、结构合理 |
| 装帧设计 | 10 | 排版专业、图文比例、易读 |

**现场提案加分维度**（公开评审口径）：创新性、实用性、表现力、答辩应对。

### 3.2 咨询公司级评审维度（MBB／4A 通用）

大赛看「创意＋执行」，咨询公司看「逻辑＋证据＋可落地」。要做到「超过咨询公司级别」，四者都得有：

| 维度 | 权重 | 评审在看什么 | 常见硬伤 |
|---|---|---|---|
| **问题定义准确** | 25% | 是不是在解决真问题；有没有排除其他解释 | 把现象当问题；问题定义和后面的方案对不上 |
| **逻辑严密（MECE）** | 25% | 分解是否相互独立、完全穷尽；结论是否有证据支撑 | 分类重叠或遗漏；结论跳步、没有论证 |
| **可落地** | 25% | 谁做、什么时候做、花多少、怎么验收 | 只有策略没有动作；动作没有责任人 |
| **有增量** | 25% | 有没有别人想不到的洞察／角度／打法 | 全是常识；换个品牌名也成立 |

### 3.3 通用扣分项（任何场景都适用）

| 扣分项 | 典型表现 |
|---|---|
| 数据无出处 | 「据统计」「据调查」后面没有来源 |
| 预算对不上 | 分项加总 ≠ 合计；超命题给定的预算 |
| 目标不可测 | 「提升品牌影响力」「增强用户粘性」 |
| 没有取舍 | 什么都要做，等于没有策略 |
| 逻辑跳步 | 从现象直接到方案，缺论证 |
| 全是形容词 | 「赋能」「抓手」「闭环」堆砌，没有动作 |
| 自我矛盾 | 前面说目标人群是 A，后面做的全是给 B 看的 |
| 承诺做不到 | 「保证销量翻倍」「行业第一」 |

## 四、咨询公司级交付方法（这一节决定你能不能「超过咨询公司」）

### 4.1 SCQA 开场（ Situation–Complication–Question–Answer ）

任何一页、任何一段的开头，都按 S-C-Q-A 走：

- **S 情境**：双方都认的事实（「贵司近 12 个月复购率 18%，行业均值 32%」）
- **C 冲突**：打破现状的事实（「但老客获取的投流成本一年涨了 2.4 倍」）
- **Q 问题**：由冲突引出的问题（「增长该从存量还是增量来？」）
- **A 答案**：你的结论（「从存量复购，因为它更便宜且我们已经有 300 人私域池」）

**检验**：把你的开场念一遍，如果听众第一句就知道你要说什么，就对了。

### 4.2 金字塔原理 ＋ MECE

- **结论先行**：任何一章、任何一段，第一句是结论，后面是支撑
- **以上统下**：上层是下层的总结，下层是上层的解释
- **MECE**：每一层的分类**相互独立、完全穷尽**（如：收入＝流量×转化×客单；人群＝新客／老客／流失客）

**自检**：把每一章的第一句抽出来连读，如果它们能独立讲清整个故事，金字塔就立住了。做不到，说明结构有问题。

### 4.3 假设驱动 ＋ 议题树

不要「收集完数据再下结论」，要「先有假设，再用数据验证」：

1. 先写假设（「我猜卡点是复购，不是获客」）
2. 画议题树：把假设拆成可验证的子问题（复购低 → 是产品问题？服务问题？触达问题？）
3. 每个子问题写：要什么数据、去哪拿、拿到什么结果说明什么
4. 只收集能验证假设的数据（**省时间，且不会淹死在数据里**）

### 4.4 so what 测试

对每一页、每一段、每一张图问一句「所以呢？」：

- 「复购率 18%」→ so what？ → 「比行业低 14 个点，按现有客单，一年少赚 X 万」
- 「我们做了 300 人私域群」→ so what？ → 「这是我们最便宜的复购触点，单客触达成本 0.02 元」

**答不出 so what 的内容，删掉。**

### 4.5 数据三要素（来源／口径／时点）

每一个数字必须能回答三个问题，写不出来就是不合格数据：

| 要素 | 要求 | 写法示例 |
|---|---|---|
| 来源 | 谁出的 | 国家统计局／XX 年报／我方后台 |
| 口径 | 怎么算的 | 复购率＝近 12 个月购买 ≥2 次的客户数 ÷ 总客户数 |
| 时点 | 什么时候的 | 2025 年 7 月–2026 年 6 月 |

> 二手数据标【已核实】／【行业认知】／【未核实】；**【未核实】不得进对外交付物**。

## 六、常见残缺清单（缺一项就是「不完整」）

按场景打勾，缺哪项补哪项：

**所有场景通用**
- [ ] 执行摘要（一页，有结论）
- [ ] 问题定义（不是现象）
- [ ] 数据来源与口径
- [ ] 明确的取舍（不做什么）
- [ ] 排期表（具体到周／日）
- [ ] 预算表（加总对得上）
- [ ] KPI（有基准值）
- [ ] 风险四件套
- [ ] 关键假设与验证方式

**大赛额外**
- [ ] 问卷／调查表原件（附件）
- [ ] 创意完稿样稿（不是只有概念）
- [ ] 符合命题给定的预算上限
- [ ] 提案脚本（8 分钟）
- [ ] 评委问答预判

**B 端额外**
- [ ] 生意拆解（营收＝流量×转化×客单×复购）
- [ ] 财务测算与盈亏平衡
- [ ] 组织与人力可行性
- [ ] 商务条款（报价／付款／验收／知识产权）

**G 端额外**
- [ ] 政策依据（文件名称＋文号＋条款）
- [ ] 可考核的绩效目标
- [ ] 资金来源与使用计划
- [ ] 保障措施（组织／人才／督导）
- [ ] 公文格式合规

**投标额外**
- [ ] 商务响应偏离表（逐条对照）
- [ ] 需求理解（证明听懂了）
- [ ] 业绩证明
- [ ] 资质文件齐全
- [ ] 符合性审查表逐项过一遍
