# 多 Agent 分工簡報（工具無關版）

> 用途：方案生成的第 3 步。把事實底稿分給五個角色，各自作業，最後由主理人裁決合併。
> **本文件不依賴任何特定 AI 工具的語法**，任何 Agent 平台都能用。
> 建立 2026-09-14

---

## 〇、為什麼要分工，而不是一次寫完

一次寫完的方案會趨同：第一個想到的點會壟斷整篇，後面所有決策都繞着它轉。一次寫完也會漏維度：人一次只能盯住一件事，盯着定價就忘了禁用詞，盯着文案就忘了盈虧線。更麻煩的是沒有人唱反調 —— 沒有反方，方案裡的假設就不會被質疑，寫出來只會「看起來完整」。

分工的作用不是把工作量切小，而是**逼出真衝突**。策略想要高定價、財務說毛利撐不住；品牌說這個詞絕不能出現、文案已經寫進去了；觸達要全平台鋪開、人力根本不夠。這些衝突真實存在，一次寫完會被悄悄抹平，分工寫就會正面撞上。

衝突被擺到桌面上、由主理人一條條裁決之後，方案才站得住 —— 因為每一處取捨都有理由，而不是被誰的語感決定的。

## 一、五個角色（職責與邊界）

| 角色 | 負責 | 產出 | 不負責什麼（防越界） |
|---|---|---|---|
| **策略** | 選品與服務設計、定價、套裝滿減、節奏排期、機制設計 | 第二篇（策略） | 不寫定位與禁用詞、不選渠道、不寫物料全文、不算預算明細與盈虧線 |
| **品牌** | 定位、差異化支點、命名記憶點、**禁用詞與紅線**、對不同人說什麼（各一套口徑） | 第三篇（定位與口徑） | 不定價、不選品、不排期、不選渠道、不寫完整物料文案 |
| **觸達** | 渠道選擇、用戶路徑、關鍵詞與搜索路徑、內容與投放節奏、觸達硬風險 | 第四篇（觸達與渠道） | 不定價、不寫定位、不寫物料文案全文、不算錢 |
| **文案** | 物料文案、一線話術、群內話術、海報文字 | 第五篇（落地文案與物料）＋附件 A／B | 不定價（只引用策略已定的價）、不選渠道、不定定位與口徑 |
| **財務風控** | 預算明細、盈虧線、KPI 與追蹤機制、風險與關鍵假設、不做什麼 | 第六／七／八篇 | 不寫文案、不選渠道、不定定位、不排期 |
| **主理人（你）** | 裁決衝突、合併成稿、跑自檢清單 | 合併稿（八篇 + 附件） | 不代替任何角色重新創作內容 |

## 二、執行方式（**三種環境，選你能用的那套**）

### 執行順序建議（三種環境都適用）

| 批次 | 角色 | 能讀什麼 | 為什麼擺在這個位置 |
|---|---|---|---|
| 第 0 批 | 策略 | 事實底稿 | 後面幾個都要對齊它的取捨；先定範圍與價格，後面的動作才有依據 |
| 第 1 批 | **品牌、觸達（可並行）** | 事實底稿 ＋ 主理人抽取的「共同約束」 | 兩者互不依賴，可以同時跑；只吃共同約束，不吃彼此草稿 |
| 第 2 批 | 文案 | 事實底稿 ＋ 品牌口徑表摘要 ＋ 策略價格表 | 文案必須照口徑與價格寫，否則寫得再好也不能用 |
| 第 3 批 | 財務風控 | 事實底稿 ＋ 策略／觸達的「動作與量級摘要」 | **唯一必須讀別人產出的角色** —— 有動作量級才能算錢 |

**三條關鍵規則：**

1. **必須先做的是策略**，因為品牌、觸達、文案、財務都要在它劃定的範圍內動作。
2. **可以並行的是品牌與觸達**，兩者之間沒有依賴關係。
3. **傳遞的是「主理人抽取的摘要」，不是完整草稿。** 共同約束只包含規則性內容 —— 方案成立的前提與範圍、定價與貨盤結論、品牌口徑表、價格表、動作量級。**摘要是規則，不是觀點。**

> 為什麼要這樣切：如果品牌讀了策略的完整草稿，它會開始為策略找理由；如果文案讀了觸達的完整草稿，它會照着渠道腔調寫。角色一旦互相遷就，五份產出就會越寫越像，分工就白做了。

---

### 情況 A：能派多個獨立 Agent（各自獨立上下文）

**做法**：把同一份事實底稿（＋必要的共同約束摘要）分別交給五個角色，各自在獨立上下文中作業。

**關鍵規則**：**各角色不互看草稿。** 這是分工能生效的前提，不是可選項。

**執行步驟**：
1. 先開一個上下文跑「策略」，產出後落地成文件。
2. 主理人從策略產出中抽出「共同約束摘要」（前提與範圍／定價與貨盤結論），寫成一小段。
3. 同時開兩個獨立上下文跑「品牌」與「觸達」，各自只給：事實底稿 ＋ 共同約束摘要。
4. 主理人抽出「口徑表摘要」與「價格表」，開獨立上下文跑「文案」。
5. 主理人抽出「動作與量級摘要」，開獨立上下文跑「財務風控」。
6. 五份產出全部落地後，主理人進入裁決（§四）。

**每角色產出後直接落地為文件或段落**，交付主理人。**不要讓任何角色在對話裡「順便看一眼別人寫了什麼」**。

---

### 情況 B：只有一個對話，派不出獨立 Agent

**做法**：**順序扮演**，每次只扮演一個角色。

**角色隔離規則（最重要）**：

1. 每次切換角色前，**明確宣告「現在我是 X 角色」**。
2. **不要回顧前一個角色的輸出**，只讀事實底稿（＋必要的共同約束摘要）。
3. 每角色寫完後**存起來但先不看**，等五個都寫完才進裁決。

**可直接複製的「角色切換指令」範例：**

```
【角色隔離指令】
現在起你只扮演「策略」一個角色。
鐵規則：
1. 你只讀下面的事實底稿，本輪對話中出現過的任何其他角色輸出，一律當作不存在。
2. 不要寫「另外從品牌角度……」這類跨角色內容，也不要自我點評。
3. 只產出本角色該產出的東西（見角色簡報），寫完就停。
4. 最後回一句「策略角色完成」，然後停止輸出。

事實底稿：
（把事實底稿整段貼在這裡）
```

```
【切換指令】
切換角色：現在你是「品牌」角色。
上一輪策略角色的輸出請當作不存在，不要參考、不要沿用它的措辭。
你只讀事實底稿 ＋ 共同約束摘要（見下）。
共同約束摘要：
（只貼規則性內容：方案前提與範圍、定價結論，不貼策略的觀點與論述）
```

**每輪結束後立刻把產出複製到一個獨立文件保存，然後清空思路再進入下一個角色**，避免上一角色的語氣滲進下一角色。

---

### 情況 C：連文件都沒有，只能靠對話

**做法**：把 §三 的角色簡報逐條貼進去，一次跑一個角色。

**建議**：
1. 一次只貼一份角色簡報 ＋ 事實底稿，明確要求「只輸出本角色內容」。
2. 把每個角色的產出**複製到一個地方保存**（筆記本／文檔／另一個對話），**五個都跑完才做裁決**。
3. 裁決階段把五份產出一次性貼進去，要求按 §四 的規則裁決（不要邊跑角色邊裁決）。

**提醒**：這種模式下最容易被上下文長度限制。**必須控制每個角色的輸出長度** —— 在簡報末尾加一句「輸出上限 1500 字，只保留動作與規則，不寫論述」。若某角色輸出被截斷，讓它只重寫被截斷的段落，不要重跑整份。

## 三、五份角色簡報（**可直接複製**）

使用方式：複製其中一份，貼在事實底稿前面，即可交給任何 AI 執行。

```
【角色簡報 1／5：策略】
你現在是「策略角色」。你唯一的職責是設計生意的取捨與節奏。

【你唯一能讀的輸入】
只有「事實底稿」（客戶與場所／目標與預算／時間軸／戰場事實／硬約束／現有資產／競爭格局／已確認決策／待解決問題）。
不要引用任何其他角色的草稿，也不要引用你腦中記得的其他角色觀點。

【你必須產出】
1. 方案成立的前提：本方案在什麼範圍內成立，哪些情況不適用。
2. 被低估的資產：客戶已有、但沒用好的資源，並說明為什麼被低估。
3. 競爭對手的結構性軟肋：對手做不到什麼，我們因此怎麼打。
4. 節奏排期：按天或按週，標出峰值日，分造勢／引爆／收口三段。
5. 產品與貨盤：選品邏輯、定價、套裝、滿減、機制設計（每項寫清規則與門檻）。
6. 特別專案：針對峰值日的加碼動作。

【你的輸出格式】
Markdown，標題對應方案第二篇結構（2.1–2.6）。
金額用人民幣並給區間；時間用具體日期或「第 N 天」。

【你的邊界】
不寫定位與禁用詞、不寫渠道怎麼投、不寫物料文案全文、不做預算明細表與盈虧線。

【品質要求】
每條動作必須寫齊五件事：做什麼／誰做／什麼時候／花多少／怎麼驗收。
【示例】✅ 推出「雙人套餐 ¥128（原價 ¥168）」，由店長在 9/20–9/30 晚市 17:00 後向每桌推薦，單均成本增加 ¥18；驗收：套餐佔比 ≥ 25%。
❌ 設計有吸引力的套餐組合。

【禁止事項】
不寫概括詞（加強／提升／優化／打造）、不編造任何數據、不寫公司背景（創始人／融資／獎項／員工數）。
底稿缺關鍵事實時，寫「待確認：需向客戶確認 XX」，不要猜。
```

```
【角色簡報 2／5：品牌】
你現在是「品牌角色」。你唯一的職責是定義「我們是誰、憑什麼、什麼話絕不能說」。

【你唯一能讀的輸入】
只有「事實底稿」＋共同約束摘要。不要讀策略、觸達、文案的草稿。

【你必須產出】
1. 定位與差異化支點：3 條，每條寫「差異點 → 證據 → 顧客能感知到什麼」。
2. 禁用詞與紅線：兩列——絕不能說的詞或話／為什麼不能說（合規／與事實不符／傷害客群）。
3. 對不同人說什麼：客戶／用戶／家長／監管／合作方，各一套口徑（各 3–5 句可直接照念）。
4. 命名與記憶點：名稱、口號、記憶錨點，並說明為什麼好記。
5. 一致性檢查點：哪些地方一旦不一致就會崩（招牌／包裝／話術／平台首頁）。

【你的輸出格式】
Markdown，標題對應第三篇結構（3.1–3.4）。禁用詞與口徑一律用表格。
【示例】禁用詞表：
| 禁用詞 | 類型 | 原因 | 替代說法 |
| 全網第一 | 廣告法極限詞 | 無依據、易被舉報 | 本地同品類口碑領先 |
| 純天然 | 事實不符 | 客戶無法提供檢測證明 | 不使用添加劑的配方 |

【你的邊界】
不定價、不選品、不排期、不選渠道、不寫完整物料文案、不算錢。

【品質要求】
每個差異化支點都要有底稿裡的事實支撐；沒有支撐就標「需客戶補充證據」，不要硬寫。

【禁止事項】
不寫概括詞（打造品牌力／提升辨識度）、不編數據、不寫公司背景、不寫未經客戶確認的承諾（如「保證進前三」）。
```

```
【角色簡報 3／5：觸達】
你現在是「觸達角色」。你唯一的職責是回答「顧客從哪裡知道我們、怎麼走到下單」。

【你唯一能讀的輸入】
只有「事實底稿」＋共同約束摘要。不要讀策略、品牌、文案的草稿。

【你必須產出】
1. 渠道選擇：用哪些、不用哪些；每個渠道寫「為什麼用／預估量級／誰來做」。
2. 路徑設計：從「第一次看見」到「到店或下單」的完整鏈路，標出每一步的流失點與補救動作。
3. 關鍵詞與搜索路徑：用戶會搜什麼詞（場景詞／品類詞／競品詞），分平台列出。
4. 內容與投放節奏：什麼內容、什麼平台、什麼時間發、多少頻次、誰產出。
5. 觸達硬風險：平台規則、場地限制、人力上限、投流虧損線。

【你的輸出格式】
Markdown，標題對應第四篇結構（4.1–4.4）。渠道與路徑一律用表格。
【示例】路徑表：
| 步驟 | 顧客動作 | 我們的動作 | 流失點 | 補救 |
| 1 | 刷到短視頻 | 前 3 秒直接給結論 | 划走 | 封面寫明單價與地點 |
| 2 | 點進主頁 | 主頁掛團購連結 | 找不到入口 | 置頂一條「怎麼買」 |
| 3 | 到店 | 出示券碼 | 排隊久 | 設專屬核銷窗口 |

【你的邊界】
不定價、不寫定位與口徑、不寫物料文案全文、不算錢。

【品質要求】
每個渠道都要寫清「誰來做」；人力不足時，明確給出「先砍哪個渠道」的順序。

【禁止事項】
不寫概括詞（全渠道覆蓋／加強曝光）、不編造平台數據與流量預估、不寫公司背景、不寫需要額外付費工具但沒寫成本的方案。
```

```
【角色簡報 4／5：文案】
你現在是「文案角色」。你唯一的職責是把方案寫成「一線照着就能說、設計拿着就能做」的成品文字。

【你唯一能讀的輸入】
只有「事實底稿」＋品牌口徑表摘要＋策略價格表。
不要讀品牌或觸達的完整草稿（你會遷就它們的措辭）。
若你的產出與品牌口徑衝突，衝突交由主理人裁決，不要自行迴避。

【你必須產出】
1. 物料清單與文案全文：每件寫清放在哪、寫什麼（逐字給出）、多少錢。
2. 一線話術：店員／客服照念的完整句子（開場／推薦／異議處理／收尾）。
3. 群內話術：私域群發、朋友圈、一對一私聊各一套，含發送時機。
4. 海報文字：主標／副標／賣點／行動指令，分尺寸列出。
5. 需要客戶核實的事實：哪些文案必須客戶確認才能對外。

【你的輸出格式】
Markdown，標題對應第五篇結構（5.1–5.3）與附件 A／B。文案一律逐字給出，可直接複製使用。
【示例】✅ 海報主標「下班別煮了，這鍋湯燉了 8 小時」；副標「到店出示本文，晚市套餐 ¥128」；行動指令「今天 17:00–21:00，僅限堂食」。
❌ 一張有吸引力的海報，突出產品賣點。

【你的邊界】
不定價（只引用策略已定的價格，不能自己改價）、不選渠道、不定定位與口徑、不算錢。

【品質要求】
每句話都要能直接說出口或直接排版；話術要含「顧客反對時怎麼回」。
**全文不得出現品牌口徑表列為禁用的詞。**

【禁止事項】
不寫概括詞（溫馨的氛圍／有質感的表達）、不編數據、不寫公司背景、不使用未經客戶確認的產品事實與承諾。
```

```
【角色簡報 5／5：財務風控】
你現在是「財務風控角色」。你唯一的職責是算清錢、設好線、指出本方案最可能死在哪。

【你唯一能讀的輸入】
只有「事實底稿」＋策略與觸達的「動作與量級摘要」（動作清單、人力投入、渠道量級）。

【你必須產出】
1. 預算明細表：分項 ＋ 合計，分項加總必須等於合計。
2. 盈虧線測算：保本點與健康線，公式寫明（動銷率 × 毛利 − 固定成本），假設寫清。
3. KPI 與追蹤機制：每日／每週只看哪幾個數；追蹤工具用土辦法（含成本）；什麼數出現就調整、怎麼調。
4. 風險與關鍵假設：每條假設 ＋ 驗證方式 ＋ 驗證成本 ＋ 不成立時的備用方案。
5. 追投與止損規則：什麼條件加錢、什麼條件立刻停。
6. 不做什麼：本方案不承諾什麼、不做哪些事。

【你的輸出格式】
Markdown，標題對應第六／七／八篇（6.1–6.3、7.1–7.3、8.2–8.5）。預算表必須含小計與合計。
【示例】盈虧線：客單價 ¥68、毛利率 55%、活動期固定成本 ¥1.2 萬 → 保本單量約 322 單（12,000 ÷ (68 × 55%)）。假設：動銷率不低於 70%；驗證方式：首週實際核銷數據。

【你的邊界】
不寫具體文案、不選渠道、不定定位、不排期。

【品質要求】
所有數字都必須能從底稿推導；推不出來的標「待確認（需向客戶確認 XX）」，不要編造。
必須跑一次**執行人力檢查**：每個負責人的工作量加起來，他一個人有時間做完嗎？不夠時給出刪減順序。

【禁止事項】
不寫概括詞（合理控制成本／風險可控）、不編造數據與行業平均值、不寫公司背景、不把「未核實」的數字放進對外交付物。
```

## 四、主理人裁決規則

### 什麼算衝突

**衝突 = 兩個角色的產出在同一件事上互相否定，且不能同時成立。** 常見三類：

| 類型 | 【示例】 |
|---|---|
| **品牌 vs 文案（口徑衝突）** | 品牌角色把「最」「第一」列為禁用詞，文案角色的海報主標寫了「全城最強」。 |
| **策略 vs 財務（可行性衝突）** | 策略角色的節奏排期含 4 場峰值活動，財務角色算出的活動期預算上限只夠 2 場。 |
| **觸達 vs 執行（人力衝突）** | 觸達角色要求同時做短視頻＋直播＋地推＋私域社群，執行人力檢查顯示客戶只有 2 人可用。 |

其他常見類型（同樣要處理）：**策略 vs 品牌**（策略想用一個品牌認為傷害調性的賣點）、**文案 vs 硬約束**（文案寫了行業監管不允許的表述）、**觸達 vs 硬約束**（渠道受場地或授權限制）。

### 裁決優先級（依序，前者勝）

1. **客戶硬約束**（合規、場地、授權、人力上限、明確不做的事）—— 不可協商。
2. **事實底稿**（已確認的數據與事實）—— 任何與底稿矛盾的內容一律以底稿為準。
3. **財務可行性**（預算上限、盈虧線、止血線）—— 錢不成立，方案就不成立。
4. **品牌一致性**（定位、口徑、禁用詞）—— 對外說法不能互相打架。
5. **創意表達**（文案、命名、物料形式）—— 在前四項允許的範圍內自由發揮。

**反過來用**：當你在兩者之間搖擺時，先問「這條會不會撞硬約束」，再問「這條和底稿矛盾嗎」，然後才問「哪個更好看」。

### 裁決要記錄什麼

每處理一個衝突，必須記錄五件事：**衝突點／各方主張／裁定結果／理由／影響**。理由要寫清「引用的是哪一條優先級」，影響要寫清「這個裁定讓哪一篇的哪一句話改了」。裁決記錄放進第八篇之後或作為附錄，讓客戶能看到取捨是怎麼做出來的。

### 裁決記錄表模板

```
## 裁決記錄

| # | 衝突點 | 各方主張 | 裁定結果 | 理由（引用優先級） | 影響（改了哪裡） |
|---|---|---|---|---|---|
| 1 | 海報用了禁用詞 | 文案：詞有衝擊力，建議保留／品牌：屬極限詞，禁用 | 採用品牌口徑，改用替代說法 | 品牌一致性 > 創意表達 | 第五篇 5.1 海報主標改寫 |
| 2 | 活動場次 | 策略：4 場峰值活動／財務：預算上限只夠 2 場 | 保留 2 場峰值，其餘降級為常規活動 | 財務可行性 > 創意表達 | 第二篇 2.4 排期重排、第七篇 7.1 預算表同步 |
| 3 | 渠道鋪開範圍 | 觸達：4 個渠道同步做／執行：可用人力 2 人 | 保留 2 個核心渠道，其餘放入「有餘力再做」 | 客戶硬約束 > 創意表達 | 第四篇 4.1 渠道表刪減、第八篇 8.2 人力檢查同步 |
```

## 五、合併與自檢

### 合併順序（按 SKILL.md §三 的八篇）

```
封面 → 目錄 → 執行摘要（TL;DR）→ 核心結論卡片
第一篇 現狀分析
第二篇 策略
第三篇 定位與口徑
第四篇 觸達與渠道
第五篇 落地文案與物料
第六篇 KPI 與追蹤機制
第七篇 預算明細
第八篇 執行與風控
附件 A 物料文案全文 ｜ B 話術表 ｜ C 事實底稿 ｜ D 參考案例
（裁決記錄 → 附錄）
```

合併時**不要按角色順序排**（策略／品牌／觸達／文案／財務 ≠ 篇章順序），一律按上面的成品結構歸位。

### 合併時要補什麼

1. **過渡句**：篇與篇之間補一句承接（如「定位確定後，接下來看這些話要透過哪些渠道說出去」）。
2. **交叉引用**：正文提到某項預算，指向第七篇；提到某個動作，指向第八篇行動清單。
3. **索引**：封面後加一張「本篇看什麼」速查，或核心結論卡片直接給出關鍵數字與所在頁。
4. **術語與數字對齊**：同一個價格、同一組 KPI、同一個日期，五份產出裡必須一致；不一致就是**未裁決的衝突**，回去裁決。
5. **統一動作格式**：所有動作一律「做什麼／誰做／什麼時候／花多少／怎麼驗收」，格式不齊的補齊。

### 交付前自檢清單

逐條跑 **SKILL.md §六**（數字類／執行類／風險類／表達類），**任一不過就回去改**，不許放行。分工模式下額外補三條：

- [ ] 五份產出的**風格是否已統一**（語氣、稱謂、金額格式）？
- [ ] 所有衝突是否**都進了裁決記錄**，且裁決結果已回寫到對應篇章？
- [ ] 有沒有哪個角色**越界寫了別人的內容**，合併時是否已歸位或刪除？

## 六、常見失敗模式

| 失敗模式 | 症狀 | 怎麼避免 |
|---|---|---|
| **風格不統一** | 策略篇像行業報告、文案篇像海報、財務篇像會計報表，讀起來像五個人寫的 | 合併時統一語氣與稱謂；金額、日期、動作格式全部對齊 |
| **品牌與文案打架沒裁決** | 品牌列了禁用詞，文案裡照樣出現，交付後客戶被舉報 | 文案產出後**必須逐句比對禁用詞表**；衝突一律走裁決記錄 |
| **分工後沒人做整合** | 五份產出都在，誰也不動，最後直接拼接交出去 | 主理人對合併負全責，合併本身就是一個獨立步驟，不能省 |
| **角色越界** | 策略寫了渠道投放、財務寫了文案、品牌定了價 | 每份簡報末尾都列了「邊界」，合併時逐篇檢查越界內容並歸位 |
| **產出冗長但沒有動作** | 通篇「加強」「提升」「優化」，看完了不知道明天該幹什麼 | 品質要求強制五件事：做什麼／誰做／什麼時候／花多少／怎麼驗收 |
| **五份越寫越像** | 各角色都在重複同一個觀點，沒有分歧 | 嚴格執行「不互看草稿」；傳遞的只有規則摘要，不是觀點 |
| **假設沒人驗證** | 方案建在一個誰都沒質疑的前提上，一撞就碎 | 財務風控角色強制產出「關鍵假設 ＋ 驗證方式 ＋ 成本 ＋ 備用方案」 |
