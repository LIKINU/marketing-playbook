# marketing-playbook · 使用說明

> 一句話：**你把客戶狀況說出來，它給你一套能用的營銷打法。**
> 不是查資料，是生成方案。

---

## 一、怎麼觸發

### 情況 A：已裝到 skills 目錄（裝好後）
直接說人話就會觸發，例如：
> 「客戶是武漢光谷的川菜館，一家店，人均 60，月流水 25 萬，隔壁新開兩家同行，客流掉了三成，預算 3 萬，老闆自己幹。給我一套打法。」

### 情況 B：沒裝（手動指路）
開頭加一句：
> 「讀 `$HOME/Desktop/Marketing-skill/marketing-playbook/SKILL.md`，然後：客戶是……」

---

## 二、怎麼問（六種常用句式）

| 你想幹嘛 | 這樣說 |
|---|---|
| **要一套打法**（最常用） | 「客戶是 {行業}，{規模}，{卡點}，預算 {X}，有什麼打法？」 |
| **要正式方案文檔** | 上面 + 「出正式方案」 |
| **想看同行案例** | 「{行業} 這個行業，別人做過哪些能抄的案例？」 |
| **想诊断卡点** | 「客戶投了很多錢效果不好，幫我診斷卡在哪」 |
| **要風險自檢** | 「幫我過一遍這方案會怎麼失敗」 |
| **要報價／分工建議** | 「這事該外包還是自己幹？怎麼報價？」 |

**說得越像人話越好，不用套格式。** 缺的資訊它會按 §五 對接實測清單問你。

---

## 三、它內部怎麼工作（三步）

**第 1 步：收集狀況** —— 拿不到完整資訊時，它會按 SKILL.md §五 的「對接實測清單」問你（分 8 組：生意基本盤／目標卡點／預算決策／資源能力／競爭市場／做過什麼／硬約束／交付期待）。
> 你**當面對接客戶時也可以直接用這份清單**，照着問，當場填。

**第 2 步：定位問題** —— 先判「這是認知問題（記不住、說不清）還是交易問題（不買、不回頭）」，再歸到 8 類（A 說不清／B 增長停滯／C 0-1／D 老化／E 復購／F 多品牌／G 出海／H 組織資本）。

**第 3 步：生成方法** —— 按 SKILL.md §三 的七節模板輸出：
診斷 → 打法組合（3–5 條）→ 排期 → 預算分配 → 風險自檢 → 不承諾的事 → 下一步（只寫一件事）。

## 四、裡面有什麼（按使用頻率）

| 什麼時候讀 | 讀哪個 |

| **生成時最先讀** | `references/打法库.md` — 104 條打法，§0 有總表一頁速查 |

| 要用具體模型 | `references/90-方法论操作手册.md` — 63 個模型，含怎麼填、輸出物、常見錯誤 |

## 五、怎麼讓它越用越準

**每次對接或項目結束後，說一句**：
> 「把這次學到的合併進 skill」

它會按 SKILL.md §六 的規則處理：

| 你拿到的東西 | 合併到 |
|---|---|
| 新打法 | `references/打法库.md` |
| 新案例 | `references/cases/{行業}.md`（清單加一條，值得深挖的寫深度卡） |
| 新失敗 | `references/26-失败归因总库.md` |
| 新的好問法 | `SKILL.md` §五 對接實測清單 |
| 新模型／工具 | `references/90-方法论操作手册.md` |

**紅線**（不會寫進去）：公司背景、創始人、營收人事、與營銷動作無關的八卦、未核實數據、客戶隱私。

---

## 六、兩條使用紀律

1. **數據三級標註**：【已核實】／【行業認知】／【未核實】。**【未核實】不能寫進給客戶的交付物。**
2. **生成的方案一定做風險自檢**（對照 §五 失敗歸因），別只交好聽的。
