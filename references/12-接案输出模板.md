# 接案輸出模板庫

> 用途：接案五步中每一步的標準交付物模板。**直接複製填寫，不要每次從零想。**
> 合規提醒：對外產出的模板（方案、一頁紙）**一律自動剔除「內部備註」內容**（底價、對人判斷、內部策略），見 AI協作總規範 §3.2。

---

## 模板 1：客戶體檢表（收案第 1 步）

> 用途：見客戶前後 30 分鐘內填完。**缺的欄位直接留空，不猜不編**（硬規則①）。
> 內部版（含底價與對人判斷），不外發。

```markdown
# 客戶體檢表 · {客戶名} · {YYYY-MM-DD}

## 一、生意基本盤
| 項 | 內容 |
|---|---|
| 行業／品類 | |
| 成立年份／規模（門店數／營收量級） | |
| 客單價 | |
| 復購頻次 | |
| 有無線下門店／貨架 | |
| 主要渠道 | |

## 二、目標與卡點
| 項 | 內容 |
|---|---|
```

## 模板 2：Creative Brief（內部對齊用）

> 用途：出招前把「為什麼做這件事」鎖死。**一頁，不超過這個長度。**

```markdown
# Brief · {項目} · {日期}

**1. 生意問題**（一句話，不是傳播問題）
例：門店月均客流下滑 20%，需拉回周邊 3 公里內的復購人群。

**2. 目標人群**（不是人口統計，是場景中的具體人）
例：工作日在附近上班、每天下午要一杯提神飲料的 25-35 歲上班族。

**3. 消費者現在的認知 → 我們要的認知**
現在：___ ／ 要變成：___

**4. 核心信息（一句話）**
＿（必須能壓縮到 15 秒／一句歌詞／一個門頭，見華與華「購買理由一句話化」）

**5. 我們期待消費者做出的行為**（不是「知道」，是「做什麼」）
例：進店掃碼領券 → 當天核銷。

**6. 必須遵守的資產**
品牌符號／既有話語／合規紅線：

**7. 交付物與數量**
**8. Deadline**
**9. 驗收指標（事前約定 3 個）**
```

## 模板 3：方案骨架（對客戶提案用）

> 用途：五步工作流的第 4 步產出。**結論先行**（金字塔原理），第一頁給答案。

```markdown
# {客戶} 營銷方案 · {日期}

## 第 1 頁：結論（一張紙講完）
- 你的問題是：___（歸到 A-H 哪一類）
- 我們建議的做法：___（流派 + 一句話）
- 三個月內你會看到：___（可驗收的指標）
- 需要你配合的事：___（只寫一件）

## 第 2 頁：診斷（為什麼是這個問題）
- 數據事實 3 條（從客戶自己的數據來，不是你猜的）
- 排除掉的假設（顯示專業度）

## 第 3 頁：選型（為什麼用這套打法）
| 可選路徑 | 誰在用 | 成本量級 | 見效週期 | 為什麼選／不選 |
|---|---|---|---|---|
| | | | | |

## 第 4 頁：打法（核心，占方案一半篇幅）
按流派拆動作，每個動作寫四件事：
1. 做什麼
2. 誰負責
3. 花多少錢
4. 怎麼驗證（哪個指標、多久看一次）

## 第 5 頁：排期（三段式）
- 第 1 個月（見信號）：___
- 第 2-3 個月（跑通）：___
- 第 4-12 個月（放大）：___

## 第 6 頁：報價與分工
見模板 4。

## 第 7 頁：風險與不做什麼
- 明確寫出不承諾的事（例：三個月內做不到品類第一）
- 明確寫出風險與應對

## 附錄（內部版才給）· 不外發
- 各家流派的可複用套路原文
- 競品情報
- 我方利潤結構
```

## 模板 4：報價結構

> **核心原則：盡量按項目／按週期收服務費，不要按媒介流水抽點。**
> 依據：媒介代理毛利只有 1.5%-5%，項目制服務費能到 15%-20%（華揚聯眾的轉型核心就是這個）。

| 收費模式 | 適用 | 優點 | 風險 |
|---|---|---|---|
| 年度服務費（retainer） | 長期陪跑、需要持續輸出的客戶 | 現金流穩定 | 甲方會壓價、要求無限次改稿 |
| 項目制（固定價） | 邊界清晰的單次交付（上市 Campaign、符號升級） | 毛利高、責任清晰 | 需求蔓延（scope creep） |
| 按階段里程碑 | 大項目分期 | 降低甲方決策門檻 | 回款依賴驗收標準清晰度 |
| 業績分成／效果對賭 | 投放類、電商代運營 | 甲方容易簽 | **只在自己控得住變量時用**，否則賠錢 |

**合約必寫五條**（血淚教訓）：
1. **陪跑期與駐場人天**（多少人在場、在場多久）
2. **驗收標準**（用模板 5 的指標，寫進合約附錄）
3. **修改次數上限**（超過如何計費）
4. **核心人員鎖定條款**（藍色光標、華揚聯眾都出過團隊震盪）
5. **回款節點與逾期條款**（尤其對方是 ST 或財務緊張的公司，見 `10-华扬联众.md`）

## 模板 5：驗收指標庫（按流派選）

> 用法：每個方案背面必須附能測的指標，否則甲方一句都過不去（台灣奧美「雙峰策略」：創意 + 效益成對寫）。

| 流派 | 該承諾的指標（選 3 個） | 不該承諾的 |
|---|---|---|
| 華與華式（符號／認知） | 終端辨識度調研、門頭／貨架辨識率、品牌詞搜索量增幅、加盟商訂貨量 | 短期 GMV（符號不是促銷） |
| 奧美式（品牌大理想） | 品牌聯想度、心智份額（BHT／Awareness）、內容自發傳播量、媒體轉發的國家數與媒體層級 | 直接 ROI |
| 陽獅式（全鏈路整合） | 曝光量、潛客到店數、跨渠道歸因一致的 CAC | 單渠道 ROI（整合項目要算總帳） |
| 貝恩式（NPS／忠誠） | NPS 分觸點得分、推薦者購買品類數、流失率、LTV/CAC 比 | 公司級 NPS 總分（沒有行動價值） |
| BCG 式（增長測算） | GROW 四因子各自貢獻度、滲透率／復購率／客單價、影響力觸點排名 | 無法歸因的「品牌好感度」 |
| 藍色光標式（出海投放） | 曝光、CPM、CPA、ROI、素材產出條數、本地化素材勝出率 | 品牌類指標（不是它的強項） |
| 華揚聯眾式（大型項目／國際傳播） | 轉發的**國家數與媒體層級** + 話題閱讀量 + 線下大屏曝光 + 官方帳號背書 | 商業轉化（政務／城市項目不是它的目標） |
| in-house 式（私域／復購） | 私域用戶數、月度消費頻次變化、優惠券核銷率、分層觸達的轉化差異、復購率 | 「漲粉數」（除非能帶動復購） |

## 模板 6：一頁紙（可外發產物）

> 硬規則（AI協作總規範 §3.2 / §9.1）：**絕不含內部備註**；產出後問一句「要我發到飛書／微信嗎」，**不問就不發**。

```markdown
# {對象／項目} · {YYYY-MM-DD}

【背景】
一段話說明現狀，語氣為可轉發的中性陳述。

【現狀】
1.
2.
3.

【建議】
1.
2.
3.

【下一步】
一句話，明確要他做什麼（CTA）。

—— 如對上述方向有調整意見，回覆即可。
```

**自檢**：發出去前問自己 —— 這段話如果被轉給第三方（客戶的老闆、競爭對手、媒體），會不會出事？會，就刪。

## 模板 7：項目卡（回寫知識庫用）

> 用途：接案完成後，按 AI協作總規範 §1.3 的卡字段契約寫入 `10-Projects/`，讓中樞頁能自動追蹤。

```yaml
---
类型: 项目卡
项目: {客戶名}營銷全案
阶段: 构想 / 验证 / MVP / 增长 / 暂停
状态: 进行中 / 暂停 / 完成
---
```

正文區塊：
- **當前假設**：我們認為客戶真正的卡點是 ___
- **怎麼驗證**：用 ___ 指標，觀察 ___ 週
- **階段結論**：
- **卡點**：
- **下一步**（只填一個）：
- **交付物**（表格）：
- **關鍵關係**：`[[關係卡名]]`

## 模板 8：接案復盤（寫進 D 層）

> 用途：項目結案後 3 天內寫，寫進 `90-Output-Trace/03-输出复盘/`。目的是把單次經驗變成可複用規律。

```markdown
# 復盤 · {客戶} · {日期}

## 一、事實
- 接了什麼單、報了什麼價、實際交付了什麼

## 二、與預期的差異
| 項 | 預期 | 實際 | 差異原因 |
|---|---|---|---|

## 三、可複用的規律（← 這部分要提煉進 B 層）
1.
2.

## 四、下次要改的動作（← 這部分要提煉進 C 層）
1.

## 五、ADR（如有重大決策）
決策 / 背景 / 選項 / 結論 / 生效日
```
