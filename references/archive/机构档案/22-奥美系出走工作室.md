# 奧美系出走的獨立創意人工作室

> 數據可信度：【已核實】= 官網／工商／主流媒體專訪可查；【行業認知】= 業內共識；【未核實】= 二手轉述／自媒體／AI 聚合，**不可對外引用**。
> **本檔的立場很重要**：中國「4A 出走的獨立工作室」數量極多，但**真正有可靠一手來源、且能查到在營運與客戶的極少**。本檔只寫能核實的，其餘一律寫「查不到」，不編造。
> **判斷標準**：有主流媒體／正規行業媒體的**署名專訪**、能查到客戶名稱或作品，才算過線。

## 一、STORY 創意精品店

**1. 一句話定位**【已核實：正規行業媒體署名專訪】
奧美老兵開的**「小而穩」創意精品店**——創始人 Jackie 白雪丹為奧美十年創意人、曾任奧美創意群總監，與當年奧美搭檔共同經營。

**2. 商業模式與收費方式**
- 創意精品店模式，專案制服務費。【行業認知】
- 客戶（媒體披露）：伊利、雀巢、悅刻、戴爾、361 度、知乎、B 站、抖音電商。【已核實：專訪披露】
- **具體報價、團隊人數、營收：查不到。**

**3. 核心方法論與代表理論**【已核實：創始人受訪原話，屬「這家公司的人講過的」，非公司成文理論】
- **「信念感」論**：創始人明確區分「興趣」與「信念感」——「現在很多新人沒有信念感，就是對這份工作的信念。大家更多的是興趣，興趣很容易會改變；信念感則是我要把這件事做出點成就的意念。」
- **「奧美要傳承的是基本功」**：她認為奧美最該被傳承的是「對行業的認知，以及如何尊重自己的工作」，具體是**文案基本功與行業經驗的師徒式傳遞**（她特別點名老奧美 ECD 林桂枝的言傳身教）。
- **對行業的判斷（接案者必讀）**：「以前 100 萬以下的項目很少，都是一個大年框才來十幾家公司比稿；現在一二百萬的項目都有七八家公司來競標。但客戶的標準沒有下降，**想用 50 萬拍出 150 萬的東西**。」——這是中國創意服務定價崩塌的第一手證詞。
- **「我們最出彩的項目，也是賠錢最多的項目。」**——精品店的永恆困境。

**4. 代表案例**
- **查不到**有公開獎項或品牌側一手來源的代表案例。媒體披露的是客戶名單，不是案例清單。
- **不作任何數據引用。**

**5. 適用場景**：甲方需要**「懂大品牌流程、又不想走 4A 流程」**的資深團隊；預算中等但要求文案質感；需要一個人從策略到執行盯到底。
**6. 局限與坑**：① 精品店普遍**現金流脆弱**（創始人自述「最出彩的項目賠錢最多」）；② 媒體曝光極少，**沒有案例獎背書，只能靠客戶口碑轉介紹**；③ 創始人個人的奧美標籤既是信用也是天花板——客戶會拿奧美標準要求你，但不付奧美價格。
**7. 可直接複用的套路**：
1. **用「前 4A 資歷」定價但用「精品店成本」交付**：這是所有 4A 出走工作室唯一的商業模式，關鍵是把資歷講清楚（哪家公司、什麼職位、哪些客戶）。
2. **挑選「不願意付 4A 價但要求 4A 質」的客戶**：這是精品店的精準客群，不要試圖服務所有人。
3. **年框比稿前先算成本**：創始人自述的「50 萬要做出 150 萬」是真實市場價。接案前先算一遍，賠錢的「代表作」要控制數量。
4. **把創始人資歷寫成一句話**（「奧美十年創意人，曾任創意群總監」），比作品集更早建立信任。
5. **用媒體專訪替代案例獎**：正規行業媒體的署名訪談是低成本、可核實的信用背書，比虛構數據安全。

## 二、繁榮學社

**1. 一句話定位**【已核實：媒體署名專訪】
前奧美中國高管的**「創始人 IP 諮詢」機構**——賣的是「超級個人品牌」方法論，不是廣告。

**2. 商業模式與收費方式**
- 創始人**陳蓉**：1996 年入行互聯網營銷，2000 年加入奧美互動，2021 年以首席增長官身份重返奧美中國，次年兼任奧美北京總裁，**2024 年從奧美中國退休後**成立繁榮學社。
- 2025 年起從戰略走向落地，**親自下場操盤全案客戶**（首個全案客戶為一位企業家創始人的個人品牌打造）。【已核實：專訪】
- 收費模式為諮詢＋落地操盤。【行業認知】

**3. 核心方法論與代表理論**【已核實：創始人公開訪談原話】
- **「超級個人品牌」**：主張未來企業最大的增長紅利不在流量投放，而在**創始人本人**。
- **對行業的核心診斷**：「**誤把知名度當信任，這是整個中國品牌行業的問題。**」——這一句可直接用作提案開場的問題定義。
- **對流量型操盤手的批評**：「今天市面上很多做 IP 的團隊，大多是流量型操盤手，而不是把 IP 當成品牌來做。」
- **操作要點（提煉）**：創始人 IP 要按品牌的方法論做（定位、內容體系、長期一致），而不是按流量的方法論做（追熱點、刷曝光）。

**4. 代表案例**
- 媒體披露：首個全案客戶為某集團創始人的個人品牌打造，具體品牌名、數據、年份**查不到**。
- **不作任何數據引用。**

**5. 適用場景**：創始人本人願意出鏡、且企業有品牌升級需求的甲方；B 端、專業服務、教育類企業。
**6. 局限與坑**：① IP 諮詢賽道**門檻低、供給過剩**，差別只在創始人的信用；② 「創始人 IP」的效果**難以歸因**，一旦創始人不出鏡或中途放棄，專案立即歸零；③ 前高管光環在中國市場能撐多久取決於實際案例產出，**目前公開可查的落地案例極少**。
**7. 可直接複用的套路**：
1. **「誤把知名度當信任」**照抄為診斷句：任何品牌問題都可以拆成「有名但沒信任」或「有信任但沒名」，兩者解法完全不同。
2. **創始人 IP ＝ 品牌方法論，不是流量方法論**：先定「他要代表什麼」，再定內容；不要先開帳號再想定位。
3. **把前公司資歷寫成時間軸**：1996→2000 奧美互動→2021 首席增長官→2022 奧美北京總裁→2024 退休創業。**時間軸是最有說服力的自我介紹格式。**
4. **「戰略＋親自下場」雙軌**：只賣戰略的顧問很容易被替換，把自己綁進執行交付環節才能留住客戶。

## 四、這個品類的通用結論（給接案者的判斷）

1. **「4A 出走工作室」不是一個商業模式，只是一個資歷標籤。** 真正的分水嶺是：有沒有穩定的年框客戶。
2. **最容易踩的坑是把「前公司案例」寫成「自己的案例」。** 客戶常會直接問：「那個案子是你做的還是你在場？」——**準備好一句誠實的回答**。
3. **定價參照**：本檔 STORY 創始人披露的市場真實行情是「一二百萬的項目有七八家競標、客戶想用 50 萬拿到 150 萬的產出」。【已核實：媒體專訪】報價時以此為錨。
4. **最穩的架構是「1 個年框客戶養活團隊 + 1–2 個代表作保信用」。** 這與勝加（方太 20 年）、W+K（Nike 40 年）的邏輯完全一致——**長期客戶才是獨立公司的護城河。**
