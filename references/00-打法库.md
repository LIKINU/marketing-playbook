# 营销打法库

> **这是什么**：打法引擎：**104 条打法**，每条含「为什么用它／具体动作到每一步／验收指标／可抄案例」
> **什么时候读**：**动笔前出骨架时**（第 -1 步导航表：『动笔前出骨架』）
> **读完你能**：按客户状况查到 3–7 条可执行打法，每条都能直接抄成动作
> **目录**：§0 打法总表（一页速查） ｜ §1 认知类打法（让客户记住你） ｜ §2 内容类打法（自产内容获客） ｜ §3 投放类打法（花钱买流量） ｜ §4 私域类打法（让客户回头） ｜ §5 渠道类打法（货怎么铺出去） ｜ §6 事件与话题类打法（借势与造势） ｜ §7 信任类打法（让人敢买） ｜ §8 定价与转化类打法（把流量变成钱） ｜ §9 诊断类打法（先搞清楚卡在哪） ｜ §10 特殊主体专用打法（小企业／新品牌／第二曲线／AI产品／B2B） ｜ §11 特殊场景专用打法（B端商业／投标响应／G端政府）
> **规模**：9.4 万字
> 定位：**生成器的引擎**。接到客户状况 → 在本档查打法 → 组合成方案。
> 用法：先看 §0 总表定位，再跳对应章节读具体打法。
> 建立 2026-09-14 ｜ 可信度：【已核实】【行业认知】【未核实】【判断】

**怎么用这本档（给 AI 的调取规则）**
1. 先把客户状况拆成四件事：**卖什么**（品类/客单/毛利）、**给谁**（人群/场景/频次）、**现在卡在哪**（曝光/信任/转化/复购/渠道任一环节）、**有多少钱和多少人**。
2. 拿这四件事去 §0 总表对「适用状况」栏做匹配，挑出 3–7 条候选打法。
3. 用「预算量级 × 见效周期 × 谁来做」三栏做减法，砍掉客户做不了、等不起、做不动的。
4. 排序原则：**诊断类常驻在第一位**（§9），先确认卡点再选打法；**信任类与转化类必须配套出现**，只做曝光不做承接是常见死法。
5. 每条打法都要回报「主要风险」，让客户知道代价。

**可信度标记规则**
- 【已核实】：有公开可查来源、数据可对得上。
- 【行业认知】：行业内普遍这么认为，但无单一权威来源。
- 【未核实】：听过但找不到可靠出处，仅供假设，必须先验证。
- 【判断】：本档给出的操作建议与经验值，不是事实，是决策建议。
- 所有预算与周期数字，除标【已核实】外，一律视为【判断】的量级参考，实际必须按客户所在城市、品类、平台竞价波动重新报价。

| 详情页六要素 | 有流量但转化率低于行业 | 一次性 0.3–5 万 | 2–4 周 | 自夸式文案，没有证据 | §8.8 |
| 客服话术 | 询单多、下单少 | 人工，0–1 万 | 1–2 周 | 话术机械，用户直接跑 | §8.9 |
| 加购推荐 | 已在成交，想提升客单 | 0 | 2–4 周 | 推不相关商品，干扰成交 | §8.10 |
| 购物车挽回 | 加购不下单占比 30% 以上 | 让利 3–10% | 1–2 周 | 直接降价，伤正价客 | §8.11 |
| 全链路数据表 | 所有客户的第一步 | 0 | 1–2 周 | 数据造假，结论全错 | §9.1 |
| 流失用户深访 | 复购率低、不知道为什么 | 300–500 元／人 | 2–4 周 | 只访熟人，听不到真话 | §9.2 |
| 复购用户深访 | 想找可放大的买点 | 300–500 元／人 | 2–4 周 | 样本偏，只听忠粉 | §9.3 |
| 竞品拆解 | 竞品卖得好，想抄得明白 | 0–2 万 | 2–4 周 | 只抄形式，不懂机制 | §9.4 |
| 品类机会扫描 | 想开新品、找新赛道 | 0–5 万 | 2–8 周 | 只看宏大趋势，不看自家能力 | §9.5 |
| 客单-频次四象限 | 不确定该做拉新还是复购 | 0 | 当天 | 象限判断错，资源全押错方向 | §9.6 |
| LTV-CAC 测算 | 决定要不要放大投放 | 0 | 1–2 周 | 把复购算太乐观 | §9.7 |
| 小店三公里打法 | 单店、服务半径 3 公里 | 0.3–2 万／月 | 1–2 个月 | 想服务全市，什么都做不深 | §10.1 |
| 单店餐饮全套 | 一家店从开业到稳定 | 开业期 1–10 万 | 3–6 个月 | 开业活动爆量后，服务跟不上 | §10.2 |
| 新品牌 90 天 | 零基础、90 天要见结果 | 5–50 万 | 90 天 | 什么都做，什么都没做透 | §10.3 |
| 第二曲线品牌架构 | 主品牌老化，想开新品牌 | 30–300 万 | 12–24 个月 | 用主品牌名硬套，新旧互相拖 | §10.4 |
| AI 产品的 PLG 与开发者营销 | AI／工具类产品，需要自增长 | 5–100 万 | 3–12 个月 | 免费版太强，没人付费 | §10.5 |
| B2B 信任营销 | 大客户、长决策链 | 5–100 万 | 6–18 个月 | 做消费品那套，完全打不动 | §10.6 |
| 区域公用品牌 | 农产品／地方产业带 | 50–500 万（常为政府专项） | 12–36 个月 | 政府换届，项目断档 | §10.7 |

## §1 认知类打法（让客户记住你）

> 本节只解决一件事：**消费者能不能记住你、能不能用一句话把你转述给别人。** 认知没解决就投流量，等于往漏桶里倒水。所有打法在报价前都必须先过 §1.12 品牌三问自检。

### 1.1 超级符号（视觉记忆点）

**一句话定义**：把品牌压缩成一个不用解释、看一眼就记住的图形或角色，并在所有触点反复重复它。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 客户说不清自己是谁；投了广告但没人记得；品牌名抽象（X 科技／X 优选）；竞品视觉全一个样 |
| 不适用 | 品牌已有清晰形象；没有重复曝光的预算（符号靠重复才生效） |
| 预算量级 | 一次性 0.5–5 万（设计）；含 IP 三视图＋延展 5–20 万 |
| 见效周期 | 3–6 个月 |
| 谁来做 | 外部设计／符号顾问；老板必须亲自拍板 |
| 难度 | ★★☆ |

**怎么做**：
1. 找出产品最核心的一个动作或结果（快／辣／洗得干净／送得快），写成一句核心词。产出：核心词 1 句。
2. 把核心词转成 3–5 个可视化方向（动物／器物／动作／字体变形／几何）。产出：草图方向清单。
3. 用三条标准筛：不解释就懂、与品类有关联、竞品没在用。产出：1–2 个候选。
4. 做「一秒测试」：给 10 个外行看 1 秒，问「这是干什么的」，答对率低于 5 成淘汰。产出：测试记录。
5. 定稿并出规范：主符号、辅助图形、最小尺寸、禁用示例。产出：符号使用规范 1 份。
6. 全触点铺开：包装、门头、快递箱、直播背景、详情页眉屏、工服。产出：触点改造清单。
7. 设固定露出位：短视频片尾、直播贴片、包装固定角落。产出：露出 SOP。

**关键技巧**：符号要绑「购买理由」而非好看；能动起来的（可做表情包、贴纸、片尾）胜过纯静态；先在单一渠道打透再铺全渠道。
**常见错误**：设计师按审美选、不看品类关联；细节太多缩小就糊；一年换一版，永远从零开始。
**怎么验收**：无提示回忆测试——抽 30 个目标消费者看符号图，能正确说出品牌名的比例，3 个月由 <10% 升到 30% 以上算有效。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/02-食品饮料与酒.md`（旺旺）。

### 1.2 品牌谚语（口号写作）

**一句话定义**：写一句消费者愿意主动替你说出去的话，而不是一句你希望他记住的话。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有产品、无一句可传播的话；广告语全是「引领／赋能／匠心」；销售靠人解释半天 |
| 不适用 | 产品本身没有一个明确购买理由；to B 超长决策链（此时口号作用有限） |
| 预算量级 | 一次性 1–8 万（含创作＋测试） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 文案／策略；老板定稿 |
| 难度 | ★★☆ |

**怎么做**：
1. 收齐三样素材：消费者买你的原话（客服记录、评论区）、竞品口号、你的最大差异。产出：素材表。
2. 从买家原话里找「已存在的句子」，谚语多半是发现而不是发明。产出：10 句候选原话。
3. 按四个模板各写 5 句：**说结果**（怕上火喝王老吉）、**说场景**（送礼就送…）、**说身分**（我是…我选…）、**说对立**（不含…的…）。产出：20 句。
4. 用三条删：同行也能说（删）、说了等于没说（删）、读出来拗口（删）。产出：3–5 句。
5. 做转述测试：让 20 个非用户听一次，隔 24 小时后问「那句话是什么／你会跟朋友怎么说」。产出：转述准确率。
6. 定稿后全线统一：包装、门头、电商首图、直播背景、员工话术。产出：口号使用规范。

**关键技巧**：一句话只能有一个意思；口语优先于书面语（能被说出来才叫谚语）；字数 6–12 字最稳；带节奏／押韵的更好记。
**常见错误**：老板自己写一句自我感动的话；堆砌四个字的漂亮词；口号与产品体验不符，喊越大越假。
**怎么验收**：24 小时转述准确率 >30%，且能写出大致意思；同时追踪客服「客户主动提及口号」的次数。
**案例**：`cases/02-食品饮料与酒.md`（王老吉／加多宝、东鹏特饮）；`cases/04-服饰运动户外.md`（安踏主品牌）。

### 1.3 品牌命名（取名与改名）

**一句话定义**：选一个好记、好读、能注册、能延伸的名字，这是品牌最贵的一次性决策。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 新品牌注册；商标被驳回或被抢注；名字本地话读出来有歧义；名字完全看不出品类 |
| 不适用 | 品牌已有一定资产、改名成本大于收益（此情况只做「加注释」而非改名） |
| 预算量级 | 一次性 0.3–10 万（含商标检索与注册） |
| 见效周期 | 1–2 个月（含商标风险排查） |
| 谁来做 | 品牌方主导；商标事务所配合检索 |
| 难度 | ★★☆ |

**怎么做**：
1. 先做商标检索（同类＋近似类），把已被占用的方向整体划掉。产出：可注册词库。
2. 明确命名策略：**描述型**（看出品类）、**联想型**（有画面）、**造词型**（无含义、好注册）、**人名型**（创办人背书）。产出：策略选择 1 项。
3. 每种策略出 10 个候选，共 30–40 个。产出：候选清单。
4. 用五条硬标准筛：能注册、2–4 字、不含生僻字、普通话与主要方言都读得顺、不会被误解。产出：10 个。
5. 做「电话测试」：电话里念一次，对方能不能一次写对。写错的淘汰。产出：通过名单 3 个。
6. 同步想域名与社群帐号名是否可用、能否延伸（未来出新品不尴尬）。产出：终选 1 个＋备胎 2 个。
7. 完成注册类别布局（核心类＋防御类）再对外公布。产出：注册清单。

**关键技巧**：名字自带场景或结果，等于免费广告；两字名稀缺，三字是主流，四字上限；避免用「王／皇／极／尊」等溢价词，显假且难注册。
**常见错误**：先做包装再做商标检索；名字要解释才懂；用生僻字显得高级（用户打不出来就搜不到你）。
**怎么验收**：电话测试一次写对率 >70%；商标初审通过；半年后自然搜索（品牌词）有稳定量。
**案例**：`cases/02-食品饮料与酒.md`（元气森林）；`cases/05-3C数码与家电.md`（小米）。

### 1.4 包装即媒体（货架与快递箱）

**一句话定义**：把包装当成免费的广告位，让它在货架、快递站、用户家里持续替你说话。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 产品在货架／快递箱上无人注意；用户收到货直接扔包装；包装只是为了好看 |
| 不适用 | 纯 to B 大宗原料；产品形态无法承载资讯（如裸装生鲜） |
| 预算量级 | 一次性 1–20 万（设计＋开版）；开版费按印刷方式差异极大 |
| 见效周期 | 2–6 个月 |
| 谁来做 | 包装设计＋印刷厂；营销方给「要传达的资讯」 |
| 难度 | ★★☆ |

**怎么做**：
1. 列清包装要承担的 4 件事：品类识别、核心卖点、信任凭证、引流入口（QR／企微）。产出：资讯优先级表。
2. 定「3 米／1 米／30 公分」三级可读性：3 米看得到品类色块，1 米看到品牌与口味，30 公分看到成分与信任状。产出：包装版面草图。
3. 印前做盲测：把新旧包装放一起，让 20 人各看 3 秒，问「哪个更想买、为什么」。产出：盲测结果。
4. 快递箱／外箱单独设计：加一句社群引流语＋一个 QR，不写废话。产出：外箱设计稿。
5. 开版前确认印刷工艺与成本（专色、UV、击凸会显著加价）。产出：报价对比。
6. 上市后做「开箱 UGC 监控」：看用户自发拍开箱的比例。产出：开箱内容月报。

**关键技巧**：货架上是比色块不是比插画——同品类里「最不像」的那个最容易被拿走；包装上只放一个购买理由；把 QR 的位置做成用户不得不看的动作位（如撕口处）。
**常见错误**：设计图很美，缩小到实物就废；资讯堆满没有主次；包装和详情页各说一套，用户困惑。
**怎么验收**：货架拿取率（门店可抽样观察）、开箱 UGC 条数、QR 扫码率（行业经验值 3–10%，【判断】）。
**案例**：`cases/02-食品饮料与酒.md`（农夫山泉、三顿半）。

### 1.5 门头改造（招牌即广告）

**一句话定义**：把最贵的那块广告位（门头）从「装修的一部分」改成「一天 24 小时的销售员」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 街边／商场店路过人流不进；门头只有品牌名没有品类；晚上看不清；隔壁店更抓眼 |
| 不适用 | 纯线上生意；门头位置被物业限制无法改动 |
| 预算量级 | 一次性 0.5–8 万／店 |
| 见效周期 | 1 个月内 |
| 谁来做 | 招牌制作商＋品牌方；连锁需先做 1 家样板店 |
| 难度 | ★☆☆ |

**怎么做**：
1. 先记数：高峰与低峰各站店外 30 分钟，数「经过人数／看门头人数／进店人数」。产出：进店率基线。
2. 定门头要回答的三个问题：卖什么、多少钱起、为什么现在进（优惠／新品）。产出：门头文案清单。
3. 做「夜色测试」：拍一张晚上 8 点的实景照，看 10 公尺外能否读清品牌与品类。产出：测试照。
4. 强化三个元素：大色块（品类色）、大字（品类词＋品牌名）、灯光（亮灯时间与门头同时）。产出：设计稿。
5. 加一个「可读的价格／爆品图片」，让路人不用问就知道消费门槛。产出：侧招／灯箱。
6. 施工后同法再数一次，对比进店率。产出：改造前后数据表。

**关键技巧**：门头上「品类词」比「品牌名」更能带来第一次进店；一句话最强是「结果＋价格」；同商圈做到「最亮／最大字」通常赢一半。
**常见错误**：只换门头不改产品与服务，来一次不回头；门头放英文与抽象 logo，路人看不懂；白天好看、晚上黑。
**怎么验收**：进店率提升幅度（样本 ≥3 天，各时段）；改造后 1 个月内自然到店占比。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城、老乡鸡）。

### 1.6 货架陈列（终端动销）

**一句话定义**：在货架这个「最后三秒的战场」上，用位置与陈列方式换取被拿取的概率。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 商超／便利店／药店有铺货但动销差；陈列费花了没效果；新品进店后被埋在底层 |
| 不适用 | 纯电商品牌；渠道拒绝让价或无陈列资源 |
| 预算量级 | 一次性 0.3–3 万／渠道（陈列费＋物料） |
| 见效周期 | 1–2 个月 |
| 谁来做 | 业务／督导团队；需门店配合 |
| 难度 | ★★☆ |

**怎么做**：
1. 走店 20 家，记录你的位置（层高、左右邻居、朝向）与动销。产出：位置—动销对照表。
2. 锁定「黄金层」（视线 1.2–1.6 公尺、主通道右手边、收银动线末端）。产出：要争取的位置清单。
3. 设计陈列物料：跳跳卡、货架贴、爆炸贴、堆头，每件只承载一个资讯。产出：物料清单与效果图。
4. 谈陈列方式：争取「端架／堆头／收银台小展架」，这三处动销效率远高于普通货架。产出：陈列协议。
5. 做「陈列前后对比照」制度：业务每次拜访拍 6 张标准角度照片上传。产出：陈列稽核表。
6. 建立「动销监控」：按周看单店单品销量，做不动销的门店淘汰或换位。产出：门店分级表。

**关键技巧**：货架上的第一竞争对手是「左右邻居」，不是品类领导者；同色系陈列会被淹没，要制造对比；陈列资源要和导购试吃／试用配套才有效。
**常见错误**：花了陈列费但没有稽核，物料被扔仓库；同一位置放太多 SKU，每个都不显眼；只做堆头不做补货，三天后就空了。
**怎么验收**：单店单品周销量对比、陈列执行率（拜访抽查合格率 ≥80%）、堆头 ROl。
**案例**：`cases/02-食品饮料与酒.md`（农夫山泉）；`cases/14-零售商超与便利店.md`（罗森）。

### 1.7 品牌色与视觉锤

**一句话定义**：用一个专属颜色或重复出现的视觉元素，让消费者在 0.5 秒内把你从货架／资讯流里认出来。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 品类同质化严重、辨识度低；资讯流素材换一套就不像同一家；品牌看起来「没有品牌感」 |
| 不适用 | 品类已有强势颜色垄断（如快递用橙）且你无法差异化 |
| 预算量级 | 一次性 0.5–5 万 |
| 见效周期 | 3–6 个月 |
| 谁来做 | 品牌设计；营销方管一致性执行 |
| 难度 | ★★☆ |

**怎么做**：
1. 扫竞品主色，列出前三名已被占用的颜色。产出：颜色占位图。
2. 选色标准：与品类联想不冲突、在手机屏幕上不刺眼、印刷不易偏色。产出：2–3 个候选色（含专色号）。
3. 定「视觉锤」：一个反复出现的形状／构图／人物姿势／画面处理方式。产出：视觉锤定义。
4. 做缩略图测试：把 20 张竞品图与你的图缩到 100px，测能否认出你。产出：辨识率。
5. 写死「一致性清单」：主色占比、字体、版式、禁用项，交给所有外包团队。产出：VI 执行清单。
6. 每月抽查素材，一致性不合格的退回重做。产出：一致性稽核记录。

**关键技巧**：颜色要「抢」而不是「美」——饱和度稍高反而记得牢；一个品牌只用一个主色最有效；视觉锤要能适配不同媒介（竖屏、方图、包装）。
**常见错误**：主色用黑色白色（等于没有颜色）；同一帐号每条视频风格都不一样；颜色与品类冲突（食品用工业灰）。
**怎么验收**：缩略图辨识率（测试组 vs 对照组）、资讯流点击率变化、品牌搜索量。
**案例**：`cases/03-美妆个护.md`（花西子、毛戈平）。

### 1.8 声音符号（jingle／听觉锤）

**一句话定义**：用一段 2–5 秒的声音，在用户不看屏幕时也能触发品牌记忆。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有大量视频、直播、门店播报但无声音记忆点；品类在音频场景被消费（开车、做家务） |
| 不适用 | 内容以图文为主、无视频矩阵；预算撑不起持续投放（声音需重复才有效） |
| 预算量级 | 一次性 1–15 万（原创＋制作） |
| 见效周期 | 3–12 个月 |
| 谁来做 | 音乐制作＋品牌方；需法律确认版权归属 |
| 难度 | ★★★ |

**怎么做**：
1. 定声音要传递的情绪（快／暖／高端／有趣）与使用场景。产出：声音 brief。
2. 选形式：**旋律型**（朗朗上口）、**口播型**（一句话固定念法）、**音效型**（一个标志性声音）。产出：形式选择。
3. 出 3 个版本 Demo，各 2–5 秒，做 AB 测试：听 3 次隔 1 天再听，测能否哼出。产出：测试结果。
4. 定稿后规范使用位置：视频开头／片尾、直播间进人提醒、门店广播、客服来电问候。产出：声音使用规范。
5. 做成资产包（不同时长版本），并注册版权与商标（声音商标）。产出：资产包＋权利文件。
6. 追踪效果：品牌词搜索、无提示哼唱测试。产出：季度评估。

**关键技巧**：越短越好，2–4 秒；旋律要「容易唱错」才好记（有记忆钩）；口播型最便宜，效果靠重复次数；不要用已经很红的歌，用户只记得歌不记得你。
**常见错误**：做得太复杂像广告歌听不完；太难听导致用户反感（负面记忆也是记忆）；只在广告用、门店不用，浪费触点。
**怎么验收**：无提示哼唱测试正确率、品牌词搜索量增幅、直播间进人停留时长变化。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/45-物流与快递服务.md`（货拉拉）。

### 1.9 品类定位（开新品类）

**一句话定义**：不在老品类里竞争排名，而是新造一个品类，让你自动成为第一名。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 老品类被巨头垄断、挤不进前五；客户有真实技术／产品差异化；有教育市场的预算与耐心 |
| 不适用 | 产品没有实质差异；预算和时间撑不起 1 年以上教育；品类太小养不活自己 |
| 预算量级 | 一次性 5–30 万（含调研与定位）；落地传播 30 万起 |
| 见效周期 | 6–18 个月 |
| 谁来做 | 策略顾问＋创办人；需老板亲自决策 |
| 难度 | ★★★ |

**怎么做**：
1. 做品类树：把用户购买时的心智路径写出来（想吃点好的 → 零食 → 坚果 → 每日坚果）。产出：品类心智图。
2. 找「未被命名的需求」：用户已在用老品类解决但觉得不满意的场景。产出：需求缺口 3 条。
3. 命名新品类（名字要能自己解释自己，如「每日坚果」「电动牙刷」「即食燕窝」）。产出：品类名候选。
4. 造「品类标准」：定义凭什么算这个品类（原料标准、工艺标准、使用场景）。产出：品类标准 1 页。
5. 选「品类第一」的证据：销量／专利／检测／权威背书，用一句话说「开创者」。产出：定位语。
6. 先在小圈层打透（一个城市／一个平台／一个人群），跑通再放大。产出：样板市场数据。
7. 用内容持续教育：每年固定投入教育预算，并监控品类词搜索量。产出：品类词监控表。

**关键技巧**：品类名要「口语化到能被搜索」；先做「品类第一」再做「品牌第一」；别造一个连自己员工都讲不清的品类。
**常见错误**：品类太小，做到第一也只有几百万市场；品类名太抽象（消费者记不住也搜不到）；定位改了产品没改，讲一次就露馅。
**怎么验收**：品类词搜索量趋势、被媒体／竞品用你的品类名描述（这是最高信号）、新品类贡献的营收占比。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（黄天鹅）；`cases/40-预制菜与方便速食.md`（空刻意面）；`cases/41-文具文创与办公.md`（猫太子）。

### 1.10 对立定位（打第一品牌）

**一句话定义**：找准行业第一的「强势中的弱点」，站到它的对立面，借它的名气把自己抬进消费者视野。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 行业有绝对老大（市占 30%+）；客户是老二老三，正攻打不动；老大有明显的「反面诉求」 |
| 不适用 | 没有明确老大；客户自己也有同样的弱点（对立会反噬自己） |
| 预算量级 | 一次性 3–20 万（策略＋传播创意） |
| 见效周期 | 3–12 个月 |
| 谁来做 | 策略＋传播；需法务把关（避免不正当竞争） |
| 难度 | ★★★ |

**怎么做**：
1. 列出老大的三个强项与对应的三个弱点（强的代价）。产出：强弱对照表。
2. 挑一个「老大不能反驳也不能跟进」的角度（跟进就自我否定）。产出：对立点 1 个。
3. 写对立句式：「他不是…我是…」「别人都…我偏偏…」。产出：口号 3 句。
4. 法务审查：不点名、不贬损、不比数据（避免法律风险）。产出：法务意见。
5. 用具体证据支撑对立点（配方、工序、材质、服务）；没证据就别说。产出：证据清单。
6. 全线落地：包装、详情页、直播话术、门店物料统一说同一句话。产出：落地清单。
7. 监控老大是否回应；若老大跟进，立即升级到「新的差异点」。产出：竞争应对手册。

**关键技巧**：对立点要选「老大不能改」的（改了要放弃它最大的优势）；不必点名，消费者自己会对号入座；要能在 5 秒内讲清楚。
**常见错误**：选了老大可以轻松跟进的点（如降价、加料）；说话太狠变成攻击，引发反感；自己也被同一句话反打（如说别人含糖自己却含更多）。
**怎么验收**：品牌认知度提升、与老大的「替代率」（有无抢到它的用户）、媒体／用户是否自发引述这个对立。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/20-跨境电商与出海品牌.md`（石头科技）。

### 1.11 单一特性占位

**一句话定义**：产品有很多优点，但只选一个最能被打赢的特性，反复说到底。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 产品有多个卖点、一个都记不住；竞品也都在说「十全十美」；已有一定产品力可支撑某一项 |
| 不适用 | 所选特性竞品也同样强且已占位；特性无法验证（说不出具体证据） |
| 预算量级 | 一次性 2–10 万（含证据挖掘与传播创意） |
| 见效周期 | 3–12 个月 |
| 谁来做 | 策略＋产品端配合 |
| 难度 | ★★☆ |

**怎么做**：
1. 穷举卖点（10–20 个），每个写清「证据是什么」。产出：卖点—证据表。
2. 用四条筛：用户真在乎、竞品没占或占得不牢、你有硬证据、能一句话说清。产出：3 个候选特性。
3. 做「特性优先级测试」：给 50 个目标用户看 3 个特性，问如果只能记住一个选哪个。产出：得票结果。
4. 把特性变成一句「可验证的宣称」（不是形容词，是事实）。产出：核心宣称 1 句。
5. 全媒体只讲这一句，其他卖点退到详情页与客服话术。产出：资讯层级表。
6. 每季度复核一次是否被竞品跟进占位。产出：占位监控表。

**关键技巧**：特性最好是「可被测量」的（速度、时长、成分含量）；选「用户能感知」的而非「技术上最厉害」的；说一个就要放弃其他，这是策略的必然代价。
**常见错误**：特性选得太抽象（「更懂你」没法验证）；口号说一个，包装说五个，用户混乱；特性被竞品抄了也不换。
**怎么验收**：无提示下能说出「你等于什么」的用户比例、该特性相关搜索词的点击与转化率。
**案例**：`cases/32-珠宝钟表.md`（老铺黄金）；`cases/33-箱包皮具配饰.md`（山下有松）。

### 1.12 品牌三问自检（接案第一步）

**一句话定义**：用三个问题判断客户的品牌认知到底有没有问题——答不出来就别往下花钱。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 所有新接案的客户，尤其是「产品不错但卖不动」的；预算有限、怕花错钱 |
| 不适用 | 已在做具体执行、需要立刻解决单点问题时可暂时跳过 |
| 预算量级 | 0（2 小时人工） |
| 见效周期 | 当天 |
| 谁来做 | 顾问／营销负责人，直接访谈老板 |
| 难度 | ★☆☆ |

**怎么做**：
1. 问第一题「**你是谁**」：顾客会怎么向朋友介绍你？写下你听到的原话。产出：顾客原话 3 条。
2. 问第二题「**你卖给谁、在什么场景**」：把订单按人群／场景分类，看是不是同一批人。产出：人群—场景表。
3. 问第三题「**凭什么选你不选别人**」：要求说出对方没有的证据。产出：差异点＋证据。
4. 对照老板的自述与顾客的原话，找出落差（落差就是问题所在）。产出：落差清单。
5. 判断卡点类型：是「不知道」还是「不信」还是「买不到」——三者打法完全不同。产出：卡点结论 1 句。
6. 出 1 页诊断结论，含建议下一步（可搭配 §9 诊断类）。产出：诊断 1 页。

**关键技巧**：三问要问「顾客」，不要只问老板；老板的答案与顾客答案不一致时，一律以顾客为准；三问跑完再谈预算，顺序反了就白做。
**常见错误**：走过场，直接跳到「做个活动吧」；把老板的自我定位当答案；三问结果不落到具体打法。
**怎么验收**：能否用一句话写出「卡点在曝光／信任／转化／复购／渠道中的哪一个」；客户是否认同这个结论。
**案例**：`cases/23-银发经济与健康养老.md`（足力健）；`cases/29-农业生鲜与供应链品牌.md`（认养一头牛）。

### 1.13 VI 一致性（识别落地）

**一句话定义**：把已经定好的符号、颜色、字体、话术，在所有触点上执行到「像同一家公司」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 门店／电商／物料／外包团队各说各话；换个代运营就变风格；用户在各平台认不出是同一品牌 |
| 不适用 | VI 尚未定稿就先别做手册（会白做） |
| 预算量级 | 一次性 1–10 万（含手册与模板） |
| 见效周期 | 2–6 个月 |
| 谁来做 | 品牌设计＋内部营销；需要有人负责稽核 |
| 难度 | ★★☆ |

**怎么做**：
1. 清点全部触点（线上＋线下），列出每个触点现在用什么视觉／话术。产出：触点清单。
2. 定义最小必要规范：主色、辅助色、字体、logo 使用、图片风格、话术三句。产出：核心规范 1 页。
3. 做成「填空式模板」：详情页、九宫格、海报、直播贴片、门店物料，让外包照填。产出：模板包。
4. 交付给所有执行方（设计、代运营、门店、员工），并要求回签。产出：交底记录。
5. 建立稽核机制：每月抽查 20 份素材，不合格退回。产出：稽核表。
6. 每半年更新一次规范（随著新触点出现补充）。产出：版本记录。

**关键技巧**：手册一定要做成模板而非 PDF 说明书，否则没人看；规范条目越少越可能被执行（10 条以内）；把「稽核」写进外包合约。
**常见错误**：出一本 80 页手册，结果吃灰；只规范 logo 不规范语气；门店加盟商不执行，总部也没罚则。
**怎么验收**：素材抽查合格率 ≥85%；用户能否在无 logo 情况下认出你的内容（盲测）。
**案例**：`cases/01-餐饮与茶饮.md`（喜茶 × FENDI、蜜雪冰城）。

## §2 内容类打法（自产内容获客）

> 本节解决：**没有投放预算，靠内容把陌生人变成客户。** 顺序铁律：先有帐号定位与模型（2.1、2.3），再做钩子与量产（2.2、2.14），最后才谈投放放大。没跑通自然流就别投。

### 2.1 短视频帐号冷启动

**一句话定义**：用 30–60 条内容把一个新帐号从「没人看」推到「有一批稳定精准观众」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有抖音／快手／视频号帐号但播放长期三位数；新品类需要低成本获客；有老板或员工人格可出镜 |
| 不适用 | 品类完全无视觉可展示性；团队没人能持续拍 3 个月 |
| 预算量级 | 0.3–3 万／月（手机拍摄可近 0） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 1 人主导＋1 人剪辑；前期建议老板本人出镜 |
| 难度 | ★★☆ |

**怎么做**：
1. 定帐号身分一句话：**谁（职业／身分）＋为谁＋解决什么**。产出：帐号一句话定位。
2. 找 20 个同品类对标帐号，按「内容类型」拆解（教学／测评／剧情／探店／Vlog）。产出：对标表。
3. 选 3 个能长期做的内容支柱，各写 10 个题目。产出：30 条选题库。
4. 用最低成本拍摄：自然光、手机、一到两个场景，先解决「能发出来」。产出：首批 10 条。
5. 每天固定时间发 1 条，连发 30 天不间断（前 30 条是练手，不是成果）。产出：30 条记录。
6. 每 10 条做一次复盘：看 3 秒完播率、平均播放、涨粉、咨询数，砍掉最差类型。产出：复盘表。
7. 出一条数据明显好的内容后，复制该结构再拍 5 条。产出：爆款复制清单。

**关键技巧**：前 30 条不要追求爆，追求「稳定产出能力」；帐号定位要窄到能一句话讲清；先做「能被搜索」的内容（品类词／问题词）比追热点更稳。
**常见错误**：拍 5 条没数据就放弃；每条风格都不同，系统不知道推荐给谁；追求画质却没有内容讯息，完播率极低。
**怎么验收**：3 秒完播率（经验值 >35% 合格，【判断】）、平均播放量趋势、私信／咨询数（最终指标）。
**案例**：`cases/01-餐饮与茶饮.md`（老乡鸡、费大厨）。

### 2.2 前 3 秒钩子设计

**一句话定义**：把视频最贵的 3 秒重新设计，让刷到的人停下来，而不是划走。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有播放但不完播、不进店；帐号播放量靠系统推荐但转化为 0；同一内容换开头效果差好几倍 |
| 不适用 | 内容本身无价值，钩子只会加速流失与负评 |
| 预算量级 | 人工为主，0.2–1 万／月 |
| 见效周期 | 1–2 周 |
| 谁来做 | 编导／剪辑；需大量 AB 测试 |
| 难度 | ★★☆ |

**怎么做**：
1. 把现有 10 条视频的开头逐条写成文字，标出问题。产出：开头诊断表。
2. 用五种钩子各改 3 条：**结果前置**（先给成品／效果）、**冲突提问**（你是不是也…）、**反常识**（千万别…）、**利益直给**（教你一招省…）、**身分喊话**（做 XX 的一定要看）。产出：15 条开头。
3. 前 3 秒内必须出现「画面变化」或「关键词字幕」，不能只有静态人物说话。产出：成片。
4. 同素材剪 3 个不同开头，用小额投放或自然流量 AB 测试。产出：完播率对比。
5. 建立「钩子库」：把跑得好的开头句式存档，之后重复套用。产出：钩子库文件。
6. 每周新增 5 条钩子并测试，汰换效果最差的。产出：周更记录。

**关键技巧**：钩子要与内容一致，标题党会拉高跳出并伤帐号；前 3 秒不要出现 logo 与自我介绍；字幕的前 6 个字就是第二个钩子。
**常见错误**：开头先打招呼「大家好，今天讲…」；钩子太泛（「一个很重要的知识」）；用了钩子但内容接不住，评论区骂人。
**怎么验收**：3 秒完播率提升幅度、5 秒留存，以及最终的进店／私信转化率（不能只看播放）。
**案例**：`cases/03-美妆个护.md`（韩束、完美日记）。

### 2.3 口播脚本结构

**一句话定义**：给不会讲话的老板或员工一套固定结构，让镜头前有话可说、说了有用。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 客户本人不会讲、镜头前尬；有专业知识但讲出来像课本；拍了几十条都是流水帐 |
| 不适用 | 品类适合展示不需要讲解（纯视觉类） |
| 预算量级 | 人工，0–1 万／月 |
| 见效周期 | 1 个月 |
| 谁来做 | 编导写模板，客户本人讲 |
| 难度 | ★★☆ |

**怎么做**：
1. 选一个固定结构，建议四段式：**钩子（3 秒）→ 痛点共鸣（5 秒）→ 具体解法 1–3 步（20–40 秒）→ 一句行动指令（5 秒）**。产出：脚本模板。
2. 每条只讲一件事（一个问题、一个方法），能写在标题里。产出：单一主题确认。
3. 用「说人话」原则改稿：删掉专业术语、每句话不超过 15 个字。产出：定稿。
4. 加「具体数字与场景」（我上周遇到一个客户…），避免空泛。产出：案例补充。
5. 拍摄时用手机提词器，控制在 60–90 秒。产出：成片。
6. 建立「内容转化位」：每 3 条里有 1 条提产品或引导私信，其余纯给价值。产出：比例表。

**关键技巧**：先写「口语稿」不要写「书面稿」，写完念一遍、念不顺就改；一次录 5 条，提高效率；结尾指令要具体（「评论区扣 1」胜过「欢迎咨询」）。
**常见错误**：抄同行的稿导致同质化；一条视频讲五个点，用户记不住；全程只讲产品不讲用户问题。
**怎么验收**：平均观看时长、评论区提问数、私信咨询数、单条内容带来的成交（哪怕 1 单）。
**案例**：`cases/03-美妆个护.md`（韩束、珀莱雅）。

### 2.4 探店视频

**一句话定义**：用第三方视角把门店的「值得来一趟」讲清楚，换取周边人的到店。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 本地门店需要周边客流；有明确的一个到店理由（新店／新菜／环境／价格） |
| 不适用 | 产品体验撑不住探店（来一次就差评）；无本地达人资源且预算极低 |
| 预算量级 | 0.1–1 万／条（含置换） |
| 见效周期 | 2–6 周 |
| 谁来做 | 本地生活达人／素人；店家配合安排 |
| 难度 | ★☆☆ |

**怎么做**：
1. 定「一个到店理由」并写成 5 个字以内（如「39 块吃到饱」）。产出：到店理由。
2. 选人：优先本地 1–10 万粉的生活类达人，粉丝画像需与门店商圈重叠。产出：达人清单 5–10 人。
3. 出拍摄 briefing：必拍的 5 个镜头（门头／招牌菜特写／价格牌／环境／吃后表情）。产出：brief 1 页。
4. 要求达人挂团购链接／定位，并在评论区置顶核销方式。产出：链接核销数据。
5. 同步做「素人探店」：邀请真实顾客拍摄，给予免单＋小礼。产出：素人内容 10 条。
6. 把达人内容二次剪辑放在门店自有帐号，形成内容矩阵。产出：二次剪辑 3 条。
7. 一周后看核销率，不是看播放量。产出：核销报告。

**关键技巧**：探店必须说清价格与位置，这是两大转化要素；同时找 3–5 个中小达人比 1 个大达人风险更低、核销更真实；要求达人在视频里「当场下单」示范流程。
**常见错误**：只看播放量不看核销；探店内容拍成了宣传片；一次投 10 个达人同一周发，流量互相冲淡。
**怎么验收**：团购核销率（经验值 5–20%，【判断】）、到店提及「看视频来的」的比例、核销后是否加私域。
**案例**：`cases/15-教育文旅与本地生活.md`（淄博烧烤）；`cases/10-B2B工业品与农产品区域品牌.md`（天水麻辣烫）。

### 2.5 工厂溯源内容

**一句话定义**：把生产过程拍给用户看，用「看得见的真实」换取信任。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 品类信任门槛高（食品／保健品／母婴／护肤）；被质疑「智商税」「代工贴牌」 |
| 不适用 | 生产过程有合规风险不能公开；工厂不允许拍摄 |
| 预算量级 | 0.5–3 万／条（含差旅与制作） |
| 见效周期 | 2–4 个月 |
| 谁来做 | 内容团队进厂；工厂配合 |
| 难度 | ★★☆ |

**怎么做**：
1. 让用户提问：收集「你们是不是代工」「原料哪来的」等质疑。产出：信任缺口清单。
2. 按缺口设计拍摄脚本：原料进厂 → 检验 → 生产线 → 质检 → 包装出库，全程不跳。产出：分镜脚本。
3. 必须有三个「不能造假」的镜头：原料包装上的产地／批号、检测仪器读数、工人真实操作。产出：关键镜头清单。
4. 用「一镜到底」或显著时间戳，提高可信度。产出：成片。
5. 拍成系列（每集回答一个质疑），不要一支宣传片讲完。产出：系列规划 5 集。
6. 在详情页、包装 QR、直播间循环使用。产出：素材再分发清单。

**关键技巧**：允许拍「不完美」（工人手上有面粉、机器有噪音）比干净的宣传片更可信；让工人自己说话，比旁白可信；一定要拍到「你在别的地方看不到的东西」。
**常见错误**：拍成 3 分钟企业宣传片，没人看完；找专业演员演工人，一眼假；讲了工艺但没讲「这对用户有什么好处」。
**怎么验收**：溯源系列的平均完播率、详情页停留时长、「代工／假货」类质疑在评论区的下降。
**案例**：`cases/01-餐饮与茶饮.md`（老乡鸡、蜜雪冰城）。

### 2.6 产品测评内容

**一句话定义**：用可被验证的硬指标对比，让第三方替你回答「到底值不值」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 产品有硬参数（续航／成分含量／清洁力／耐用度）；品类充斥智商税争议 |
| 不适用 | 产品参数不如竞品（测评会反伤自己）；无第三方愿意测 |
| 预算量级 | 0.3–2 万／条 |
| 见效周期 | 1–3 个月 |
| 谁来做 | 垂直测评达人／机构；需送样与配合答疑 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「可测的宣称」：把卖点转成能测的指标（如「洗得干净」→ 去污率对比）。产出：测试指标表。
2. 选测评方：优先「长期做同品类对比」的帐号，而非纯种草号。产出：达人名单。
3. 提供完整样品与资料，但不干预结论（干预会毁掉可信度）。产出：寄样记录。
4. 要求测评含「对比组」与「测试方法」，方法越透明越可信。产出：内容验收标准。
5. 内容发布后在官方帐号转发并补充「测试条件说明」。产出：转发内容。
6. 针对「测出来的弱点」提前准备回应话术，避免评论区崩。产出：FAQ 话术表。

**关键技巧**：中立测评的价值在于「可能说你不好」，全说好的等于广告；优先选「有对比、有仪器、有重复测试」的内容形态；测评要和客服话术对接，用户会带著问题来问。
**常见错误**：买测评结论，被扒出后信任破产；测评只讲参数不讲使用场景；测评人恰饭痕迹明显，用户一眼识破。
**怎么验收**：测评内容带来的搜索量、进店流量、转化率；评论区负面质疑比例的变化。
**案例**：`cases/20-跨境电商与出海品牌.md`（石头科技）；`cases/05-3C数码与家电.md`（大疆 DJI）。

### 2.7 图文种草（小红书笔记）

**一句话定义**：用「像朋友分享」的图文，在女性为主的生活方式平台卡住搜索与推荐两条流量。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 女性／生活方式品类；客单 50–500 元；决策前会搜索（美妆／家居／母婴／旅行） |
| 不适用 | 极低价冲动消费；纯男性向硬科技；平台判定违规的品类 |
| 预算量级 | 0.5–5 万／月（含达人与投流） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 内容运营＋达人／素人矩阵 |
| 难度 | ★★☆ |

**怎么做**：
1. 挖词：在站内搜索框输入品类词，记录下拉词与「大家都在搜」。产出：关键词库（20–50 个）。
2. 按「搜索意图」分四类笔记：**痛点型**（我的问题）、**攻略型**（怎么选）、**开箱型**（我买了）、**对比型**（A vs B）。产出：选题表。
3. 写标题：关键词前置＋情绪／结果（「敏感肌｜用了 3 个月终于不泛红」）。产出：标题 20 条。
4. 做封面：一张图说清主题，大字＋真实场景，避免纯产品图。产出：封面模板 3 套。
5. 正文用「口语＋分行＋emoji 分段」，结尾埋 2 个相关关键词。产出：正文模板。
6. 发布节奏：自有号每周 3–5 篇，达人／素人每周 5–10 篇。产出：排期表。
7. 对有自然流量的笔记做小额投流（薯条／聚光），放大搜索排名。产出：投流记录。

**关键技巧**：小红书是「搜索＋推荐」双引擎，关键词比创意更决定生死；真实感来自「不完美的细节」（如自己家里的乱背景）；一个帐号只做一个垂直方向，混发会掉权重。
**常见错误**：笔记像广告（全是产品美图＋夸张效果），被限流；标题不带关键词，搜不到；一次铺太多同质内容被封。
**怎么验收**：笔记搜索排名、单篇互动率（赞藏比）、店铺／私域的来源占比、投流 ROI。
**案例**：`cases/01-餐饮与茶饮.md`（老乡鸡）。

### 2.8 公众号长图文

**一句话定义**：用一篇有观点的长文，把品牌想说的立场说清楚，换取「被转发」与深度信任。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有品牌故事或创办人观点可讲；需要影响行业／媒体／B 端；客单高、决策周期长 |
| 不适用 | 纯低价快消；没有持续写作能力 |
| 预算量级 | 人工 0.3–2 万／月 |
| 见效周期 | 3–6 个月 |
| 谁来做 | 内容主编／创办人亲写 |
| 难度 | ★★★ |

**怎么做**：
1. 定专栏结构：如「行业观察」「用户故事」「幕后」三个固定栏目。产出：栏目规划。
2. 选题标准：能给读者一个「新的看法」，而不是通知新品。产出：选题库 10 条。
3. 写作结构：**具体故事开头（第一段就有画面）→ 引出问题 → 给出观点／方法 → 落到品牌做的事**。产出：长文 1 篇。
4. 标题与摘要单独打磨，微信打开率主要取决于标题与首图。产出：标题 10 个。
5. 排版：段落短、关键句加粗、配图 3–6 张，控制在 1500–2500 字。产出：排版稿。
6. 分发：公众号＋知乎／头条／行业社群转发，把一篇长文拆成 5 条短内容。产出：二次分发清单。

**关键技巧**：先写给 100 个精准的人看，而不是给所有人；观点要具体、可被反驳；结尾不要硬推销，放一个自然入口。
**常见错误**：写成企业新闻稿，无观点；标题平淡，打开率个位数；只发不推，读者只有自己人。
**怎么验收**：打开率（行业均值 3–8%，【判断】）、在看／转发数、由文章带来的 B 端咨询或合作。
**案例**：`cases/01-餐饮与茶饮.md`（老乡鸡）；`cases/02-食品饮料与酒.md`（卫龙）。

### 2.9 短剧植入

**一句话定义**：把产品写进有剧情的短剧里，借剧的流量做一次性大曝光。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要快速起量；品类适合剧情化（美妆／食品／小家电／App）；能承受 ROI 波动 |
| 不适用 | 预算不足 30 万；需要精准转化与可控 ROI 的生意 |
| 预算量级 | 30–500 万／部（头部作品更高） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 短剧制作方＋平台；品牌方做植入监审 |
| 难度 | ★★★ |

**怎么做**：
1. 选剧：看制作方过往作品的完播与人群画像，不看明星。产出：候选剧单。
2. 定植入方式：**道具植入**（出现产品）、**台词植入**（角色说出卖点）、**剧情植入**（产品推动情节）。产出：植入方案。
3. 写清「必现信息」：品牌名、核心卖点、购买入口，且必须自然融入。产出：植入要求单。
4. 谈权益：除剧内露出，要拿到片段剪辑权、达人帐号二次分发权。产出：权益清单。
5. 播出后同步承接：搜索广告卡位品牌词与剧名词、旗舰店首页改版。产出：承接方案。
6. 监控：剧集播放量 → 品牌词搜索量 → 店铺访客 → 成交，做归因。产出：归因报告。

**关键技巧**：一定要提前准备承接，短剧流量来得快去得也快；「剧名＋品牌」的组合搜索关键词要提前买好；选剧先看它的「人群」与你的目标人群是否重叠。
**常见错误**：植入太硬像广告，观众反感；没做承接，流量全漏掉；只看播放量不看品牌词搜索增幅。
**怎么验收**：品牌词／剧名搜索量增幅、播出期间店铺访客与成交增幅、单次曝光的有效触达成本。
**案例**：`cases/03-美妆个护.md`（韩束）；`cases/26-影视综艺与内容IP.md`（金典 ×《乘风2025》）。

### 2.10 微短剧自制

**一句话定义**：品牌自己做一部剧，把产品变成故事主角，长期沉淀为可反复使用的内容资产。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有内容团队与持续预算；品类需要反复解释（新品类／复杂产品）；想建品牌世界观 |
| 不适用 | 没有内容制作能力；只想做一次性曝光（那用植入更划算） |
| 预算量级 | 5–50 万／部 |
| 见效周期 | 1–3 个月 |
| 谁来做 | 自有内容团队或外部制作公司 |
| 难度 | ★★★ |

**怎么做**：
1. 定剧集核心设定：主角是谁、每集解决什么问题、产品在剧中的角色。产出：世界观 1 页。
2. 选平台：抖音／快手走竖屏强冲突、视频号走生活流。产出：平台选择。
3. 写前 5 集剧本，每集 1–3 分钟，主要目的是「让人想追下一集」。产出：剧本。
4. 边拍边测：先发 5 集测数据，好就续，不好就改。产出：数据决策点。
5. 产品植入遵循「解决问题的道具」原则，不做硬广口播。产出：植入检查表。
6. 做 IP 化沉淀：角色做成头像、表情包、周边，形成长期资产。产出：IP 延展清单。

**关键技巧**：先做小成本试水再放大；每集结尾留钩子；把剧的片段剪成 20 条短内容二次分发。
**常见错误**：一上来就拍 30 集，全部扑掉；剧本像广告剧本；平台审核与版权没提前确认。
**怎么验收**：追更率、单集完播率、剧集带来的品牌搜索与复购、IP 内容的自然传播量。
**案例**：`cases/03-美妆个护.md`（韩束）；`cases/26-影视综艺与内容IP.md`（开心麻花）。

### 2.11 品牌 IP 形象

**一句话定义**：养一个有性格、会说话的虚拟角色，让它替品牌长期与用户互动。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 面向年轻人；需要长期品牌资产；有持续内容预算（3 年以上） |
| 不适用 | 需要短期业绩；没有内容团队喂养 IP |
| 预算量级 | 一次性 3–30 万；养成 5–20 万／年 |
| 见效周期 | 6–18 个月 |
| 谁来做 | 设计＋内容运营团队 |
| 难度 | ★★★ |

**怎么做**：
1. 定 IP 的「性格三词」与「口头禅」，越具体越好。产出：人设卡 1 页。
2. 定与品牌关系：是品牌的化身，还是品牌的伙伴。产出：关系设定。
3. 出三视图＋表情包＋动作库，确保全平台可用。产出：素材包。
4. 让 IP 进入日常内容：客服头像、评论区回复、视频角色、包装。产出：触点清单。
5. 给 IP 设固定栏目（每周一期），保证持续曝光。产出：栏目规划。
6. 半年一次检验：用户是否能说出 IP 的名字与性格。产出：认知调研。

**关键技巧**：IP 的性格要「有缺点」才可爱；要先有内容场景再设计形象，否则只是一个 logo；IP 的说话方式要统一，连客服回复都要照著写。
**常见错误**：设计得很可爱但没有内容喂养，变成吉祥物；IP 与品牌无关联，养大了用户不记得是谁家的；多个 IP 同时做，资源分散。
**怎么验收**：IP 名称的自发提及量、IP 相关内容的互动率、周边／表情包的使用量。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/14-零售商超与便利店.md`（泡泡玛特）。

### 2.12 创始人 IP（不写脚本版）

**一句话定义**：让老板本人成为品牌的信任入口，用「真人」代替「广告」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 老板愿意露脸、有表达欲；品类需要人格信任（食品／教育／医疗／B2B）；没有预算请明星 |
| 不适用 | 老板不愿意／不会表达；创办人有未处理的负面风险 |
| 预算量级 | 0–2 万／月（含剪辑） |
| 见效周期 | 3–6 个月 |
| 谁来做 | 老板本人＋1 个剪辑 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「一句话人设」：我做这个生意的最初原因（故事比头衔有用）。产出：人设 1 句。
2. 设计三个固定内容栏目（如「带你看工厂」「回答一个问题」「行业真相」）。产出：栏目规划。
3. 不写稿，用「问题清单」代替：每条视频前列 3 个要回答的问题，直接讲。产出：问题清单。
4. 固定拍摄场景（办公室／门店／工厂），形成视觉识别。产出：场景选择。
5. 每周固定更新 2–3 条，并在评论区亲自回复。产出：互动记录。
6. 把老板内容与产品卖点对接：讲行业知识时自然带出产品标准。产出：内容—产品对应表。

**关键技巧**：讲「行业真相」比讲「我们多好」更能建立信任；允许有情绪与观点，太圆滑等于没人设；评论区回复是第二条内容线，不能外包。
**常见错误**：找人代写稿导致语气不像本人；只讲成功不讲困难，假；更新断断续续，人设立不住。
**怎么验收**：老板帐号的粉丝画像是否与客户重叠、私信咨询数、由「创始人推荐」带来的成交占比。
**案例**：`cases/01-餐饮与茶饮.md`（老乡鸡）；`cases/16-金融与保险.md`（保险经纪人 IP）。

### 2.13 员工矩阵号

**一句话定义**：把一线员工变成一批小帐号，用「量」覆盖本地流量，降低对单一帐号的依赖。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有 5 家以上门店／30 人以上团队；本地生意需要周边覆盖；已有可复制的内容模板 |
| 不适用 | 团队小于 5 人；员工完全不配合；产品不适合出镜 |
| 预算量级 | 0.3–2 万／月（激励＋剪辑支持） |
| 见效周期 | 2–4 个月 |
| 谁来做 | 总部做模板与培训，员工产出 |
| 难度 | ★★★ |

**怎么做**：
1. 定「统一动作清单」：每条视频必有的 3 个元素（定位／一句门店资讯／统一音乐）。产出：SOP。
2. 给模板与选题库：每周总部下发 5 个题目与示范片。产出：周更选题包。
3. 培训一次：手机拍摄角度、光线、口播三句话。产出：培训记录。
4. 设激励：按播放量／带来的到店数给奖金，不按发帖数。产出：激励规则。
5. 统一挂定位与团购链接，形成本地流量网。产出：帐号清单表。
6. 建立「内容稽核」防止跑偏与违规（用词、价格、承诺）。产出：稽核表。

**关键技巧**：激励必须和「生意结果」挂钩；帐号归属要在入职文件里写清（避免离职带走）；总部只做模板与素材，不做审美要求。
**常见错误**：只发文件不培训，员工不会做；考核发帖数导致应付式内容；员工离职带走帐号与粉丝。
**怎么验收**：矩阵号总曝光、本地到店提及率、平均单帐号产生的咨询数。
**案例**：`cases/01-餐饮与茶饮.md`（海底捞、老乡鸡）。

### 2.14 内容日历

**一句话定义**：把「靠灵感更新」改成「按表更新」，让内容变成可持续的生产线。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 内容靠灵感、经常断更；多人协作没有统一节奏；不知道下周发什么 |
| 不适用 | 只有 1 个人且内容量极小（先解决产能） |
| 预算量级 | 0（人工为主） |
| 见效周期 | 1 个月 |
| 谁来做 | 内容负责人统筹 |
| 难度 | ★☆☆ |

**怎么做**：
1. 定更新频率（不要贪多，先定一个能完成的数字）。产出：频率承诺。
2. 把内容分成四类并配比例：**引流型**（知识／痛点）50%、**种草型**（产品）30%、**信任型**（幕后／溯源）15%、**互动型** 5%。产出：内容配比表。
3. 建立「选题池」：把用户问题、客服记录、评论区问题都丢进去，每周补充 20 条。产出：选题池文件。
4. 排月历：把固定栏目与节点（节日／大促／新品）先排好，再填空。产出：月度日历。
5. 建立「一次生产多次分发」流程：一条视频拆成图文、短句、音频。产出：分发清单。
6. 每月复盘一次：哪类内容产出最多咨询，调整下月比例。产出：复盘报告。

**关键技巧**：日历要排「能完成的量」而不是理想的量；把节日、大促、新品、行业节点一次排半年；内容要「可复用」，别每条都从零开始。
**常见错误**：日历排满但没人执行；只排节日不排日常；不与业务节奏对齐（如淡季猛推）。
**怎么验收**：更新达成率（实际／计划 ≥80%）、每月由内容带来的咨询与成交。
**案例**：`cases/42-摄影与影像服务.md`（海马体）；`cases/01-餐饮与茶饮.md`（麦当劳中国）。

### 2.15 UGC 征集机制

**一句话定义**：设计一个让用户愿意主动拍内容的机制，用用户的内容做免费的广告。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有一定用户基数；产品有可展示性（外观／效果／场景）；缺素材 |
| 不适用 | 用户基数太小；产品无视觉展示价值；没有可给的奖励 |
| 预算量级 | 1–20 万（奖品＋传播） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 内容运营＋社群 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「一句话参与指令」：让用户知道拍什么、怎么拍、发哪里、加什么标签。产出：活动规则（≤50 字）。
2. 定奖励结构：**参与奖**（人人有份，低成本）＋**排名奖**（大奖吸引认真拍）。产出：奖励方案。
3. 降低门槛：提供模板、贴纸、滤镜、拍摄角度示范。产出：素材包。
4. 建「征集入口」：包装 QR、社群、直播间、详情页。产出：入口清单。
5. 做「二次传播」：把优质 UGC 官方转发，并给作者奖励，刺激更多人拍。产出：转发排期。
6. 监控负面内容：设定关键词监控，避免征集变成吐槽大会。产出：监控清单。

**关键技巧**：参与门槛越低越好（一张图＋一句话也算）；要先示范 5 条「样板 UGC」，用户才知道怎么拍；奖励要有「晒得出来」的价值感。
**常见错误**：规则太复杂没人看懂；奖励太小没人参与；不审核内容，负面 UGC 被大量传播。
**怎么验收**：UGC 提交量、带标签的总曝光、UGC 内容被官方二次使用的比例。
**案例**：`cases/08-游戏与泛娱乐.md`（《蛋仔派对》）；`cases/01-餐饮与茶饮.md`（蜜雪冰城）。

### 2.16 直播间脚本结构

**一句话定义**：把直播从「随机聊」变成有节奏的循环脚本，让任何主播上场都能讲出同样效果。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 开了直播但留不住人、讲不明白；主播一换业绩就崩；流量来了不知道怎么接 |
| 不适用 | 产品不适合直播展示；没有稳定小时流量 |
| 预算量级 | 人工，1–3 万／月 |
| 见效周期 | 1–2 个月 |
| 谁来做 | 直播运营写脚本，主播执行 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「5 分钟一循环」脚本：**钩子（留人）→ 产品痛点 → 产品卖点 → 价格对比 → 库存紧迫 → 下单指令**。产出：循环脚本模板。
2. 写 3 套不同循环（进人循环、讲品循环、逼单循环），按在线人数切换。产出：脚本三套。
3. 准备「话术卡」：材质、成分、价格、售后、常见质疑的回答，贴在主播台前。产出：话术卡。
4. 设计「憋单—放价」节奏：整点或半点放一波，形成观看习惯。产出：场控时间表。
5. 每场复盘三个数：进入率、停留时长、转化率，针对最差的环节改脚本。产出：复盘表。
6. 把最强的一段脚本录成示范视频，用来培训新主播。产出：培训素材。

**关键技巧**：主播不需要背稿，需要的是「顺序」；每 30 秒要有一个「留人动作」（提问、抽奖、发券）；价格对比必须有参照物。
**常见错误**：全程硬喊麦，来人就走；脚本太长太复杂，主播记不住；只讲卖点不讲价格与售后。
**怎么验收**：平均停留时长、每小时成交额、进人—停留—下单的漏斗转化率。
**案例**：`cases/42-摄影与影像服务.md`（海马体）；`cases/33-箱包皮具配饰.md`（妃鱼）。

### 2.17 自播 vs 达播（算帐决策）

**一句话定义**：用真实的利润帐，判断该自建直播团队还是投达人，而不是跟风。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有直播收入但算不清哪个更划算；达播一直亏但停不下来；想决定要不要建自播团队 |
| 不适用 | 完全没有直播基础，先做 §5.2 直播间搭建 |
| 预算量级 | 自播 3–20 万／月（含人力）；达播按坑位＋佣 |
| 见效周期 | 1–2 个月 |
| 谁来做 | 财务＋直播负责人共同测算 |
| 难度 | ★★★ |

**怎么做**：
1. 建立「单场损益表」：GMV − 佣金 − 坑位费 − 样品 − 退货 − 履约成本 = 净利。产出：达播损益表。
2. 同样算自播：人力＋场景折旧＋投流＋退货，算出「单场净利」与「单小时成本」。产出：自播损益表。
3. 对比三件事：**净利率、可控性（价格／话术／数据归属）、可复制性**。产出：对比表。
4. 判断品类适合性：高毛利＋需反复讲解 → 自播；极低价＋需大流量 → 达播。
5. 定组合策略：达播做拉新与背书，自播做承接与复购。产出：比例方案。
6. 设定「止损线」：达播 ROI 低于某值连续 2 场即停。产出：止损规则。

**关键技巧**：达播的坑位费是「租流量」，自播是「买产能」，两者要算不同的帐；自播的核心价值是数据与用户资产归自己；达播要看「复播 ROI」而不是单场。
**常见错误**：达播亏钱做规模，越做越亏；自播团队建了但没有稳定流量；只看 GMV 不看退货与履约成本。
**怎么验收**：自播与达播的净利润率对比、复播率、用户留存（达播带来的用户是否复购）。
**案例**：`cases/33-箱包皮具配饰.md`（妃鱼、山下有松）。

## §3 投放类打法（花钱买流量）

> 本节解决：**付钱换流量，并且算得清划不划算。** 铁律：投放前必须先有「承接」（详情页 §8.8、客服 §8.9、私域 §4），否则买来的流量全漏。任何投放都要先做小额测试帐户，跑通 ROI 再放量。

### 3.1 信息流投放（冷启动）

**一句话定义**：用平台算法把广告推给「可能感兴趣的人」，靠素材与人群包不断测试找到能赚钱的组合。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 已有成交模型想放大；新品要快速起量；客单与毛利支撑得起单次获客成本 |
| 不适用 | 毛利极低（<30%）且无复购；详情页与客服没做好（投了必亏） |
| 预算量级 | 1–10 万／月起（测试期建议 300–500 元／天） |
| 见效周期 | 1–4 周 |
| 谁来做 | 投手＋素材团队；素材产能决定成败 |
| 难度 | ★★★ |

**怎么做**：
1. 先算清楚「能承受的获客成本」（CAC 上限 = 客单 × 毛利率 × 可接受回本周期系数）。产出：CAC 红线。
2. 建 3 个帐户分别测：**人群包**（相似人群／兴趣／达人粉丝）、**素材**（口播／剧情／开箱）、**出价方式**。产出：测试矩阵。
3. 每天固定时间看数据，前 3 天只看「消耗与点击」，第 4 天起看「转化成本」。产出：日报表。
4. 每个变量至少测到 50 个转化再判断，否则样本不足。产出：决策记录。
5. 找到「低成本素材＋高转化人群」后，逐步提预算（每次不超过 30%），避免帐户跑崩。产出：放量计划。
6. 建立「素材迭代机制」：每周至少上新 5 条素材，因为素材会衰减。产出：素材排期。
7. 做「承接优化」：落地页、客服、库存同步，避免流量来了接不住。产出：承接检查表。

**关键技巧**：信息流的成败 80% 在素材，不在出价技巧；不要频繁调整帐户设定，会打乱模型学习；「低价起量」的素材常带来低质用户，要按 LTV 而非单次转化判断。
**常见错误**：一天改十次出价，模型永远学不出来；只做一套素材，两周后成本翻倍；没设 CAC 红线，亏到最后才发现。
**怎么验收**：ROI（首单 ROI 与 90 天 LTV ROI 两个口径都要看）、单次转化成本、素材衰减周期。
**案例**：`cases/03-美妆个护.md`（完美日记、韩束）。

### 3.2 搜索广告

**一句话定义**：买用户已经在搜索的关键词，接住「有明确需求」的流量。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 用户会主动搜的品类（家电／教育／医疗／B2B／高客单）；有明确品类词与品牌词 |
| 不适用 | 完全冲动型消费、无人搜索的品类；关键词被竞品垄断且价格极高 |
| 预算量级 | 0.5–20 万／月 |
| 见效周期 | 2–4 周 |
| 谁来做 | 投手；需与客服／落地页配合 |
| 难度 | ★★☆ |

**怎么做**：
1. 分四类建词：**品牌词**（防守，必买）、**竞品词**（进攻，看预算）、**品类词**（主力）、**问题词**（长尾，成本低）。产出：关键词表。
2. 给每个词组配对应的落地页，不要全部丢首页。产出：词—页对应表。
3. 设否定词清单（避免买到无关流量），每周更新。产出：否定词库。
4. 分帐户／分计划跑，分别设定目标转化成本。产出：计划结构。
5. 用「搜索词报告」反查实际来的流量，砍掉无效词。产出：优化记录。
6. 对高转化词加价抢排名，对无效词降价或暂停。产出：出价调整表。

**关键技巧**：品牌词必须买（否则竞品会截走你的老客）；问题词（如「XX 怎么选」）往往 ROI 最高；落地页标题要与关键词一字对应，点击后不跳脱。
**常见错误**：只买大词不买长尾；落地页与搜索意图不符，跳出率极高；不设否定词，钱被无关流量吃掉。
**怎么验收**：关键词质量分、单词转化成本、有效咨询率、品牌词的截流保护率。
**案例**：`cases/20-跨境电商与出海品牌.md`（石头科技）；`cases/06-汽车与出行.md`（长城）。

### 3.3 场景化长尾词挖掘

**一句话定义**：不抢贵的大词，专买「带场景、带问题」的长尾词，用低成本卡精准需求。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 大词买不起（单次点击过高）；品类有大量细分场景（如「产后掉发」「加班胃疼」） |
| 不适用 | 品类场景极少、无搜索行为 |
| 预算量级 | 人工＋0.3–2 万／月 |
| 见效周期 | 1 个月 |
| 谁来做 | 内容＋投手协作 |
| 难度 | ★★☆ |

**怎么做**：
1. 用三种来源挖词：平台搜索下拉框、客服高频问题、评论区与小红书笔记标题。产出：原始词库。
2. 按「人群 × 场景 × 需求」三维组合生成词（如「哺乳期 掉发 怎么办」）。产出：长尾词 100+。
3. 用工具看每个词的搜索量与竞争度，选「有量＋低竞争」的。产出：优先词表。
4. 每个词写一条对应的内容或落地页（标题即关键词）。产出：词—内容对应表。
5. 小额投搜索，观察 7 天，留下有转化的词。产出：验证结果。
6. 把验证过的词做成「内容日历」，用自然流量长期卡位。产出：长期卡位计划。

**关键技巧**：长尾词最好用「内容」接而不是「广告」接，成本更低；把客服问题直接变成词库，最精准；同一场景的多个词要合并到同一落地页，避免分散权重。
**常见错误**：词挖了一堆但不做内容承接；词太冷门，搜寻量撑不起量；只投不做自然排名，一停投就没流量。
**怎么验收**：长尾词的整体转化成本（应显著低于大词）、自然搜索进站占比、词库的月度新增数。
**案例**：`cases/03-美妆个护.md`（珀莱雅）；`cases/29-农业生鲜与供应链品牌.md`（认养一头牛）。

### 3.4 本地生活团购

**一句话定义**：在平台（抖音／美团）上用低价套餐卡住周边客流，换取到店与核销。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有线下门店、需要周边客流；有可标准化的套餐；门店承接能力足够 |
| 不适用 | 服务质量不稳定（差评会发酵）；门店坪效已满、无需引流 |
| 预算量级 | 0.3–3 万／月（含佣金与达人） |
| 见效周期 | 2–6 周 |
| 谁来做 | 平台运营＋门店；达人探店配合 |
| 难度 | ★★☆ |

**怎么做**：
1. 设计「引流套餐」：一份明显低于正价但有辨识度的组合（不是全品类打折）。产出：套餐设计。
2. 算清「核销成本」：套餐让利＋平台佣金＋履约成本，确认单客不亏或可接受。产出：单位经济测算。
3. 上架并优化「团购主图与标题」：写清价格、内容、位置、使用时间。产出：商品页。
4. 找 3–5 个本地达人拍探店视频挂链接，错峰发布（不要同一天）。产出：发布排期。
5. 门店做「核销动作」：核销时引导加私域、发复购券。产出：门店 SOP。
6. 每周看三个数：曝光→点击→核销，卡在哪一环改哪一环。产出：周报。

**关键技巧**：引流套餐要「看得出便宜」而不是「真的全打折」；核销时必须做私域承接，否则只是一次性亏钱；达人分层（1 个中腰部＋4 个素人）比单投头部更稳。
**常见错误**：低价套餐把利润打穿还不带私域；达人同一天发布互相抢流量；套餐使用限制太多，被投诉。
**怎么验收**：核销率、核销后 30 天复购率、加私域人数、单客综合成本。
**案例**：`cases/15-教育文旅与本地生活.md`（淄博烧烤）；`cases/01-餐饮与茶饮.md`（太二酸菜鱼）。

### 3.5 达人分层投放

**一句话定义**：按粉丝量与内容类型分层投放达人，用头部做声量、腰部做背书、尾部做量大。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要规模曝光且预算 10 万以上；新品上市需要集中声量 |
| 不适用 | 预算小于 5 万（先做 KOC）；没有承接方案 |
| 预算量级 | 头部 5–50 万／条；腰部 0.5–3 万／条；尾部 500–3000 元／条 |
| 见效周期 | 1–3 个月 |
| 谁来做 | 媒介／MCN 对接＋内容审核 |
| 难度 | ★★★ |

**怎么做**：
1. 定「投放目的」：是搜索卡位、是声量、还是直接转化？不同目的选不同层。产出：目的界定。
2. 选人标准四条：粉丝画像匹配、互动率真实、内容类型吻合、过往带货数据可查。产出：达人名单。
3. 分层配比（经验值）：头部 10%、腰部 30%、尾部 60%（【判断】）。产出：投放结构。
4. 给统一 brief：必讲 3 个卖点、必出 1 个证据、必有购买入口。产出：brief。
5. 排期错峰：避免所有内容同周发布，形成持续声量。产出：日历。
6. 监控数据：播放、互动、进店、成交，识别「有水分的达人」。产出：效果归因表。
7. 对有真实转化的达人做「复投」。产出：复投名单。

**关键技巧**：看互动率与评论区真实度，不看粉丝量；同一达人连投 3 次比投 3 个新达人更能沉淀认知；一定要拿「二次分发权」，把达人内容放在自己帐号再投一次。
**常见错误**：只买粉丝量大的头部，结果僵尸粉一片；brief 太松，达人全讲自己想讲的；没有承接，流量来了一次性流走。
**怎么验收**：达人内容的进店率、单条 ROI、复投率、品牌词搜索增幅。
**案例**：`cases/03-美妆个护.md`（完美日记）；`cases/51-本土数字营销与MCN.md`（无忧传媒）。

### 3.6 KOC 铺量

**一句话定义**：用大量真实素人／小微帐号的内容，把「搜索结果」铺满，形成看起来「很多人都在用」的效果。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要真实口碑、预算有限；用户决策前会搜（美妆／母婴／家居） |
| 不适用 | 品类无搜索行为；没有足够的真实体验素材 |
| 预算量级 | 500–5 万／月（单条 100–2000 元或置换） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 内容运营＋素人资源池 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「搜索关键词」：确定用户搜什么，所有 KOC 内容都埋这些词。产出：关键词表。
2. 招募 KOC：从老客、社群活跃用户、垂直社群中找，真实用户优先。产出：KOC 名单 30–100 人。
3. 给「内容框架」不给「统一文案」：规定必讲的 3 点，其余让他们自由写。产出：内容指引。
4. 分批发布：每天 3–5 篇，持续 4 周，避免集中发布被判定水军。产出：发布排期。
5. 对自然流量好的内容做小额投流，推上搜索首页。产出：投流清单。
6. 监控「笔记存活率」与「搜索排名」。产出：铺量报告。

**关键技巧**：内容必须「不一样」，否则平台判定同质化；优先选有真实使用场景的帐号；KOC 的核心价值是搜索卡位而不是爆文。
**常见错误**：统一发同一段文案，被平台一锅端；只发不投，笔记沉底；用了僵尸号，一眼看出是水军。
**怎么验收**：目标关键词下自有内容占比、笔记存活率、由搜索带来的进店与成交。
**案例**：`cases/03-美妆个护.md`（完美日记、珀莱雅）。

### 3.7 电商站内推广

**一句话定义**：在天猫／京东／拼多多站内买关键词与展示位，换取搜索排名与流量。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有站内店铺；需要冲销量、拿搜索权重；有明确主推款 |
| 不适用 | 店铺基础（详情页／评价）没做好，投了等于烧钱 |
| 预算量级 | 1–20 万／月 |
| 见效周期 | 2–6 周 |
| 谁来做 | 店铺运营＋投手 |
| 难度 | ★★☆ |

**怎么做**：
1. 先做店铺基础体检：主图、详情页、评价数、售后分数。产出：体检表。
2. 选 1–2 个「主推款」，集中所有资源打单品排名。产出：主推策略。
3. 分两种计划：**搜索推广**（卡关键词）＋**展示推广**（拉新人群）。产出：计划结构。
4. 用「低价引流款」拿流量，「利润款」承接转化。产出：产品组合。
5. 每天监控「投产比（ROI）」与「自然搜索排名」，两者一起涨才算成功。产出：日报。
6. 大促前 30 天开始蓄水，大促期间放量，大促后收缩保利润。产出：大促节奏表。

**关键技巧**：站内推广的目的是「用付费换自然权重」，不是长期靠付费卖货；评价与销量是搜索权重的核心，必须先解决；ROI 要看「付费＋自然」的综合账。
**常见错误**：只做直通车不做店铺基础，越投越亏；停投即死（没有沉淀自然权重）；忽略大促节奏，该收的时候还在冲。
**怎么验收**：综合 ROI、自然搜索排名提升、主推款的自然流量占比。
**案例**：`cases/03-美妆个护.md`（韩束）；`cases/40-预制菜与方便速食.md`（空刻意面）。

### 3.8 品牌广告（开屏／楼宇／电梯）

**一句话定义**：用大曝光媒介一次性触达大量人群，目的是「记住」，不是「马上买」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 已验证转化模型、要做品类心智；有预算支撑 3 个月以上持续曝光 |
| 不适用 | 没验证模型就砸（纯烧钱）；预算撑不过 3 个月 |
| 预算量级 | 开屏 10–100 万／期；分众类 30 万起 |
| 见效周期 | 3–12 个月 |
| 谁来做 | 品牌方＋媒介代理 |
| 难度 | ★★★ |

**怎么做**：
1. 明确「要占什么心智」：一句话＋一个符号，其他全砍。产出：传播主题。
2. 选媒介与人群：电梯看社区与写字楼（覆盖重复率高）、开屏看平台用户画像。产出：媒介组合。
3. 素材必须「3 秒可读」：品牌＋品类＋一句话，不要堆资讯。产出：素材 3 版。
4. 排周期：至少连续 4–8 周，覆盖同一批人 3 次以上。产出：投放排期。
5. 同步做线上承接：搜索广告买品牌词、旗舰店首页改为广告主题。产出：承接方案。
6. 用「品牌搜索量」与「无提示认知度」而不是即时 ROI 验收。产出：效果评估。

**关键技巧**：品牌广告的验收指标是搜索量与认知，不是当期 ROI；重复比覆盖广度重要；线上线下必须同主题，否则钱白花。
**常见错误**：素材资讯太多，3 秒看不完；只投一周，等于没投；投了品牌广告但品牌词没买，流量被竞品截走。
**怎么验收**：品牌词搜索量增幅、无提示认知度、品类词搜索中的品牌提及率。
**案例**：`cases/51-本土数字营销与MCN.md`（分众传媒）；`cases/33-箱包皮具配饰.md`（爱华仕）。

### 3.9 朋友圈广告

**一句话定义**：用微信生态的精准定向能力，把广告投给指定人群并直接留资或到店。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要精准定向＋留资／到店；客单较高、需要线索；有能承接的客服或门店 |
| 不适用 | 无法承接线索（没人跟进就等于白投）；素材违规风险高的品类 |
| 预算量级 | 1–10 万／月 |
| 见效周期 | 2–6 周 |
| 谁来做 | 投手＋客服／门店 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「转化动作」：留电话、加企微、领券到店——只能有一个。产出：转化目标。
2. 定人群包：地域（半径）、年龄、性别、兴趣、行为（如「近期关注装修」）。产出：定向方案。
3. 做素材：外层图（3 秒看懂）+ 内层落地页（表单 3 个字段以内）。产出：素材包。
4. 小额测试（1000–3000 元）测 3 套素材，挑最好的放量。产出：测试结果。
5. 线索进入客服后 5 分钟内必须跟进，否则转化率断崖。产出：跟进 SOP。
6. 记录每个线索的来源与最终成交，计算「单线索成本」与「单线索价值」。产出：线索账。

**关键技巧**：表单字段越少越好（多一个字段流失 20%+，【判断】）；外层素材要像「原生内容」而不是广告；线索响应速度决定成交率。
**常见错误**：素材违规被拒审还没备用方案；线索没人跟；投给太宽的人群，成本虚高。
**怎么验收**：单线索成本、线索有效率（能联系上且有意向的比例）、线索成交转化率与 ROI。
**案例**：`cases/06-汽车与出行.md`（长城）；`cases/33-箱包皮具配饰.md`（爱华仕）。

### 3.10 平台活动报名

**一句话定义**：报名平台大促与行业日，借平台流量池做一次集中的销量与曝光。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 平台有大促／行业日；产品有价格竞争力与库存准备 |
| 不适用 | 产品无让利空间；大促后无法维持价格体系 |
| 预算量级 | 让利 5–20% ＋ 报名门槛＋活动费 |
| 见效周期 | 1 个月 |
| 谁来做 | 店铺运营；需与供应链协同 |
| 难度 | ★★☆ |

**怎么做**：
1. 提前 45–60 天拿到平台活动规则（门槛、价格要求、资源位）。产出：活动规则表。
2. 算「活动价」：让利后是否仍有利润，是否会破坏日常价格体系。产出：价格测算。
3. 准备专属货盘：大促款／清仓款／新品首发，不要用日常主推款全让。产出：活动货盘。
4. 报名并争取资源位（会场坑位、搜索加权），用历史数据谈。产出：资源位清单。
5. 蓄水：活动前 2 周透过私域、内容、老客预告。产出：蓄水计划。
6. 活动期间实时监控库存与客服，活动后做复盘与老客沉淀。产出：复盘表。

**关键技巧**：大促的目的是「拉新客＋清库存」，不是「赚钱」；一定要做活动款的专属规格，避免和日常价比；大促后必须做价格修复（透过换规格、换组合）。
**常见错误**：大促后价格回不去，日常卖不动；库存备太多造成滞销；活动没做私域承接，新客一次流失。
**怎么验收**：活动期 GMV、新客占比、活动后 30 天复购率、价格体系恢复情况。
**案例**：`cases/42-摄影与影像服务.md`（海马体）；`cases/27-茶饮咖啡与烘焙.md`（古茗）。

### 3.11 CPS 分佣投放

**一句话定义**：不预付广告费，按成交付佣金，用别人的流量换自己的销量。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 毛利高、能承受 20–40% 分佣；有用户但缺流量；想低成本测试渠道 |
| 不适用 | 毛利低于 40%（分佣后不赚）；不能接受价格体系被冲击 |
| 预算量级 | 按成交付；先备 1–5 万保证金／样品 |
| 见效周期 | 2–8 周 |
| 谁来做 | 渠道运营＋财务结算 |
| 难度 | ★★☆ |

**怎么做**：
1. 定佣金阶梯：按销售额分档（如 10 万内 20%、以上 25%），激励做大。产出：佣金政策。
2. 选渠道：导购类 App、社群团长、内容带货达人、异业伙伴。产出：渠道清单。
3. 提供「专属链接＋素材包」：图片、文案、短视频、直播切片。产出：推广素材包。
4. 建立结算与对帐制度：数据实时可查，每月固定结算。产出：结算规则。
5. 监控「退货与刷单」，设定风控红线。产出：风控规则。
6. 对业绩好的渠道升级为「独家／定制款」合作，避免互相比价。产出：渠道分层。

**关键技巧**：一定要做「一物一码／专属链接」防串货与归因；把结算周期写进协议（结算慢＝渠道跑）；用「定制规格」避免各渠道比价。
**常见错误**：分佣养出不可控的推广大户，反过来要挟品牌；没有风控，被刷单刷走佣金；各渠道价格不一，用户比价后退货。
**怎么验收**：单渠道 ROI、渠道留存（复推率）、退货率与刷单率、综合毛利。
**案例**：`cases/33-箱包皮具配饰.md`（妃鱼）；`cases/03-美妆个护.md`（完美日记）。

## §4 私域类打法（让客户回头）

> 本节解决：**把一次性流量变成可反复触达的资产，提升复购与客单。** 私域的核心公式：**收到好友的人数 × 触达频率 × 内容质量 × 时机精准度 = 复购。** 没有「加好友的理由」就别做私域，硬加只会被删。

### 4.1 包裹卡引流

**一句话定义**：在包裹里放一张卡，把已购买的用户从平台导到自己的私域。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 已有稳定发货量（月 1000 单以上）；想累积自有用户池 |
| 不适用 | 发货量太小（<300 单／月）；平台明确禁止导流且有封店风险 |
| 预算量级 | 0.1–0.3 元／张（含印刷） |
| 见效周期 | 2–6 周 |
| 谁来做 | 电商运营；客服承接 |
| 难度 | ★☆☆ |

**怎么做**：
1. 定「加好友的理由」：不是「加我领券」，而是「加我领一份专属的东西」（食谱／使用指南／售后服务包）。产出：引流钩子。
2. 设计卡片：正面一句利益，反面一个大 QR＋一句「扫码需要 3 秒」。产出：卡面设计。
3. 选投放位置：放在用户一定会看到的地方（如产品说明书旁、外包装内侧）。产出：投放位置测试。
4. 做「来源标记」：不同渠道用不同 QR，追踪哪个渠道效率高。产出：渠道码表。
5. 加好友后 24 小时内发放承诺的权益，建立第一印象。产出：履约 SOP。
6. 测试三版卡面，选加好友率最高的（经验值 5–15%，【判断】）。产出：测试结果。

**关键技巧**：利益要「具体且即时」（马上给），不要「入群抽奖」；QR 要大到不用对焦；不同渠道分开统计才能持续优化。
**常见错误**：卡片写「扫码领券」但券没吸引力；加了不加群，好友沉底；没有来源标记，不知道哪个渠道有效。
**怎么验收**：包裹卡扫码率、加好友率、加好友后 7 天内首单／复购率。
**案例**：`cases/03-美妆个护.md`（完美日记）；`cases/02-食品饮料与酒.md`（元气森林）。

### 4.2 企微欢迎语 SOP

**一句话定义**：用户刚加你时的那 3 条讯息，决定了他是留下还是删除。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 已加好友但没人回复；加好友后直接发广告导致删除 |
| 不适用 | 还没有好友来源（先解决引流） |
| 预算量级 | 人工，0–0.5 万 |
| 见效周期 | 1–2 周 |
| 谁来做 | 私域运营；需客服配合 |
| 难度 | ★☆☆ |

**怎么做**：
1. 定「欢迎语三段」：**我是谁**（一句，带真人头像）→ **你能得到什么**（三条具体价值）→ **现在做一个小动作**（回复 1／领取权益）。产出：欢迎语模板。
2. 不要一上来发券，先发「内容型价值」（如「这是新手最常问的 3 个问题」）。产出：价值内容。
3. 设定发送节奏：加好友后即时 1 条，10 分钟后 1 条，次日 1 条。产出：发送时间表。
4. 准备「标签问题」：问 1–2 个问题以打标签（如「你偏好哪种口味」）。产出：标签规则。
5. 监控「首日回复率」与「首周删除率」，迭代文案。产出：迭代记录。

**关键技巧**：用真人头像与真实姓名（或暱称），不要用 logo；欢迎语要短，一屏能读完；第一个动作要简单（回复数字），让用户养成互动习惯。
**常见错误**：一上来发优惠券＋长篇介绍；欢迎语太长（超过一屏）；没有标签，后续无法分层运营。
**怎么验收**：首日回复率（经验值 30–50%，【判断】）、首周删除率、标签完成率。
**案例**：`cases/31-眼镜与视光.md`（宝岛眼镜）；`cases/43-婚庆与人生仪式消费.md`（蜜丝卡伦）。

### 4.3 社群分层运营

**一句话定义**：把不同价值、不同意图的用户分到不同群，用不同的内容与节奏运营。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 群超过 3 个、人群混杂；群变成广告群、退群率高 |
| 不适用 | 好友数少于 300（先做一对一） |
| 预算量级 | 0.3–1.5 万／月（人工为主） |
| 见效周期 | 1–2 个月 |
| 谁来做 | 私域运营＋群管理员 |
| 难度 | ★★☆ |

**怎么做**：
1. 定分层维度：**价值**（成交金额／频次）、**意图**（潜在客户／老客／KOC）。产出：分层规则。
2. 建三类群：**福利群**（大而泛，走量）、**VIP 群**（小而精，高客单）、**兴趣群**（按主题，如「减脂食谱」）。产出：群结构。
3. 每群定「群规＋固定栏目」：如周一上新、周三问答、周五福利。产出：群运营日历。
4. 配「群管理员」：真人负责，不要纯机器人。产出：人员安排。
5. 设置「群内价值内容」：群主每天至少发 1 条非广告的价值内容。产出：内容库。
6. 每月清理沉默用户，重新分层。产出：分层更新表。

**关键技巧**：群越小越有效（VIP 群 50–150 人最佳）；群必须有「非广告内容」，否则用户只当广告群；用「兴趣」而非「消费金额」来建群，互动更好。
**常见错误**：所有人群丢一个群；群里只有广告没有内容；群规不执行，变成刷屏群。
**怎么验收**：群活跃度、群内成交额占比、退群率、VIP 群的人均产出。
**案例**：`cases/31-眼镜与视光.md`（宝岛眼镜）；`cases/21-企业服务与SaaS.md`（Notion）。

### 4.4 朋友圈内容配比

**一句话定义**：用「不像广告的人」的姿态发朋友圈，让用户不屏蔽你并主动找你。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 好友数 1000 以上但发圈没人点；全是卖货内容被屏蔽 |
| 不适用 | 好友太少（先解决加好友） |
| 预算量级 | 人工 |
| 见效周期 | 2–4 周 |
| 谁来做 | 私域运营／导购 |
| 难度 | ★☆☆ |

**怎么做**：
1. 定「四类内容配比」：**生活类** 30%（有画面、有情绪）、**专业类** 30%（知识／答疑）、**用户类** 25%（证言／案例）、**卖货类** 15%。产出：配比表。
2. 每天发 1–2 条，固定时段（早 8 点、午 12 点、晚 9 点）。产出：发布时间表。
3. 每条配「真人场景图」，不用产品白底图。产出：素材库。
4. 卖货内容要「有理由」：上新／限时／断货补货，不要天天折扣。产出：卖货理由清单。
5. 每周看一次「互动率」（点赞＋评论／好友数），少于 3% 就换内容结构。产出：周报。

**关键技巧**：先用「生活与专业」内容建立人格，再卖货；评论区主动互动比内容本身更重要；同一个内容可以「一张图＋一句话」，不要长文。
**常见错误**：一天发 5 条全是产品图；把朋友圈当公众号发长文；复制黏贴统一文案，一眼是机器。
**怎么验收**：单条互动率、私聊咨询数、朋友圈带来的成交占比。
**案例**：`cases/31-眼镜与视光.md`（宝岛眼镜）；`cases/03-美妆个护.md`（完美日记）。

### 4.5 分时段分人群发券

**一句话定义**：不再群发同一张券，而是按人群与时间点给「他此刻需要的券」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有标签数据、想提升核销率；券发很多但核销率低 |
| 不适用 | 没有用户标签（先做标签体系） |
| 预算量级 | 让利 3–15% |
| 见效周期 | 2–4 周 |
| 谁来做 | 私域运营＋数据 |
| 难度 | ★★☆ |

**怎么做**：
1. 给用户打三类标签：**价值**（客单／频次）、**偏好**（品类／口味）、**状态**（新客／沉睡／活跃）。产出：标签体系。
2. 设计券的类型：**新客首单券**、**复购券**、**唤醒券**、**升单券**（满 X 减 Y）。产出：券矩阵。
3. 定发送时机：新客加好友 24 小时内、复购周期到点前 3 天、沉睡 60 天后。产出：发送时间表。
4. 分时段发送（如晚餐前发食品券、周末前发到店券）。产出：时段规则。
5. AB 测试：同人群一半发券一半不发，测增量。产出：测试结果。
6. 监控核销率与带来的客单，砍掉核销率过低的券型。产出：券效果表。

**关键技巧**：券要有「使用理由」与「期限」；测试组要有对照，否则分不清是券带来的还是自然购买；券的金额要与客单匹配（太低没感觉、太高伤利润）。
**常见错误**：所有人发同一张券，成本高效果差；券面额过大，正价卖不动；不设对照组，无法判断增量。
**怎么验收**：核销率、领券到核销的转化、券带来的增量 GMV（对照组法）、优惠成本占比。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/01-餐饮与茶饮.md`（麦当劳中国）。

### 4.6 会员阶梯设计

**一句话定义**：设计一套「爬梯子」的会员体系，让用户为了升等级而不断买。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有复购但客户没有升级理由；想提升用户终身价值 |
| 不适用 | 一次性消费品类；没有可持续提供的会员权益 |
| 预算量级 | 让利 3–10% |
| 见效周期 | 3–6 个月 |
| 谁来做 | 私域／会员运营 |
| 难度 | ★★☆ |

**怎么做**：
1. 定 3–4 级（不要超过 4 级），每级有明确门槛（累计消费／次数）。产出：等级结构。
2. 设计「权益阶梯」：低级给价格优惠，中级给专属服务，高级给身分与特权。产出：权益表。
3. 确保「每级都有感」：升级后必须立刻能感受到差异。产出：升级触点清单。
4. 设计「保级／降级」规则，制造每年回头的理由。产出：升降规则。
5. 通知机制：进度条、差多少升级、升级提醒。产出：触达脚本。
6. 监控升级率与高级会员的贡献占比。产出：会员报告。

**关键技巧**：第一级门槛必须「很容易达到」（第一单就能进）；高级权益要「稀缺」，不能人人可得；身分感比折扣更能留住高价值用户。
**常见错误**：门槛设太高，没人爬到第二阶；权益只是折扣，用户没感觉；等级太多，用户记不住。
**怎么验收**：会员升级率、高级会员的人均消费与复购频次、会员贡献的 GMV 占比。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/31-眼镜与视光.md`（宝岛眼镜）。

### 4.7 积分体系

**一句话定义**：把消费变成积分，用积分换取下一次消费的理由，适合高频低客单品类。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 高频低客单品类（饮料／零食／日用）；有线上或门店的会员系统 |
| 不适用 | 低频高客单品类（积分兑换周期太长，无感） |
| 预算量级 | 让利 1–5% |
| 见效周期 | 3–6 个月 |
| 谁来做 | 会员运营＋系统支持 |
| 难度 | ★★☆ |

**怎么做**：
1. 定积分获取规则：消费、签到、评价、分享各给多少分。产出：获取规则表。
2. 定积分使用规则：可兑换的商品、比例、是否有门槛。产出：兑换商城。
3. 设计「积分有效期」（如 12 个月），制造使用紧迫。产出：有效期规则。
4. 兑换商品要是「用户真想要的」，不要放卖不掉的库存。产出：兑换品清单。
5. 做「积分进度提示」：差多少分能换什么，提高黏性。产出：触达脚本。
6. 每季核算积分成本占营收比，控制在目标内。产出：成本报告。

**关键技巧**：兑换门槛要低（第一档 100 分就能换点东西）；积分是「负债」，成本要提前算；兑换品最好和主营相关（能带动连带销售）。
**常见错误**：积分只能换滞销品，用户懒得用；积分成本失控，变成纯亏损；兑换规则太复杂，用户看不懂。
**怎么验收**：积分获取率与使用率、积分会员的复购频次、积分成本占营收比。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/01-餐饮与茶饮.md`（蜜雪冰城）。

### 4.8 沉睡用户唤醒

**一句话定义**：对 60 天以上没买的用户做一次有理由的触达，把一部分人拉回来。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 沉睡用户占比高（如 60 天未购 >50%）；有完整的用户联系方式 |
| 不适用 | 产品已停产或品牌已转型；用户明确表达过不想被打扰 |
| 预算量级 | 0.2–1 元／人（含让利） |
| 见效周期 | 2–6 周 |
| 谁来做 | 私域／CRM 运营 |
| 难度 | ★☆☆ |

**怎么做**：
1. 分层沉睡用户：30–60 天、60–90 天、90 天以上，分开对待。产出：沉睡前段表。
2. 找「唤醒理由」：新品／升级／专属回归价／库存清仓。产出：唤醒主题。
3. 用不同渠道分头测：企微一对一、短信、公众号、外呼。产出：渠道测试结果。
4. 一对一讯息要「像人写的」：带称呼、带上次购买的品类。产出：讯息模板。
5. 给「回归的台阶」：不是直接买，而是先领个小权益。产出：回归路径。
6. 一个月后统计唤醒率与复购率，砍掉无效渠道。产出：唤醒报告。

**关键技巧**：带上「上次买的产品」资讯，唤醒率显著提升（【判断】）；一次只提供一个理由，不要一次发三张券；对 90 天以上的用户考虑「放弃」而不是一直打扰。
**常见错误**：群发同一条讯息给所有人；不带称呼的模板讯息；唤醒太频繁，被拉黑。
**怎么验收**：唤醒率（回复或下单比例）、唤醒成本、唤醒后的 30 天留存。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/31-眼镜与视光.md`（宝岛眼镜）。

### 4.9 老带新裂变机制

**一句话定义**：设计一套让老客愿意主动带新客的机制，用老客的信任降低获客成本。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 产品有社交属性、满意度高；获客成本高于预期 |
| 不适用 | 产品体验差（带来的客会反噬）；没有可追踪的推荐机制 |
| 预算量级 | 让利 8–30%（含奖励） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 私域运营＋技术支持 |
| 难度 | ★★☆ |

**怎么做**：
1. 选「推荐动机」：省钱（双方得券）、赚钱（分佣）、面子（专属邀请码）。产出：激励设计。
2. 降低分享门槛：一键生成的分享图＋一句现成的话。产出：分享物料。
3. 设「双向奖励」：老客得券，新客也得券（双边都有好处，转化才高）。产出：奖励规则。
4. 做「进度可视化」：老客能看到我已推荐几人、还差几人升级。产出：进度页。
5. 分层激励：推荐 1 人得小奖，推荐 5 人得大奖。产出：阶梯奖励。
6. 监控「裂变质量」：新客的复购率，避免拉来纯羊毛。产出：质量报告。

**关键技巧**：奖励要「即时到帐」，延迟到帐等于没有；新客的门槛要低（首单即可）；推荐人最好有「身分感」（如合伙人、体验官）。
**常见错误**：只奖励老客，新客没动力；奖励太大，被刷单党盯上；裂变来的用户无后续承接，一次流失。
**怎么验收**：老带新占新客比例、新客首单率、新客 90 天复购率、单个新客获客成本。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/24-二手与循环消费.md`（转转）。

### 4.10 复购提醒

**一句话定义**：在产品快用完的时点主动提醒用户，把「想起来要买」变成「刚好收到讯息」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有明确消耗周期的品类（护肤／母婴／宠物粮／耗材） |
| 不适用 | 耐用品（无消耗周期）；购买频率极低 |
| 预算量级 | 0.1–0.5 元／人 |
| 见效周期 | 1 个月 |
| 谁来做 | 私域／CRM 运营 |
| 难度 | ★☆☆ |

**怎么做**：
1. 测算每个品类的消耗周期（从购买记录算平均间隔）。产出：周期表。
2. 定提醒时点：消耗周期的 70% 处第一次提醒，90% 处第二次。产出：提醒节奏。
3. 提醒内容要「有用」：附使用建议／新用法，不要只是催单。产出：提醒模板。
4. 附一个「一键复购」链接，减少操作步骤。产出：直达链接。
5. 对提醒后未购的用户，隔 7 天再用不同理由触达一次。产出：二次触达。
6. 监控「提醒后购买率」与「骚扰投诉率」。产出：效果报告。

**关键技巧**：提醒时点比内容更重要——早了没需求，晚了已买别家；提醒要带「新资讯」（新配方／优惠／用法），否则像催单；允许用户一键「暂停提醒」。
**常见错误**：凭感觉定周期，不按数据；提醒太频繁，用户反感；只催单不给价值。
**怎么验收**：提醒后 7 天购买率、复购周期缩短幅度、投诉／拉黑比例。
**案例**：`cases/43-婚庆与人生仪式消费.md`（蜜丝卡伦）；`cases/31-眼镜与视光.md`（宝岛眼镜）。

### 4.11 私域反哺选品

**一句话定义**：用私域用户的真实需求与投票，决定下一个新品做什么，降低开发风险。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 私域有 3000 人以上；有新品开发计划；想降低开发失败率 |
| 不适用 | 私域人数太少（样本不足）；只有单一产品线且不打算扩 |
| 预算量级 | 0（调研成本） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 产品＋私域运营 |
| 难度 | ★★☆ |

**怎么做**：
1. 从私域收集「未被满足的需求」：群聊、客服、评论区的问题都记下来。产出：需求清单。
2. 让用户投票：给 3–5 个方向，用群投票或表单选。产出：投票数据。
3. 邀请 20–50 个核心用户做「试用官」，参与样品测试。产出：试用官名单。
4. 做「预售测试」：在新品量产前用小批量预售验证真实购买意愿。产出：预售数据。
5. 让参与者成为「首批推荐人」，形成口碑。产出：推荐计划。
6. 把「用户共创」的故事做成内容，强化品牌与用户的关系。产出：内容素材。

**关键技巧**：最贵的资讯是「用户愿意为什么付钱」，预售比投票更真实；只听核心用户会做出小众产品，要搭配沉默用户数据；让用户参与的过程本身就是营销。
**常见错误**：只听老客意见，做成小众产品；投票结果好看但没人真买（没做预售验证）；参与者觉得被利用，没有后续反馈。
**怎么验收**：新品预售转化率、试用官的推荐转化、新品上市后的复购率。
**案例**：`cases/31-眼镜与视光.md`（宝岛眼镜）；`cases/03-美妆个护.md`（完美日记）。

## §5 渠道类打法（货怎么铺出去）

> 本节解决：**消费者想买的时候，能不能买到。** 渠道是承接，不是曝光。渠道类打法最大的坑是「只铺货不做动销」，货铺出去不等于卖出去。

### 5.1 电商店铺从零

**一句话定义**：把一个空店铺搭成「能承接流量并完成转化」的完整销售系统。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有产品没店，或店是「僵尸店」；准备开始做线上零售 |
| 不适用 | 产品不适合线上销售（需体验／需安装／保鲜期极短） |
| 预算量级 | 1–5 万起步（不含投流） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 运营＋视觉＋客服（可 1 人起步） |
| 难度 | ★★☆ |

**怎么做**：
1. 定「店铺定位」：卖什么、卖给谁、主推哪一款。产出：店铺定位 1 页。
2. 建立基础设施：类目选择、店铺首页、分类结构、优惠券、客服自动回复。产出：店铺框架。
3. 做主推款详情页（按 §8.8 六要素），务必先做完再投流。产出：详情页。
4. 铺基础评价：透过老客／私域做前 30 条真实评价与晒图。产出：评价计划。
5. 开通必要工具：优惠券、满减、物流模板、售后政策。产出：工具清单。
6. 测转化率：用小额流量测试，看「访客—加购—下单」的漏斗。产出：转化基线。
7. 转化率达标（高于同类目均值）后才开始放量投放。产出：放量决策。

**关键技巧**：详情页与评价是「转化地基」，没打牢就投流等于漏钱；店铺首页只做三件事：主推款、活动、信任；先做单品爆款再谈店铺。
**常见错误**：详情页没做完就投流，钱全放空；铺 50 个 SKU 没有一个主推；没有客服自动回复，夜间流量白流。
**怎么验收**：店铺转化率（对标类目均值）、主推款访客数与加购率、客服响应时长。
**案例**：`cases/03-美妆个护.md`（韩束）；`cases/40-预制菜与方便速食.md`（空刻意面）。

### 5.2 直播间搭建

**一句话定义**：从零建一个能开播、能承接、能持续产出的直播间（人／货／场）。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有货源想开播，缺人缺场景；已有直播但场景寒酸、进人就走 |
| 不适用 | 没有稳定流量来源（先解决流量）；产品无法在直播中展示价值 |
| 预算量级 | 一次性 2–15 万（设备＋场景）；每月人力 2–10 万 |
| 见效周期 | 1–2 个月 |
| 谁来做 | 主播＋场控＋运营（最少 2–3 人） |
| 难度 | ★★★ |

**怎么做**：
1. 定「直播定位」：卖谁的货、什么价格带、什么时间段播。产出：定位 1 页。
2. 搭场景：背景要有品牌辨识（色块／符号／灯光），不要白墙。产出：场景设计。
3. 配置设备：相机／手机＋补光＋收音（收音比画质更重要）。产出：设备清单。
4. 定「货盘结构」：引流款（不赚钱拉人）＋利润款（赚钱）＋形象款（拉品牌）。产出：货盘表。
5. 用 §2.16 的循环脚本排练，先录播测试再开播。产出：脚本＋录播。
6. 定开播节奏：固定时间、固定时长（不要随意改），养成用户习惯。产出：排期表。
7. 每场复盘三数：进入率、停留、转化，只改一个变量。产出：复盘记录。

**关键技巧**：货盘结构比主播话术更重要；固定开播时间让系统与用户都养成习惯；直播间的核心指标是「停留」，先让人留下再谈卖货。
**常见错误**：先买贵设备再想内容；主播换来换去，没有稳定人设；卖的货和平时价一样，用户没有下单理由。
**怎么验收**：平均停留时长、每小时 GMV、进入率、退货率。
**案例**：`cases/33-箱包皮具配饰.md`（妃鱼、山下有松）。

### 5.3 线下门店动线

**一句话定义**：重新设计顾客从进门到结帐的行走路线，让该看到的都看到、该买的都买到。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 进店人数不少但成交率低；客单低、顾客买完就走 |
| 不适用 | 进店人数本身就极少（先做引流） |
| 预算量级 | 一次性 0.5–5 万 |
| 见效周期 | 2–6 周 |
| 谁来做 | 门店运营＋设计；店长执行 |
| 难度 | ★★☆ |

**怎么做**：
1. 画「实际动线图」：连续 3 天观察 30 个顾客怎么走、在哪停、在哪买单。产出：动线热区图。
2. 定三个关键位置：**入口吸引区**（3 秒内看到爆品）、**主动线陈列区**（高毛利／要推的品）、**收银台加购区**。
3. 调整动线：把「要卖的」放在必经之路上；把「顺手买的」放收银台。产出：陈列调整方案。
4. 做「价格可见」：主推品必须有清楚价格牌，降低询问门槛。产出：物料清单。
5. 导购话术配套：把「欢迎光临」改成「今天有 X 活动」。产出：话术卡。
6. 观察 2 周后的「停留时长」与「客单」，再调整。产出：效果对比。

**关键技巧**：门店的核心不是陈列好看，是「让人多走两步」；收银台是最后一次加购机会，必须放东西；价格牌能显著降低询问门槛。
**常见错误**：只改陈列不改导购话术；动线设计成「绕一圈」，顾客烦躁；把高毛利品放在死角。
**怎么验收**：进店成交率、客单价、顾客平均停留时长、动线热区是否符合设计。
**案例**：`cases/01-餐饮与茶饮.md`（太二酸菜鱼）；`cases/42-摄影与影像服务.md`（海马体）。

### 5.4 异业合作

**一句话定义**：找客群重叠但不冲突的品牌互换资源，用低成本换来对方的客户。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 客群重叠但品类不冲突；双方体量相当；都想低成本扩客 |
| 不适用 | 对方会截走你的客户（品类有替代关系）；体量差距太大（谈不动） |
| 预算量级 | 0–5 万（资源互换为主） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 商务／BD；需老板拍板 |
| 难度 | ★★☆ |

**怎么做**：
1. 列出「同一批客户还会买什么」的清单，找 20 个候选品牌。产出：合作清单。
2. 筛选：客群重叠度高、品类不冲突、体量相当、对方也有扩客需求。产出：优先名单。
3. 设计「互换方案」：不是你买我我买你，而是**联合权益**（联名券包／互相引流赠品／联合活动）。产出：合作方案。
4. 明确权责：谁出物料、谁出场地、数据怎么共享、谁负责客服。产出：合作协议。
5. 做一次小规模测试（一场活动／一个券包），成功再扩大。产出：测试结果。
6. 建立长期机制：季度联名／固定互推位。产出：年度合作表。

**关键技巧**：最好的异业合作是「同一场景不同需求」（婚礼＋婚纱＋婚宴）；先小后大，一次活动验证再谈年度；数据共享要写清，否则无法评估。
**常见错误**：找了替代品类合作，客户被截走；只换物料不换客户；没有明确 KPI，做完不知道有没有用。
**怎么验收**：互换带来的实际线索／订单数、获客成本对比、合作方是否愿意续约。
**案例**：`cases/01-餐饮与茶饮.md`（喜茶 × FENDI）；`cases/42-摄影与影像服务.md`（海马体）。

### 5.5 加盟招商

**一句话定义**：把已跑通的单店模型打包成可复制的「招商品」，卖给想创业的人。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 单店模型已跑通（稳定盈利 6 个月以上）；有标准化能力与管理团队 |
| 不适用 | 模型没跑通就招商（加盟商全亏，品牌被毁）；无供应链与督导能力 |
| 预算量级 | 招商会 5–50 万；每年品牌建设 30 万+ |
| 见效周期 | 3–12 个月 |
| 谁来做 | 招商团队＋督导＋供应链 |
| 难度 | ★★★ |

**怎么做**：
1. 验证「单店模型」：把单店损益表、回本周期、选址标准做成一页。产出：样板店文件。
2. 打包「招商品」：品牌手册、选址评估表、开店手册、督导流程、供应链清单。产出：招商资料包。
3. 找「加盟商画像」：谁适合开你的店（资金、时间、性格）。产出：画像定义。
4. 拓客：招商会、短视频内容、行业网站、老加盟商转介绍。产出：招商渠道。
5. 严格筛选：不只看钱，看是否愿意执行标准（不合格的加盟商是品牌杀手）。产出：筛选标准。
6. 建立督导与培训：开店前培训＋开业扶持＋每月巡店。产出：督导 SOP。
7. 设退出机制：亏损店如何处置，避免长期拖累品牌。产出：退出条款。

**关键技巧**：加盟的核心是「让加盟商赚钱」，所以要挑好址、控好成本；用老加盟商的真实数据做招商素材，比广告可信；供应链是长期利润来源，但要透明定价。
**常见错误**：模型未跑通就大规模招商；只收加盟费不管运营；区域保护没做好，同品牌互打。
**怎么验收**：样板店平均回本周期、加盟商 12 个月存活率、加盟商转介绍率。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/32-珠宝钟表.md`（老凤祥）。

### 5.6 分销体系

**一句话定义**：让一批中间商／个人帮你卖货，你给分润并管住价格与秩序。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有毛利空间＋现成渠道人脉；想快速铺开渠道 |
| 不适用 | 毛利低于 40%；没有价格管控能力 |
| 预算量级 | 让利 10–40% |
| 见效周期 | 2–6 个月 |
| 谁来做 | 渠道运营＋财务；需系统支持 |
| 难度 | ★★★ |

**怎么做**：
1. 定「分销层级」（建议不超过 2 级）与每级利润空间。产出：分润政策。
2. 建立「价格体系」：零售价、渠道价、活动价，写死并执行。产出：价格表。
3. 招募分销商：从老客户、行业社群、展会中找。产出：分销商名单。
4. 提供「一套工具」：产品素材、下单系统、培训、售后支持。产出：赋能包。
5. 做「一物一码／专属链接」管理窜货与归因。产出：管控方案。
6. 建立「分销商分级」：业绩好的给独家款、给返点；差的淘汰。产出：分级表。

**关键技巧**：价格体系是分销的生命线，崩了就没人卖；分销商要的是「好卖」不是「利润高」；一定要有数字化管控，否则串货无法查。
**常见错误**：多级分销导致终端价虚高；不做控价，各渠道乱价；只招不管，分销商拿了货就消失。
**怎么验收**：分销商活跃率（持续下单的比例）、终端价格稳定性、窜货投诉数。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/03-美妆个护.md`（完美日记）。

### 5.7 即时零售（闪购）

**一句话定义**：透过平台（美团闪购／京东到家／淘鲜达）做「半小时送达」，承接即时性需求。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 快消／日用／药品／生鲜；门店在核心城区；有拣货配送能力 |
| 不适用 | 低频高客单耐用消费品；无线下履约能力 |
| 预算量级 | 0.3–3 万／月（含平台费用与履约） |
| 见效周期 | 1–2 个月 |
| 谁来做 | 门店＋线上运营；需与平台对接 |
| 难度 | ★★☆ |

**怎么做**：
1. 选品：只上「即时需求高＋毛利够＋易配送」的 SKU（20–100 个）。产出：上架清单。
2. 优化商品卡片：主图清晰、名称含关键词、价格有竞争力。产出：商品页。
3. 计算「履约成本」：包装＋配送＋平台佣金，确认单均有利润。产出：单位经济表。
4. 设置「起送价与满减」引导客单。产出：门槛设计。
5. 用站内广告与平台活动拉首单。产出：推广计划。
6. 监控「缺货率」与「逾时率」，这两项直接影响平台流量分配。产出：履约看板。

**关键技巧**：即时零售的对手是「楼下便利店」，所以价格与速度都要过关；缺货率是平台流量分配的关键；起送价设计得好能显著提升单均。
**常见错误**：把全品类都上架，拣货效率低；履约成本没算清，单单亏损；缺货不及时下架，被平台降权。
**怎么验收**：单均利润、缺货率、逾时率、月订单量与复购率。
**案例**：`cases/40-预制菜与方便速食.md`（三全食品）；`cases/29-农业生鲜与供应链品牌.md`（钱大妈）。

### 5.8 出海（选市场／本地化／自播）

**一句话定义**：把国内验证过的产品与打法搬到海外，但要重新做市场选择、本地化和流量渠道。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 国内见顶；产品有供应链优势；有跨境团队或愿意投入学习 |
| 不适用 | 产品有本地化壁垒（食品口味／尺码／法规）；资金撑不过 18 个月 |
| 预算量级 | 10–200 万（首期） |
| 见效周期 | 6–18 个月 |
| 谁来做 | 跨境团队＋本地合作方 |
| 难度 | ★★★ |

**怎么做**：
1. 选市场：用「品类搜索量／竞品密度／物流成本／合规难度」四项打分，选 1 个市场先做。产出：市场评分表。
2. 选渠道：平台型（Amazon／Shopee／TikTok Shop）、独立站（Shopify）、线下分销，先选一个。产出：渠道决策。
3. 做本地化：包装文案、产品规格、支付方式、售后政策、客服语言。产出：本地化清单。
4. 合规先行：认证、商标、税务、标签法规，一项都不能省。产出：合规清单。
5. 做自播／达人：TikTok 直播与达人分销是当前主要增长渠道。产出：直播排期。
6. 建履约：海外仓或本地仓，先算清「时效—成本」平衡。产出：履约方案。
7. 每月看三数：单件利润、退货率、获客成本，一项不达标就调整。产出：月度看板。

**关键技巧**：不要用国内打法硬套（价格战、直播话术都要改）；先做「小而美」的单点市场，别一上来铺全欧美；本地化不只是翻译，是消费习惯。
**常见错误**：一上来多市场并行，资源全散；忽略认证与税务，货被扣；只看 GMV 不看单件利润与退货。
**怎么验收**：单件净利、退货率、复购率、单市场的月度增长。
**案例**：`cases/20-跨境电商与出海品牌.md`（石头科技、SHEIN）。

### 5.9 批发与供应链

**一句话定义**：把产品卖给 B 端（经销商／零售商／工厂客户），用稳定的大单换取现金流与规模。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有生产能力；想做 B 端；产品标准化程度高 |
| 不适用 | 产能不足；无帐期承受能力 |
| 预算量级 | 0.5–10 万（含展会与样品） |
| 见效周期 | 3–12 个月 |
| 谁来做 | 销售团队＋供应链；需财务配合 |
| 难度 | ★★★ |

**怎么做**：
1. 定「B 端客户画像」：是经销商、连锁零售、还是工厂配套。产出：客户画像。
2. 做「报价体系」：按量分档，并算清帐期成本（帐期 = 隐性利息）。产出：报价表。
3. 准备「B 端资料包」：资质、检测报告、产能、交期、样品。产出：招商资料。
4. 拓客渠道：行业展会、B2B 平台（1688／阿里国际）、老客转介绍、直拜访。产出：拓客计划。
5. 做「样品测试」：先小批量试单，验证质量与交期再谈大单。产出：试单记录。
6. 管控「帐期与回款」：设信用额度，超额停止发货。产出：风控规则。
7. 用 B 端订单反哺自有品牌（供应链能力成为信任背书）。产出：协同计划。

**关键技巧**：B 端要的是「稳定」而不是「便宜」，交期与质量一致性最重要；帐期是最大的隐形杀手，必须算进报价；先做小单建立信任再谈大单。
**常见错误**：为了接单无限延长帐期，现金流被拖死；报价没算帐期成本，越做越亏；只做一家大客户，被对方议价压死。
**怎么验收**：回款周期、客户复单率、单客户毛利率、应收帐款周转。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/40-预制菜与方便速食.md`（安井食品）。

## §6 事件与话题类打法（借势与造势）

> 本节解决：**在短时间内获得大量关注。** 事件类打法是「脉冲式」的，必须配好承接（私域、库存、客服），否则热度来得快、走得也快。

### 6.1 联名合作

**一句话定义**：与另一个品牌／IP 合作推出限定产品或活动，借双方的粉丝做一次集中爆发。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要一次集中爆发、破圈；品牌年轻化；有话题嫁接点 |
| 不适用 | 品牌缺乏基础粉丝（借不到力）；找不到契合的联名对象 |
| 预算量级 | 5–200 万 |
| 见效周期 | 1–3 个月 |
| 谁来做 | 品牌＋商务；需法务确认 IP 授权 |
| 难度 | ★★★ |

**怎么做**：
1. 定「联名目的」：拉新、破圈、还是清库存。产出：目的界定。
2. 选对象三条标准：粉丝重叠但人群不同、调性有张力（反差有话题）、对方也愿意投入。产出：候选名单。
3. 定「联名产品」：必须是「只有在这次才能买到」的限定款（换包装不算）。产出：产品方案。
4. 谈清权益：授权范围、使用期限、分成、宣传义务。产出：合作协议。
5. 造势节奏：悬念预热（§6.5）→ 官宣 → 限量开售 → 二次传播。产出：传播排期。
6. 准备承接：库存、客服、物流、二级市场话题管理。产出：承接方案。
7. 复盘：拉新数、话题量、二级市场溢价（重要信号）。产出：复盘报告。

**关键技巧**：联名必须有「限定理由」（过期不补），否则只是换包装；选「有反差」的对象最容易出话题；二级市场有溢价说明联名成功。
**常见错误**：联名只有包装，产品没变化；双方都不投入宣传，变成单方自嗨；限量太少/太多，没有稀缺感或卖不完。
**怎么验收**：话题量与自然讨论、联名款售罄速度、新客占比、二级市场溢价。
**案例**：`cases/01-餐饮与茶饮.md`（瑞幸 × 贵州茅台、喜茶 × FENDI）。

### 6.2 造节（自己的节日）

**一句话定义**：创造一个属于品牌的固定节日，让每年到这个时间用户就会想起你。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 想固定流量高峰、建立节奏；有明确的品类场景（如夏天／开学／年货） |
| 不适用 | 品类没有季节性；没有持续投入 3 年以上的准备 |
| 预算量级 | 一次性 1–20 万；每年固定投入 |
| 见效周期 | 6–18 个月 |
| 谁来做 | 品牌＋市场部 |
| 难度 | ★★★ |

**怎么做**：
1. 选「时间点」：与品类场景强绑定（如冬天第一杯奶茶、会员日）。产出：节日时间。
2. 给节日一个「固定名字与动作」：名字要短、动作要有辨识度。产出：节日设定。
3. 设计「只有这天才有」的权益：限定产品、限定价格、限定活动。产出：权益方案。
4. 做第一年：不要追求大，追求「记住日期」。产出：首年方案。
5. 每年重复同一动作 3 年，形成习惯。产出：三年规划。
6. 让用户参与共创（投票、征集），把节日变成「大家的」。产出：互动机制。

**关键技巧**：节日必须固定在「同一天／同一时间」，才能形成期待；第一年做得小没关系，关键是年年重复；给节日一个用户能参与的动作。
**常见错误**：造了节没人记得住日期；每年换主题，无法沉淀；第一次就投大钱，第二年撑不住。
**怎么验收**：节日当天的销售峰值、用户主动提及节日的量、节日的年增长。
**案例**：`cases/01-餐饮与茶饮.md`（麦当劳中国）；`cases/43-婚庆与人生仪式消费.md`（中国婚博会）。

### 6.3 热点接梗（响应机制）

**一句话定义**：建立一套快速响应机制，让热点发生时能在数小时内产出自己的版本。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 品类容易与热点挂钩；品牌调性轻松、有网感 |
| 不适用 | 严肃／专业品类；热点涉及灾难、政治、敏感事件 |
| 预算量级 | 0.5–5 万／次 |
| 见效周期 | 48 小时内 |
| 谁来做 | 内容团队；需有「快速拍板」的授权 |
| 难度 | ★★☆ |

**怎么做**：
1. 建「热点雷达」：固定人每天盯平台热榜、行业新闻、社群话题。产出：热点日报。
2. 定「响应分级」：可以接的（娱乐／生活）、不接的（灾难／政治／悲剧）。产出：红线清单。
3. 建「模板库」：把品牌的核心卖点转成 10 个可以套热点的句式。产出：句式库。
4. 设定「30 分钟决策链」：谁拍板、谁制作、谁发布，写清楚避免来不及。产出：响应 SOP。
5. 执行：只做「轻快的 15 秒内容／一张图」，不追求制作精良。产出：响应内容。
6. 复盘：哪些接了有效、哪些接了反而掉粉，更新红线。产出：复盘记录。

**关键技巧**：热点只有 4–24 小时窗口，慢了就没意义；可以不完美但要快；「不接」也是一种策略，乱接比不接更伤。
**常见错误**：蹭灾难／敏感事件翻车；接了但内容与品牌无关，用户莫名其妙；响应太慢，发出来已经过气。
**怎么验收**：响应内容的互动量与涨粉、响应带来的品牌搜索、负面反馈比例。
**案例**：`cases/01-餐饮与茶饮.md`（海底捞、老乡鸡）。

### 6.4 城市营销

**一句话定义**：把品牌与一座城市绑定，用城市的文化与情绪换取本地的深度认同。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 本地属性强（地方餐饮／文旅／区域品牌）；想从本地走向全国 |
| 不适用 | 品牌与城市无关联；没有地方政府／文旅资源配合 |
| 预算量级 | 5–100 万 |
| 见效周期 | 3–12 个月 |
| 谁来做 | 品牌＋本地资源方（文旅／政府） |
| 难度 | ★★★ |

**怎么做**：
1. 找「城市的一个符号」：一种食物、一句方言、一个地标、一种情绪。产出：城市符号。
2. 把品牌与这个符号绑定：产品命名、包装、门店设计、内容都呼应。产出：绑定方案。
3. 争取官方支持：文旅／商务部门的背书与资源位。产出：合作文件。
4. 做「本地专属」：只有本地才有的产品或体验。产出：地域限定款。
5. 引爆：本地达人矩阵＋外地游客的打卡内容同步。产出：传播排期。
6. 走出本地：在外地的门店复制「城市主题」，把地域感变成品牌风格。产出：扩张方案。

**关键技巧**：城市营销的关键是「本地人觉得骄傲」；官方背书能显著放大效果；要有「外地人来一定要打卡」的理由。
**常见错误**：官方不认可，变成自嗨；只做外地人不懂的梗，无法外传；用完城市符号后没有累积品牌资产。
**怎么验收**：本地人的主动传播量、外地游客打卡数、城市主题产品的销售占比、政府资源落地情况。
**案例**：`cases/15-教育文旅与本地生活.md`（淄博烧烤）；`cases/10-B2B工业品与农产品区域品牌.md`（哈尔滨、天水麻辣烫）。

### 6.5 悬念预热

**一句话定义**：在正式发布前有节奏地放出一点资讯，让用户自己猜、自己讨论、自己期待。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 新品发布需要攒期待；已有一定粉丝基础；产品本身有话题点 |
| 不适用 | 没有粉丝基础（没人一起猜）；预热期太长用户失去耐心 |
| 预算量级 | 1–20 万 |
| 见效周期 | 2–6 周 |
| 谁来做 | 品牌市场部＋内容团队 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「一个核心悬念」：只能有一个（新品是什么／价格多少／和谁合作）。产出：悬念设定。
2. 设计 3–4 个「资讯碎片」，分周释放：先是轮廓，再是局部，最后是答案。产出：释放节奏表。
3. 在社群／评论区收集猜测，并给猜对的人奖励。产出：互动机制。
4. 制造「可讨论空间」：留一点争议性（好／不好看都要有人说）。产出：讨论话题。
5. 发布日一次性给出答案，并同步公布「预热期的猜测合集」。产出：发布内容。
6. 追踪预热期间的「主动提及量」与「预约人数」。产出：预热报告。

**关键技巧**：悬念要「能猜得到但猜不全」；预热期控制在 2–4 周最有效；一定要给参与猜测的人回馈，否则下次没人参与。
**常见错误**：吊太久（超过 6 周）用户失去耐心；悬念太抽象，没人猜得出来；预热很热但发布日无货可卖。
**怎么验收**：预热期的讨论量与预约数、发布日的首日销量、预约到购买的转化率。
**案例**：`cases/01-餐饮与茶饮.md`（老乡鸡、瑞幸 × 贵州茅台）。

### 6.6 快闪店

**一句话定义**：开一家只存在几天到几周的店，用限时稀缺换取打卡与体验。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要短期曝光＋试用；新品上市；想进新城市试水 |
| 不适用 | 只想做曝光不想沉淀用户；选址人流本身不足 |
| 预算量级 | 3–60 万／场 |
| 见效周期 | 2–6 周 |
| 谁来做 | 品牌＋活动执行公司 |
| 难度 | ★★★ |

**怎么做**：
1. 定「一个到店理由」：限定产品／沉浸体验／明星到场／免费试用。产出：核心卖点。
2. 选址：人流＋目标人群密度＋社交媒体友好度（好拍照）。产出：选址评估。
3. 设计「必拍场景」：至少一个能出片的装置或空间。产出：空间设计。
4. 设计「数据获取」：进店扫码、试用登记、加私域，每个动作都要有激励。产出：数据方案。
5. 内容配套：本地达人探店＋用户自发打卡＋官方帐号直播。产出：传播排期。
6. 收尾：把快闪店的装置／内容二次利用到其他渠道。产出：资产再利用清单。

**关键技巧**：快闪店的核心 KPI 不是卖货，是「数据获取＋内容生产」；一定要有一个「非来不可」的理由；离场后要有沉淀（私域、会员）。
**常见错误**：只换来打卡照，没沉淀用户；选址在偏僻商场，人流不足；没有内容配套，全靠路人自发。
**怎么验收**：进店人数、内容生产量（UGC 条数）、加私域人数、媒体曝光。
**案例**：`cases/33-箱包皮具配饰.md`（山下有松）；`cases/42-摄影与影像服务.md`（盘子女人坊）。

### 6.7 线下活动引流

**一句话定义**：办一场有吸引力的线下活动，把周边人流变成进店客流与私域用户。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有门店或园区；需要周边导流；有可承办活动的场地 |
| 不适用 | 场地本身无人流；活动与生意无关联 |
| 预算量级 | 0.5–20 万／场 |
| 见效周期 | 2–6 周 |
| 谁来做 | 门店＋活动执行 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「活动钩子」：免费体验、比赛、市集、亲子活动，选一个与客群匹配的。产出：活动主题。
2. 选时间：与门店的低峰时段错开或补峰（如工作日晚上）。产出：时间安排。
3. 做「进店动线」：活动区与销售区链接，让参与者必经货架。产出：场地动线。
4. 定「数据动作」：报名填资料、扫码进群、领券到店。产出：数据方案。
5. 预热：社群＋本地达人＋门店海报，提前 1 周。产出：预热排期。
6. 现场执行 SOP：签到、引导、转化、拍照。产出：执行手册。
7. 会后跟进：48 小时内触达所有参与者。产出：跟进清单。

**关键技巧**：活动必须与主营生意相关，否则来的是「活动爱好者」不是客户；现场必须设计一个「购买动作」；会后跟进比活动本身更重要。
**常见错误**：只来一次，不进私域；活动太泛（如免费送鸡蛋），来的人不是目标客群；没有现场转化设计，活动结束就结束了。
**怎么验收**：活动参与人数、进店率、加私域人数、活动后 30 天成交额。
**案例**：`cases/01-餐饮与茶饮.md`（太二酸菜鱼、老乡鸡）。

### 6.8 媒体发布会

**一句话定义**：用一次正式的发布会向媒体与行业宣告「我们要做一件大事」，换取报导与背书。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有明确新闻点（新技术／新品类／大融资／战略合作）；需要行业与媒体背书 |
| 不适用 | 没有新闻点（记者不会发稿）；面向纯 C 端低价产品 |
| 预算量级 | 3–100 万 |
| 见效周期 | 1–2 个月 |
| 谁来做 | 公关团队＋活动执行 |
| 难度 | ★★★ |

**怎么做**：
1. 提炼「一句话新闻点」：记者会用这个标题写稿。产出：新闻点。
2. 准备「新闻资料包」：新闻稿、数据、图片、创办人简介（本档不含人物资讯，采访由品牌方自行提供）。产出：媒体包。
3. 邀约名单：产业媒体（影响行业）＋大众媒体（影响消费者）＋垂直 KOL。产出：邀约清单。
4. 设计「可被引用的数据或产品」：发布会要有硬内容，不能只有情怀。产出：核心发布内容。
5. 流程排练：控制在 60–90 分钟，创办人讲话不超过 20 分钟。产出：流程表。
6. 会后分发：48 小时内完成通稿分发与二次解读。产出：分发记录。

**关键技巧**：发布会的成功标准是「报导篇数与质量」，不是现场热闹；必须给媒体一个「可以写的标题」；能现场演示的产品比 PPT 更有说服力。
**常见错误**：没有新闻点，记者不发稿；创办人讲太久，媒体提前离场；会后不跟进，报导量归零。
**怎么验收**：报导篇数与媒体层级、行业内主动讨论量、会后一周内的合作咨询数。
**案例**：`cases/01-餐饮与茶饮.md`（老乡鸡）；`cases/06-汽车与出行.md`（长城）。

### 6.9 公关事件（危机处理）

**一句话定义**：在负面事件发生后，用最快的速度、最诚实的姿态控制损失并重建信任。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 出现产品／服务／言论负面；舆情正在扩散；需要转危为机 |
| 不适用 | 尚无负面（可先做预案）；事实未查清前不要急著发声 |
| 预算量级 | 应急 1–50 万 |
| 见效周期 | 48 小时起，修复期 3–12 个月 |
| 谁来做 | 公关＋法务＋最高决策人 |
| 难度 | ★★★ |

**怎么做**：
1. 建「危机预案」：常见风险清单＋对应话术＋决策链，提前做好。产出：预案手册。
2. 事发 4 小时内：确认事实、评估范围、指定唯一发言人。产出：事实核查表。
3. 24 小时内发声：**承认事实 → 说明处理 → 给出补偿 → 承诺改进**，四段不能少。产出：声明稿。
4. 执行补偿：把承诺兑现并公开进度。产出：进度公示。
5. 持续沟通：不回避、不删评、不做小动作（删评是二次危机）。产出：沟通记录。
6. 修复期：用产品改进与透明化内容重建信任。产出：修复计划。

**关键技巧**：速度 > 完美，慢一步舆论就定型；诚实承认比狡辩有效；唯一发言人，多人发声必然互相矛盾。
**常见错误**：回应太慢或撒谎，二次爆炸；删评／控评被截图，火上浇油；只道歉不赔偿，用户不买帐。
**怎么验收**：舆情峰值持续天数、负面声量占比回落速度、事后 6 个月的品牌搜索与销售恢复。
**案例**：`cases/02-食品饮料与酒.md`（钟薛高）；`cases/01-餐饮与茶饮.md`（西贝）。

### 6.10 公益绑定

**一句话定义**：把品牌与一项社会议题长期绑定，用「持续做对的事」换取信任与情感认同。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要信任与情感认同；品类与某个议题天然相关（环保／助农／教育） |
| 不适用 | 只想做一次性曝光（会被看穿作秀）；没有可持续投入的资源 |
| 预算量级 | 5–100 万 |
| 见效周期 | 3–12 个月 |
| 谁来做 | 品牌＋公益组织；需财务透明 |
| 难度 | ★★★ |

**怎么做**：
1. 选「与生意相关的议题」：你卖什么就关心什么（卖水的做水源保护）。产出：议题选择。
2. 找合作方：正规公益组织，需具备公开募捐资格。产出：合作确认。
3. 定「可量化承诺」：如「每卖一瓶捐一分」。产出：承诺条款。
4. 做「透明披露」：定期公开捐赠金额与去向。产出：披露报告。
5. 让消费者参与：设计可参与的动作（如包装上写「你已捐出」）。产出：参与机制。
6. 长期做：至少 3 年，不要一年换一个议题。产出：三年规划。

**关键技巧**：公益要和生意相关，否则显得刻意；透明是最好的公关；消费者参与感比捐款本身更能换取忠诚。
**常见错误**：被扒出作秀或数据不实，反噬更狠；一次做完就停，变成一次性营销；承诺过度，无法兑现。
**怎么验收**：议题相关的品牌好感度、公益相关内容的自然传播量、参与消费者的复购率。
**案例**：`cases/45-物流与快递服务.md`（顺丰）；`cases/02-食品饮料与酒.md`（白象）。

## §7 信任类打法（让人敢买）

> 本节解决：**用户已经知道你、也有需求，但不敢下单。** 信任类打法是转化率提升最快的一类，成本低、见效快，且几乎所有客单 100 元以上的生意都必须做。

### 7.1 评测与背书

**一句话定义**：让第三方替你说话，用「别人说好」代替「自己说好」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 新品无信任基础；需要第三方发声；品类有「王婆卖瓜」的天然质疑 |
| 不适用 | 找不到可信的第三方；产品经不起检验 |
| 预算量级 | 0.3–10 万 |
| 见效周期 | 1–3 个月 |
| 谁来做 | 公关／媒介；需产品端配合送样 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「要证明的三件事」：安全、有效、值得这个价。产出：信任缺口清单。
2. 选背书类型：**权威机构**（检测／认证）、**专业人士**（医生／工程师／主厨）、**垂直媒体**、**真实用户**。产出：背书组合。
3. 准备「可验证的证据」：检测报告编号、专利号、实测数据。产出：证据包。
4. 安排第三方独立体验，不给「结论要求」。产出：体验记录。
5. 把背书做成「可视化物料」：详情页、包装、门店展板。产出：物料清单。
6. 监控「背书是否被质疑」，有质疑立即补证据。产出：舆情监控。

**关键技巧**：能被验证的背书才有效（有编号、有机构、有日期）；不要买评测结论，会被扒；专业人士的背书比明星更适合功能型产品。
**常见错误**：买来的背书被扒，信誉破产；背书放在详情页底部没人看；背书内容与用户关心的问题不对位。
**怎么验收**：详情页停留时长、加购率变化、咨询中「可信吗」类问题的下降。
**案例**：`cases/31-眼镜与视光.md`（明月镜片）；`cases/20-跨境电商与出海品牌.md`（石头科技）。

### 7.2 权威认证展示

**一句话定义**：把已获得的资质、认证、标准用最直观的方式展示给用户看。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 专业品类（医疗／母婴／食品／建材）；用户对安全与合规敏感 |
| 不适用 | 没有任何真实认证（不可造假，造假直接违法） |
| 预算量级 | 0.5–20 万（含认证申请成本） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 合规／品控＋品牌设计 |
| 难度 | ★☆☆ |

**怎么做**：
1. 盘点已拥有的认证与资质（生产许可、检测标准、专利、行业协会）。产出：认证清单。
2. 判断「用户真正在乎哪一项」，不要全堆上去。产出：优先展示项。
3. 做成「图形化标签」放在用户必看位置（详情页前 3 屏、包装、门店）。产出：标签设计。
4. 每项认证配一句「这对你有什么好处」的解释。产出：解释文案。
5. 附上「可查询的编号或链接」，提高可信度。产出：查询入口。
6. 定期更新（认证过期是常见的翻车点）。产出：到期提醒表。

**关键技巧**：认证要「翻译成人话」（用户不懂国标编号）；放在决策位置而不是页脚；可查询的编号能显著提升可信度。
**常见错误**：把认证堆成一面墙，用户看不懂；认证过期未更新被用户发现；展示的认证与用户关心的问题无关。
**怎么验收**：详情页跳出率、转化率变化、咨询中合规类问题的下降。
**案例**：`cases/20-跨境电商与出海品牌.md`（石头科技）；`cases/31-眼镜与视光.md`（明月镜片）。

### 7.3 真实用户证言

**一句话定义**：把用户的原话搜集起来，用最真实的样子展示，让潜在客户看到「和你一样的人已经买了」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有种子用户但没收集；用户决策受同侪影响大（母婴／教育／3C） |
| 不适用 | 用户基数太小；证言未经授权使用 |
| 预算量级 | 0–2 万 |
| 见效周期 | 1 个月 |
| 谁来做 | 社群运营＋内容 |
| 难度 | ★☆☆ |

**怎么做**：
1. 主动收集：售后回访、社群、评论区，用「三个问题」引导（你为什么买／用了多久／效果如何）。产出：证言池。
2. 分三类整理：**功效型**（解决了什么问题）、**场景型**（什么场景用）、**对比型**（比之前用的好在哪）。产出：证言分类表。
3. 保留真实感：原文照登、不修饰、允许有小瑕疵。产出：证言卡片。
4. 展示位置：详情页、直播间贴片、门店展板、社群。产出：投放位置表。
5. 征得授权（文字或录音同意），避免法律风险。产出：授权文件。
6. 持续更新，避免「三年前的证言」。产出：更新节奏。

**关键技巧**：有具体细节的证言更可信（「用了 3 周，早上起来不泛红了」胜过「很好用」）；带真实场景照（不是摆拍）胜过纯文字；负面转正的证言力量最大。
**常见错误**：编造证言被识破；用网图配假证言；证言与产品宣称不一致（如食品说疗效）。
**怎么验收**：详情页加购率、社群中用户主动分享的数量、咨询转化率。
**案例**：`cases/03-美妆个护.md`（珀莱雅）；`cases/31-眼镜与视光.md`（宝岛眼镜）。

### 7.4 成分与工艺透明化

**一句话定义**：把配方、原料、工艺摊开给用户看，用透明换信任。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 品类信任门槛高（护肤／保健品／母婴／食品）；用户对「智商税」敏感 |
| 不适用 | 配方是核心机密且无法回避（可改为展示工序而非配方） |
| 预算量级 | 0.5–20 万 |
| 见效周期 | 3–6 个月 |
| 谁来做 | 产品／研发＋内容团队 |
| 难度 | ★★☆ |

**怎么做**：
1. 列出用户最常质疑的 5 件事（含什么／不含什么／为什么贵）。产出：质疑清单。
2. 针对每一项给出「可公开的资讯」：成分表、含量、产地、检测结果、工艺流程。产出：公开资讯表。
3. 把专业内容「翻译成人话」：一句成分，配一句「对你有什么用」。产出：成分卡。
4. 做成系列内容（每集讲一个成分／一道工序）。产出：内容系列规划。
5. 在包装与详情页设置「成分查询区」。产出：查询入口。
6. 开放参观／直播工厂，让透明可被验证。产出：开放计划。

**关键技巧**：透明不是把所有资讯丢出来，是「回答用户真正想问的」；主动讲「我们不含什么」比讲「我们含什么」更有力；工艺透明要和价格挂钩（解释为什么贵）。
**常见错误**：讲太专业，消费者听不懂；只讲优点不讲取舍（显得不真诚）；透明化后被发现有隐瞒，信任崩塌更严重。
**怎么验收**：详情页停留时长、客单价接受度、关于成分的咨询转化率。
**案例**：`cases/03-美妆个护.md`（珀莱雅）；`cases/32-珠宝钟表.md`（老铺黄金）。

### 7.5 第三方检测

**一句话定义**：花钱做一次公开的第三方检测，用机构的公信力对抗「智商税」质疑。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要对抗「智商税」质疑；品类有明确可测指标（功效／安全／耐用） |
| 不适用 | 检测项目与用户关切不对位（测了没人关心的指标） |
| 预算量级 | 0.3–5 万／次 |
| 见效周期 | 1–2 个月 |
| 谁来做 | 品控＋公关；需选有公信力的机构 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「用户最想被证明的指标」（不是你能测的指标）。产出：检测项目清单。
2. 选机构：优先国家级／国际互认（CNAS、SGS、Intertek 等），并确认其报告可公开。产出：机构选择。
3. 送检并保留完整样品链路凭证。产出：检测报告。
4. 把报告「可视化」：把结论翻译成一句话＋图表。产出：物料。
5. 把报告编号做成可查询入口。产出：查询链接。
6. 若结果不理想，先改产品而不是隐瞒。产出：改进决策。

**关键技巧**：测用户关心的指标，不是自己最容易过的指标；报告要能查；把「检测条件」一并公开，避免被质疑「有条件才达标」。
**常见错误**：检测项目与用户关切不对位；报告不可查被质疑造假；测出问题后隐瞒，被扒后爆炸。
**怎么验收**：咨询中质疑类问题的下降、详情页转化率、公关负面声量占比。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（黄天鹅）；`cases/31-眼镜与视光.md`（明月镜片）。

### 7.6 创始人出镜背书

**一句话定义**：创办人用自己的名字与人格替产品做担保，让「跑路」的担心消失。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 品类需要人格担保（食品／教育／医疗／高客单）；用户担心售后与跑路 |
| 不适用 | 创办人有未处理的负面；创办人不愿承担（口头背书不可靠） |
| 预算量级 | 0–3 万／月 |
| 见效周期 | 2–6 个月 |
| 谁来做 | 创办人本人＋内容团队 |
| 难度 | ★★☆ |

**怎么做**：
1. 让创办人做一个「具体承诺」：如「不满意我亲自退」。产出：承诺条款。
2. 承诺要「可执行」：写明规则与时限（空话无效）。产出：执行细则。
3. 用内容反复展示承诺：短视频／直播／详情页。产出：内容排期。
4. 让创办人亲自处理一次投诉并公开过程。产出：案例内容。
5. 保持一致性：承诺不因销量增长而缩水。产出：履约监控。
6. 若创办人有专业背景（如医生／工程师），优先展示专业而非身分。产出：背书重点。

**关键技巧**：承诺要「具体到能被检验」；创办人的专业背景比职位更有说服力；一次真实的售后处理比 10 条广告有效。
**常见错误**：承诺太模糊（「做好每一件产品」）；承诺后不执行被用户截图；创办人说错话翻车，波及品牌。
**怎么验收**：售后纠纷的用户满意度、详情页信任类模块的停留与点击、退款率与好评率。
**案例**：`cases/01-餐饮与茶饮.md`（老乡鸡）；`cases/29-农业生鲜与供应链品牌.md`（认养一头牛）。

### 7.7 试用装策略

**一句话定义**：用一个小规格让用户零风险试一次，把「不敢买」变成「先试试」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 客单高、决策门槛高（护肤／香氛／小家电）；用户对效果有疑虑 |
| 不适用 | 试用装成本高于获客价值；产品无法用小规格呈现效果 |
| 预算量级 | 单份成本 3–20 元 |
| 见效周期 | 1–2 个月 |
| 谁来做 | 产品＋电商／私域运营 |
| 难度 | ★☆☆ |

**怎么做**：
1. 定「试用装要证明的唯一效果」，不要什么都试。产出：试用目标。
2. 设计规格：能用 3–7 天（够判断效果），成本可控。产出：规格与成本表。
3. 定发放方式：随正装附赠、低价单独售、社群免费领、门店派样。产出：发放方案。
4. 设置「回购钩子」：试用装里放专属正装券，并限定有效期。产出：券策略。
5. 追踪「试用—购买」转化路径，识别哪个渠道的试用转化最好。产出：转化追踪表。
6. 对未回购的试用用户做二次触达（问效果，不催单）。产出：回访话术。

**关键技巧**：试用装要「真的够用出效果」，太小的试用装等于没试；券要有期限；别让试用装比正装更划算（会只卖试用装）。
**常见错误**：只领不买，亏在物流与包装；试用装效果不明显，反而打消购买；没有券与回访，试用就白费。
**怎么验收**：试用装发放量、试用后 30 天回购率、单个回购客的获客成本。
**案例**：`cases/03-美妆个护.md`（完美日记、珀莱雅）。

### 7.8 无条件退换

**一句话定义**：把退换货门槛降到零，用「你自己承担风险」换取消费者的下单决心。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 用户担心买错、转化卡在最后一步；退货成本可控；产品不易被恶意退 |
| 不适用 | 食品／个护等卫生类不可退品类；退货成本极高的品类 |
| 预算量级 | 退货率上浮 2–8% |
| 见效周期 | 2–8 周 |
| 谁来做 | 客服＋财务；需系统支持 |
| 难度 | ★☆☆ |

**怎么做**：
1. 算清「退货成本」：物流＋损耗＋人工，与转化率提升做对比。产出：成本测算。
2. 定规则：如「30 天无理由，运费我出」，规则要一眼看懂。产出：退换政策。
3. 把政策放在「决策位置」：详情页、商品标题、客服话术第一句。产出：物料位置。
4. 简化流程：一键申请、免举证、快速退款。产出：流程设计。
5. 监控「恶意退货」：设定风控门槛（如同一帐号频繁退）。产出：风控规则。
6. 对退货用户做「为什么退」的调研，反哺产品。产出：退货原因报告。

**关键技巧**：政策要「口语化到能被记住」（30 天不喜欢就退）；流程越简单效果越好（要举证的等于没有）；退货原因是最真实的产品反馈。
**常见错误**：政策写在隐蔽处等于没做；退货流程复杂，用户放弃；被恶意退货拖垮，没设风控。
**怎么验收**：转化率提升幅度、退货率、退货用户的二次购买率、退货成本占营收比。
**案例**：`cases/24-二手与循环消费.md`（只二）；`cases/20-跨境电商与出海品牌.md`（石头科技）。

## §8 定价与转化类打法（把流量变成钱）

> 本节解决：**流量已经有了，但转化率低、客单低。** 转化类打法见效最快、成本最低，通常是投入产出比最高的一类，任何客户都应该先做一轮。

### 8.1 价格锚定

**一句话定义**：用一个参照价格让用户觉得「现在这个价很划算」，从而提升客单与转化。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要拉高客单或显得划算；有高价款与主推款可组合 |
| 不适用 | 单一 SKU、无对比空间；锚点太假（用户会算出溢价） |
| 预算量级 | 0（策略设计） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 定价／运营 |
| 难度 | ★★☆ |

**怎么做**：
1. 建立三个价格点：**锚点款**（高价，树立价值）、**主推款**（想卖的，居中）、**引流款**（低价，拉人）。产出：价格结构。
2. 锚点款要「真实存在且功能更强」，不能只是虚高标价。产出：产品差异表。
3. 在详情页做「对比展示」：把三个款并排放，标出各自适合谁。产出：对比模块。
4. 用「原价划线」时，必须是真实的历史售价（否则违法）。产出：合规检查。
5. 测试：A 版只放主推款，B 版放三款对比，看客单与转化。产出：测试结果。
6. 每季复核价格结构是否还合理。产出：价格复核表。

**关键技巧**：锚点的核心是「让主推款看起来是性价比最高的」；三个价格点最有效，多了用户会决策瘫痪；锚点必须真实，否则被投诉。
**常见错误**：锚点太假，用户算出溢价；只标高价却没有对应价值；原价划线不实，触法风险。
**怎么验收**：客单价、主推款销售占比、转化率、价格相关投诉数。
**案例**：`cases/32-珠宝钟表.md`（老铺黄金）；`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）。

### 8.2 套餐设计

**一句话定义**：把商品组合成套餐，用「配套更省」的理由提升客单与转化。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 单品毛利低，需要提升客单；产品有天然搭配关系 |
| 不适用 | 产品之间无搭配关系；套餐卖爆但毛利为负 |
| 预算量级 | 让利 3–12% |
| 见效周期 | 1–2 个月 |
| 谁来做 | 产品＋运营 |
| 难度 | ★★☆ |

**怎么做**：
1. 找「天然搭配」：用户买 A 也常买 B（用订单数据找）。产出：搭配关联表。
2. 定套餐类型：**入门组合**（降低尝试门槛）、**周期组合**（一次买够一个周期）、**升级组合**（含高毛利款）。产出：套餐矩阵。
3. 定价格：套餐价要比单买便宜，但整体毛利不能为负。产出：毛利测算表。
4. 在详情页／直播间把套餐放在预设选中位置。产出：页面设计。
5. 给套餐一个「使用场景名字」（如「新手 7 天入门装」）。产出：命名。
6. 监控套餐占比与毛利，砍掉亏损套餐。产出：套餐效果表。

**关键技巧**：套餐要有一个「用户故事」（谁在什么场景用）；套餐里的高毛利款要「藏在组合里」而不是单独卖；周期组合最能提升客单。
**常见错误**：为凑客单硬搭不相关商品；套餐打折太狠，毛利为负；套餐让用户更难选择。
**怎么验收**：套餐销售占比、客单价提升幅度、套餐毛利率、退货率。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）。

### 8.3 首单钩子（引流品）

**一句话定义**：设计一个「几乎不赚钱但让人愿意试一次」的产品，把新客拉进来。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 新客进不来、不敢试；需要快速累积首批用户与评价 |
| 不适用 | 钩子太便宜引来纯羊毛党，永远不买正价；钩子与正价品无关联 |
| 预算量级 | 让利 30–100%（单品） |
| 见效周期 | 2–6 周 |
| 谁来做 | 产品＋运营 |
| 难度 | ★☆☆ |

**怎么做**：
1. 选「钩子品」：必须是「体验得到核心价值」的产品（不是最便宜的那个）。产出：钩子品。
2. 定价格与限量（免费／1 元／9.9 元），并设定每人限购 1 份。产出：规则。
3. 设计「升级路径」：钩子品用完后自然需要正装（如小样→正装、耗材→主机）。产出：路径设计。
4. 承接：领钩子的用户必须进私域或留下联系方式。产出：承接 SOP。
5. 追踪「钩子客的 90 天复购率」，这才是真正的 KPI。产出：追踪表。
6. 对未复购的用户做一次定向唤醒。产出：唤醒方案。

**关键技巧**：钩子品要能「体验到核心价值」，否则领了也不知道你好在哪；一定要有升级路径，否则就是纯亏；钩子客的质量用复购率衡量，不用领取量。
**常见错误**：钩子太便宜，引来纯羊毛（用完就走）；钩子与正价品无关，领了也不会买；没有承接，领完即流失。
**怎么验收**：钩子客的 90 天复购率、钩子客的 LTV、单个钩子客的获客成本。
**案例**：`cases/42-摄影与影像服务.md`（海马体）；`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）。

### 8.4 免费模式（前端免费后端赚）

**一句话定义**：前端用免费换用户规模，后端用高毛利服务或耗材把钱赚回来。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 后端有高毛利服务／耗材；产品有网络效应；有资金撑前期亏损 |
| 不适用 | 没有后端变现路径；现金流撑不过 18 个月 |
| 预算量级 | 前期投入 5–100 万 |
| 见效周期 | 6–18 个月 |
| 谁来做 | 创办人＋财务；需精算模型 |
| 难度 | ★★★ |

**怎么做**：
1. 算清「后端转化率」：多少人会为后端付费、付多少。这是整个模式的生死线。产出：模型测算表。
2. 定「免费的边界」：免费的部分刚好让用户体验到价值，但不足以完全解决问题。产出：功能分层。
3. 算「单用户补粘贴限」：CAC 必须小于 LTV × 转化率。产出：补贴红线。
4. 先小范围验证：在一个城市／一个人群跑通，再放大。产出：验证数据。
5. 设「止损线」：转化率低于某值即停补贴。产出：止损规则。
6. 逐步收窄免费边界（随著用户习惯形成）。产出：调整计划。

**关键技巧**：免费模式最常死于「后端转化率算错」；免费的边界设计是核心技艺；一定要有止损线，否则越免费越亏。
**常见错误**：后端转化率算太乐观；免费版太强，没人付费；补贴换来的用户没有真实需求。
**怎么验收**：免费用户到付费的转化率、付费用户的 LTV、补贴总额与回本周期。
**案例**：`cases/21-企业服务与SaaS.md`（钉钉、Zoom）。

### 8.5 满减与凑单

**一句话定义**：设置「满 X 减 Y」的门槛，让用户为了达到金额多买一件。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 已有流量，想提升客单；商品单价低、有组合购买可能 |
| 不适用 | 客单已很高；商品间无组合可能 |
| 预算量级 | 让利 5–15% |
| 见效周期 | 2–4 周 |
| 谁来做 | 运营 |
| 难度 | ★☆☆ |

**怎么做**：
1. 定门槛：设在「当前客单的 1.2–1.3 倍」位置，让用户「差一点就想凑」。产出：门槛金额。
2. 算清「让利后毛利」：满减不能让整体毛利为负。产出：毛利测算。
3. 在购物车显示「再买 X 元可减 Y」，推动凑单。产出：购物车提示。
4. 提供「凑单专区」：放低价、高需求的小件商品（如配件、小样）。产出：凑单商品池。
5. 设置阶梯（满 199 减 20、满 299 减 40），引导往上一档凑。产出：阶梯表。
6. 监控「凑单商品是否为低毛利品」，避免凑单拉低毛利。产出：毛利监控。

**关键技巧**：门槛要「差一点就能达到」，太高没人凑；凑单区的商品要「本来就想买」；阶梯档位差异要明显，才有升级动力。
**常见错误**：门槛设太高，用户直接放弃；凑单买一堆低毛利品；满减常年开，变成变相降价。
**怎么验收**：客单价提升幅度、满减使用率、整体毛利率、凑单商品的动销。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城、麦当劳中国）。

### 8.6 限时限量

**一句话定义**：给优惠加上时间或数量限制，把「以后再买」变成「现在就买」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 需要节奏感、制造紧迫；有明确的活动节点 |
| 不适用 | 天天限时，用户不信；库存不足导致履约问题 |
| 预算量级 | 让利 5–20% |
| 见效周期 | 1–2 周 |
| 谁来做 | 运营＋客服 |
| 难度 | ★☆☆ |

**怎么做**：
1. 定「限制类型」：限时（几小时）、限量（几百件）、限人（前 N 名）——只选一种为主。产出：限制设计。
2. 让限制「可见」：倒计时插件、库存进度条、已抢数量。产出：页面组件。
3. 提前预告（24 小时前），让用户有准备。产出：预告内容。
4. 开抢后的「节奏」：分批放量，制造二次抢购。产出：放量节奏。
5. 售罄后立刻公示，强化稀缺信任。产出：售罄公告。
6. 监控用户是否开始「疲劳」，降低频次。产出：疲劳度指标。

**关键技巧**：限制必须真实（假限量被发现后信任崩塌）；倒计时与进度条能显著提升即时转化；频次控制在每月 1–2 次。
**常见错误**：天天限时，用户不信了；假限量被截图，品牌受损；限量后库存不足，履约出问题。
**怎么验收**：活动期转化率、单场销售额、用户对活动的响应度变化（是否递减）。
**案例**：`cases/32-珠宝钟表.md`（DR）；`cases/42-摄影与影像服务.md`（海马体）。

### 8.7 会员价

**一句话定义**：用价格分层奖励会员，让非会员为了省钱而加入，让会员为了划算而多买。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有复购客群，想做价格分层；已有会员系统 |
| 不适用 | 非会员基数大且会觉得被歧视；没有系统支持 |
| 预算量级 | 让利 5–15% |
| 见效周期 | 1–3 个月 |
| 谁来做 | 会员运营＋系统 |
| 难度 | ★★☆ |

**怎么做**：
1. 定「会员价的幅度」：要让人有感但不伤毛利（建议比非会员低 5–15%）。产出：价格表。
2. 加入门槛要低（免费注册／首单即可），目的是把人变成会员。产出：入会规则。
3. 会员价要「明显标示」（如「会员价 ¥89，非会员 ¥109」）。产出：商品页设计。
4. 给会员「额外权益」（免运、专属客服、优先购），不要只有便宜。产出：权益清单。
5. 在结帐页推「一键入会立省 X 元」，是最有效的入会时机。产出：入会引导。
6. 监控会员与非会员的客单、复购差异。产出：会员报告。

**关键技巧**：入会时机选在结帐页最有效；会员价要能「一眼算出省多少」；权益中「专属感」比折扣更能留人。
**常见错误**：非会员觉得被歧视，流失；会员价太低，毛利受损；会员权益只有折扣，没有差异。
**怎么验收**：会员转化率（入会人数／访客）、会员客单与非会员对比、会员复购率。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）；`cases/01-餐饮与茶饮.md`（蜜雪冰城）。

### 8.8 详情页六要素

**一句话定义**：用固定的六个模块重写详情页，系统性解决「看不懂、不信、不敢买」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 有流量但转化率低于行业；详情页靠自夸文案堆砌 |
| 不适用 | 没有流量（先解决流量）；没有证据可用 |
| 预算量级 | 一次性 0.3–5 万 |
| 见效周期 | 2–4 周 |
| 谁来做 | 运营＋设计 |
| 难度 | ★★☆ |

**怎么做**：
1. 重写第 1 屏：**一句话说清你是谁＋解决什么问题＋一个证据**（不要 logo＋大图）。产出：首屏方案。
2. 第 2 屏：**用户痛点场景**（第一人称描述，让用户觉得「说的就是我」）。产出：痛点模块。
3. 第 3 屏：**产品如何解决**（用图示，不用术语）。产出：原理图。
4. 第 4 屏：**证据区**（检测／认证／用户证言／数据）。产出：证据模块。
5. 第 5 屏：**对比区**（与竞品／与旧款的对比表）。产出：对比表。
6. 第 6 屏：**打消疑虑**（售后政策、FQA、快递时效、客服入口）。产出：FAQ 模块。
7. 上线后做 A/B 测试，逐屏优化转化。产出：测试记录。

**关键技巧**：第一屏决定 80% 的去留；每个卖点必须配证据；用「用户说」代替「我们说」。
**常见错误**：首屏是大 logo 与品牌故事；全是形容词没有证据；模块顺序错（先讲自己再讲用户）。
**怎么验收**：详情页跳出率、停留时长、加购率、转化率（对标行业均值）。
**案例**：`cases/03-美妆个护.md`（韩束）；`cases/40-预制菜与方便速食.md`（空刻意面）。

### 8.9 客服话术

**一句话定义**：把客服从「回答问题」变成「解决疑虑并促成下单」，用话术把询单变成订单。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 询单多、下单少；客服只会报价格与库存 |
| 不适用 | 没有询单（先解决流量与详情页） |
| 预算量级 | 人工，0–1 万 |
| 见效周期 | 1–2 周 |
| 谁来做 | 客服主管＋运营 |
| 难度 | ★☆☆ |

**怎么做**：
1. 收集「询单后没下单」的 20 个常见问题。产出：疑虑清单。
2. 为每个问题写「三步话术」：**先共情 → 再给证据 → 最后给一个小推动**。产出：话术库。
3. 建立「主动提问」机制：不等待，先问「你主要想解决什么问题」。产出：开场话术。
4. 设定「异议处理」话术：太贵／再看看／怕没效果，各有应对。产出：异议话术表。
5. 用快捷回复但不机械：保留个性化称呼与上下文。产出：快捷短语库。
6. 每周复盘「询单转化率」，更新话术。产出：周报。

**关键技巧**：客服的第一句要「提问」而不是「您好」；给一个「小推动」（今日下单赠 X）比讲十个卖点有效；把差评与退款原因写进话术库。
**常见错误**：话术机械被用户识破；只回答不引导；把「亲，还有什么问题吗」当结尾。
**怎么验收**：询单转化率、平均回复速度、客服满意度评价、退款原因分布。
**案例**：`cases/42-摄影与影像服务.md`（海马体）；`cases/31-眼镜与视光.md`（宝岛眼镜）。

### 8.10 加购推荐

**一句话定义**：在用户已经决定买的时候，顺手推荐一件相关商品，用最低成本提升客单。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 已在成交，想提升客单；有搭配关系的商品 |
| 不适用 | 推荐不相关商品，干扰成交 |
| 预算量级 | 0 |
| 见效周期 | 2–4 周 |
| 谁来做 | 运营＋客服 |
| 难度 | ★☆☆ |

**怎么做**：
1. 从订单数据找出「买 A 也常买 B」的组合。产出：关联商品表。
2. 选「低价、高相关、高毛利」的加购品。产出：加购品池。
3. 设置「加购价」：比单买略便宜，但幅度不用太大（用户已在买）。产出：加购定价。
4. 在三个位置推：购物车、结帐页、客服确认订单时。产出：推荐位置。
5. 话术要「顺手」：如「要不要顺便带一支替换刷头，一起发」。产出：加购话术。
6. 监控加购接受率，砍掉接受率低于 5% 的商品。产出：加购效果表。

**关键技巧**：加购品要「买了主商品一定会需要」；推一个就好，推三个等于没推；客服主动提加购比页面推荐更有效。
**常见错误**：推不相关商品干扰成交；加购品太多选择瘫痪；加购价太低，变成变相打折。
**怎么验收**：加购接受率、客单价提升、加购品的毛利率。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/27-茶饮咖啡与烘焙.md`（瑞幸咖啡）。

### 8.11 购物车挽回

**一句话定义**：对「加购但没下单」的用户做定向触达，把已经有购买意向的人拉回来。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 加购不下单占比 30% 以上；有用户联系方式或平台触达工具 |
| 不适用 | 没有触达渠道；加购率高但下单率本来就正常 |
| 预算量级 | 让利 3–10% |
| 见效周期 | 1–2 周 |
| 谁来做 | 运营＋客服 |
| 难度 | ★☆☆ |

**怎么做**：
1. 分析「加购未下单」的原因：价格、运费、库存、忘了、比价。产出：原因分布。
2. 分头设计触达：**忘了**用提醒、**价格**用限时券、**运费**用免运、**比价**用差异说明。产出：触达策略表。
3. 用平台工具（站内信／短信／企微）分渠道触达，间隔 4 小时以上。产出：触达排期。
4. 话术不要提「你没付款」，要提「你的商品快没了／有优惠」。产出：话术模板。
5. 对 24 小时仍未下单的用户，给「一次性限时补贴」（用完即失效）。产出：补贴规则。
6. 监控挽回率，并注意「别伤正价客」（优惠只给未下单者）。产出：效果报告。

**关键技巧**：触达要「给理由」而不是「催付款」；第一次触达不要给钱（先提醒），第二次再给；优惠要限时，否则用户会习惯等券。
**常见错误**：直接降价伤正价客；触达太频繁；不分析原因就统一发券。
**怎么验收**：挽回率（触达后 48 小时下单比例）、一次触达 vs 二次触达的效果对比、补贴成本占比。
**案例**：`cases/03-美妆个护.md`（完美日记、韩束）。

## §9 诊断类打法（先搞清楚卡在哪）

> 本节是所有接案的第一步。**没有诊断就打法，等于乱开药。** 诊断类打法成本极低、价值极高，建议每个案子的第一周都做一遍。诊断结论必须落到「曝光／信任／转化／复购／渠道」五个环节中的具体一个。

### 9.1 全链路数据表

**一句话定义**：把从曝光到复购的所有环节数据拉到一张表，一眼看出哪一环在漏水。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 所有客户的第一步；客户说「生意不好」但说不出哪不好 |
| 不适用 | 完全没有数据（先建最小可用的数据采集） |
| 预算量级 | 0 |
| 见效周期 | 1–2 周 |
| 谁来做 | 顾问＋客户的运营／财务 |
| 难度 | ★★☆ |

**怎么做**：
1. 画出完整链路：曝光 → 点击／进店 → 浏览 → 加购／询单 → 下单 → 收货 → 复购 → 推荐。产出：链路图。
2. 为每一环填写「数量、成本、转化率」三个数字。产出：全链路数据表。
3. 标出「行业基准值」（可查平台公开数据或行业报告）。产出：对照表。
4. 找出「低于基准值最多的那一环」——这就是主卡点。产出：卡点结论。
5. 用一行话写出结论：「我们卡在 ___ 环节，转化率 ___，行业均值 ___」。产出：诊断结论。
6. 每月更新一次，追踪改善效果。产出：月度追踪表。

**关键技巧**：只找一个主卡点，不要同时修五个；没有行业基准值就无法判断好坏；数据造假是这个打法最大的死因。
**常见错误**：数据造假或口径不一致，结论全错；只看最后的成交额，不看中间环节；找到卡点但不落实到打法。
**怎么验收**：能否用一句话说清卡点；改善动作执行后该环节数据是否提升。
**案例**：`cases/42-摄影与影像服务.md`（海马体）；`cases/31-眼镜与视光.md`（宝岛眼镜）。

### 9.2 流失用户深访

**一句话定义**：找已经流失的用户做 1 对 1 深度访谈，听他们为什么不买了——这是付钱也买不到的真话。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 复购率低、不知道为什么；有可联系的流失用户名单 |
| 不适用 | 用户基数太小；没有联系方式 |
| 预算量级 | 300–500 元／人（访谈费／礼品） |
| 见效周期 | 2–4 周 |
| 谁来做 | 顾问本人访谈（不要交给客服） |
| 难度 | ★★☆ |

**怎么做**：
1. 定义「流失」：如 90 天未购且无互动。产出：流失定义。
2. 抽样 15–30 人，覆盖不同客单与购买时间段。产出：访谈名单。
3. 设计「不诱导」的问题：先问「你当时为什么买」，再问「后来怎么没买了」。产出：访谈提纲。
4. 访谈 30–45 分钟，全程录音，不做产品推销。产出：录音与逐字稿。
5. 编码归类：把原因分成 4–6 类（产品／价格／服务／替代品／需求消失）。产出：归因分类表。
6. 每类原因对应一个可执行的改善动作。产出：行动清单。

**关键技巧**：一定要问「当时为什么买」，否则听不到真话；用户说的「太贵」通常不是真原因，要追问「和什么比」；找第三方访谈，用户才敢说实话。
**常见错误**：只访熟人，听不到真话；访谈中推销产品；把用户的表面理由当结论。
**怎么验收**：能否列出「流失原因分布」与对应改善动作；改善后 3 个月复购率是否回升。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（认养一头牛）；`cases/42-摄影与影像服务.md`（盘子女人坊）。

### 9.3 复购用户深访

**一句话定义**：访谈最忠诚的用户，找出「真正让人不断回购的理由」，并放大它。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 想找可放大的买点；要做新客获取的素材；想开发新品 |
| 不适用 | 复购用户太少（先做客单—频次判断） |
| 预算量级 | 300–500 元／人 |
| 见效周期 | 2–4 周 |
| 谁来做 | 顾问／产品经理 |
| 难度 | ★★☆ |

**怎么做**：
1. 选「复购 3 次以上」的用户 10–20 人。产出：访谈名单。
2. 问三个核心问题：**第一次为什么买**、**为什么又买**、**会不会推荐给朋友、怎么推荐**。产出：访谈稿。
3. 重点抓「用户的原话」，尤其是「描述产品时用的词」——这些词就是你的广告词。产出：原话库。
4. 找出「未被自己发现的买点」（用户在乎但品牌没在讲的）。产出：新买点清单。
5. 把原话转成内容素材（详情页、广告、证言）。产出：素材转化清单。
6. 对照流失用户的原因，找「留与走」的关键差异。产出：对比结论。

**关键技巧**：用户描述产品的原话就是最好的广告文案；注意「用户在乎但品牌没讲」的点，这是增长机会；一定要问推荐场景（会怎么说给朋友听）。
**常见错误**：只听忠粉，样本偏；把用户的客套话当结论；访完不转成内容素材，白访。
**怎么验收**：能否产出 5 条以上可直接用的用户原话；新素材的转化率是否优于旧素材。
**案例**：`cases/43-婚庆与人生仪式消费.md`（蜜丝卡伦）；`cases/31-眼镜与视光.md`（宝岛眼镜）。

### 9.4 竞品拆解

**一句话定义**：把卖得好的竞品拆到「可抄的动作」层面，搞清楚它到底赢在哪。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 竞品卖得好，想抄得明白；要进新市场前先做；定价与定位需要参照 |
| 不适用 | 完全没有可比竞品（新品类） |
| 预算量级 | 0–2 万 |
| 见效周期 | 2–4 周 |
| 谁来做 | 顾问＋客户团队 |
| 难度 | ★★☆ |

**怎么做**：
1. 选 3 个竞品：**领导者**、**直接对手**、**新兴挑战者**。产出：竞品名单。
2. 拆四个维度：**产品**（规格／成分／价格带）、**渠道**（在哪卖）、**内容**（发什么、发多少、什么火）、**承接**（详情页／客服／售后）。产出：竞品拆解表。
3. 做「用户视角体验」：完整走一遍竞品的购买流程，记录每个触点。产出：体验记录。
4. 找出「它做对了但你能做得更好的」与「它没做而你能补的」。产出：机会点清单。
5. 判断它的成功是「产品力」还是「流量红利」（决定值不值得学）。产出：归因结论。
6. 输出 3–5 个「可执行抄法」。产出：行动清单。

**关键技巧**：必须亲身做一次竞品的完整购买流程，光看数据看不出关键；区分「产品力」与「流量红利」；抄动作不抄表面。
**常见错误**：只抄形式（包装／话术），不懂机制；用旧数据判断；拆完不落地。
**怎么验收**：能否说出「竞品赢在哪一个环节」＋3 个可执行动作；执行后相关指标是否改善。
**案例**：`cases/27-茶饮咖啡与烘焙.md`（霸王茶姬、瑞幸咖啡）。

### 9.5 品类机会扫描

**一句话定义**：在既定品类里系统扫一遍，找出「需求在涨但供给不足」的缝隙。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 想开新品、找新赛道；现有品类增长停滞 |
| 不适用 | 只看宏大趋势不看自家能力（必失败） |
| 预算量级 | 0–5 万 |
| 见效周期 | 2–8 周 |
| 谁来做 | 顾问＋产品 |
| 难度 | ★★★ |

**怎么做**：
1. 选扫描维度：**人群**（谁在变）、**场景**（新的使用场景）、**价格带**（哪个价位缺货）、**规格**（大小／包装／组合）。产出：维度表。
2. 用平台数据找「搜索增长快但商品供给少」的词。产出：机会词清单。
3. 用「需求增速 vs 竞争密度」两维打分，圈出候选机会。产出：机会矩阵。
4. 对每个机会做「能力匹配」：你有什么供应链／渠道／团队优势。产出：能力匹配表。
5. 选 1 个机会做小成本验证（预售／小批量）。产出：验证方案。
6. 决定投入或放弃（明确的 go／no-go 标准）。产出：决策记录。

**关键技巧**：机会要「有供应链支撑」才算机会，否则只是别人的机会；先做小批量验证，不要一次备大量库存；价格带的空隙常常是最好的机会。
**常见错误**：只看趋势不看自家能力；机会太大（巨头也看到了）；验证成本太高，不敢试。
**怎么验收**：验证批量的售罄率与复购率、单品毛利、是否值得加大投入。
**案例**：`cases/40-预制菜与方便速食.md`（空刻意面）；`cases/41-文具文创与办公.md`（猫太子）。

### 9.6 客单-频次四象限

**一句话定义**：用「客单价 × 购买频次」两个维度把生意定位，决定资源该投拉新还是复购。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 不确定该做拉新还是复购；资源分配拿不定主意 |
| 不适用 | 数据不足以算出客单与频次（先补数据） |
| 预算量级 | 0 |
| 见效周期 | 当天 |
| 谁来做 | 顾问＋老板 |
| 难度 | ★☆☆ |

**怎么做**：
1. 算出实际客单价（一年营收／订单数）与年均购买频次。产出：两个数字。
2. 画四象限：**高客单高频**、**高客单低频**、**低客单高频**、**低客单低频**。产出：象限定位。
3. 对照策略：高频高客单重复购与会员；高客单低频重信任与转介绍；低客单高频重规模与便利；低客单低频要重新审视商业模式。产出：策略对应。
4. 检查「客户自以为的定位」与「实际数据的定位」是否一致。产出：落差分析。
5. 据此重排资源优先级。产出：资源分配表。

**关键技巧**：「低客单＋低频」是最危险的象限，必须改模式而不是加投放；客户的自我认知常与数据不符；象限会随业务变化，每半年重算一次。
**常见错误**：象限判断错，资源全押错方向；用「希望」而非数据定位；定位后不调整打法。
**怎么验收**：资源分配是否与象限匹配；半年后客单／频次是否按预期移动。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（钱大妈、百果园）。

### 9.7 LTV-CAC 测算

**一句话定义**：算出「一个用户一生能赚多少」与「获取一个用户要花多少」，决定能不能放大投放。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 决定要不要放大投放；投放亏损但不知道是否正常 |
| 不适用 | 没有复购数据（可用 90 天窗口估算） |
| 预算量级 | 0 |
| 见效周期 | 1–2 周 |
| 谁来做 | 财务＋运营 |
| 难度 | ★★☆ |

**怎么做**：
1. 算 LTV：客单价 × 年均购买次数 × 平均留存年限 × 毛利率。产出：LTV 数字。
2. 算 CAC：总获客成本／新增客户数（只算新客，不算复购）。产出：CAC 数字。
3. 计算 **LTV / CAC 比值**，健康线通常为 3:1（【判断】）。产出：比值。
4. 算「回本周期」：多久能收回获客成本（超过 12 个月要警惕）。产出：回本周期。
5. 用「首单 ROI」与「90 天 ROI」两个口径分别看（首单亏、长期赚是允许的）。产出：双口径报表。
6. 设定「投放上限」：CAC 不得超过 LTV ÷ 3。产出：投放红线。

**关键技巧**：一定要用「分渠道」算 LTV，不同渠道用户质量差异巨大；把退货与履约成本算进 CAC；不要用最乐观的复购率。
**常见错误**：把复购算太乐观，LTV 虚高；CAC 没算退货与履约；用平均值掩盖渠道差异。
**怎么验收**：LTV/CAC 是否 >3、回本周期是否 <12 个月、分渠道的差异是否被识别并用于分配预算。
**案例**：`cases/40-预制菜与方便速食.md`（自嗨锅）；`cases/29-农业生鲜与供应链品牌.md`（认养一头牛）。

## §10 特殊主体专用打法（小企业／新品牌／第二曲线／AI产品／B2B）

> 本节是「整套组合拳」——不是单一打法，而是把前面 9 节的打法按主体类型排成顺序。接到这五类客户时，先看本节的顺序，再回去调具体打法。

### 10.1 小店三公里打法

**一句话定义**：一家服务半径 3 公里的门店，用最小的钱把周边的人变成回头客。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 单店、服务半径 3 公里；预算极有限；周边有稳定居住或办公人群 |
| 不适用 | 想服务全市（什么都做不深）；选址本身人流不足 |
| 预算量级 | 0.3–2 万／月 |
| 见效周期 | 1–2 个月 |
| 谁来做 | 店主本人＋1 名员工 |
| 难度 | ★☆☆ |

**怎么做**：
1. 画「3 公里地图」：标出周边的社区、写字楼、学校、竞品，找出你真正能服务的人群。产出：商圈地图。
2. 定「一个到店理由」并写在门头（§1.5）。产出：门头改造方案。
3. 做「本地生活团购」（§3.4）＋「探店视频」（§2.4），拿下第一批客流。产出：引流动作。
4. 进店必做三件事：加企微（§4.1 的逻辑用在店内）、发复购券、扫码进群。产出：店内 SOP。
5. 做「社群运营」（§4.3）：只做一个群，每周 1 次福利、每天 1 条价值内容。产出：群运营表。
6. 做「老带新」（§4.9）：附近邻里关系强，裂变成本最低。产出：裂变机制。
7. 每月看三个数：进店人数、加私域人数、复购率。产出：月度看板。

**关键技巧**：3 公里的生意靠「熟悉感」，记住老客的名字比发传单有效；所有动作都要落到「加微信」；不要投大范围广告，钱会浪费在不住在附近的人身上。
**常见错误**：想服务全市，投了大范围广告；不做私域，来一次就没了；只做开业活动，活动结束客流归零。
**怎么验收**：周边人群渗透率、加私域人数、30 天复购率、单客月均消费。
**案例**：`cases/29-农业生鲜与供应链品牌.md`（钱大妈）；`cases/23-银发经济与健康养老.md`（足力健）。

### 10.2 单店餐饮全套

**一句话定义**：一家餐厅从开业到稳定的完整节奏，按开业期、磨合期、稳定期分别配置不同打法。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 一家店从开业到稳定；需要完整节奏而不是单点动作 |
| 不适用 | 连锁品牌（另有总部体系） |
| 预算量级 | 开业期 1–10 万；稳定期 0.3–2 万／月 |
| 见效周期 | 3–6 个月 |
| 谁来做 | 店主＋店长＋服务团队 |
| 难度 | ★★☆ |

**怎么做**：
1. **开业前 30 天**：定菜单结构（引流菜／利润菜／形象菜）、门头改造（§1.5）、周边探店预热（§2.4）。产出：开业方案。
2. **开业前 7 天**：上架团购套餐（§3.4）、建社群、印好包裹／桌卡引流物料。产出：物料与套餐。
3. **开业 1–14 天**：控节奏——不要一次爆量，先验证出餐与服务能力。产出：每日客流与出餐时长表。
4. **开业 15–45 天**：收集评价（大众点评／抖音），做「证言与评分」（§7.1、§7.3）。产出：评分提升计划。
5. **第 2–3 个月**：做复购体系（§4.6 会员、§4.10 复购提醒），把首批客人变成回头客。产出：会员方案。
6. **第 3–6 个月**：做社群与老带新（§4.3、§4.9），把客流从平台转到自有用户池。产出：私域规模。
7. **稳定期**：固定每月活动节奏（§6.2 造节），维持热度。产出：年度活动日历。

**关键技巧**：开业不要爆量，服务跟不上会毁掉评分；平台流量一定要转到私域；菜品结构比活动更重要（引流菜撑人气、利润菜撑赚钱）。
**常见错误**：开业活动爆量后服务崩溃，差评一堆；只做平台不做私域；没有引流菜，客单撑不住。
**怎么验收**：开业 90 天的复购率、平台评分、私域人数、单店月利润。
**案例**：`cases/01-餐饮与茶饮.md`（太二酸菜鱼、海底捞）。

### 10.3 新品牌 90 天

**一句话定义**：零基础的新品牌，用 90 天跑出「一个能复制的获客模型」，而不是追求规模。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 零基础、90 天要见结果；新品上市；预算有限 |
| 不适用 | 想 90 天做规模（不现实）；没有产品力支撑 |
| 预算量级 | 5–50 万 |
| 见效周期 | 90 天 |
| 谁来做 | 小团队（1 个负责人＋内容＋运营） |
| 难度 | ★★★ |

**怎么做**：
1. **第 1–10 天（定位）**：完成 §1.12 品牌三问、§1.11 单一特性占位、§1.3 命名与商标检索。产出：定位 1 页。
2. **第 11–20 天（面子）**：做符号（§1.1）、包装（§1.4）、详情页（§8.8）、定价结构（§8.1、§8.2）。产出：销售物料。
3. **第 21–45 天（验证渠道）**：只选 1 个渠道打透（内容或投放或私域），小预算测 3 组素材。产出：渠道验证结果。
4. **第 46–60 天（跑通模型）**：找到「可复制的获客模型」——一组能稳定带来正 ROI 的动作。产出：模型说明（1 页）。
5. **第 61–75 天（放大）**：把模型放大 2–3 倍预算，看是否还成立。产出：放大结果。
6. **第 76–90 天（承接）**：建私域与复购机制（§4），把买过的用户留下。产出：私域规模。
7. **第 90 天覆盘**：输出下一阶段 3 个月的打法清单。产出：覆盘报告。

**关键技巧**：90 天只做一个渠道，别什么都做；成功的标准是「模型可复制」而不是「某一条爆了」；前 20 天必须把物料做完，否则投放会漏钱。
**常见错误**：什么都做，什么都没做透；追求单条爆款而不是可复制模型；忽略承接，买过的人留不下。
**怎么验收**：是否有一页「可复制获客模型」；90 天末的 ROI、私域人数、复购率。
**案例**：`cases/02-食品饮料与酒.md`（元气森林）；`cases/40-预制菜与方便速食.md`（空刻意面）。

### 10.4 第二曲线品牌架构

**一句话定义**：主品牌老化时，用新的品牌架构承接新人群，避免新旧互相拖累。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 主品牌老化、想开新品牌；老客与新客需求割裂；主品牌溢价下滑 |
| 不适用 | 主品牌还有增长空间（先做 §9.5 品类扫描）；没有独立团队 |
| 预算量级 | 30–300 万 |
| 见效周期 | 12–24 个月 |
| 谁来做 | 需独立团队（不能由主品牌团队兼职） |
| 难度 | ★★★ |

**怎么做**：
1. 判断「用主品牌延伸还是做新品牌」：若新人群与老客「调性冲突」，就做新品牌。产出：架构决策。
2. 设计品牌架构：**独立品牌**（完全另起）、**背书式新品牌**（「X 出品」）、**副线**（共享品牌但不同系列）。产出：架构图。
3. 给新品牌独立团队与预算，不与主品牌共用 KPI。产出：组织设计。
4. 明确「不共用什么」：人群、内容调性、渠道、价格带。产出：隔离清单。
5. 明确「可共用什么」：供应链、财务、法务、后台。产出：共享清单。
6. 给新品牌 18 个月独立考核期，不要求短期盈利。产出：考核规则。
7. 每半年评估一次：是继续投、合并还是关闭。产出：评估记录。

**关键技巧**：新品牌必须「独立团队、独立 KPI」，否则一定被主品牌的惯性拖死；品牌架构的关键是「隔离」，不是「协同」；背书式新品牌在早期借力最有效。
**常见错误**：用主品牌名硬套新人群；新品牌共用主品牌 KPI，被逼著短期盈利；供应链共用但质量标准没对齐，互相拖累。
**怎么验收**：新品牌 18 个月的新客成本、复购率、是否形成独立人群认知；主品牌是否被影响。
**案例**：`cases/01-餐饮与茶饮.md`（蜜雪冰城）；`cases/14-零售商超与便利店.md`（名创优品）。

### 10.5 AI 产品的 PLG 与开发者营销

**一句话定义**：AI／工具类产品靠「产品自己会传播」来增长，营销的工作是降低首次使用门槛与建立开发者社群。

| 项目 | 内容 |
|---|---|
| 什么情况用 | AI／工具类产品，需要自增长；目标用户是开发者／专业用户 |
| 不适用 | 产品体验差（PLG 会放大差评）；纯 to C 情绪消费品 |
| 预算量级 | 5–100 万 |
| 见效周期 | 3–12 个月 |
| 谁来做 | 增长团队＋开发者关系（DevRel） |
| 难度 | ★★★ |

**怎么做**：
1. 定「Aha 时刻」：用户第一次感受到价值的具体时刻，并把到达它的步骤压到 3 步以内。产出：注册到 aha 的路径图。
2. 设计免费层：**额度刚好够体验价值，但不足以解决完整问题**。产出：免费／付费功能分层。
3. 做「可分享的产出」：让用户生成的成果自带品牌标识（水印、链接、模板）。产出：分享机制。
4. 建开发者内容：API 文件、教学、范例专案、开源仓库。产出：开发者内容库。
5. 做社群：Discord／GitHub／技术论坛，官方必须在里面回答问题。产出：社群运营 SOP。
6. 做「模板与插件生态」：让用户贡献模板，形成网络效应。产出：模板市场。
7. 监控三个数：**激活率**（注册到 aha）、**免费到付费转化率**、**周留存**。产出：增长看板。

**关键技巧**：PLG 的核心是「首次体验」，第一天不用完就永远不会回来；免费层太强没人付费，太弱没人体验到价值；开发者只信「自己试过的」，所以文件与范例比广告重要。
**常见错误**：免费版太强，没人付费；注册流程太长，用户在 aha 前流失；没有社群，用户遇到问题就跑了。
**怎么验收**：激活率、免费用户到付费的转化率、周留存、由分享／模板带来的新用户占比。
**案例**：`cases/42-摄影与影像服务.md`（妙鸭相机）；`cases/21-企业服务与SaaS.md`（Notion）。

### 10.6 B2B 信任营销

**一句话定义**：面对长决策链的大客户，用「内容＋案例＋关系」慢慢建立信任，而不是做消费品那套广告。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 大客户、长决策链（3 个月以上）；客单高、决策人多 |
| 不适用 | 做消费品那套（完全打不动）；没有耐心做 12 个月 |
| 预算量级 | 5–100 万 |
| 见效周期 | 6–18 个月 |
| 谁来做 | 市场＋销售＋高层 |
| 难度 | ★★★ |

**怎么做**：
1. 画「决策链地图」：谁提出、谁评估、谁批准、谁使用、谁付款，各在意什么。产出：决策链地图。
2. 为每个角色准备「对应材料」：用户看效果、评估者看参数、财务看 ROI、老板看风险。产出：材料矩阵。
3. 做「标杆案例」：把 1 个客户的真实成果写成可公开的案例（含数据）。产出：案例 1 篇。
4. 做行业内容：白皮书、报告、行业洞察，用专业度建立权威（§7.1、§7.2）。产出：内容资产。
5. 建「关系网」：行业会议、协会、社群，让决策者认识你。产出：关系清单。
6. 做「试点（POC）」：用一个小专案证明效果，再谈大合约。产出：试点方案。
7. 追踪「线索培育」：从认识到成交的每个节点记录与跟进。产出：CRM 记录。

**关键技巧**：B2B 的信任来自「同行用过」；标杆案例的价值远大于广告；决策链上每个角色的关注点不同，不能用同一份资料。
**常见错误**：只对接一个联系人，没覆盖决策链；没有案例就谈大单；用消费品的「爆量」思维做 B2B。
**怎么验收**：合格线索数、从初次接触到试点的时间、试点到合约的转化率、单客户获取成本。
**案例**：`cases/21-企业服务与SaaS.md`（飞书）；`cases/45-物流与快递服务.md`（京东物流）。

### 10.7 区域公用品牌

**一句话定义**：为一个地方产业带或农产品做区域公用品牌，用统一标准与统一形象把地方货卖出溢价。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 农产品／地方产业带；多家小生产者需要统一出口；政府或协会有推动意愿 |
| 不适用 | 没有统一标准能力；生产者不愿执行标准 |
| 预算量级 | 50–500 万（常为政府专项） |
| 见效周期 | 12–36 个月 |
| 谁来做 | 品牌方＋协会＋政府；需第三方运营主体 |
| 难度 | ★★★ |

**怎么做**：
1. 定「地区品类」：选一个最有辨识度的产品，不贪多。产出：品类选择。
2. 制定「统一标准」：品种、种植、采收、分级、包装，全部写成可执行的规范。产出：标准手册。
3. 设计「区域品牌视觉」：区域符号、名称、包装体系（§1.1、§1.4）。产出：品牌手册。
4. 建立「授权与监管机制」：谁能用、怎么用、违规怎么罚。产出：授权管理办法。
5. 做「标杆产品」：先做 1–2 家示范户，跑通溢价再推广。产出：示范案例。
6. 渠道落地：电商平台旗舰店、批发市场、文旅场景、直播助农。产出：渠道方案。
7. 做「产地内容」：溯源、产地故事、农民故事（§2.5）。产出：内容体系。
8. 建立「长期运营主体」：不能依赖单次专案预算。产出：运营架构。

**关键技巧**：区域品牌的成败在「标准执行」，不在设计好看；必须有一个可持续的运营主体（否则政府换届就断档）；先做 1 个标杆产品跑出溢价，再扩品类。
**常见错误**：只做视觉不做标准，变成「换个包装」；没有运营主体，专案结束即停摆；多家生产者质量不一，砸掉牌子。
**怎么验收**：授权企业数量与合规率、标杆产品的溢价幅度（农户收购价提升）、区域品牌的市场认知度。
**案例**：`cases/19-城市与区域公共品牌.md`（好客山东）；`cases/15-教育文旅与本地生活.md`（淄博烧烤）。

---

> **本档使用收尾**：组方案时务必回报「① 卡点在哪（§9）② 选了哪几条打法（§1–§11）③ 总预算与周期 ④ 每条的主要风险 ⑤ 用什么指标验收」。任何一条打法落地前，先确认客户有「承接能力」（人／货／客服／库存），否则热度只会制造差评。

## §11 特殊场景专用打法（B端商业／投标响应／G端政府）

> 本节专供**非纯消费品**的四类交付：B 端商业策划、投标响应文件、G 端政府项目，以及它们共用的提案场景。前面 §1–§10 解决「怎么打」，本节解决「这类交付**必须有、且消费品方案里没有的章节**」——生意拆解、财务测算、商务条款、投标偏离表、政策依据、绩效考核、资金合规、公文范式。composer 会依 `--scene B端／投标／G端` 自动把这些章节注入骨架（详见 `references/09-完整策划标准与评分表.md`）。

### 11.1 B端·生意拆解与机会量化

**一句话定义**：把「营收」拆成「流量 × 转化率 × 客单价 × 复购次数」，先找到钱漏在哪一层，再决定打哪一层——而不是泛泛喊「提升品牌」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | B 端客户要立项、要预算、要背 KPI；对「为什么投钱」说不清 |
| 不适用 | 纯品牌曝光需求（还没到算帐阶段）；创始人拒绝看数字 |
| 预算量级 | 0（人工诊断为主） |
| 见效周期 | 1–2 周 |
| 谁来做 | 策略负责人＋财务／数据 |
| 难度 | ★★☆ |

**怎么做**：
1. 列出营收等式四因子，标出每个因子的现在值（来源：后台／财报／CRM）。产出：现状基线表。
2. 对标行业基准，算出每个因子的「差距」。产出：差距清单。
3. 按「差距 × 可达性」排序，选一层作为主攻（一次只打一层）。产出：主攻层决策。
4. 把主攻层再拆成可动作的子环节（如转化率 → 询单率／下单率／支付成功率）。产出：子环节表。
5. 写成「现状 → 目标 → 动作」三栏，给老板一眼看懂。产出：生意拆解一页纸。

**关键技巧**：一次只打一层，贪多必败；每个数字必须标「来源／口径／时点」，否则讨论会变吵架。
**常见错误**：只喊「提升品牌」不拆解；把行业均值当自己的目标；四因子全想一起改。
**怎么验收**：每因子有现值／目标值／负责人；决策者能复述「我们主攻哪一层、为什么」。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（三一重工）。

### 11.2 B端·决策链与标杆案例包装

**一句话定义**：B 端成交靠「销售能拿著去见客户的东西」——把技术论证与标杆案例，包装成决策链上每个角色都买帐的素材。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 大客户、长决策链（用户／影响者／决策者／审批者角色分离） |
| 不适用 | 单人决策的小生意（不需要决策链论证） |
| 预算量级 | 2–20 万（内容＋案例拍摄／白皮书） |
| 见效周期 | 1–3 个月 |
| 谁来做 | 方案负责人＋行业专家＋设计 |
| 难度 | ★★★ |

**怎么做**：
1. 画决策链地图：列出每个角色关心的点（用户要好用、财务要 ROI、老板要战略）。产出：角色关切表。
2. 为每个角色准备「一张能说服他的牌」（数据卡／标杆卡／风险逆转卡）。产出：角色素材包。
3. 做 1 份标杆案例（同类客户怎么用、结果如何），写成可转发的一页纸。产出：标杆案例卡。
4. 把技术参数翻译成「客户业务语言」（不要讲马力，讲「省下的人工」）。产出：业务语言版说明。
5. 设计「决策加速物件」：对比表、ROI 计算器、试用报告。产出：成交工具包。

**关键技巧**：决策链上「不用的人」往往「不批」，素材要覆盖到审批者；标杆案例必须是同业、可查。
**常见错误**：只做用户爱看的炫技片；案例是别国别行业的，客户说「不适用」；参数没翻译成业务语言。
**怎么验收**：决策链每个角色至少有一张对应素材；标杆案例被客户转发／引用。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（宁德时代）。

### 11.3 B端·单位经济模型与盈亏平衡

**一句话定义**：用「CAC／LTV／回本周期／盈亏平衡点」把方案算成一本账——B 端客户答不出「花多少、赚多少」就拿不到预算。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 要跟老板要预算、要证明方案划算；有获客与复购数据 |
| 不适用 | 纯曝光活动（无法归因到营收） |
| 预算量级 | 0（模型搭建为主） |
| 见效周期 | 1–2 周 |
| 谁来做 | 财务＋策略 |
| 难度 | ★★☆ |

**怎么做**：
1. 算单客获取成本 CAC（推广费 ÷ 新客数）、单客生命周期价值 LTV（客单 × 复购次数 × 毛利）。产出：单位经济表。
2. 算回本周期（CAC ÷ 月均毛利贡献）。产出：回本测算。
3. 算盈亏平衡点（固定成本 ÷ 单客毛利），推出「要做到多少单／多少客流才打平」。产出：盈亏平衡线。
4. 做三档敏感性分析（乐观／基准／悲观），每档给营收、成本、结论。产出：敏感性表。
5. 把结论翻译成「投入 X、预期回收 Y、风险在 Z」。产出：一页财务摘要。

**关键技巧**：LTV 的复购次数要保守（实测常算乐观）；敏感性分析是「让老板放心」的关键。
**常见错误**：把一次性收入当成年化；复购次数拍脑袋；没有悲观档（一遇波动就亏）。
**怎么验收**：每个数字有来源；三档情景都给结论；老板能据此拍板预算。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（三一重工）。

### 11.4 B端·商务条款与报价框架

**一句话定义**：把「报价、付款节奏、验收标准、知识产权、违约与退出」写成清楚条款——B 端纠纷 80% 出在条款没写清。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 要签合同、要报价、要定验收 |
| 不适用 | 纯媒介投放（走平台标准合同） |
| 预算量级 | 0（法务＋业务） |
| 见效周期 | 当周 |
| 谁来做 | 业务负责人＋法务 |
| 难度 | ★★☆ |

**怎么做**：
1. 报价拆「一次性／周期性」，让客户看清时点与节奏。产出：报价表。
2. 定付款节奏（签约付 X%、中期付 Y%、验收付 Z%），绑定里程碑。产出：付款节奏表。
3. 写交付物清单与验收标准（可量化的，不是「满意」）。产出：验收标准。
4. 明确知识产权归属（交付物归客户、方法论归我方）。产出：IP 条款。
5. 写违约责任与退出机制（双方都有）。产出：风险条款。

**关键技巧**：验收标准必须可量化；付款绑里程碑，避免「做完不给钱」；IP 条款提前讲，别等签约才吵。
**常见错误**：验收写「客户满意」（主观＝赖帐）；一次性全款前付（现金流风险）；IP 不写（成果被白拿）。
**怎么验收**：条款覆盖报价／付款／验收／IP／违约五项；法务已审。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（徐工）。

### 11.5 投标·商务响应偏离表设计

**一句话定义**：逐条对照招标要求写「完全响应／正偏离／负偏离」——投标第一原则是「格式不符＝废标，一票否决」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 任何招投标项目；先过「符合性审查表」再谈创意 |
| 不适用 | 无招标文件的直客采购 |
| 预算量级 | 0（标书制作人工） |
| 见效周期 | 投标周期内 |
| 谁来做 | 投标负责人＋技术／商务 |
| 难度 | ★★☆ |

**怎么做**：
1. 先手抄「符合性审查表」每一条，标出「废标红线」（负偏离超 N 项直接出局）。产出：红线清单。
2. 逐条写响应：能完全响应的标「完全响应＋证明」；优于要求的标「正偏离」并写好处。产出：偏离表。
3. 负偏离能免则免；实在不能免的，写「替代方案＋理由」，不隐瞒。产出：负偏离说明。
4. 每条响应附「证明物」（证书编号／合同号／页码），可查可验。产出：佐证索引。
5. 最后做一次「格式自检」：签章、装订、份数、密封全对。产出：投标自查单。

**关键技巧**：正偏离是你比别人强的证据，要主动标；负偏离超标即废标，绝不抱侥幸。
**常见错误**：只看技术分不看作废标项；证明物编号写错查无此证；格式装订漏项被拒。
**怎么验收**：符合性审查表每条都有响应；零无法解释的负偏离；格式自查全过。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（三一重工）。

### 11.6 投标·需求理解与差异化定位

**一句话定义**：很多标输在「需求理解」这一步——用招标方的语言复述需求、点出别人忽略的点，证明你听懂了。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 技术标评分里有「需求理解」分值；需要与竞标者拉开 |
| 不适用 | 纯价格标（无需求理解分） |
| 预算量级 | 0 |
| 见效周期 | 投标周期内 |
| 谁来做 | 方案负责人＋行业顾问 |
| 难度 | ★★☆ |

**怎么做**：
1. 精读招标文件，抽出「核心问题」与「约束」（预算／周期／合规／既有系统）。产出：需求抽取。
2. 用自己的话复述需求（不照抄），证明真懂。产出：需求理解段。
3. 标出「关键约束」与「隐性痛点」（招标方没明说但很在意的）。产出：痛点清单。
4. 给「差异化理解」：别人可能忽略的角度，你点出来并给解法。产出：差异化论点。
5. 把理解映射到后续方案章节，前后一致。产出：映射表。

**关键技巧**：需求理解段不要抄招标原文，要「翻译＋补充」；隐性痛点是最容易拿分的差异化点。
**常见错误**：整段照抄招标书（评委看出没思考）；只讲自己强项不呼应需求；前后方案与理解段矛盾。
**怎么验收**：需求理解段含「复述＋痛点＋差异化」三要素；与后续章节一致。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（宁德时代）。

### 11.7 投标·业绩与资质包装

**一句话定义**：用「同类项目业绩＋资质证书＋验收证明」建立「做过、做成过」的信任——评委先看你有没有资格。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 评分项含「类似业绩／资质」；资质是门槛 |
| 不适用 | 资质门槛已达、业绩非重点 |
| 预算量级 | 0（资料整理） |
| 见效周期 | 投标周期内 |
| 谁来做 | 商务＋项目管理 |
| 难度 | ★☆☆ |

**怎么做**：
1. 列「同类项目业绩」：项目名、业主、金额、时间、验收情况，只放最相关的 3–5 个。产出：业绩表。
2. 附「验收证明／合同关键页」扫描件，隐去敏感资讯。产出：佐证包。
3. 做「资质证书清单」：营业执照、资质证书、财报、无重大违法声明，编号可查。产出：资质包。
4. 写「团队资历」：角色、资格、类似项目经验。产出：团队页。
5. 用「对标评分细则」排布顺序，评委要什么就先给什么。产出：业绩章节定稿。

**关键技巧**：业绩「相关性」重于「数量」；证书编号必须真实可查，造假一票否决。
**常见错误**：堆几十个不相干业绩；合同扫描件关键信息缺失；资质过期还写进去。
**怎么验收**：每项业绩有验收证明；资质编号可查且在有效期；与评分细则对齐。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（徐工）。

### 11.8 投标·实施保障与进度方案

**一句话定义**：把「谁做、什么时候交什么、怎么保质、怎么兜底」写成可执行方案——评委买的是「落得了地」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 技术标含「实施方案／保障机制」分值 |
| 不适用 | 纯货品采购标 |
| 预算量级 | 0 |
| 见效周期 | 投标周期内 |
| 谁来做 | 项目管理＋技术负责人 |
| 难度 | ★★☆ |

**怎么做**：
1. 组项目组：角色、资历、投入比例，画 RACI 矩阵。产出：组织与职责。
2. 排进度：里程碑＋交付物＋日期，用甘特图（文字版也可）。产出：进度计划。
3. 写质量保障：评审节点、验收标准、问题升级路径。产出：质保机制。
4. 列交付物清单：每项交付物名称、格式、时点。产出：交付物表。
5. 加「风险与兜底」：可能延误／不合格的预案。产出：保障附录。

**关键技巧**：里程碑要绑「可验收的交付物」，不是「完成调研」这种虚词；RACI 让责任无死角。
**常见错误**：进度只写阶段名不写交付物；质保机制空泛；风险章节直接删掉。
**怎么验收**：每里程碑有交付物与日期；有质保与兜底；RACI 覆盖全员。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（中联重科）。

### 11.9 G端·政策依据与上位规划对接

**一句话定义**：G 端立项第一关是「师出有名」——把项目对应到国家／省／市三级文件的名称、文号、条款，证明「上级要求这么干」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 政府项目申报、专项资金申请、绩效考核答辩 |
| 不适用 | 纯商业专案（无政策对应需求） |
| 预算量级 | 0（政策研究人工） |
| 见效周期 | 申报周期内 |
| 谁来做 | 政策研究＋项目牵头人 |
| 难度 | ★★★ |

**怎么做**：
1. 找上位规划：国家／省／市三级，逐级列出文件名称与文号。产出：政策层级表。
2. 抽具体条款：把与本项目相关的条款原文摘出。产出：条款摘录。
3. 写「对应关系」：本项目的哪块工作对应哪条款。产出：对应矩阵。
4. 写「必要性」：不做会怎样（用数据说话）。产出：必要性说明。
5. 汇整成「政策依据」章节，附文件复印件于附件。产出：政策依据章。

**关键技巧**：文号必须真实可查，写错文号直接掉信任；条款要「原文＋对应」，不能自己发挥。
**常见错误**：只写「符合国家政策」无文号；文号抄错；条款与项目对应不上。
**怎么验收**：三级政策都有名称＋文号＋条款；每条款对应到具体工作。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（柳州螺蛳粉）。

### 11.10 G端·绩效目标与考核指标设计

**一句话定义**：G 端立项靠「可考核的绩效目标」——指标必须分级、有目标值、有考核方式，否则立不了项。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 项目申报书、绩效目标表、中期／终期考核 |
| 不适用 | 无考核要求的纯补助 |
| 预算量级 | 0 |
| 见效周期 | 申报周期内 |
| 谁来做 | 项目办＋统计／财务 |
| 难度 | ★★☆ |

**怎么做**：
1. 定一级指标（如「带动集体经济收入」）。产出：一级指标。
2. 拆二级（年度新增就业、游客接待量）、三级（每万元投入带动增收额）。产出：指标树。
3. 给每个三级指标「目标值＋考核方式＋责任单位」。产出：指标表。
4. 目标值要有基线与依据（去年多少、今年目标多少）。产出：基线对照。
5. 设「监测频率」（月报／季评／年考）。产出：监测机制。

**关键技巧**：指标要「跳一跳够得著」，定太高完不成、定太低没意义；责任单位必须写具体部门。
**常见错误**：指标写「提升影响力」不可考；目标值无基线；责任单位写「相关部门」。
**怎么验收**：指标分三级、有值、有考核方式、有责任单位；目标值有基线。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（淄博烧烤）。

### 11.11 G端·资金测算与合规红线

**一句话定义**：把「总投资、资金来源、分年用款、管理办法」算清，并守住合规与舆情红线——G 端最怕「钱说不清、话说太满」。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 专项资金申请、预算评审、审计迎检 |
| 不适用 | 无财政资金的纯市场项目 |
| 预算量级 | 0（财务测算） |
| 见效周期 | 申报周期内 |
| 谁来做 | 财务＋项目办 |
| 难度 | ★★★ |

**怎么做**：
1. 算总投资，拆分「财政／专项债／社会资本」来源占比。产出：资金来源表。
2. 排分年度用款计划，与实施进度绑定。产出：用款计划。
3. 写资金管理办法：专账管理、专款专用、审计与社会监督。产出：管理办法。
4. 列合规红线：绝对化用语（最／第一／国家级）一律不用；承诺必须做得到。产出：红线清单。
5. 做舆情风险清单与应对（如数据翻车、群众不满）。产出：舆情预案。

**关键技巧**：资金必须「来源明、去向清、可审计」；承诺留余地，别为了立项夸海口。
**常见错误**：资金来源写「争取中」当已落实；用绝对化用语；承诺做不到的 KPI。
**怎么验收**：资金来源／用款／管理三项清晰；红线与舆情预案齐全；无绝对化用语。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（哈尔滨）。

### 11.12 G端·公文与汇报材料范式

**一句话定义**：G 端材料「第一看合规、第二看绩效、第三才看创意」——用公文范式把内容讲规范、讲层次，比写花活更重要。

| 项目 | 内容 |
|---|---|
| 什么情况用 | 汇报 PPT、申报书、答辩稿、公文函件 |
| 不适用 | 对外公众传播物料（那走 §1–§8） |
| 预算量级 | 0 |
| 见效周期 | 当次汇报 |
| 谁来做 | 材料撰写＋分管领导把关 |
| 难度 | ★★☆ |

**怎么做**：
1. 套公文结构：背景／依据／目标／任务／实施／预算／绩效／保障，逐页对应。产出：汇报骨架。
2. 每页第一句是结论，后面是支撑（金字塔原理）。产出：页面草稿。
3. 数据标「来源／口径／时点」，可核可查。产出：数据脚注。
4. 备「评审答疑口径」：预判 3–5 个问题＋标准答法。产出：答疑表。
5. 过一遍格式：标题层级、字号、行距、字数页数限制。产出：定稿。

**关键技巧**：领导看的不是文采是「规范、层次、可考」；每页结论先行，别让人猜。
**常见错误**：文体混用（公文写成广告语）；数据无来源；答辩时答非所问。
**怎么验收**：结构完整、每页有结论、数据有来源、答疑口径备齐、格式合规。
**案例**：`cases/10-B2B工业品与农产品区域品牌.md`（榕江村超）。
